# 固件低功耗策略

## 事件驱动
- 超级循环 + 中断唤醒，而非忙等待
- 主循环进入低功耗模式，等待事件唤醒

### 快速处理 + 快速睡眠
- 任务完成后立即进入睡眠，不要空转
- 计算"占空比"：工作时间 / 总周期，越低越好

###  DMA 代替 CPU
- 数据传输用 DMA，CPU 睡眠
- 如：ADC 多通道扫描 + DMA，CPU 只在转换完成后唤醒处理

### 通信协议优化
- BLE：增大连接间隔（Connection Interval），从 7.5ms 调到 100ms+
- LoRa：增大扩频因子（SF）提高距离，但降低速率和增加空中时间；优化数据包大小
- MQTT：QoS 0 最小开销，批量发布，使用遗嘱消息（LWT）
