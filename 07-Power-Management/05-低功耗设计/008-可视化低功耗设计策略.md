# 可视化：低功耗设计策略

```mermaid
graph TB
    A[系统功耗] --> B[动态功耗]

    B --> B3[外设使用]
```

### MCU 低功耗模式

```mermaid
stateDiagram-v2
    [*] --> 运行
    运行 --> 睡眠: 轻载等待
    睡眠 --> 停止: 保留 RAM
    停止 --> 待机: 最低功耗
    待机 --> 运行: 唤醒事件
    睡眠 --> 运行: 中断
    停止 --> 运行: 中断
```
