### 滤波器设计流程

```mermaid
graph TB
    A[明确需求] --> B["选择类型<br/>LPF/HPF/BPF/BSF"]
    B --> C["确定指标<br/>fc, 衰减, 纹波, 群延迟"]
    C --> D["选择近似<br/>Butterworth/Chebyshev/Bessel"]
    D --> E[确定阶数]
    E --> F["选择拓扑<br/>Sallen-Key/MFB"]
    F --> G[计算元件值]
    G --> H[LTspice 仿真验证]
    H --> I{指标满足？}
    I -->|否| C
    I -->|是| J[制作/测试]
    
    style J fill:#e1f5e1
    style I fill:#fff4e1
```

### 无源 vs 有源滤波器对比

```mermaid
graph LR
    A[滤波器实现] --> B["无源 RC/LC"]
    A --> C["有源 运放+RC"]
    
    B --> B1["优点：简单、高频"]
    B --> B2["缺点：负载敏感、大电感笨重"]
    
    C --> C1["优点：可调增益、高输入低输出阻抗"]
    C --> C2["缺点：受运放带宽限制、需供电"]
```
