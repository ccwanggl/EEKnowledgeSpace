# 无源滤波器（RC/RL/LC）

## 一阶 RC 低通
- 截止频率：$f_c = 1/(2\pi RC)$
- 衰减斜率：-20 dB/decade（十倍频程幅值降至 1/10）
- 相位偏移：-45° 在 $f_c$，趋近 -90° 在高频
- 用途：简单去耦、信号调理、PWM 滤波为模拟电压

### 一阶 RC 高通
- 截止频率：$f_c = 1/(2\pi RC)$
- 用途：隔直流、音频耦合、消除传感器偏移

### LC 谐振电路
- 谐振频率：$f_0 = 1/(2\pi\sqrt{LC})$
- 高品质因数 Q = $f_0 / BW$
- 用途：RF 选频、开关电源谐振、无线能量传输
