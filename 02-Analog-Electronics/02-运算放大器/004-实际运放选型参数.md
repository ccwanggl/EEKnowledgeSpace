# 实际运放选型参数

| 参数 | 说明 | 典型值 | 影响 |
|------|------|--------|------|
| GBW | 增益带宽积 | 1MHz~100MHz | 决定最高工作频率 |
| Slew Rate | 压摆率 | 0.5~1000 V/μs | 大信号响应速度 |
| Input Offset | 输入失调电压 | 0.1mV~5mV | 直流精度 |
| CMRR | 共模抑制比 | 60~120 dB | 共模噪声抑制 |
| PSRR | 电源抑制比 | 60~100 dB | 电源噪声抑制 |
| Iq | 静态电流 | 10μA~10mA | 功耗 |
| Rail-to-Rail | 输入/输出 | — | 接近电源轨的摆幅 |

## 常用型号选择
- **通用低成本**：LM358、LM324、MCP6001
- **精密低噪声**：OPA2134、TL072、NE5532
- **高速**：ADA4891、OPA690
- **低功耗微功耗**：MCP6001、TLV9001
- **仪表放大器**：INA128、AD620、INA333
