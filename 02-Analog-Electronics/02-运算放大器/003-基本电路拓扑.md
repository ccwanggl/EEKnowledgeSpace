# 基本电路拓扑

## 反相放大器
```
Vin ---R1---+---> Vout
             |
            Rf
             |
            GND
```
- $V_{out} = -(R_f/R_1) \cdot V_{in}$
- 输入阻抗 ≈ $R_1$
- 增益为负（反相）

### 同相放大器
```
Vin ---> V+
V- ---R1---+---> Vout
           |
          Rf
           |
          GND
```
- $V_{out} = (1 + R_f/R_1) \cdot V_{in}$
- 输入阻抗极高（理想无穷）
- 增益 ≥ 1

### 电压跟随器（缓冲器）

```
         +-------+
Vin ---->|  V+   |
         |  V- <-|------+
         |       |      |
         |  Vout |------+
         +-------+
```
- $V_{out} = V_{in}$
- 极高输入阻抗，极低输出阻抗
- 用于隔离信号源和负载，防止负载拉低信号源

### 差分放大器

```
V1 --R1--+--> V-          V2 --R1--+--> V+
         |                           |
        Rf                          Rf
         |                           |
        GND                        GND
         |                           |
         +--> Vout = (Rf/R1)(V2-V1)-+
```
- $V_{out} = (R_f/R_1)(V_2 - V_1)$（匹配电阻时）
- 提取差模信号，抑制共模干扰
- 仪表放大器是更精确的版本（三运放结构）

### 比较器（含施密特迟滞）

```
         +-------+
Vref --->|  V+   |
Vin ---->|  V-   |
         |  Vout |--+--> 输出
         +-------+  |
                    Rf
                    |
                   V+ <--------------+
```
- 无负反馈或正反馈（比较器模式）
- $V_{out} = V_{high}$（当 $V_+ > V_-$），否则 $V_{low}$
- 注意：运放作比较器时响应慢，专用比较器（LM393）更好
- 施密特触发器：正反馈产生迟滞，抗噪声

### 积分器

```
Vin --R--+--> V- (V- = V+ = 0)
         |
         C
         |
        +-----> Vout = -1/(RC) ∫Vin dt
         |
        GND
```
- 输出是输入的积分，用于波形变换、三角波生成
- 实际需并联大电阻（如 1MΩ）防止直流漂移

### 微分器

```
Vin --C--+--> V- (V- = V+ = 0)
         |
         R
         |
        +-----> Vout = -RC * dVin/dt
         |
        GND
```
- 输出是输入的变化率，用于脉冲检测、边沿提取
- 实际需串联小电阻限制高频增益，防止噪声放大
