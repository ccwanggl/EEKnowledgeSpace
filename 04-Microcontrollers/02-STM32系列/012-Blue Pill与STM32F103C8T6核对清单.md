# Blue Pill 与 STM32F103C8T6 核对清单

Blue Pill 适合学习 Cortex-M3、F1 时钟、GPIO、定时器和 SWD，但它不是 ST 官方 Nucleo 板。不同生产批次可能采用不同 MCU、晶振、USB 上拉、电源器件和 LED 连接，板上丝印也不能替代芯片顶标、原理图和测量。

## 使用前确认板卡身份

- 读取芯片顶标、器件 ID、Flash 标称容量和芯片修订；
- 找到与当前板版图一致的原理图，不使用泛称 Blue Pill 的任意图片；
- 测量 3.3 V 稳压输出和静态电流；
- 确认 HSE/LSE 晶体是否实际装配及频率；
- 确认用户 LED 的引脚和有源电平，常见 PC13 连接不代表所有板相同；
- 检查 USB D+ 上拉和接口焊接；
- 使用 SWD 读取、擦除和下载最小程序。

## F103 与现代 STM32 的差异

| 内容 | STM32F1 常见模型 | 迁移时注意 |
|---|---|---|
| GPIO | CRL/CRH 组合配置输入输出模式 | 现代系列常拆成 MODER、OTYPER、OSPEEDR、PUPDR、AFR |
| 复用 | AFIO 重映射 | 现代系列通常为逐引脚 AF 编号 |
| DMA | 固定通道映射 | 新系列可能有 Stream、DMAMUX、GPDMA 或链表 |
| ADC | 经典 F1 规则组/注入组 | 新系列校准、过采样、差分和触发能力不同 |
| USB | 取决于具体 F103 型号与板级上拉 | 时钟精度、连接器和上拉必须核对 |
| 调试 | JTAG/SWD 引脚复用影响可用 GPIO | 保留 SWD 恢复路径后再关闭 JTAG |

## 不再维护静态 48 引脚复用表的原因

一个引脚能否使用，取决于完整料号、封装、复用重映射、调试配置和板级连接。复制表格容易漏掉电气条件、脚注和芯片修订。本笔记改用核对路径：

1. 在 STM32F103x8/xB 数据手册中找到 LQFP48 引脚表；
2. 查复用功能和重映射表；
3. 在参考手册 AFIO、GPIO 和目标外设章节确认配置；
4. 在板卡原理图确认该引脚实际接到哪里；
5. 用万用表、示波器或最小固件验证。

## 最小练习顺序

1. SWD 连接、读 ID、擦除和下载；
2. 内部时钟下翻转板载或外接 LED；
3. 测量 HSE 和系统时钟输出；
4. UART 回环与带超时发送；
5. 定时器更新、输入捕获和 PWM；
6. ADC 单通道，随后验证源阻抗和扫描；
7. EXTI 消抖和 DMA 缓冲；
8. 将同一设备能力接口迁移到较新的 Nucleo 板。

Blue Pill 练习不应把标准外设库、F1 寄存器布局和板级引脚当作整个 STM32 生态的统一写法。
