# 代码示例

## STM32 HAL DMA 循环接收

```c
#define RX_BUF_SIZE 64
uint8_t rx_buf[RX_BUF_SIZE];

// 启动循环 DMA 接收
HAL_UART_Receive_DMA(&huart1, rx_buf, RX_BUF_SIZE);

// 半传输/传输完成回调
void HAL_UART_RxHalfCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart == &huart1) {
        // 处理前半缓冲区
    }
}

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart == &huart1) {
        // 处理后半缓冲区（循环模式下等同于新开始）
    }
}
```

### Cortex-M7 Cache 维护

```c
// DMA 发送前：确保 CPU 写入的数据已刷新到内存
SCB_CleanDCache_by_Addr((uint32_t *)tx_buf, TX_BUF_SIZE);

// DMA 接收后：使 Cache 失效，CPU 读取到最新数据
SCB_InvalidateDCache_by_Addr((uint32_t *)rx_buf, RX_BUF_SIZE);
```
