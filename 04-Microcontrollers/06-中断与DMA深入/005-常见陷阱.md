# 常见陷阱

| 问题 | 现象 | 解决 |
|------|------|------|
| 中断优先级设置错误 | 关键中断被屏蔽 | 合理分组抢占/子优先级 |
| ISR 过长 | 系统响应迟钝，看门狗复位 | 缩短 ISR，使用队列/标志 |
| DMA 缓冲区未对齐 | 传输错误、硬 fault | 使用 `__attribute__((aligned(32)))` |
| Cache 不一致 | DMA 数据旧/错误 | Clean/Invalidate DCache 或配置 MPU |
| 循环 DMA 下标越界 | 访问到正在写入的区域 | 使用半传输/传输完成双指针 |
