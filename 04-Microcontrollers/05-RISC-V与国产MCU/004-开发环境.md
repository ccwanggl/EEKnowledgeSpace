# 开发环境

## RISC-V 工具链
- **GCC RISC-V**：开源编译器，支持所有标准扩展
- **PlatformIO**：支持 GD32V、ESP32-C3、CH32V307
- **MounRiver Studio**：沁恒官方 IDE，基于 Eclipse，支持 CH32V 全系列
- **WCH-Link**：沁恒调试器，便宜（~$3），支持 SWD 和 RISC-V 调试

### 学习平台
- **FPGA RISC-V 软核**：
  - **learn-fpga**（Bruno Levy）：从 Blinky 到 RISC-V，开源课程
  - **VexRiscv**：高性能可配置 RISC-V 软核（SpinalHDL）
  - **PicoRV32**：极简 RISC-V 软核（Claire Wolf）
  - **FemtoRV**：教育级 RISC-V 软核
- **RVfpga**（Imagination University）：基于 VeeR 核心的教学课程
- **昉·星光 2（VisionFive 2）**：高性能 RISC-V 单板计算机，跑 Linux
