# RISC-V MCU 产品

## 国际
- **SiFive**：RISC-V 先驱，FE310、E31/E51 核心
- **Microchip PolarFire SoC**：FPGA + RISC-V 核心（MPFS250T）
- **Espressif ESP32-C3/C6**：集成 WiFi/BLE 的 RISC-V MCU
- **Andes**：台湾晶心科技，RISC-V IP 供应商

### 国产 RISC-V MCU
- **沁恒微 CH32V307**：RISC-V3A 核心，144MHz，USB+ETH+CAN
- **沁恒 CH32V003**：超低成本，青稞 V2A，48MHz
- **沁恒 CH32X035**：RISC-V，USB PD+触摸
- **兆易创新 GD32VF103**：Bumblebee 核心，108MHz，兼容 STM32F1 外设
- **兆易 GD32VW553**：RISC-V + WiFi 6 + BLE 5.3
- **先楫 HPM5300**：双核 RISC-V，600MHz，高性能运动控制
- **乐鑫 ESP32-C3/C6/P4**：WiFi/无线 + RISC-V
- **平头哥/阿里**：玄铁 C906/C910，高性能，用于芯片和 FPGA
- **赛昉科技**：昉·星光（VisionFive）系列单板计算机
- **MUSE Pi Pro**：集成 Imagination GPU 的 RISC-V 开发板
