# MCU 核心组成

## CPU 核心
- **ALU**：算术逻辑单元，执行运算
- **寄存器组**：快速存储运算数据
- **控制单元**：取指、译码、执行、写回
- **流水线**：现代 MCU 多为 3~5 级流水线

### 存储器架构
- **改良哈佛架构**：程序存储和数据存储有独立总线，但统一地址映射（如 ARM Cortex-M）
- **Von Neumann 架构**：统一存储空间和总线（如 8051、部分 AVR）
- **Flash**：程序存储，非易失，可擦写 10K~100K 次
- **SRAM**：数据存储，易失，速度快
- **EEPROM**：小容量非易失参数存储（逐渐被 Flash 替代）

### 外设系统
- **GPIO**：通用输入输出，最基本的外设
- **定时器/计数器**：延时、PWM、输入捕获、编码器接口
- **ADC/DAC**：模拟数字转换
- **通信接口**：UART、SPI、I2C、CAN、USB、Ethernet
- **DMA**：直接存储器访问，减轻 CPU 负担
- **看门狗**：系统复位保护
- **RTC**：实时时钟，低功耗计时

### STM32F103 片上外设全景

以下以 STM32F103（Cortex-M3）为例，展示典型 32 位 MCU 的片上资源：

| 外设类别 | 具体模块 | 功能说明 |
|----------|----------|----------|
| **内核** | NVIC | 嵌套向量中断控制器，管理中断优先级 |
| | SysTick | 系统滴答定时器，提供 1ms 时基 |
| **时钟** | RCC | 复位和时钟控制，管理所有时钟源 |
| **GPIO** | GPIOA~GPIOG | 通用输入输出（F103 有 GPIOA~GPIOE） |
| | AFIO | 复用功能 I/O，引脚重映射 |
| **中断** | EXTI | 外部中断/事件控制器，支持 16 条外部线 |
| **定时器** | TIM1~TIM8 | 高级（TIM1）、通用（TIM2~5）、基本（TIM6/7） |
| **ADC** | ADC1/ADC2 | 12 位模数转换器，支持双 ADC 模式 |
| **DAC** | DAC1/2 | 12 位数模转换器（F103 仅部分型号有） |
| **通信** | USART1~3 | 同步/异步串口 |
| | SPI1/2 | SPI 通信 |
| | I2C1/2 | I2C 通信 |
| | CAN | CAN 总线通信 |
| | USB | USB 设备接口 |
| **DMA** | DMA1/2 | DMA1（7 通道）、DMA2（5 通道） |
| **其他** | RTC | 实时时钟，带备份寄存器 |
| | BKP | 备份寄存器（20 个 16 位寄存器） |
| | PWR | 电源控制，支持睡眠/停止/待机模式 |
| | IWDG/WWDG | 独立看门狗 / 窗口看门狗 |
| | CRC | CRC 计算单元 |
| | SDIO | SD 卡接口（部分型号） |
| | FSMC | 可变静态存储控制器（100 脚以上型号） |
