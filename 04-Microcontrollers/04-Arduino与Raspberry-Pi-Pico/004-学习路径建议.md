# 学习路径建议

**纯初学者**：
1. Arduino Uno → 点亮 LED、读取按钮、串口通信（2-4周）
2. 连接传感器（温度、光、距离）（2-3周）
3. 简单项目（智能灯、温控器）（2-3周）
4. 过渡到 Pico 或 STM32，学习底层（持续）

**有编程基础**：
1. 直接入手 Pico + MicroPython → 快速验证想法（2-3周）
2. 切换到 C SDK → 学习中断、DMA、PIO（3-4周）
3. 复杂项目（数据记录仪、协议桥接）（持续）
