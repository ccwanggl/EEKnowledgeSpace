# 对比：Arduino vs Pico vs ESP32

| 特性 | Arduino Uno | Pico / RP2350 | ESP32 |
|------|-------------|---------------|-------|
| 价格 | ~$25 | ~$4/$5 | ~$5 |
| 性能 | 16MHz 8-bit | 133~150MHz 32-bit | 240MHz 32-bit |
| 无线 | 无（需外挂） | Pico W 有 WiFi/BLE | 内置 WiFi+BLE |
| 调试 | 无 | 内置 SWD | 需外接 JTAG |
| 功耗 | 低 | 极低 | 中高 |
| 易用性 | 极高 | 高 | 中 |
| 特色 | 生态庞大 | PIO + 可编程 | 无线集成 |
| 适用 | 教学、原型 | 教学、工业控制 | IoT、无线 |
