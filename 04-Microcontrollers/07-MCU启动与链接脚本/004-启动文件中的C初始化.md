# 启动文件中的 C 初始化

## Reset_Handler 典型代码
```c
void Reset_Handler(void)
{
    // 复制 .data 从 Flash 到 RAM
    uint32_t *src = &__data_load;
    uint32_t *dst = &__data_start;
    while (dst < &__data_end) {
        *dst++ = *src++;
    }

    // 清零 .bss
    dst = &__bss_start;
    while (dst < &__bss_end) {
        *dst++ = 0;
    }

    // 调用 SystemInit（时钟、FPU 等）
    SystemInit();

    // 调用 main
    main();

    // main 不应返回，若返回则死循环
    while (1);
}
```
