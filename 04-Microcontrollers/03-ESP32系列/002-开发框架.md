# 开发框架

## Arduino
- 最友好的入门方式
- `WiFi.h`、`BluetoothSerial.h`、丰富的第三方库
- 缺点：部分高级功能受限

### ESP-IDF（Espressif IoT Development Framework）
- 官方框架，基于 FreeRTOS，完整功能
- 支持所有硬件特性，如 ULP、Deep Sleep、Secure Boot、OTA
- 学习曲线较陡，但功能最全

### MicroPython / CircuitPython / Lua
- 解释型语言，快速原型和教学
- 适合传感器读取、简单控制、Web 服务器
- 性能低于 C/C++

### PlatformIO
- VS Code 插件，支持 Arduino/ESP-IDF/MicroPython
- 现代开发体验，推荐
