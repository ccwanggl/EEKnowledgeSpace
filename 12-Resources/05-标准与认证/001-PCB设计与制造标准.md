# PCB 设计与制造标准

## IPC 标准
| 标准 | 名称 | 说明 |
|------|------|------|
| IPC-2221 | Generic Standard on Printed Board Design | PCB 设计通用标准 |
| IPC-2222 | Rigid Organic PCB Design | 刚性有机 PCB 设计 |
| IPC-2223 | Flexible PCB Design | 柔性 PCB 设计 |
| IPC-7351 | Surface Mount Design and Land Pattern | 表面贴装焊盘设计 |
| IPC-A-600 | Acceptability of Printed Boards | PCB 可接受性标准 |
| IPC-A-610 | Acceptability of Electronic Assemblies | 电子组件可接受性 |
| IPC-J-STD-001 | Requirements for Soldered Electrical and Electronic Assemblies | 焊接要求 |
| IPC-2581 | Generic Requirements for PCB Data Exchange | PCB 数据交换格式 |

### JEDEC 标准
- 半导体器件封装、测试、可靠性标准
- 常见：JESD22（可靠性测试方法）、JESD47（集成电路应力测试）
