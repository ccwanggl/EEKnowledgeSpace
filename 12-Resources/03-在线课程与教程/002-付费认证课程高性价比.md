# 付费/认证课程（高性价比）

## Coursera / edX
- **"Embedded Systems"（UC Boulder）** — Coursera，ARM Cortex-M 系列，付费认证
- **"FPGA Design for Embedded Systems"（UC Boulder）** — Coursera，FPGA 专项课程
- **"Introduction to Electronics"（Georgia Tech）** — Coursera，电路基础
- **"Circuits and Electronics 1/2/3"（MITx）** — edX，MIT 电路课程，付费认证
- **"Linux Foundation: Embedded Linux** — edX/Linux 基金会，Yocto/Buildroot

### Udemy
- **"Microcontroller Embedded C Programming"** — 嵌入式 C 经典
- **"STM32 HAL"** — 多个 STM32 课程，注意评分和评论
- **"KiCad PCB Design"** — 多个 KiCad 课程
- **Udemy 特点**：常打折（$10~$15），课程质量参差不齐，需看评价

### 国内平台
- **Bilibili** — 大量中文技术教程（免费），搜索 "STM32 教程"、"FPGA 入门"、"PCB 设计"
- **慕课网 / 网易云课堂** — 嵌入式、硬件设计课程（付费）
- **正点原子 / 野火** — STM32 视频教程（开发板附带或付费）
- **凡亿教育** — PCB 设计课程（Altium/KiCad）
- **硬禾学堂** — 硬件设计实战课程
- **电子发烧友学院** — 国内电子课程平台

### 专项培训
- **FastBit Embedded Brain Academy** — 付费课程（STM32、FreeRTOS、RTOS）
- **Contextual Electronics** — 付费硬件设计课程（Chris Gammell）
- **Code and Circuit** — 付费 PCB 设计课程
- **Embedded.fm** — 播客（免费，但有 Patreon 额外内容）
