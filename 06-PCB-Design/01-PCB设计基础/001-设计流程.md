软件是过时的 Protel，但"准备 → 画库 → 原理图 → PCB → 出 Gerber"的流程思想与今天的 KiCad 完全一致；实操请配合 [[06-PCB-Design/05-KiCad教程/002-快速入门流程|KiCad 快速入门]]。


```
需求分析 → 方案设计 → 原理图设计 → 元器件选型 → 封装制作
   ↓
PCB 布局 → 布线 → DRC 检查 → 信号/电源完整性仿真
   ↓
Gerber 输出 → 打样 → 焊接调试 → 测试验证 → 修改迭代
```
