# PCB 布局（Layout）

## 层数选择
| 层数 | 特点 | 适用 |
|------|------|------|
| 单层 | 最便宜，跳线多 | 极简单电路、LED 灯 |
| 双层 | 性价比最佳，最常用 | 大多数嵌入式项目 |
| 四层 | 电源/地平面，信号完整性 | 高速、复杂、噪声敏感 |
| 六层+ | 高密度、高速、多层电源 | 高端产品、FPGA、处理器 |

### 布局顺序
1. **固定接口**：连接器、按键、LED、天线按外壳位置固定
2. **大器件优先**：MCU、电源芯片、连接器
3. **模块化聚集**：相关器件靠近，减少走线长度
4. **热管理**：发热器件周围留空间，考虑散热片位置
5. **去耦电容**：尽可能靠近芯片电源/地引脚

### 关键规则
- **最短路径**：高速/敏感信号优先，走线最短
- **回路面积**：信号电流去路和返回路径围成的面积最小
- **3W 规则**：相邻走线间距 ≥ 3 倍线宽，减少串扰
- **20H 规则**：电源层缩进 20 倍层厚，减少边缘辐射
