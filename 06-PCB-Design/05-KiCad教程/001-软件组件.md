# 软件组件

| 组件 | 功能 | 说明 |
|------|------|------|
| **KiCad 管理器** | 项目总览 | 打开/管理项目、文件 |
| **Eeschema** | 原理图编辑器 | 绘制电路、符号库、ERC |
| **Symbol Editor** | 符号编辑器 | 创建自定义原理图符号 |
| **Pcbnew** | PCB 编辑器 | 布局、布线、DRC、3D 查看 |
| **Footprint Editor** | 封装编辑器 | 创建自定义 PCB 封装 |
| **Gerber Viewer** | Gerber 查看 | 预览制造输出 |
| **Calculator** | 工具 | 导线宽度、过孔、PCB 成本计算 |
