## 1. 创建项目
- File → New Project → 选择目录
- 生成 `.kicad_pro`（项目）、`.kicad_sch`（原理图）、`.kicad_pcb`（PCB）

### 2. 绘制原理图（Eeschema）

<details>
<summary>墓中巫人《手搓电脑》0065 绘制原理图</summary>
<iframe src="https://player.bilibili.com/player.html?bvid=BV1DhmGBiEtF&amp;autoplay=0&amp;danmaku=0" title="墓中巫人《手搓电脑》0065 绘制原理图" width="100%" height="360" loading="lazy" referrerpolicy="strict-origin-when-cross-origin" allow="encrypted-media; picture-in-picture; fullscreen" allowfullscreen></iframe>
<p><a href="https://www.bilibili.com/video/BV1DhmGBiEtF">在 B 站打开</a></p>
</details>

- 放置符号（Place Symbol）：从库中选择电阻、电容、芯片
- 连接导线（Place Wire）：用导线或网络标签连接
- 添加电源符号（Place Power Symbol）：VCC、GND、+3.3V
- 标注值和型号（Edit Value）：如 "10k"、"0.1uF"、"STM32F103C8T6"
- 分配封装（Assign Footprints）：电阻 → 0603/0805，芯片 → LQFP48
- 电气规则检查（ERC）：Tools → ERC，修复错误和警告

### 3. 设计 PCB 封装（Footprint Editor）
- 如果库中没有合适封装，自己绘制
- 从芯片 datasheet 提取焊盘尺寸、间距、封装外形
- 常用封装库：KiCad 自带、SnapEDA、Ultra Librarian

- 导入网表（Update PCB from Schematic）：自动放置器件和飞线
- 布局（Move/Rotate）：按信号流向和功能模块排列
- 定义板框（Edge.Cuts）：用线条绘制 PCB 外形
- 布线（Route Tracks）：按飞线连接，Shift+V 切换过孔尺寸
- 铺铜（Add Filled Zones）：GND 和 Power 层铺铜
- 设计规则检查（DRC）：检查间距、短路、未连接
