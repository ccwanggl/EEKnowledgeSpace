# 常用快捷键

| 快捷键 | 功能 | 场景 |
|--------|------|------|
| `A` | 添加符号 | 原理图 |
| `W` | 导线 | 原理图 |
| `L` | 网络标签 | 原理图 |
| `X` | 布线 | PCB |
| `V` | 添加过孔 | PCB 布线中 |
| `B` | 铺铜 | PCB |
| `D` | 拖动（保持连接） | PCB 调整布局 |
| `M` | 移动 | 通用 |
| `R` | 旋转 | 通用 |
| `Del` | 删除 | 通用 |
| `Ctrl+Z` | 撤销 | 通用 |
