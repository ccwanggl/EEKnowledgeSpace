# 高级技巧

## 四层板设计
- 层叠：Top（信号）→ GND → Power → Bottom（信号）
- 高速信号优先在 Top/Bottom，参考 GND/Power
- 电源分割：模拟电源和数字电源在不同区域

### 差分对布线
- 定义差分对（Route → Differential Pair）
- 等长：Tools → Length Tuning
- 等距：保持差分对线间距一致
- 参考：完整的 GND 平面

### 设计规则
- File → Board Setup → Design Rules → Constraints
- 按板厂工艺设置最小线宽/间距/过孔
- 约束特定网络（如 USB 差分对 90Ω，线宽 0.15mm/间距 0.15mm）
