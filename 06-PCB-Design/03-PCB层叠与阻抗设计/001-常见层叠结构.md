# 常见层叠结构

## 两层板
```
Top Layer  → 信号 + 少量电源
Bottom Layer → GND 平面 + 信号
```
- 成本低，适合低频、简单电路
- 高速信号必须保持下方完整参考平面

### 四层板（标准叠层）
```
L1: Top Signal
L2: GND Plane
L3: Power Plane
L4: Bottom Signal
```
- 最常用的高速入门叠层
- L2 和 L3 提供完整参考平面
- 顶层信号参考 L2 GND，底层信号参考 L3 Power（需 stitching）

### 六层板
```
L1: Top Signal
L2: GND
L3: Signal
L4: Signal
L5: Power
L6: Bottom Signal
```
- 两层内部信号层，适合复杂设计
- 或优化为：L1 Signal / L2 GND / L3 Signal / L4 Power / L5 GND / L6 Signal

### 八层板（高速/射频常用）
```
L1: Signal
L2: GND
L3: Signal
L4: Power
L5: GND
L6: Signal
L7: Power
L8: Signal
```
- 多层参考平面，适合 DDR、PCIe、SerDes 等高速信号
