# 时序分析与约束

## 建立时间与保持时间
- **Setup 违规**：数据变化太慢，在时钟沿前未稳定
- **Hold 违规**：数据变化太快，在时钟沿后未保持足够时间
- **解决方案**：
  - Setup：降低时钟频率、优化组合逻辑延迟、使用流水线
  - Hold：增加缓冲延迟、调整时钟偏斜（clock skew）

### 亚稳态（Metastability）
- 当数据在时钟沿附近变化时，触发器可能进入亚稳态
- 输出在不确定时间内徘徊于 0 和 1 之间
- 无法完全避免，但可通过同步器（双触发器）降低概率

### 时钟域交叉（CDC）
- 信号从一个时钟域传到另一个时钟域
- 必须使用同步器或 FIFO 处理
- 单 bit 信号：双触发器同步器
- 多 bit 信号：异步 FIFO、握手协议、Gray 码

### SDC 基础
- **SDC（Synopsys Design Constraints）**：时序约束文件
- 定义时钟周期、输入/输出延迟、虚假路径、多周期路径
- FPGA 工程中通过 SDC 指导综合和布局布线满足时序
