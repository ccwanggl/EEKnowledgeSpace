# 学习建议

1. 始终记住 Verilog 描述的是**并行硬件**，不要按 C 语言的顺序思维理解
2. 避免在 `always` 块内混用阻塞和非阻塞赋值
3. 组合逻辑用 `always @(*)` + `=`，时序逻辑用 `always @(posedge clk)` + `<=`
4. 不要综合出锁存器（Latch）：`always @(*)` 中必须覆盖所有分支
5. 从简单电路开始，仿真验证后再上板
6. 时序约束是 FPGA 设计的关键，不要忽略
