# 仿真与测试

## Testbench 结构
```verilog
module tb;
    reg clk, reset, a, b;
    wire result;
    
    dut uut(.clk(clk), .reset(reset), ...);
    
    initial begin
        clk = 0;
        reset = 1;
        #20 reset = 0;
        #100 a = 1; b = 0;
        #100 $finish;
    end
    
    always #5 clk = ~clk;  // 10ns 周期 = 100MHz
endmodule
```

### 仿真工具
- **Icarus Verilog** + **GTKWave**：开源免费（[[02-工具清单]]）
- **ModelSim/QuestaSim**：专业，支持 VHDL+Verilog
- **Vivado Simulator**：Xilinx 集成
- **Verilator**：高速 C++ 仿真，用于大规模验证
