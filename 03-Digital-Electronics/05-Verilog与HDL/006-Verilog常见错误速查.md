# Verilog 常见错误速查

| 错误 | 现象 | 正确做法 |
|------|------|----------|
| 混用 `=` 和 `<=` | 仿真结果与综合不一致 | 组合逻辑用 `=`, 时序逻辑用 `<=` |
| 不完整 `case` / `if` | 综合出 Latch | 补全 `else` / `default` |
| 敏感列表遗漏 | 仿真时信号不更新 | 组合逻辑用 `always @(*)` |
| 组合逻辑自环 | 综合失败或不稳定 | 检查反馈路径 |
| 未使用 `wire` / `reg` 正确 | 编译错误 | `assign` 目标用 `wire`, `always` 左值用 `reg` |
| 无复位 | 上电时状态不确定 | 所有时序逻辑加 `reset` |
| 跨时钟域直传 | 亚稳态、数据丢失 | 用同步器或 FIFO |
| 除法/取模 `%` | 消耗大量资源，慢 | 避免除法，用移位或查表 |
