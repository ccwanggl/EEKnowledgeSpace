# 描述风格

## 数据流（Dataflow）
- 用 `assign` 连续赋值，描述组合逻辑
- 对应门级电路
```verilog
assign y = a & b;
assign z = (sel) ? a : b;
```

### 行为级（Behavioral）
- 用 `always` 块，描述更复杂的逻辑
- 组合逻辑：`always @(*)`
- 时序逻辑：`always @(posedge clk)`
```verilog
always @(posedge clk) begin
    if (reset)
        q <= 0;
    else
        q <= d;
end
```
- **阻塞赋值 `=`**：立即执行，用于组合逻辑
- **非阻塞赋值 `<=`**：并行更新，用于时序逻辑

### 结构化（Structural）
- 实例化子模块，类似原理图连接
```verilog
adder u1(.a(a), .b(b), .cin(cin), .sum(sum), .cout(cout));
```
