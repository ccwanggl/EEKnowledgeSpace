# 核心思想：硬件 vs 软件

| 软件（C/Python） | 硬件（Verilog） |
|------------------|-----------------|
| 顺序执行 | 并行执行 |
| 变量 = 内存 | 变量 = 导线/寄存器 |
| 循环 = 重复执行 | 循环 = 复制硬件 |
| 函数调用 | 模块实例化（复制电路） |
| 调试用断点 | 调试用仿真波形 |

**Verilog 不是编程语言，而是电路描述语言。**
