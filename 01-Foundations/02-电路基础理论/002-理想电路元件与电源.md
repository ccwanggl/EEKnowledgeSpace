# 理想电路元件与电源

> [!abstract] 本章定位
> **前置知识**：[[001-电路模型、参考方向与功率]]。
>
> **本章回答**：电阻、电容、电感和电源分别用什么端口方程描述？哪些元件耗散能量，哪些元件储存能量？受控源为什么重要？
>
> **本章边界**：本章只讲理想模型。实际器件的容差、寄生、损耗、额定值和失效模式见 [[01-Foundations/04-电子元器件/000-README|电子元器件]]。
>

## 1. 伏安关系定义元件模型

元件的伏安关系描述端口电压和电流之间的约束。相同外形的器件可以使用不同精度的模型；在电路基础中，先使用线性、时不变、集总的理想模型。

| 元件    | 伏安关系         | 能量特征      |
| ----- | ------------ | --------- |
| 电阻    | $v=Ri$       | 耗散能量      |
| 电容    | $i=C\,dv/dt$ | 储存电场能量    |
| 电感    | $v=L\,di/dt$ | 储存磁场能量    |
| 理想电压源 | $v=v_s(t)$   | 电流由外部电路决定 |
| 理想电流源 | $i=i_s(t)$   | 电压由外部电路决定 |

## 2. 理想电阻建立代数关系

按被动符号约定：

$$v(t)=Ri(t)$$

功率为：

$$p(t)=vi=i^2R=\frac{v^2}{R}\ge0$$

正电阻只吸收功率，不储存可恢复能量。$R=0$ 对应理想短路，端电压为零；$R\to\infty$ 对应理想开路，支路电流为零。

### 2.1 串并联

串联电阻流过同一电流：

$$R_{eq}=\sum_kR_k$$

并联电阻承受同一电压：

$$\frac{1}{R_{eq}}=\sum_k\frac{1}{R_k}$$

串并联判断来自节点连接关系，不来自原理图上的视觉排列。

## 3. 理想电容的状态变量是电压

$$q=Cv$$

$$i=C\frac{dv}{dt}$$

积分形式为：

$$v(t)=v(t_0)+\frac{1}{C}\int_{t_0}^{t}i(\tau)\,d\tau$$

储能为：

$$w_C=\frac{1}{2}Cv^2$$

有限电流不能在零时间内改变有限电容的电压，因此常规换路问题中电容电压连续。若模型允许冲激电流，电容电压也可以发生跳变，这一边界在 [[007-动态元件与换路定则]] 讨论。

### 3.1 直流稳态与串并联

理想电容在直流稳态中 $dv/dt=0$，因此支路电流为零，可视为开路。这**只描述稳态**；接通、断开和电压变化期间仍会有电流。

并联电容电压相同：

$$C_{eq}=\sum_kC_k$$

串联电容带有相同幅值的支路电荷时：

$$\frac{1}{C_{eq}}=\sum_k\frac{1}{C_k}$$

实际串联电容还涉及初始电荷、漏电、均压和耐压分配，不能只用理想等效式完成器件设计。

## 4. 理想电感的状态变量是电流

$$v=L\frac{di}{dt}$$

积分形式为：

$$i(t)=i(t_0)+\frac{1}{L}\int_{t_0}^{t}v(\tau)\,d\tau$$

储能为：

$$w_L=\frac{1}{2}Li^2$$

有限电压不能在零时间内改变有限电感的电流，因此常规换路问题中电感电流连续。开断电感电流时，器件会建立能够维持电流的端电压，实际电路需要续流或钳位路径。

### 4.1 直流稳态与串并联

理想电感在直流稳态中 $di/dt=0$，端电压为零，可视为短路。真实线圈仍有绕组电阻和磁芯限制。

无互感时，串联电感满足：

$$L_{eq}=\sum_kL_k$$

并联且初始条件相容时：

$$\frac{1}{L_{eq}}=\sum_k\frac{1}{L_k}$$

存在磁耦合时必须引入互感，不能直接套用无耦合公式。

## 5. 独立源规定一个端口变量

理想电压源规定端电压，电流由外部电路决定；理想电流源规定支路电流，电压由外部电路决定。

理想电压源不能直接并联不同电压值的另一理想电压源，因为同一节点对将被要求同时具有两个电压。理想电流源不能串联不同电流值的另一理想电流源，因为同一支路将被要求同时具有两个电流。

### 5.1 实际电源的一阶模型

实际电压源常用理想电压源 $V_s$ 串联内阻 $R_s$：

$$v=V_s-iR_s$$

实际电流源常用理想电流源 $I_s$ 并联内阻 $R_p$：

$$i_{out}=I_s-\frac{v}{R_p}$$

这两个模型描述负载变化导致的端口电压或电流变化。更复杂的频率、温度和动态行为需要增加模型阶数。

## 6. 受控源建立跨端口关系

受控源的输出由电路中另一电压或电流控制。四种理想形式为：

| 类型 | 关系 | 增益单位 |
|---|---|---|
| 电压控制电压源 VCVS | $v_o=\mu v_x$ | 无量纲 |
| 电流控制电压源 CCVS | $v_o=r_m i_x$ | Ω |
| 电压控制电流源 VCCS | $i_o=g_m v_x$ | S |
| 电流控制电流源 CCCS | $i_o=\beta i_x$ | 无量纲 |

受控源是有源器件小信号模型和反馈电路的基本组成。晶体管的跨导模型可用 VCCS 表示，运放的开环模型可用高增益 VCVS 表示。

受控源不能在“关闭独立源”时一并置零，因为它仍由电路变量控制。求含受控源网络的等效电阻时，通常需要保留受控源并施加测试源。

## 7. 理想模型和实际器件的对应

| 理想模型 | 实际器件增加的主要因素 |
|---|---|
| 电阻 | 容差、温漂、噪声、额定功率、寄生电感和电容 |
| 电容 | ESR、ESL、漏电、偏压降容、纹波和寿命 |
| 电感 | 绕组电阻、寄生电容、饱和、磁芯损耗和耦合 |
| 电压/电流源 | 内阻、带宽、限流、噪声、效率和稳定性 |

理想模型负责建立方程，实际模型负责判断设计是否可实现。两者不能互相替代。

## 8. 常见误区

> [!warning]
> - 电容“隔直”只描述理想直流稳态，不描述充电过程和实际漏电。<br>
> - 电感“通直”只描述理想直流稳态，不表示真实线圈没有压降和损耗。<br>
> - 理想电压源的电流和理想电流源的电压没有由源本身限定，实际源必须有额定边界。<br>
> - 受控源是电路模型的一部分，不等于外部可独立设置的电源。
