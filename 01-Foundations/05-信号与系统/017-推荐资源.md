# 信号与系统推荐资源

[[000-信号与系统|模块学习路径]]给出知识顺序。配套课程使用 [MIT OCW RES.6-007 Signals and Systems（Alan Oppenheim，英语）](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/resources/lecture-videos/) 的官方讲次索引。可以随本地章节跳读，行内数字是 MIT 讲次。

| 本地学习顺序 | 配套观看 | 练习 |
|---|---|---|
| 001–003 [[001-信号、系统与LTI基础\|LTI]]、[[002-时域响应与微分方程\|时域响应]]、[[003-卷积：从冲激响应到输出\|卷积]] | MIT 2–6：信号与系统、卷积、LTI 性质、系统方程 | 求 RC 低通冲激响应，用卷积复现零状态阶跃响应 |
| 004–006 [[004-为什么需要变换域\|变换观]]、[[005-频域表示与傅里叶级数\|傅里叶级数]]、[[006-傅里叶变换详解\|傅里叶变换]] | [3Blue1Brown：傅里叶变换可视化（YouTube，英语）](https://www.youtube.com/watch?v=spUNpyF58BY) 可作预习；MIT 7–9 对照定义和推导 | 求矩形脉冲频谱，解释时宽变化如何影响主瓣 |
| 007–009 [[007-拉普拉斯变换与系统函数\|拉普拉斯]]、[[008-极点零点与系统稳定性\|极点与稳定性]]、[[009-频率响应与Bode图\|频率响应]] | MIT 20–21；[Brian Douglas：Bode 图入门（YouTube，英语）](https://www.youtube.com/watch?v=_eh1conN6YM)，勘误见视频说明 | 从 RC 的微分方程得到系统函数，手算截止频率和截止处相位 |
| 010 [[010-采样、混叠与重建\|采样与重建]] | MIT 16–17：采样、插值 | 以 8 kHz 采样 7 kHz 和 1 kHz 余弦，对比样本 |
| 011–013 [[011-离散时间信号与系统\|离散时域]]、[[012-DTFT与离散频率响应\|DTFT]]、[[013-Z变换与离散时间系统\|Z 变换]] | MIT 2–6 中的离散部分、10–12（离散傅里叶与滤波）、22（Z 变换） | 对同一个一阶 IIR 分别写递推式、冲激响应、ROC 与单位圆频率响应 |
| 014–015 [[014-DFT与FFT频谱分析\|FFT]]、[[015-信号与系统综合工程案例\|工程案例]] | 用本地 FFT 示例串接前面讲次，重点练习窗、补零与幅值标定 | 分别改变采样率、记录长度和 FFT 点数，记录谱峰、栅格和泄漏的变化 |
