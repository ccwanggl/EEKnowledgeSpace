# 011-离散时间信号与系统

> [!abstract] 本章定位
> **前置知识**：001 的序列与系统性质、002 的零状态概念、003 的离散卷积、010 的采样接口。
> **本章回答**：怎样用序列、延迟、差分方程和卷积和描述离散系统？
> **学习出口**：不用 Z 变换，也能求一个一阶系统的响应并判断因果性与稳定性。

## 1. 序列本身就是研究对象

$x[n]$ 定义在整数索引上，可以来自采样，也可以来自计数或算法。仅在明确采样周期 $T_s$ 后，才把 $n$ 对应到物理时刻 $nT_s$。离散时间不等于幅值量化。

基本序列是 $\delta[n]$、$u[n]$、$a^nu[n]$ 和 $e^{j\Omega n}$。任意序列可写为

$$x[n]=\sum_{k=-\infty}^{\infty}x[k]\delta[n-k].$$

数字角频率 $\Omega$ 的单位为 rad/sample；模拟角频率 $\omega$ 为 rad/s。采样关联为 $\Omega=\omega T_s=2\pi f/f_s$。

$$e^{j(\Omega+2\pi m)n}=e^{j\Omega n},\qquad m\in\mathbb Z.$$

因此数字频率相差 $2\pi$ 的整数倍时对应相同复指数序列。复指数周期性的判据为存在正整数 $N$ 使 $\Omega N=2\pi k$，即 $\Omega/(2\pi)$ 为有理数。

## 2. 从差分方程逐点求输出

贯穿后三章的例子是

$$y[n]=a y[n-1]+(1-a)x[n],\qquad 0<a<1.$$

这是线性常系数递推关系。必须同时说明初始状态；固定非零初始状态下，仅从输入到总输出的映射一般不是线性的。后续 LTI 输入—输出分析使用零状态。

取 $a=1/2$、$y[-1]=0$、$x[n]=u[n]$：

| $n$ | 输入 | 输出计算 | 结果 |
|---|---|---|---|
| 0 | 1 | $0.5\times0+0.5$ | 0.5 |
| 1 | 1 | $0.5\times0.5+0.5$ | 0.75 |
| 2 | 1 | $0.5\times0.75+0.5$ | 0.875 |

输出逐步接近 1。延迟支路保存上一时刻状态；系数同时决定响应速度和对快速变化的平滑程度。

## 3. 零输入、零状态与卷积和

令 $y[-1]=y_{-1}$，零输入响应为 $y_{zi}[n]=a^{n+1}y_{-1}$，$n\ge0$。

零状态下输入单位脉冲：$h[0]=1-a$，此后每一步乘 $a$，所以

$$h[n]=(1-a)a^nu[n].$$

由线性与时不变性，任意输入的零状态响应为

$$y_{zs}[n]=\sum_{k=-\infty}^{\infty}x[k]h[n-k].$$

对单位阶跃，用几何级数求和：

$$y_{zs}[n]=(1-a)\sum_{k=0}^n a^k=1-a^{n+1},\quad n\ge0.$$

总响应为 $a^{n+1}y_{-1}+1-a^{n+1}$。注意离散卷积本身不乘 $T_s$；只有把求和作为连续积分近似时才需要积分步长。

## 4. 因果、稳定、FIR 与 IIR

离散 LTI 系统因果当且仅当 $h[n]=0$（$n<0$）；BIBO 稳定当且仅当 $\sum_n|h[n]|<\infty$。

本例 $0<a<1$ 时 $\sum_n|h[n]|=1$，所以稳定。一般递推 $y[n]=a y[n-1]+b x[n]$ 在 $b\ne0$、因果零状态下，稳定要求 $|a|<1$。

- FIR：冲激响应有限长。例如 $h[n]=[1/2,1/2]$，直接实现为 $y[n]=(x[n]+x[n-1])/2$。
- IIR：冲激响应无限长。本例属于 IIR，通常用递推高效实现。

FIR 也有记忆；“有没有输出反馈”不能取代“冲激响应是否有限”的定义。一般 FIR 系数也不必全为正或归一化为平均权重。

## 5. 与 RC 的联系及边界

连续 RC 满足 $\tau\dot y+y=x$。如果输入在每个采样区间内恒定，令 $x[n]$ 为 $[nT_s,(n+1)T_s)$ 的保持输入、$y[n]=y(nT_s)$，精确递推为

$$y[n+1]=\alpha y[n]+(1-\alpha)x[n],\qquad\alpha=e^{-T_s/\tau}.$$

这与前面递推具有相同衰减模态，但输入、输出的索引时刻不同。不能只凭 $a=e^{-T_s/\tau}$ 就忽略保持器和一拍延迟；数字算法的时间约定必须写清楚。

## 6. 验证与自测

```python
import numpy as np
x = np.ones(20)
a = 0.5
y = np.empty_like(x)
state = 0.0
for n, value in enumerate(x):
    state = a * state + (1-a) * value
    y[n] = state
h = (1-a) * a**np.arange(len(x))
y_conv = np.convolve(x, h)[:len(x)]
print(np.max(np.abs(y-y_conv)))  # 应接近 0
```

1. 把初始状态改为 $y[-1]=2$，求前三项。核对：$1.5,1.25,1.125$。
2. 对因果系统 $y[n]=1.1y[n-1]+x[n]$ 判断 BIBO 稳定性。核对：$h[n]=1.1^nu[n]$ 不绝对可和，因此不稳定。
3. 两点平均器对 $x[n]=(-1)^n$ 的稳态输出是什么？核对：0；下一章用频率响应解释。
