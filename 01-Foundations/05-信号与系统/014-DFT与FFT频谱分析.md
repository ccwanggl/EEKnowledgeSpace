# 014-DFT与FFT频谱分析

> [!abstract] 本章定位
> **前置知识**：003 的离散卷积、010 的采样、012 的 DTFT。013 可帮助理解单位圆，但不是计算 DFT 的硬性先修。
> **本章回答**：如何从有限记录得到可信的频谱，区分泄漏、混叠和分辨率？
> **学习出口**：解释 FFT 每个频点的频率、幅值规范与计算对象。

## 1. 从有限记录的 DTFT 到 DFT

对长度为 $N$ 的数据 $x_N[n]$（区间外为零）：

$$X[k]=\sum_{n=0}^{N-1}x_N[n]e^{-j2\pi kn/N},\quad k=0,\ldots,N-1,$$
$$x_N[n]=\frac1N\sum_{k=0}^{N-1}X[k]e^{j2\pi kn/N},\quad 0\le n<N.$$

DFT 是有限序列 DTFT 在 $\Omega_k=2\pi k/N$ 的取值。逆 DFT 的表达式在索引上周期重复；只取原区间即恢复输入数据。对周期延拓的 DTFS，系数为 $c_k=X[k]/N$。

FFT 是计算 DFT 的快速算法，不是另一种变换，也不要求所有实现都只能处理 2 的整数次幂长度。

## 2. 频率轴与幅值标定

频点间隔 $\Delta f=f_s/N$。通常把后半段索引解释为负频率：对应 $(k-N)f_s/N$。实序列可使用单边谱，偶数 $N$ 时包含 $k=0,\ldots,N/2$。

对恰好落在频点上的实余弦 $A\cos(2\pi k_0 n/N+\varphi)$，且 $k_0$ 不是直流或奈奎斯特频点：双边 DFT 模长为 $NA/2$，单边幅值应取 $2|X[k_0]|/N$。直流和奈奎斯特频点不翻倍。

加窗后，对孤立、相干采样且谱峰附近正负频率不相互污染的正弦，可用 $2|X_w[k_0]|/\sum_nw[n]$ 校正窗的相干增益；非整数频点信号仍可能存在栅栏效应与幅值偏差。功率谱密度使用不同归一化，不能套用这个幅值公式。

## 3. 泄漏、窗函数与补零

记录有限等于原序列乘以窗 $w[n]$。时域乘法对应 DTFT 的周期卷积，谱线被窗频谱展宽。非整数周期截断尤其容易在多个频点上看到能量。

| 现象或操作 | 原因/作用 | 能否恢复已丢失信息 |
|---|---|---|
| 混叠 | 采样前频谱重叠 | 一般不能靠采样后滤波恢复 |
| 泄漏 | 有限观察窗导致谱展宽 | 可选窗控制旁瓣，但同时改变主瓣 |
| 延长记录 | 增加实际观测时长 | 通常改善相近频率的分辨能力 |
| 补零 | 更密地取样同一个有限记录 DTFT | 不增加观测信息，不缩窄原窗主瓣 |

若实际记录长度 $N_r$、FFT 长度 $N_f\ge N_r$，栅格间隔为 $f_s/N_f$，真实观测时长为 $N_r/f_s$。分辨能力还受窗主瓣、信噪比与两频率幅度差影响，不能只看 FFT 点数。

## 4. 完整例子：8 kHz 采样的正弦

取 $f_s=8000$ Hz、$N_r=1024$：观察时长 0.128 s，未补零频点间隔 7.8125 Hz。1 kHz 对应 $k=128$，包含整数周期；1003 Hz 则不落在整数频点上。

```python
import numpy as np
fs, N = 8000.0, 1024
n = np.arange(N)
x = np.cos(2*np.pi*1000*n/fs)
X = np.fft.rfft(x)
amplitude = np.abs(X)/N
amplitude[1:-1] *= 2  # 此例 N 为偶数
frequency = np.fft.rfftfreq(N, 1/fs)
k = np.argmax(amplitude)
print(frequency[k], amplitude[k])  # 1000 Hz, 约 1

# 改为非整数频点，比较窗与补零后的曲线
x = np.cos(2*np.pi*1003*n/fs)
w = np.hanning(N)
Xw = np.fft.rfft(x*w, n=8192)
f = np.fft.rfftfreq(8192, 1/fs)
A = np.abs(Xw)/w.sum()
A[1:-1] *= 2
# 绘制 f 与 A：频点更密，记录仍只有 0.128 s。
```

验证时分别改变正弦频率、记录长度和 FFT 长度，每次只改变一个条件。不要把一条变密的频谱曲线误读为测量精度必然提高。

## 5. DFT 相乘与循环卷积

$$\operatorname{IDFT}\{X[k]H[k]\}[n]
=\sum_{m=0}^{L-1}x[m]h[(n-m)\bmod L].$$

它计算长度 $L$ 的循环卷积。若两段有限序列长度分别为 $N,M$，补零到 $L\ge N+M-1$ 后，循环卷积在完整输出区间内等于线性卷积。

例如 $x=[1,2,3]$、$h=[1,-1]$，线性卷积为 $[1,1,1,-3]$；若只用 3 点 DFT，末项绕回起点，得到 $[-2,1,1]$。这属于循环折叠，与 ADC 采样混叠应分开描述。

## 6. 自测与工程出口

1. 将 1024 点记录补零到 8192 点，频点间隔是多少？核对：0.9765625 Hz；实际观测时长仍是 0.128 s。
2. 长度 1000 与 50 的序列做 FFT 线性卷积，最短长度是多少？核对：1049；可为效率选择更长长度。
3. 一条谱峰在改变采样率后移动，延长记录后又变窄，分别可能涉及什么？核对：前者需排查混叠，后者可能是窗主瓣变窄；两种现象可同时存在，需结合模拟输入验证。
