# 学习方法与工具

电子工程学习同时涉及数学推导、器件知识、软件实现、实验测量和故障排查。读完一章、做过一道题或跑通一个例程，只能说明接触过材料。更可靠的完成标准是：隔一段时间仍能从问题出发选用方法，给出推导或设计，并用计算、仿真、代码和实验说明结果为什么可信。

## 学习闭环

```mermaid
flowchart LR
    A["定义任务与验收标准"] --> B["补齐前置知识"]
    B --> C["例题、推导与检索练习"]
    C --> D["计算、仿真或实现"]
    D --> E["测量与交叉验证"]
    E --> F["记录错误和决策"]
    F --> G["延迟复测与迁移"]
    G -->|未达到标准| B
    G -->|达到标准| H["进入下一任务"]
```

这条闭环不规定理论、实践和复盘各占多少时间。任务难度、已有基础、工具条件和目标保持期不同，固定比例很快会失去意义。用可观察的产出和验收结果调节投入更稳妥。

## 学习顺序

### 把模糊目标变成可执行任务

1. [[001-把目标改写成可验证的学习任务]]：定义产出、约束、前置知识和完成标准。
2. [[002-检索练习、间隔复习与交错学习]]：用主动回忆、反馈和延迟复测巩固长期保持。
3. [[003-例题、推导与分层练习]]：从完整示范逐步过渡到独立分析和新场景迁移。

### 用工程活动连接理论与实物

4. [[004-项目驱动学习与最小工程闭环]]：把知识放进范围受控、可以验收的小项目。
5. [[005-如何阅读教材、论文和数据手册]]：根据问题选择资料，并记录结论的出处和边界。
6. [[006-计算、仿真与实验怎样互相校验]]：区分模型、数值结果和真实系统，解释它们之间的差异。

### 让知识可以积累和维护

7. [[007-知识笔记、双向链接与可检索结构]]：用索引、概念、实验和来源笔记组织知识库。
8. [[008-错题、故障记录与工程复盘]]：把错误转成检查项、测试或新的知识节点。
9. [[009-AI辅助学习与事实核验]]：用 AI 解释、审阅和生成练习，同时保留独立验证。
10. [[010-学习计划、进度评估与知识维护]]：按里程碑限制并行任务，定期复测和更新旧笔记。

## 用什么证明已经掌握

| 层级 | 可观察的表现 | 合适的检查方式 |
|---|---|---|
| 识别 | 看见术语或电路时能辨认对象 | 概念辨析、标注图、选择题并说明理由 |
| 回忆 | 不看资料能写出关键关系和条件 | 空白纸回忆、简答、公式及单位检查 |
| 解释 | 能用模型说明因果和适用边界 | 自己画图、推导、回答反例 |
| 应用 | 能在已知类型问题中独立选方法 | 混合练习、计算、仿真或编码 |
| 迁移 | 能处理参数、约束或结构变化 | 变式题、故障诊断、设计与权衡 |
| 验证 | 能用独立证据判断结果是否可信 | 测试计划、误差分析、交叉测量和复盘 |

掌握层级随任务变化。查阅冷门寄存器定义是正常工程活动，不能背下全部细节不等于没有掌握；不会判断来源版本、约束和测试结果，则说明能力还没有闭环。

## 方法与工具怎样分工

| 需求 | 方法 | 工具只承担什么 |
|---|---|---|
| 长期记住概念 | 检索练习和间隔复习 | Anki 或 Obsidian 安排卡片与回顾 |
| 理解公式和模型 | 推导、量纲检查、极限情况 | 纸笔、符号计算或数值脚本辅助检查 |
| 预测电路行为 | 建模、手算、参数扫描 | SPICE、Python、MATLAB 或 Octave 执行模型 |
| 验证真实系统 | 测试设计、误差分析、交叉验证 | 仪器采集数据，不替代结果解释 |
| 管理来源 | 记录版本、页码、引用和适用条件 | Zotero、文件系统与笔记库保存材料 |
| 维护工程产物 | 版本控制、评审和可复现流程 | Git 保存历史，不能代替清晰的提交边界 |
| 辅助分析 | 提供上下文、拆分任务、验证输出 | AI 生成候选解释和草稿，不作为事实来源 |

工具选择随平台和项目改变，本目录重点说明怎样用。书籍、课程、网站和软件清单由 [[12-Resources/00-README|12-Resources]] 维护。

## 研究依据与使用边界

检索练习和分散学习在多类实验中表现稳定，交错练习与完整例题也在特定数学任务中显示出优势。研究任务、学习者经验和最终测验形式会影响效果，本目录把这些方法当作可检验的设计起点，不把单项研究直接推广成所有工程学习场景的定律。

- [Dunlosky 等：常用学习技术的证据综述](https://doi.org/10.1177/1529100612453266)
- [Karpicke 与 Blunt：检索练习与概念学习](https://pubmed.ncbi.nlm.nih.gov/21252317/)
- [Cepeda 等：分散学习元分析](https://pubmed.ncbi.nlm.nih.gov/16719566/)
- [Taylor 与 Rohrer：交错练习实验](https://doi.org/10.1002/acp.1598)
- [Sweller 与 Cooper：完整例题研究](https://doi.org/10.1207/s1532690xci0201_3)
