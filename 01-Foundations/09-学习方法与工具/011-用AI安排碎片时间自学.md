# 用 AI 安排碎片时间自学

从 [[00-Index/03-AI自学任务索引|全库自学任务]] 选一个能留下结果的动作，例如计算 RC 时间常数、读一帧 UART 波形，或判断任务的调度顺序。[[00-Index/01-学习路线图|学习路线图]]说明任务之间的依赖，本页用来安排下一次学习。

## 一次学习怎么进行

| 当前空档 | 动作 | 留下什么 |
|---|---|---|
| 10 分钟 | 合上笔记，做一道回忆题或画一张简图，再打开笔记核对 | 一句结论、一个待补知识点 |
| 25 分钟 | 先尝试入口题，按卡点找提示、读一小节或看一段视频，再独立求解 | 一份解答、一处更正、下次要做的题 |
| 60 分钟或以上 | 先写预测，再用代码、仿真或测量核对，最后改变一个参数 | 条件、预测、结果和差异说明 |

1. **先做入口题。** 能独立给出方法、条件和结果，就进到变式。知道方法但写不下去，找 AI 要一级提示。连方法都选不出，沿任务里的先修链接补一个知识点。
2. **根据卡点读或看。** 用正文、教材或手册确认定义和条件。看不清波形、操作或直觉时，从 [[12-Resources/01-YouTube频道推荐/000-视频学习索引|视频学习索引]] 找当前问题对应的一段。暂停后自己重画、重算或重做。
3. **让 AI 审阅你的尝试。** 提供条件、单位、自己的步骤以及第一个疑点。每次只请它指出一处断点。公式有分歧时做量纲或极限检查，器件和 API 回到对应版本手册。[[009-AI辅助学习与事实核验|AI 核验方法]]
4. **关掉提示后复测。** 用任务的验收标准核对。借助提示完成的题先记作待复测，下次独立做一道只改变一个条件的变式，能解释结果后再记通过。[[002-检索练习、间隔复习与交错学习|检索练习与间隔复习]]

时间用尽时，写下卡住的步骤和下次只做的一件事。保留一个主任务和一道复测题，方便不同长度的空档接续。

## 可复制到 AI 对话的提示

AI 能读取知识库时，请它先打开任务中的相关笔记。只收到摘录时，请它据此解释并指出还缺什么。

```text
我有【时间】，想完成【任务】。
参考笔记或摘录：【路径或片段】。
题目条件与我的尝试：【参数、单位、当前推导或现象】。
请一次只给一题，等我先答，再判断我卡在先修、方法选择还是计算。
第一轮只给一个引导问题，等我回应后再决定是否给下一步提示。
说明依据的是哪一篇笔记或哪个小节。信息不足时说明需要核对什么。
```

完成后可继续发送：

```text
这是我的独立答案和验证结果：【粘贴】。
请先指出第一处会影响结论的错误，或列出我已核对的关键条件。
给一道只改变一个条件的变式题，等我答完再核对。
建议下一次复测只做哪一个动作。
```

## 保存一条可以接着做的记录

放进当前任务笔记或日记。详细实验可使用 [[11-Projects/06-项目笔记模板/009-测试验证|测试验证模板]]。

```markdown
任务与时间：
独立尝试与卡点：
证据：手算、章节出处、代码输出或波形
状态：待补先修 / 待复测 / 已通过
下次只做：
```

## 技术笔记怎样接入自学

模块总览提供先修和下一站，任务页给一道入口题、对应材料和独立验收，正文承载完整推导和工程条件。视频按卡点链接到笔记。把稳定结论和依据留在正文，把个人进度留在任务记录。新增主题时可参考 [[001-把目标改写成可验证的学习任务|学习任务模板]] 和 [[010-学习计划、进度评估与知识维护|进度评估]]。
