# 如何阅读教材、论文和数据手册

资料类型决定它能回答什么。教材适合建立模型，数据手册给出某个器件在规定条件下的规格，参考手册说明接口和寄存器，标准定义合规方法，论文报告特定研究问题与实验结果。把应用笔记或论坛经验当作保证规格，容易把适用条件一起丢掉。

## 1. 阅读前写下问题

| 问题类型 | 优先资料 |
|---|---|
| 某个物理关系怎样推导 | 教材、课程讲义、综述和原始论文 |
| 某器件能否承受工作条件 | 最新数据手册、勘误和封装资料 |
| 寄存器如何配置 | 参考手册、数据手册、芯片勘误和官方驱动 |
| 推荐外围电路怎样工作 | 数据手册、评估板原理图和厂商应用笔记 |
| 某测试是否满足标准 | 标准正文、官方解释和认可实验室流程 |
| 某故障是否有人遇到 | 厂商论坛、问题跟踪和社区讨论，再回到原始资料验证 |
| 某算法效果如何 | 原始论文、数据、实现、基线和后续复现 |

检索问题要包含对象、版本、条件和想得到的结果。只搜“FOC 电流采样”，很容易混入不同拓扑、PWM 方法和采样位置的方案。

## 2. 来源靠近原始事实

同一个结论经过博客、视频、问答和 AI 多次转述后，限定条件容易消失。可以按以下顺序追溯：

1. 找到当前资料引用的原始名称、型号、标准号或论文；
2. 获取对应版本的官方文档或出版物；
3. 定位页码、表格、测试条件和修订记录；
4. 把结论改写成包含条件的陈述；
5. 用计算、代码、仿真或测量检查它能否用于当前任务。

来源层级并非固定。厂商数据手册对器件保证值最直接，独立论文或实验对某些失效和应用行为可能提供数据手册没有的信息。

## 3. 数据手册先看版本和边界

阅读器件数据手册时，优先定位：

- 文档版本、发布日期、订购型号和产品状态；
- 绝对最大额定值；
- 推荐工作条件；
- 电气特性及其测试条件；
- 典型性能曲线；
- 功能框图和工作模式；
- 时序、接口和状态转换；
- 应用电路、布局与散热要求；
- 封装、引脚、机械尺寸和焊接信息；
- 勘误、修订记录和配套参考手册。

绝对最大额定值描述损坏边界附近的限制，不是推荐工作点。典型值和典型曲线帮助估计行为，通常不构成全范围保证。最小值和最大值是否保证，还要结合表头、温度、供电、负载和脚注阅读。

## 4. 规格不能脱离测试条件

看到“带宽 10 MHz”“精度 0.1%”“导通电阻 5 mΩ”时，同时记录：

- 电源电压、温度和负载；
- 输入幅度、频率和共模；
- 测试电流、栅极电压或偏置；
- 量程、带宽和统计口径；
- 典型、最小、最大还是保证值；
- 单次测试、全温度还是生产筛选范围。

工程笔记中只保留数字不保留条件，会使后续设计无法判断它是否仍然适用。

## 5. 教材按模型、例题和边界阅读

一章教材可以分三次处理：

- 快速定位本章解决的问题、输入输出和前置知识；
- 精读核心模型，自己补出省略的推导、单位和假设；
- 关闭材料后重建框图、公式与例题，再做变式练习。

章节顺序服务于作者叙述，不一定等于当前任务的依赖顺序。可以围绕问题跨章节阅读，但要补回被跳过的定义和假设。

## 6. 论文先判断研究问题和证据

阅读论文时记录：

| 项目 | 需要回答的内容 |
|---|---|
| 研究问题 | 作者比较或解释什么 |
| 基线 | 与哪些已有方法比较 |
| 方法 | 模型、样本、仪器、数据和统计口径 |
| 结果 | 哪些指标改善，幅度和不确定性如何 |
| 条件 | 数据集、工况、参数和硬件平台 |
| 限制 | 作者声明和从方法中能看出的边界 |
| 可复现性 | 代码、数据、版本和步骤是否可得 |
| 当前用途 | 结论能否直接用于当前设计，还是只提供假设 |

摘要用于筛选，不能替代方法、图表和限制。图表中的坐标、归一化、误差条和被省略的基线，往往比结论段更影响工程判断。

## 7. 用“结论、证据、边界”记录

```markdown
结论：在什么条件下，什么量呈现什么结果
证据：文档版本、页码、表格、公式或实验数据
边界：未覆盖的温度、频率、负载、样本或故障条件
当前用途：用于计算、选型、仿真假设还是待验证假设
复核状态：未核对 / 已回到原文 / 已计算 / 已仿真 / 已测量
```

引用应指向稳定来源并保留标题、作者、版本和访问日期。网页会更新，关键数据手册和标准可保存受许可的本地副本或文档编号。

## 8. 多个来源冲突时先对齐条件

冲突常来自：

- 文档版本或芯片修订不同；
- 典型值与保证值混用；
- 测试温度、带宽、负载或样本不同；
- 术语定义不同；
- 测量方法和参考点不同；
- 二手资料遗漏脚注；
- 真实器件行为超出简化模型。

先把这些条件放进对照表，再决定是否需要实验。不能判断时，在笔记中保留冲突和待验证状态，不要为了得到单一答案而选一条看起来更合理的说法。

## 9. FOC 电流采样的资料链示例

设计电流采样链路可能需要：

1. 电机控制教材或论文说明采样位置与电流重构关系；
2. MCU 参考手册说明 ADC 触发、采样时间和校准；
3. 放大器数据手册给出输入范围、建立、偏置和共模瞬态；
4. 分流器数据手册给出阻值、温漂、功率和寄生电感；
5. 评估板原理图和布局说明开尔文连接与滤波；
6. 实际计算和仿真形成误差与时序预算；
7. 台架测量核对零点、增益、饱和和动态响应。

单独一篇应用笔记无法覆盖整条链路，每个结论要回到它负责的层级。

## 10. 资料管理分工

- Zotero 或同类工具保存论文元数据、附件和引用；
- Obsidian 保存经过消化的解释、推导、链接和当前用途；
- Git 保存可比较的文本、脚本、配置和修改历史；
- 项目目录保存与某个硬件和版本绑定的证据；
- `12-Resources` 保存供全库复用的外部资源入口。

不要把 PDF 全文复制进主题笔记。笔记记录结论、出处、边界和自己的验证，原文保持独立可追溯。
