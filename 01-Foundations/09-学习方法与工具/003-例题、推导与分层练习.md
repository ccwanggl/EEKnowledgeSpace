# 例题、推导与分层练习

初学者直接面对开放问题时，很多时间会耗在搜索路径上。完整例题可以展示问题表征、方法选择和中间步骤；随着结构逐渐熟悉，提示需要撤掉，练习才能过渡到独立解决和迁移。

## 1. 从示范到独立解决

```mermaid
flowchart LR
    A["完整例题：解释每一步"] --> B["补全题：完成缺失步骤"]
    B --> C["近变式：改变参数或表示"]
    C --> D["混合题：先选择方法"]
    D --> E["开放题：加入约束和权衡"]
    E --> F["延迟复测：减少提示"]
```

撤掉提示的速度取决于表现。能跟着例题看懂，却无法补出下一步，说明示范中的关键选择还没有被提取出来；可以独立完成同结构题，再加入方法相近但条件不同的问题。

## 2. 读例题时解释选择

抄写步骤不会自动形成可迁移的结构。每一步至少检查：

- 当前目标量是什么；
- 为什么使用这个定律、模型或坐标系；
- 哪些条件允许这一步成立；
- 单位、符号和参考方向是否一致；
- 有没有另一种方法，代价是什么；
- 参数或边界改变后，哪一步会失效。

例题的价值在于展示决策，而不只是展示最后的计算过程。

## 3. 推导前先写假设和目标

工程推导常在以下位置出错：参考方向没有定义、近似条件丢失、连续域和离散域混用、峰值与有效值混用、单位不一致。可以用固定页眉：

```markdown
目标量：
已知量与单位：
参考方向：
采用模型：
假设与忽略项：
适用范围：
预期数量级：
```

推导结束后检查量纲、极限情况和符号。把电阻取零或无穷、频率取零或很大、采样周期趋近零，常能暴露不合理的表达式。

## 4. 一个 RC 低通的分层练习

完整例题给出电路、KCL、传递函数和截止频率：

$$
H(s)=\frac{1}{1+sRC},\qquad f_c=\frac{1}{2\pi RC}
$$

可以按下面的方式增加难度：

1. 补全从 KCL 到传递函数的中间步骤；
2. 给定 $R$、$C$，计算截止频率并画出渐近 Bode 图；
3. 给定截止频率和电容标准值，选择电阻并计算偏差；
4. 加入信号源电阻和负载电阻，重新推导；
5. 给出示波器测得的响应，判断偏差来自元件容差、负载还是测量带宽；
6. 把滤波器放到 ADC 前端，加入采样建立和抗混叠约束。

层级变化来自模型和约束的变化，不是把数字变得更复杂。

## 5. 练习题需要覆盖不同动作

| 类型 | 训练动作 | 电子工程示例 |
|---|---|---|
| 复述题 | 提取定义和条件 | 说明运放虚短近似成立的条件 |
| 推导题 | 重建模型关系 | 从状态方程得到传递函数 |
| 计算题 | 数量化和单位处理 | 计算 ADC 量化步长与输入噪声 |
| 辨析题 | 区分相近概念 | 分辨相位裕度与闭环带宽 |
| 诊断题 | 从证据筛选原因 | 根据纹波和频谱定位电源干扰 |
| 设计题 | 在约束下权衡 | 选择分流电阻和放大器增益 |
| 反例题 | 找出方法边界 | 构造虚短近似失效的运放电路 |

同一主题只做一种题，会让能力被题目格式绑定。考试、设计和调试给出的线索不同，练习也应改变信息呈现方式。

## 6. 错误分类决定下一次练什么

- **概念错误**：对象或因果关系理解不对，需要回到模型和反例；
- **条件错误**：忘记适用范围，需要在答案中显式写假设；
- **方法错误**：选错定理或模型，需要交错相似题型；
- **表示错误**：坐标、符号、单位或参考方向混乱，需要统一记号；
- **计算错误**：代数、数值或量级错误，需要短而集中的基础练习；
- **执行错误**：代码、工具设置或接线偏离推导，需要对照测试点；
- **验证错误**：答案与预期一致就停止检查，需要独立证据和反例。

错误记录和复盘方法见 [[008-错题、故障记录与工程复盘]]。

## 7. 对照多种解法时比较代价

节点法、回路法、戴维南等效和状态空间可能得到同一个结果。比较时重点看：

- 哪种表示让未知量最少；
- 哪种方法保留了需要解释的物理量；
- 哪种方法便于参数扫描或扩展；
- 哪种方法容易引入符号错误；
- 哪种结果更方便和仿真、代码或测量对照。

多解法的目的不是收集技巧，而是理解问题结构如何决定表示方式。

## 8. 工具应在独立尝试之后介入

符号计算可以检查代数，SPICE 可以检查模型行为，AI 可以生成变式题和指出遗漏。它们过早给出完整步骤时，学习者可能只剩阅读和确认。

较稳妥的流程为：

1. 独立写出已知量、模型和预期结果；
2. 尝试推导或方案，标出卡住的位置；
3. 请求工具只解释当前阻塞或检查已有过程；
4. 关闭提示后重新完成；
5. 用新参数或新场景做迁移测试。

AI 输出的验证方法见 [[009-AI辅助学习与事实核验]]，计算、仿真与实验的分工见 [[006-计算、仿真与实验怎样互相校验]]。

## 9. 练习已经足够的信号

- 延迟后仍能独立完成关键步骤；
- 混合题中能解释为什么选用当前方法；
- 参数和表示变化后仍能建立模型；
- 能预测常见错误会怎样影响结果；
- 结果可以通过另一种计算、仿真或实验核对；
- 新错误不再重复来自同一项基础缺口。

达到这些条件后，可以转入更高层的设计和项目，不需要为了完成题量继续重复同结构练习。
