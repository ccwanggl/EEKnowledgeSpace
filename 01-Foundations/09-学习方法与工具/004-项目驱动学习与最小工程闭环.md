# 项目驱动学习与最小工程闭环

项目能把分散知识放进同一个约束环境：公式要变成参数，代码要满足时序，电路要承受误差，结果还要接受测量。项目范围过大时，反馈会被装配、采购和多领域故障淹没；范围过小又可能只剩照着教程复现。

## 1. 项目从可测问题开始

“做一个电机控制器”难以直接学习。可以改写成：

- 在固定母线电压和空载条件下，让电机按给定方向稳定运行；
- 验证三相电流采样的极性、零点和比例；
- 测量电流环阶跃响应，并与模型预测比较；
- 注入编码器方向错误，记录保护和诊断行为。

每个问题都能产生具体波形、参数、日志或设计决策，失败时也更容易定位缺失知识。

## 2. 项目约定控制范围

| 项目字段 | 需要写明的内容 |
|---|---|
| 学习目标 | 这次重点训练哪项能力 |
| 交付物 | 原理图、代码、模型、测试数据或说明文档 |
| 输入条件 | 电源、负载、器件、软件版本和环境 |
| 排除项 | 本轮明确不解决的功能和性能 |
| 验收标准 | 可测的数值、行为和容差 |
| 风险 | 高能量、机械运动、器件损坏和数据丢失 |
| 证据 | 计算、仿真、编译、测试和测量记录 |
| 检查点 | 何时判断继续、缩小范围或停止 |

排除项需要写得具体。比如电流环项目可以先排除速度环、弱磁、无传感器控制和量产 EMC，这不会妨碍学习电流采样、坐标变换与 PI 调节。

## 3. 最小工程闭环

```mermaid
flowchart LR
    A["问题与规格"] --> B["模型和数量级"]
    B --> C["计算与仿真"]
    C --> D["最小实现"]
    D --> E["测量与测试"]
    E --> F["解释差异"]
    F --> G["记录决策和复现条件"]
    G -->|未通过| B
    G -->|通过| H["增加一个新约束"]
```

闭环的最小单位取决于目标。学习 RC 瞬态时，一次闭环可以在一小时内完成；验证电机电流环时，可能需要多次台架实验。关键是每轮只引入少量新变量，并留下可以判断的结果。

## 4. 四级项目梯度

| 层级 | 学习活动 | 需要避免的假进度 |
|---|---|---|
| 复现 | 按可靠资料完成并解释每一步 | 只确认现象相同，不核对条件和参数 |
| 修改 | 改参数、器件、负载或接口 | 只改外观和无关功能 |
| 独立实现 | 从规格出发选择方案并验收 | 没有基线就同时重写所有部分 |
| 组合与迁移 | 把多个子系统放进新约束 | 复杂度超过测量和诊断能力 |

从复现开始不表示机械照抄。复现阶段应记录来源版本、预期结果和与原资料的差异，并能说明关键设计选择。

## 5. 每次迭代只增加一个主要未知量

一次同时更换 MCU、功率板、电机、编码器和控制算法，失败后很难分辨原因。可以按风险和依赖安排：

1. 用已知输入验证采样与单位换算；
2. 用开环低能量激励验证相序和角度方向；
3. 闭合电流环，保持速度与负载简单；
4. 加入速度环和负载变化；
5. 再进入参数失配、弱磁或无传感器控制。

每一步保留上一阶段的回归测试。增加新功能后，旧基线仍应能够运行和复测。

## 6. 验收标准覆盖功能和边界

“电机转起来”没有覆盖方向、过流、启动、停止和异常输入。验收可以包括：

- 正常输入下的功能和稳态误差；
- 启动、停止和模式切换；
- 参数上下限、饱和与限幅；
- 传感器断线、通信超时和供电变化；
- 温升、电流和机械速度的安全边界；
- 断电再上电后的可重复性；
- 代码、配置、硬件版本和测试数据可以对应。

学习项目不必覆盖量产验证的全部项目，但要说明当前结论没有覆盖哪些边界。

## 7. 版本基线减少无效排查

建议为每次可工作的状态保存：

- 原理图与 PCB 版本；
- BOM 和器件替代记录；
- 固件提交、编译选项和配置；
- 仿真模型、参数文件和脚本；
- 仪器设置、测试接线和原始数据；
- 已知问题和通过的验收项。

Git 适合管理文本、代码和配置，大型波形与二进制文件可以用清单、校验值或外部存储关联。具体规范见 [[11-Projects/07-项目文档与Git规范/07-项目文档与Git规范|项目文档与 Git 规范]]。

## 8. 失败结果也需要可复现

项目没有达到目标时，至少留下：

- 预期现象与实际现象；
- 发生条件和复现概率；
- 已排除与尚未排除的原因；
- 关键波形、日志和测量设置；
- 失败前后的代码与硬件差异；
- 出于安全、时间或工具限制而停止的位置。

失败记录能阻止下一轮重复相同路径，也为后续学习任务提供清楚入口。写法见 [[008-错题、故障记录与工程复盘]]。

## 9. FOC 学习项目的渐进样例

| 阶段 | 最小产出 | 验收证据 |
|---|---|---|
| 变换与模型 | Clarke/Park 数值脚本 | 已知相量下的方向、幅值和逆变换误差 |
| PWM 与采样 | 定时器时序图和测试 GPIO | PWM 更新、ADC 触发与中断延迟波形 |
| 电流采样 | 零点、增益和极性标定 | 参考电流、原始码和温漂数据 |
| 开环旋转 | 受限电压下稳定转动 | 相序、角度方向、电流和速度记录 |
| 电流闭环 | $i_d$、$i_q$ 阶跃响应 | 带宽、超调、饱和与延迟对照 |
| 速度闭环 | 负载变化下保持速度 | 速度误差、电流限制和恢复过程 |
| 故障处理 | 传感器或通信故障注入 | 关断时间、锁存状态和复位条件 |

高压母线、旋转电机和再生能量的安全要求见 [[01-Foundations/07-测量与仪器基础/010-实验安全、ESD与上电流程|实验安全与上电流程]]。

## 10. 项目结束检查

- [ ] 学习目标和项目功能范围没有混淆；
- [ ] 每项验收都有对应证据和测试条件；
- [ ] 关键参数可以追溯到计算、资料或测量；
- [ ] 失败路径和未覆盖边界已经记录；
- [ ] 最后状态可以由版本和步骤复现；
- [ ] 新知识已经进入主题笔记，项目记录没有变成唯一出处；
- [ ] 下一阶段只增加少量主要未知量。

完整项目记录结构见 [[11-Projects/06-项目笔记模板/06-项目笔记模板|项目笔记模板]]。
