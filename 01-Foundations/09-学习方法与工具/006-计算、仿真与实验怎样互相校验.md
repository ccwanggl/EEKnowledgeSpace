# 计算、仿真与实验怎样互相校验

手算提供数量级和关系，仿真执行选定模型，实验观察真实对象与测量系统共同产生的结果。三者回答的问题不同。把实测波形调到与仿真完全重合，可能掩盖参数拟合、测量误差和模型遗漏；保留并解释残差更有助于判断模型能否用于设计。

## 1. 三种证据各有边界

| 方法 | 擅长回答 | 主要盲区 |
|---|---|---|
| 手算与解析模型 | 数量级、参数关系、极限情况和设计方向 | 复杂非线性、寄生和多变量耦合 |
| 数值计算与仿真 | 给定模型下的时域、频域和参数扫描 | 模型错误、参数不准、求解器与初始条件 |
| 实验测量 | 样品在当前工况下的实际行为 | 仪器负载、带宽、不确定度和样本代表性 |

仿真结果精确到很多位，只说明数值求解给出了很多位，不表示模型具备同样准确度。

## 2. 从数量级和方向开始

打开仿真工具前，至少估计：

- 输出的正负方向；
- 直流工作点；
- 时间常数、谐振频率或带宽；
- 最大电压、电流、功率和温升范围；
- 哪个参数最可能主导结果；
- 极端条件下系统应趋向什么状态。

预估为后续提供错误检测。电容充电时间常数预计为毫秒，仿真却在纳秒内完成，应检查单位、模型、初始条件和时间步长，而不是直接接受曲线。

## 3. 建立从简到繁的模型层级

```mermaid
flowchart LR
    A["理想解析模型"] --> B["加入主要损耗与延迟"]
    B --> C["加入容差、寄生和非线性"]
    C --> D["加入控制、采样与量化"]
    D --> E["与实验数据比较"]
    E --> F["只增加能解释残差的复杂度"]
```

复杂模型包含更多参数，也增加不可辨识性和配置错误。先用最小模型解释主要行为，再根据残差和任务精度增加电阻、延迟、饱和、死区、温漂或机械负载。

## 4. 仿真记录要能复现

一次可复现的仿真至少记录：

- 软件和模型版本；
- 原理图、网络表或脚本提交；
- 器件模型来源和适用范围；
- 参数值、容差和温度；
- 激励、负载、初始条件和边界条件；
- 求解器、时间步长、收敛选项和停止时间；
- 数据处理、窗函数、滤波和绘图脚本；
- 预期结果和判断标准。

截图不能保存全部设置。应优先保存工程文件、参数文件和原始数据，并让图表可以由脚本重新生成。

## 5. 数值设置可能制造现象

常见问题包括：

- 时间步长过大，漏掉快速边沿或把系统错误地变稳定；
- 仿真时间太短，尚未进入稳态；
- 默认初始条件与真实上电过程不同；
- 理想开关和理想源形成不现实的无限斜率或冲击；
- 求解器容差改变振荡、碰撞或刚性系统结果；
- FFT 窗口不含整数周期，频谱泄漏被当作杂散；
- 参数扫描只改变标称值，没有覆盖相关容差和温度。

改变时间步长、求解器或初始条件后，关键结果应保持在可解释范围内。结果随数值设置大幅变化时，先解决数值可信度。

## 6. 实验也需要测量模型

实验读数受探头输入阻抗、接地、带宽、采样率、量程和后处理影响。与仿真比较前要对齐：

- 输入激励和工作点；
- 参考节点、极性和单位；
- 测量带宽和滤波；
- 采样时刻与时间对齐；
- 传感器、探头和放大器增益；
- 环境温度、负载和样品状态；
- 仿真输出中是否包含测量链模型。

测量方法和不确定度见 [[01-Foundations/07-测量与仪器基础/001-测量任务、测量模型与实验记录|测量任务与实验记录]] 与 [[01-Foundations/07-测量与仪器基础/002-测量误差、不确定度与校准|测量不确定度]]。

## 7. 差异按来源分类

| 差异特征 | 优先检查 |
|---|---|
| 直流偏差稳定 | 参数容差、零点、负载效应、参考值和单位 |
| 幅值随频率偏离 | 模型带宽、探头负载、采样和寄生参数 |
| 相位或时间偏差 | 延迟、触发、通道去偏斜和离散实现 |
| 只在大信号出现 | 饱和、限流、死区、磁性非线性和热效应 |
| 只在启动出现 | 初始条件、时序、预充和控制状态机 |
| 偶发尖峰或丢步 | 采样混叠、数值步长、EMI、竞争和触发条件 |
| 调一个参数就能贴合所有曲线 | 检查参数是否具有物理依据，避免过拟合 |

修改模型前保存原始差异。一次同时改变多个参数，即使曲线更接近，也无法知道哪项修正有效。

## 8. 工具按问题选择

| 工具类型 | 合适任务 | 不合适的替代关系 |
|---|---|---|
| Python、NumPy、SciPy | 数据处理、参数扫描、离散算法和自动化 | 不能自动证明物理模型正确 |
| SPICE | 模拟电路、器件模型和瞬态频域分析 | 不直接代表布局、热和所有寄生 |
| MATLAB、Octave | 控制、信号处理、矩阵与系统级仿真 | 高层模型不能替代功率器件验证 |
| 电磁或热仿真 | 场分布、热阻和结构耦合 | 依赖材料、网格和边界条件 |
| HIL 或实时仿真 | 控制器时序、接口和故障注入 | 不能覆盖实际功率级全部失效模式 |
| 实验台架 | 样机性能、异常和测量证据 | 单个样品不能代表全容差与全环境 |

## 9. FOC 验证链示例

1. 从电机方程和控制目标估算电流环带宽与采样要求；
2. 用连续模型检查参数关系和稳定裕度；
3. 加入离散采样、计算延迟、限幅和反积分饱和；
4. 加入逆变器死区、母线变化、传感器偏置和量化；
5. 用软件单元测试检查坐标变换与限幅；
6. 用受限能量台架测量采样时序、开环方向和电流比例；
7. 逐步闭环，比较阶跃、频率响应和故障条件；
8. 对无法解释的残差建立新假设和独立测试。

模型通过一次波形对照后仍要检查其他工作点。只在单一速度和负载下拟合的参数，可能无法用于启动、弱磁和温升后的系统。

- [ ] 关键结果不依赖未解释的数值设置；
