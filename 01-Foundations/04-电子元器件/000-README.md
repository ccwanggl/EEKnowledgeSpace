# 电子元器件

## 1. 主线：从端口关系走向完整电路

```mermaid
flowchart LR
    A["001 电阻<br/>耗散与比例"] --> B["002 电容<br/>电场储能"]
    B --> C["003 电感<br/>磁场储能"]
    C --> D["004 二极管<br/>PN 结与单向非线性"]
    D --> E["005 BJT<br/>偏置、放大与开关"]
    E --> F["006 MOSFET<br/>栅极驱动与功率开关"]
    F --> G["007 运算放大器<br/>差分输入与负反馈"]
    G --> H["008 线性稳压器<br/>基准、反馈与热设计"]
    H --> I["009 继电器与机电元件<br/>电气和机械接口"]
```

这条顺序包含三层依赖：

1. 电阻、电容和电感建立代数关系、微分关系、阻抗、储能与损耗的共同语言；
2. 二极管、`BJT` 和 `MOSFET` 引入非线性、偏置、工作区、驱动与热限制；
3. 运算放大器、稳压器和继电器把前述器件组合成可直接承担功能的电路单元。

## 3. 按目标选择路径

### 3.1 完整基础路径

[[001-电阻]] → [[002-电容]] → [[003-电感]] → [[004-二极管]] → [[005-BJT晶体管]] → [[006-MOSFET]] → [[007-运算放大器]] → [[008-稳压器]] → [[009-继电器与机电元件]]

### 3.2 模拟电路路径

[[001-电阻]] → [[002-电容]] → [[004-二极管]] → [[005-BJT晶体管]] → [[006-MOSFET]] → [[007-运算放大器]] → [[008-稳压器]]

这条路径重点关注偏置、小信号模型、反馈、噪声、失真和电源完整性。电感可在滤波、振荡或电源设计需要时补学。

### 3.3 电源与功率电子路径

[[001-电阻]] → [[002-电容]] → [[003-电感]] → [[004-二极管]] → [[006-MOSFET]] → [[008-稳压器]]

本模块只讲器件行为和基础选型。完整变换器拓扑、控制环路、磁性元件设计和 PCB 功率回路应进入电源管理与电力电子专题。

### 3.4 嵌入式硬件路径

[[001-电阻]] → [[002-电容]] → [[004-二极管]] → [[005-BJT晶体管]] / [[006-MOSFET]] → [[007-运算放大器]] → [[008-稳压器]] → [[009-继电器与机电元件]]

重点是上拉与限流、去耦、输入保护、负载驱动、模拟采样、供电和外部连接。

### 3.5 FOC 硬件路径

[[001-电阻]] → [[002-电容]] → [[003-电感]] → [[004-二极管]] → [[006-MOSFET]] → [[007-运算放大器]] → [[008-稳压器]] → [[009-继电器与机电元件]] → [[14-FOC-电机控制/00-README|FOC 电机控制]]

这条路径对应电流采样、电源去耦与直流母线、电机绕组、续流路径、三相逆变桥、采样放大、控制电源和上电隔离。BJT 不是主功率器件，但理解其偏置和开关方式有助于阅读驱动与接口电路。

## 4. 三组需要分清的边界

### 4.1 理想模型与真实器件

理想关系用于建立电路方程，数据手册用于判断器件能否在实际条件下工作。$V=IR$、$i=C\,dv/dt$、$v=L\,di/dt$ 都不包含温度、寄生参数、额定值和失效模式，不能单独承担选型结论。

### 4.2 典型值、保证值与绝对最大额定值

- 典型值描述某组测试条件下的常见表现，不保证每颗器件都达到；
- 最小值和最大值通常是设计应使用的保证边界，但仍要满足表格中的测试条件；
- 绝对最大额定值是不可越过的损伤边界，不是推荐工作点。

### 4.3 器件选型与系统设计

本模块回答“器件本身怎样工作、关键参数怎样读”。滤波器、放大器、变换器、驱动器和保护网络的系统级设计仍需结合电路分析、信号与系统、控制理论、热设计、EMC 和安全规范。

## 5. 通用读表与选型流程

1. 写清端口条件：电压、电流、频率、占空比、源阻抗、负载和启动/故障状态。
2. 计算工作点和损耗，区分稳态、瞬态、峰值与均方根值。
3. 核对保证参数和适用条件，不用典型值替代最坏情况。
4. 同时检查电气、热、机械、寿命和环境约束。
5. 按实际 PCB、散热和控制方式仿真或搭样验证，测量时保留探头和夹具带来的寄生参数。

> [!warning] 降额不是固定百分比
> “统一留 20%”或“功率乘 1.5”只能作早期估算。最终裕量取决于器件类别、温度、寿命目标、瞬态波形、失效后果和适用标准。
