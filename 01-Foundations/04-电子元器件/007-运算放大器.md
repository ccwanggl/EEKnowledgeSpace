# 运算放大器（Op-Amp）

> **前置知识**：[[001-电阻]]、[[002-电容]]、[[005-BJT晶体管]]、[[006-MOSFET]]，以及基尔霍夫定律和负反馈。

## 1. 开环关系只有在输出未饱和时才有意义

运放对两个输入端的差模电压进行高增益放大：

$$V_o=A_{OL}(V_+-V_-)$$

开环增益 $A_{OL}$ 很大，但输出受电源轨、输出级电流和频率响应限制。没有负反馈时，极小的输入差分电压也可能把输出推到正或负饱和，运放更接近比较器而不是线性放大器。

理想运放分析常使用：

- 开环增益无限大；
- 输入电流为零；
- 输出阻抗为零；
- 带宽和压摆率无限；
- 输入失调、噪声和共模增益为零。

这些假设用于推导电路关系，选型和调试必须回到真实参数。

## 2. 负反馈建立“虚短”，工作条件不能省略

当输出通过负反馈回到反相输入端，闭环稳定且输出没有饱和时，高开环增益会使：

$$V_+\approx V_-$$

理想输入电流近似为零：

$$I_+\approx I_-\approx0$$

这两条分别称为虚短和虚断。它们不表示两个输入端真的短接，也不表示所有运放输入电流都为零。

“虚地”是更窄的情形：某个输入端接地，负反馈使另一个输入端电位近似为 0 V。该节点没有直接接地，不能承担任意外部电流。输入超出共模范围、输出触及电源轨、带宽不足或反馈变成正反馈时，虚短和虚地都不再成立。

## 3. 反相放大器的输入阻抗由输入电阻决定

![[01-Foundations/assets/op-amp-inverting-amplifier.jpg|1500]]
*同相端接参考电位，输入信号经 $R_{in}$ 注入反相节点。单电源电路中的参考电位可能是中点基准，而不是 0 V。来源：All About Circuits，The Inverting Configuration of an Amplifier。*

理想闭环增益为：

$$A_v=\frac{V_o}{V_i}=-\frac{R_f}{R_{in}}$$

输入阻抗约为 $R_{in}$。反相结构可方便地实现加法、跨阻和有源滤波，但源电阻、输入偏置电流、运放输入电容与反馈电阻都会产生额外误差和极点。

噪声增益不是信号增益的绝对值，而是把输入源置零后反馈网络形成的：

$$NG=1+\frac{R_f}{R_{in}}$$

稳定性和带宽判断应使用噪声增益。

## 4. 同相放大器提供较高输入阻抗

![[01-Foundations/assets/op-amp-non-inverting-amplifier.webp|1500]]
*信号接同相端，反相端使用 $R_f$ 与 $R_g$ 设置反馈比例。来源：ElectronicsHub，Non-Inverting Operational Amplifiers。*

理想闭环增益为：

$$A_v=1+\frac{R_f}{R_g}$$

同相端输入阻抗主要由运放输入级和偏置网络决定。输入源必须落在允许共模范围内，输出也要在目标负载下保留摆幅。标注“轨到轨输入/输出”仍需查看对应电源、负载和温度下能接近电源轨多少。

### 4.1 电压跟随器是单位增益同相结构

![[01-Foundations/assets/op-amp-voltage-follower.webp|1500]]
*输出直接反馈到反相端，闭环增益为 1。来源：ElectronicsHub，Voltage Follower Circuit。*

跟随器可隔离高阻信号源与较低阻负载，但不是任意运放都能在单位噪声增益下稳定。驱动 ADC 采样电容、长电缆或大电容负载时，还要检查瞬态输出电流和相位裕度，必要时使用隔离电阻、RC 网络或专用 ADC 驱动器。

## 5. 七类非理想参数经常先于直流增益成为限制

| 参数 | 说明 | 对电路的影响 |
|---|---|---|
| 输入共模范围 | 两个输入端允许的共模电压区间 | 超出后可能失真、相位反转或失去控制 |
| 输出摆幅和输出电流 | 指定负载下可达到的输出范围 | 决定能否驱动负载及接近电源轨 |
| 输入失调电压 | 使输出归零所需的等效差分电压 | 直流精度误差，按噪声增益放大 |
| 输入偏置电流 | 流入或流出输入端的直流电流 | 与源电阻形成额外失调 |
| 增益带宽积（GBW） | 单极点近似下增益与带宽的乘积 | 闭环增益越高，带宽通常越低 |
| 压摆率（SR） | 输出电压最大变化速率 | 大信号高频时产生转换速率失真 |
| CMRR、PSRR | 抑制共模与电源扰动的能力 | 影响采样共模变化和电源纹波耦合 |

### 5.1 小信号带宽和大信号带宽不是一回事

单极点、稳定闭环条件下可粗略估算：

$$f_{BW}\approx\frac{GBW}{NG}$$

正弦输出不发生压摆率限制时：

$$SR\ge2\pi fV_{pk}$$

一个运放可能在小信号频响上满足带宽，却在大幅度信号下因压摆率不足而失真。

## 6. 噪声和直流误差要沿噪声增益计算

运放噪声包含输入电压噪声、输入电流噪声和低频 $1/f$ 噪声，外围电阻还产生热噪声。总输出噪声应按各噪声源的传递函数和测量带宽做均方根合成，不能把数据手册首页的单个噪声密度直接当作输出噪声。

直流误差预算通常包含：

- 输入失调电压及温漂；
- 输入偏置电流乘以源等效电阻；
- 电阻容差、温度系数和自热；
- 有限开环增益造成的闭环增益误差；
- 输出负载和输入共模对参数的影响。

在反相结构中，可让同相端看到接近 $R_{in}\parallel R_f$ 的直流电阻，以减小两输入偏置电流相近时的误差；对偏置电流不匹配较大的输入级，这种补偿不能消除全部误差。

## 7. 稳定性取决于环路，而不只取决于运放型号

负反馈环路在增益交越附近的相位裕度不足会产生振铃或振荡。常见诱因包括：

- 使用非单位增益稳定运放做电压跟随器；
- 大电容负载在输出端引入额外极点；
- 反相节点寄生电容与大反馈电阻形成极点；
- 供电去耦和接地回路过长；
- 高速输出耦合回高阻输入节点；
- PCB 焊剂残留和保护器件增加输入电容或漏电。

判断稳定性应查看数据手册推荐噪声增益、容性负载曲线、建立时间和参考布局。示波器上持续振荡、阶跃过冲和长时间振铃都可能提示相位裕度不足。

## 8. FOC 电流采样对运放提出额外要求

分流电阻输出通常只有几十毫伏，并叠加快速 PWM 共模变化。采样放大器需要同时满足：

1. 输入共模范围覆盖低侧、母线或相电流采样位置；
2. 共模瞬态抑制和建立时间满足 PWM 后的采样窗口；
3. 输入失调与温漂不占用过多电流测量量程；
4. 带宽足以跟踪控制信号，又能配合 RC 滤波抑制开关尖峰；
5. 输出范围与 ADC 输入范围、采样电容和参考电压匹配；
6. 输入保护在故障时限制电流，同时不过度增加正常工作的误差和恢复时间。

通用运放未必能在高 $dv/dt$ 的相电流采样中替代专用电流检测放大器。器件选择要根据采样拓扑和共模波形决定。

## 9. 选型与调试顺序

1. 确定电源、电压基准、输入共模、输出摆幅和负载。
2. 根据闭环噪声增益确定所需 GBW、单位增益稳定性和压摆率。
3. 根据直流误差预算选择失调、偏置电流、温漂和开环增益。
4. 根据源阻抗和带宽选择电压噪声、电流噪声与外围电阻。
5. 检查容性负载、建立时间、过载恢复、输入保护和电源时序。
6. 每个电源脚就近去耦，保持反相节点紧凑，并让输出大电流回路避开输入参考地。
7. 调试时先确认供电和静态工作点，再观察输入差分电压、输出是否饱和、是否振荡以及负载电流。

常见型号只能作为检索入口：LM358 适合许多低速单电源场景，但不是轨到轨输出；TL072 具有 JFET 输入，但低压单电源能力有限；LM741 主要适合学习经典双电源电路，不应作为现代低压通用默认选择。最终以具体后缀、供电条件和数据手册保证参数为准。

> [!warning] 常见误区
> - 虚短、虚断和虚地都有负反馈、稳定和未饱和条件。<br>
> - “轨到轨”不表示输入和输出在任意负载下都能精确到达电源轨。<br>
> - GBW 足够不代表大信号带宽足够，还要检查压摆率和建立时间。<br>
> - 输出能达到目标电压不代表能提供目标电流，负载会改变摆幅、失真和温升。
