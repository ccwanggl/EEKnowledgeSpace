# ADC 与 DAC 基础

ADC 把连续时间、连续幅值的模拟信号转换为数字码；DAC 把数字码转换为模拟电压或电流。转换器位于模拟前端、时钟、基准、电源、数字接口和算法的交界处，系统性能通常受整条信号链共同限制。

## 选型起点

| 场景 | 常见起点 | 主要约束 |
|---|---|---|
| 低带宽桥式传感器、称重 | ΔΣ 或积分型 ADC | 输入噪声、漂移、工频抑制、延迟 |
| 通用多通道数据采集 | SAR ADC | 建立时间、通道切换、吞吐率 |
| 电机相电流采样 | SAR 或隔离式 ΔΣ | PWM 同步、延迟、共模瞬变、采样窗口 |
| 音频 | 音频 ΔΣ ADC/DAC | 动态范围、失真、群延迟、接口时钟 |
| 通信、成像和高速仪器 | Pipeline 或时间交织 ADC | 模拟带宽、时钟抖动、功耗、接口带宽 |
| 精密直流输出 | 电阻串或 R-2R DAC | INL、单调性、温漂、输出缓冲 |
| 高频波形合成 | 电流舵 DAC | 更新率、SFDR、毛刺、重建滤波 |

架构名称只能缩小候选范围，最终选择仍要回到数据手册的输入范围、噪声、延迟、参考要求、接口和工作温度。
