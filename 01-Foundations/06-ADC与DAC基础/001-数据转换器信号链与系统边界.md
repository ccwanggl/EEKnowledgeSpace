# 数据转换器信号链与系统边界

转换器不能脱离前后级单独评价。ADC 的输入是否建立、参考端是否稳定、采样时刻是否正确，都会改变最终数字码；DAC 的参考、输出负载和重建滤波器也会改变模拟输出。

## 1. ADC 信号链

```mermaid
flowchart LR
    A["传感器或模拟输入"] --> B["保护与偏置"]
    B --> C["放大和电平转换"]
    C --> D["模拟抗混叠滤波"]
    D --> E["ADC 驱动与采样保持"]
    E --> F["量化与编码"]
    F --> G["数字接口或 DMA"]
    G --> H["校准、滤波与算法"]
```

每一级都有不同的限制：

| 环节 | 主要问题 |
|---|---|
| 传感器 | 输出范围、源阻抗、带宽、共模和噪声 |
| 保护 | 漏电、电容、钳位电流和故障能量 |
| 放大与偏置 | 增益误差、失调、噪声、输出摆幅和稳定性 |
| 抗混叠 | 阻带衰减、过渡带、相位和建立时间 |
| ADC 驱动 | 采样电容充电、差分共模、参考瞬态 |
| 转换器 | 静态误差、动态性能、延迟和失码 |
| 数字链路 | 吞吐率、数据格式、时钟域和丢样 |
| 算法 | 标定、滤波延迟、饱和和单位换算 |

## 2. DAC 信号链

```mermaid
flowchart LR
    A["数字样值"] --> B["插值、缩放和限幅"]
    B --> C["数字接口与锁存"]
    C --> D["DAC 核心"]
    D --> E["输出缓冲或电流电压转换"]
    E --> F["重建滤波"]
    F --> G["负载"]
```

DAC 的数字码正确，不代表负载端电压正确。还要检查输出顺从范围、建立时间、毛刺、负载电容、缓冲器稳定性和参考源负载。

## 3. 从应用指标反推转换器要求

系统需求应先写成可验证的量：

- 信号范围、共模范围和允许过载；
- 有效带宽和带外干扰频谱；
- 允许的总 RMS 噪声、偏置和增益误差；
- 允许延迟、通道间时间偏差和更新周期；
- 温度、电源、隔离与共模瞬变条件；
- 接口带宽、功耗和校准能力。

标称位数不是需求。若系统要求在 $0\sim10\ \text V$ 范围分辨 $1\ \text{mV}$，需要先计算码宽，再为噪声、INL、基准误差和前端误差留余量。

## 4. 连续时间、离散时间和数字码

ADC 依次完成三个概念上不同的动作：

1. 在离散时刻观察连续信号，得到采样值；
2. 把采样值映射到有限个幅值区间，完成量化；
3. 用约定格式表示量化结果，完成编码。

采样造成时间离散，量化造成幅值离散。数字码还需要结合输入范围、极性和编码格式解释。

DAC 的方向相反，但输出通常经过零阶保持，在相邻更新时刻之间保持一个码值。其频谱镜像和 sinc 包络属于 [[01-Foundations/05-信号与系统/010-采样、混叠与重建|采样与重建理论]]，本目录主要讨论器件和信号链实现。

## 5. 吞吐率、更新率和延迟不是同一指标

- 采样率：ADC 每秒取得多少个输入样值；
- 输出数据率：数字接口每秒提供多少个结果；
- 吞吐率：连续工作时单位时间可完成多少次有效转换；
- 延迟：从物理采样时刻到对应结果可用的时间；
- DAC 更新率：每秒可锁存多少个新码；
- 建立时间：DAC 码更新后，模拟输出进入指定误差带所需时间。

流水线和 ΔΣ ADC 的吞吐率可以很高，但单个样值延迟不一定小。实时控制必须使用延迟，而不能只看每秒样值数。

## 6. 单端、伪差分和全差分接口

单端输入相对地测量，连接简单，但容易受地电位差和共模噪声影响。伪差分输入允许负端在有限范围内变化；全差分输入同时规定差分幅值和共模电压：

$$
v_d=v_p-v_n,
\qquad
v_{cm}=\frac{v_p+v_n}{2}.
$$

满足差分范围不代表满足共模范围。驱动电路必须同时保证 $v_d$、$v_{cm}$、输入过压和采样瞬态都符合数据手册。

## 7. 参考源属于信号通道

在比例型转换器中，输入结果本质上是 $V_{in}/V_{ref}$ 的测量。参考噪声、温漂和瞬态阻抗会直接调制码值。若传感器和 ADC 共用同一激励作为参考，可形成比例测量并抵消部分绝对参考误差，但仍要检查激励负载、布线压降和通道匹配。

## 8. 系统边界检查

- ADC 前的模拟滤波不能由采样后的数字滤波完全替代；
- 前端驱动误差会被 ADC 记录，无法靠增加标称位数消除；
- DAC 后的缓冲和滤波是输出精度的一部分；
- 数字平均可降低随机噪声，不能自动修复失调、增益误差或 INL；
- 软件标定只在校准条件和模型有效范围内成立；
- 隔离器、数字接口和控制算法引入的延迟应纳入系统模型。
