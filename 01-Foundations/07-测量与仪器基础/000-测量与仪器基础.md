# 测量与仪器基础

测量不是把探头接上去读一个数，而是用有限带宽、有限精度并且会扰动电路的仪器，对某个明确的物理量作出有边界的判断。可信的结果需要同时说明测了什么、怎样连接、仪器如何设置、结果有多大不确定度，以及测量是否改变了被测对象。

## 从问题选择仪器

| 想回答的问题 | 常用仪器 | 容易漏掉的限制 |
|---|---|---|
| 某节点的直流电压是否正确 | 万用表 | 输入阻抗、量程、共模与安全等级 |
| 电压或电流怎样随时间变化 | 示波器与合适探头 | 带宽、采样率、探头负载、接地 |
| 数字接口是否按协议传输 | 逻辑分析仪 | 阈值、采样率、毛刺和模拟信号质量 |
| 电源在动态负载下是否稳定 | 示波器、电子负载 | 接线电感、负载跃变速度、测量点 |
| 谐波、杂散或噪声位于哪些频率 | 频谱分析仪 | 最大输入、RBW、衰减、前置放大器 |
| 滤波器或传输网络怎样改变信号 | 网络分析仪 | 校准面、端口阻抗、夹具与动态范围 |
| 电阻、电容或电感的真实参数是多少 | LCR 表、阻抗分析仪 | 测试频率、电平、直流偏置和等效模型 |
| 毫欧级电阻或分流器压降是多少 | 四线电阻表、微欧计 | 热电势、测试电流、引线布置和自热 |

仪器名称只决定大致方向。最终选择还要核对被测信号的幅度、带宽、源阻抗、共模电压、瞬态能量和允许扰动。

## 一次完整测量需要留下什么

- 被测量及其参考节点；
- 原理图、板卡版本、工作状态和环境条件；
- 仪器、探头、附件、校准状态和关键设置；
- 量程、带宽限制、采样率、记录长度与平均方式；
- 原始数据、处理方法、单位和不确定度；
- 预期值、判定标准、异常现象和复测结果。

截图只保存显示结果，不能替代设置和连接记录。波形一旦离开测量上下文，通常无法判断它来自真实电路、探头负载还是错误的采集设置。
