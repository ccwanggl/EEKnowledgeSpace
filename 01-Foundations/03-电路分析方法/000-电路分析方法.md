# 电路分析方法

电路基础理论回答“元件和基本定律是什么”，本目录回答“面对一个具体电路，怎样选择变量、建立方程并验证结果”。学习顺序从静态电阻网络开始，再进入端口等效、动态电路和正弦稳态。

## 学习路线

```mermaid
flowchart LR
    A["分析流程与结果校验"] --> B["等效变换"]
    B --> C["节点法与网孔法"]
    C --> D["线性电路定理"]
    D --> E["端口等效与负载匹配"]
    E --> F["一阶与二阶动态电路"]
    F --> G["正弦稳态与交流功率"]
    G --> H["方法选择与仿真验证"]
```

### 先建立可靠的分析过程

1. [[001-分析流程、参考方向与结果校验]]：明确目标、假设、参考方向和结果校验方法。
2. [[002-等效变换与源变换]]：在保留端口特性的前提下缩小电路。
3. [[003-节点电压法与改进节点法]]：以节点电压为未知量，适合节点较少或包含较多电流源的电路。
4. [[004-网孔电流法与支路法]]：以回路或支路电流为未知量，适合平面网络和电压源较多的电路。

### 再学习降低问题规模的定理

5. [[005-叠加、替代与拓扑定理]]：理解线性、叠加、替代、互易和 Tellegen 定理的适用边界。
6. [[006-戴维南、诺顿与端口等效]]：把线性二端网络压缩为一个源和一个等效阻抗。
7. [[007-最大功率传输与负载匹配]]：区分直流匹配、交流共轭匹配和效率约束。

### 最后进入动态和交流分析

8. [[008-一阶动态电路分析]]：用初始值、终值和时间常数求解 RC、RL 电路。
9. [[009-二阶RLC电路分析]]：从特征根和阻尼解释 RLC 瞬态。
10. [[01-Foundations/03-电路分析方法/010-正弦稳态相量分析|正弦稳态相量分析]]：把单频正弦稳态问题转化为复数代数问题。
11. [[011-交流功率、谐振与阻抗匹配]]：分析复功率、功率因数、谐振和交流负载匹配。
12. [[012-方法选择、错误诊断与仿真验证]]：根据拓扑、激励和目标选择方法，形成计算与仿真的验证闭环。

## 一张表选择起点

| 问题特征 | 优先考虑 | 入口 |
|---|---|---|
| 节点少、电流源多、含非接地电压源 | 节点法、超节点或 MNA | [[003-节点电压法与改进节点法]] |
| 平面电路、网孔少、电压源多 | 网孔法或超网孔 | [[004-网孔电流法与支路法]] |
| 只关心某个负载端口 | 戴维南或诺顿等效 | [[006-戴维南、诺顿与端口等效]] |
| 多个独立源，需要区分各源贡献 | 叠加定理 | [[005-叠加、替代与拓扑定理]] |
| 一阶换路过程 | 三要素法 | [[008-一阶动态电路分析]] |
| 二阶 RLC 瞬态 | 特征根与阻尼分类 | [[009-二阶RLC电路分析]] |
| 单频正弦稳态 | 相量法 | [[01-Foundations/03-电路分析方法/010-正弦稳态相量分析|正弦稳态相量分析]] |
| 结果可疑或仿真不一致 | 分层校验 | [[012-方法选择、错误诊断与仿真验证]] |
