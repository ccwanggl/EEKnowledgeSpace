# 推荐资源

> 围绕 Linux 设备驱动开发，与 [[12-Resources/00-README|12-Resources]] 的完整资源列表互为补充。

## 官方文档

| 资源 | 内容 | 适用 |
|------|------|------|
| **Kernel Driver API 手册** | kernel.org `Documentation/driver-api/`：GPIO、I2C、SPI、regmap、时钟、pinctrl、中断子系统的 API 权威说明 | 全部驱动笔记，写代码时查 API 语义 |
| **内核源码树文档** | `Documentation/devicetree/bindings/`：每个子系统的 dts 绑定规范；`Documentation/trace/`：ftrace/dynamic debug 完整文档 | [[004-设备树开发]]、[[008-驱动调试排错]]，写 dts 前必查绑定 |
| **Bootlin Elixir** | elixir.bootlin.com：任意内核版本的源码交叉索引，比本地 grep 快 | 查函数定义、结构体字段、版本差异（如 `class_create`、`remove` 签名变化） |
| **LWN.net** | 内核社区深度文章，驱动模型演进背景 | [[003-Linux设备模型]]"为什么这样设计" |

## 书籍

| 书籍 | 作者 | 级别 | 适用内容 |
|------|------|------|----------|
| **《Linux Device Drivers》第 3 版** | Corbet / Rubini / Kroah-Hartman | 中级~高级 | 字符设备、内存映射、中断的**经典体系**；基于 2.6 内核，API 有年代差异但模型不变，免费在线（lwn.net） |
| **《Linux设备驱动开发详解》** | 宋宝华 | 中级 | 中文驱动教材覆盖面最全，含设备树、平台设备、中断体系；对应 002–007 篇（中文） |
| **《Linux内核设计与实现》** | Robert Love | 中级 | 内核机制（调度、内存、同步）背景，理解驱动运行环境 |
| **《嵌入式Linux驱动开发实践》** | 各类 RK/全志平台实战书 | 初级~中级 | 平台化流程参考，注意甄别内核版本 |

## 课程与培训

| 资源 | 形式 | 特点 |
|------|------|------|
| **Bootlin 培训材料** | 免费 PDF/视频 | 内核驱动开发培训的完整讲义与实验（有中文社区翻译），实验设计可直接搬到 RK 板 |
| **内核文档《Writing a Linux kernel module》** | 官方文档 | [[001-开发环境与内核模块]] 的延伸阅读，含字符设备完整教学例子 |
| **正点原子/野火 RK 驱动教程** | Bilibili/手册 | 中文 RK 平台（RK3568/RK3588）驱动实操视频，dts、pinctrl、GPIO、I2C 章节与 004、006、007 对应（中文） |

## 工具与速查

| 工具 | 用途 |
|------|------|
| `i2c-tools` / `gpiod` | 用户态总线与 GPIO 验证（007、006 篇的先行步骤） |
| `dtc` | dts↔dtb 编译反编译、overlay 制作（004 篇） |
| `trace-cmd` / KernelShark | ftrace 图形前端（008 篇） |
| `addr2line` / `decode_stacktrace.sh` | oops 定位（008 篇） |
| `checkpatch.pl` / `sparse` / coccinelle | 风格与静态检查门禁（009 篇） |
| RK 官方 TRM（技术参考手册） | RK3588 寄存器级手册：GPIO bank、pinmux、时钟树细节，dts 管脚配置的最终依据（瑞芯微官网/论坛获取） |
