# Linux 设备驱动开发（16-Linux设备驱动开发）

> MCU 的"驱动"是操作寄存器的 C 函数，Linux 的"驱动"是挂接在内核设备模型上的模块：设备树描述硬件、总线负责匹配、probe 收取资源、文件接口面向用户态。本章节按九节体系组织，以 RK3588 开发板为实验平台，兑现 [[10-RTOS与系统/05-嵌入式Linux入门/007-学习路径以RK3588为核心平台|嵌入式 Linux 学习路径]]阶段三"驱动与接口开发"的全部内容。
