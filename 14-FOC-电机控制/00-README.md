## 工程目标

完成本微专业后，你应该能够：

1. 独立推导 PMSM 在 abc/αβ/dq 坐标系下的电压和转矩方程
2. 设计电流环和速度环 PI 参数，理解稳定性约束
3. 手工计算 SVPWM 的扇区判断和占空比
4. 在 STM32 上实现 50μs 电流环，包含 Clarke/Park/逆变换/SVPWM
5. 实现无传感器 SMO 或 HFI，完成开环→闭环切换
6. 测量或辨识 $R$、$L_d$、$L_q$、$K_e$、$J$、$B$ 等模型参数，并说明测试条件、模型假设和不确定度
7. 调试并解决振动、噪声、过流、温升等典型问题
8. 针对伺服/机器人/EV/无人机场景做系统选型和设计
