> **本篇解决的问题**：FOC 采样到的 $i_a,i_b,i_c$ 分别代表什么？绕组的 $120°$ 与波形的 $120°$ 是否是一回事？逆变器输出的极点电压、绕组相电压和线电压又该如何区分？

在 FOC 的起点，所有电流、电压和磁链都先写在固定不转的 $abc$ 自然坐标系中。它不是“落后的三维表示”，而是传感器、绕组和逆变器实际接触到的语言；理解它，才能知道后续 Clarke 变换究竟省去了什么、保留了什么。

## 1. 先分清：空间轴、时间波形与变量

### 1.1 $abc$ 自然坐标系是什么

$a$、$b$、$c$ 轴分别与三相定子绕组的磁轴重合，彼此在**空间**相差 $120°$ 电角度。它们固定在定子上，因此也称三相静止坐标系。

![[14-FOC-电机控制/assets/abc_coordinate_system.png|1500]]
*图：三相定子绕组的空间磁轴；通常约定 $a$ 轴为参考轴。*

对任意三相量 $x\in\{i,u,\psi\}$，可写为 $x_a,x_b,x_c$。例如平衡正序电流常用约定为：

$$
\begin{aligned}
i_a&=I_m\cos\omega_e t\\
i_b&=I_m\cos(\omega_e t-120°)\\
i_c&=I_m\cos(\omega_e t+120°)
\end{aligned}
$$

这里的相序是 $a\to b\to c$；若项目采用相反相序或正弦而非余弦作为参考，公式中的正负号会相应变化。**先声明相序和电压极性，再比较相位。**

### 1.2 两个 $120°$，不要混为一谈

![[14-FOC-电机控制/assets/abc_waves_on_axes.png|1500]]
*图：把三条时间波形贴在各自空间轴上的教学示意。径向位置用于展示波形幅值，并不代表电机中真实的第三个空间坐标。*

| 概念 | 表示什么 | 是否随时间改变 |
|---|---|---|
| 绕组空间夹角 | 三个线圈磁轴的相对位置 | 否 |
| 时间相位差 | 同频正弦量在同一时刻的相对相位 | 是，随电角度推进 |

在对称正序基波条件下，两者数值都写成 $120°$，这是三相绕组分布与三相激励相配合的结果，不代表它们是同一个量。

### 1.3 三线制下只有两个独立电流

对常见的三相三线、星形绕组且中性点没有外部回流通道的 FOC 驱动，有：

$$i_a+i_b+i_c=0$$

因此可由两个采样值重构第三相：$i_c=-(i_a+i_b)$。定义零序电流

$$i_0=\frac{i_a+i_b+i_c}{3}$$

便知理想三线制中 $i_0=0$。这条约束并非所有接法都成立：有中线、对地泄漏、传感器偏置、故障电流或特殊绕组连接时，应先检查零序通路，而不能强行重构第三相。

## 2. 三种电压名称必须分开

| 名称 | 记号与定义 | 典型用途 |
|---|---|---|
| 极点电压 | $v_{aN},v_{bN},v_{cN}$：桥臂中点相对直流母线负端 $N$ | PWM 与逆变器开关状态 |
| 绕组相电压 | $u_a=v_{aN}-v_{nN}$ | 电机绕组电压方程 |
| 线电压 | $u_{ab}=u_a-u_b=v_{aN}-v_{bN}$ | 线间测量、SVPWM 分析 |

其中 $n$ 是电机星点。对理想对称、浮置星点，可近似得到：

$$v_{nN}=\frac{v_{aN}+v_{bN}+v_{cN}}{3},\qquad u_a=v_{aN}-v_{nN}$$

这说明浮置星点会随开关状态移动；但线电压中星点电位相消，所以 $u_{ab}$ 不依赖 $v_{nN}$。零矢量 $000$ 或 $111$ 时，线电压均为零，却仍会产生不同的共模电压——二者不能混淆。

对于平衡正弦量，$U_{LL,\mathrm{rms}}=\sqrt3U_{ph,\mathrm{rms}}$。在本文的 $a-b-c$ 相序及余弦约定下，$u_{ab}$ 相对 $u_a$ 超前 $30°$；改变相序或极性定义时，此表述也会改变。

## 3. 从三相量到旋转磁场

每相绕组沿自己的空间轴产生磁动势。只保留基波时，三相磁动势的合成可写成空间矢量：

$$
\underline f_s=\frac{2}{3}\left(f_a+f_be^{j2\pi/3}+f_ce^{-j2\pi/3}\right)
$$

![[14-FOC-电机控制/assets/foc_mmf_composition.png|1500]]
*图：三相基波磁动势的矢量合成。平衡正序激励时，合成矢量近似以恒定幅值旋转。*

这正是“看似有三个量、实际用二维平面描述”的物理原因。下一篇 [[002-Clarke变换与等幅值等功率变换]] 会在此基础上给出 $\alpha,\beta$ 投影、零序项和等幅值/等功率两套规范化；本篇不重复推导系数。

## 4. $abc$ 电压方程：控制模型的原始形式

逐相绕组都满足：

$$u_k=R_si_k+\frac{d\psi_k}{dt},\qquad k\in\{a,b,c\}$$

其中磁链包含电感耦合与永磁体磁链。以 PMSM 的基波模型为例，永磁体部分随转子电角度 $\theta_e$ 投影到三相绕组：

$$
\boldsymbol\psi_{pm}=\psi_f
\begin{bmatrix}
\cos\theta_e\\
\cos(\theta_e-120°)\\
\cos(\theta_e+120°)
\end{bmatrix}
$$

完整的电感矩阵、凸极效应与反电动势将在 [[004-PMSM电压方程与磁链模型]] 展开。本篇只需记住：$abc$ 方程直接对应三相绕组，而 $dq$ 方程是为了控制便利而做的坐标变换，并没有改变物理电机。

## 5. 两个快速核对例子

### 5.1 线电压与浮置中性点

若绕组相电压为 $(u_a,u_b,u_c)=(220,-110,-110)\ \mathrm V$，则：

$$u_{ab}=330\ \mathrm V,\quad u_{bc}=0\ \mathrm V,\quad u_{ca}=-330\ \mathrm V$$

这与另一组桥臂极点电压 $(v_{aN},v_{bN},v_{cN})=(220,0,0)\ \mathrm V$ 不是同一件事。后者的浮置星点为 $v_{nN}=73.3\ \mathrm V$，实际绕组相电压才是 $(146.7,-73.3,-73.3)\ \mathrm V$；线电压仍为 $(220,0,-220)\ \mathrm V$。

### 5.2 三相电流和

令 $I_m=26.9\ \mathrm A$、$\omega_et=302.5°$，按上一节余弦约定可得近似：

$$i_a=-22.7\ \mathrm A,\quad i_b=-1.17\ \mathrm A,\quad i_c=23.9\ \mathrm A$$

三者相加约为零。该例只验证三线制约束；电机实际电压还会包含电阻压降、电感压降和反电动势，不能把简单 $RL$ 负载公式直接当作 PMSM 工作点。

## 6. 与控制软件对应的最小实现

以下代码仅覆盖三线制 FOC 常见的电流重构与电压换算。若硬件有中线或检测到明显零序电流，不应使用第三相重构。

```c
#include <stdbool.h>
#include <math.h>

void ReconstructThirdPhaseCurrent(float ia, float ib, float *ic)
{
    *ic = -(ia + ib);
}

float CalculateFloatingNeutralVoltage(float vaN, float vbN, float vcN)
{
    return (vaN + vbN + vcN) / 3.0f;
}

float PhaseToLineVoltage(float ua, float ub)
{
    return ua - ub;
}

bool IsThreeWireCurrentBalanced(float ia, float ib, float ic, float tolerance)
{
    return fabsf(ia + ib + ic) <= tolerance;
}
```

## 7. 最常见的四类错误

1. **把极点电压当绕组相电压**：浮置星点存在时，必须先减去 $v_{nN}$。
2. **把 $i_a+i_b+i_c=0$ 当普适定律**：它依赖三线制与没有零序回路的前提。
3. **把空间 $120°$ 当成波形的时间延迟**：两者相关，但描述的是不同维度。
4. **只写“线电压超前 $30°$”而未写约定**：相序、极性和正弦/余弦参考一变，符号就可能相反。
