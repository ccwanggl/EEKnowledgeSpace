# 三相逆变器与8种开关状态

> **为什么学？**
> FOC 控制器输出的是 $d$、$q$ 轴电压，但最终必须转换成逆变器六个开关管的通断指令。如果不理解三相逆变器有哪 8 种开关状态、每种状态对应什么相电压/线电压，就无法把空间矢量脉宽调制（SVPWM, Space Vector Pulse Width Modulation）算出的占空比正确写入脉宽调制（PWM, Pulse Width Modulation）寄存器，电机得到的实际电压会与控制器期望电压完全对不上，电流环和速度环都会失调。
>
> **在 FOC 中的作用**
> 这一节是 SVPWM 的“物理基础”。它定义了开关函数与电压矢量的映射关系，输出 8 个基本电压矢量（6 个有效矢量 + 2 个零矢量），为后续 SVPWM 矢量合成、扇区判断和占空比计算提供输入。

FOC 的完整链路是：电流环算出 $V_d$、$V_q$，逆 Park 变换得到 $V_\alpha$、$V_\beta$，再交给调制算法变成三相 PWM。要设计调制算法，首先得知道逆变器每个开关组合到底“输出什么电压”，否则后续的合成与优化都是无源之水。

## 1. 拓扑结构与开关函数定义

三相两电平电压源逆变器（VSI, Voltage Source Inverter）由三个桥臂组成，每个桥臂包含两个带反并联二极管的开关器件（如 MOSFET, Metal-Oxide-Semiconductor Field-Effect Transistor 或 IGBT, Insulated Gate Bipolar Transistor）。直流母线电压为 $U_{dc}$，三相输出端记为 $a$、$b$、$c$。

定义第 $k$ 相上桥臂开关函数：

$$
S_k = \begin{cases} 1, & \text{上管导通、下管关断} \\ 0, & \text{上管关断、下管导通} \end{cases}
$$

其中 $k \in \{a, b, c\}$。由于同一桥臂上下管互补，下桥臂状态为 $\bar{S}_k = 1 - S_k$。

## 2. 数学推导：相电压与线电压

为什么要做这一步：只有把 8 种开关状态翻译成电机端实际能看到的相电压和线电压，才能知道每个开关组合对电机绕组施加了什么激励，也才能解释中性点漂移、电流采样误差等工程现象。

三相开关状态共有 $2^3 = 8$ 种组合，记为 $(S_a, S_b, S_c)$。对于星形连接（Y 接）的负载，各相电压（相对直流母线负端 $N$）为：

$$
\begin{cases}
U_{aN} = S_a \cdot U_{dc} \\
U_{bN} = S_b \cdot U_{dc} \\
U_{cN} = S_c \cdot U_{dc}
\end{cases}
$$

设负载中性点为 $n$，则相电压（相对中性点）为：

$$
\begin{cases}
U_{an} = U_{aN} - U_{nN} \\
U_{bn} = U_{bN} - U_{nN} \\
U_{cn} = U_{cN} - U_{nN}
\end{cases}
$$

对于对称三相负载，三相相电压之和为零：

$$
U_{an} + U_{bn} + U_{cn} = 0
$$

由此推导出中性点偏移电压：

$$
U_{nN} = \frac{U_{aN} + U_{bN} + U_{cN}}{3} = \frac{U_{dc}}{3}(S_a + S_b + S_c)
$$

代入得相电压：

$$
\begin{cases}
U_{an} = \frac{U_{dc}}{3}(2S_a - S_b - S_c) \\
U_{bn} = \frac{U_{dc}}{3}(2S_b - S_a - S_c) \\
U_{cn} = \frac{U_{dc}}{3}(2S_c - S_a - S_b)
\end{cases}
$$

线电压可由相电压差直接得到：

$$
\begin{cases}
U_{ab} = U_{an} - U_{bn} = U_{dc}(S_a - S_b) \\
U_{bc} = U_{bn} - U_{cn} = U_{dc}(S_b - S_c) \\
U_{ca} = U_{cn} - U_{an} = U_{dc}(S_c - S_a)
\end{cases}
$$

## 3. 8种开关状态的空间矢量表示

为什么要做这一步：SVPWM 的核心是在 $\alpha\beta$ 平面上用几何方法合成任意电压矢量，因此必须先把 8 个离散的开关状态映射成平面上的 8 个矢量，才能判断目标矢量落在哪个扇区、由哪两个相邻矢量合成。

将三相电压变换到 $\alpha\beta$ 静止坐标系（等幅值变换）：

$$
\begin{cases}
U_\alpha = \frac{2}{3}\left(U_{an} - \frac{1}{2}U_{bn} - \frac{1}{2}U_{cn}\right) = \frac{U_{dc}}{3}(2S_a - S_b - S_c) \\
U_\beta = \frac{2}{3}\left(\frac{\sqrt{3}}{2}U_{bn} - \frac{\sqrt{3}}{2}U_{cn}\right) = \frac{U_{dc}}{\sqrt{3}}(S_b - S_c)
\end{cases}
$$

8 种开关状态对应的空间矢量如下表：

| 矢量 | $(S_a, S_b, S_c)$ | $U_\alpha$ | $U_\beta$ | 幅值 | 类型 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| $\vec{V}_0$ | (0,0,0) | 0 | 0 | 0 | 零矢量 |
| $\vec{V}_1$ | (1,0,0) | $\frac{2U_{dc}}{3}$ | 0 | $\frac{2U_{dc}}{3}$ | 有效矢量 |
| $\vec{V}_2$ | (1,1,0) | $\frac{U_{dc}}{3}$ | $\frac{U_{dc}}{\sqrt{3}}$ | $\frac{2U_{dc}}{3}$ | 有效矢量 |
| $\vec{V}_3$ | (0,1,0) | $-\frac{U_{dc}}{3}$ | $\frac{U_{dc}}{\sqrt{3}}$ | $\frac{2U_{dc}}{3}$ | 有效矢量 |
| $\vec{V}_4$ | (0,1,1) | $-\frac{2U_{dc}}{3}$ | 0 | $\frac{2U_{dc}}{3}$ | 有效矢量 |
| $\vec{V}_5$ | (0,0,1) | $-\frac{U_{dc}}{3}$ | $-\frac{U_{dc}}{\sqrt{3}}$ | $\frac{2U_{dc}}{3}$ | 有效矢量 |
| $\vec{V}_6$ | (1,0,1) | $\frac{U_{dc}}{3}$ | $-\frac{U_{dc}}{\sqrt{3}}$ | $\frac{2U_{dc}}{3}$ | 有效矢量 |
| $\vec{V}_7$ | (1,1,1) | 0 | 0 | 0 | 零矢量 |

6 个有效矢量将平面均分为 6 个扇区，相邻矢量夹角为 $60°$。两个零矢量 $\vec{V}_0$、$\vec{V}_7$ 位于原点。

## 4. 几何直观：电压矢量六边形

![[14-FOC-电机控制/assets/inverter_voltage_hexagon.png|1500]]
*图：6 个有效矢量 $\vec{V}_1 \sim \vec{V}_6$ 构成正六边形，2 个零矢量 $\vec{V}_0$、$\vec{V}_7$ 位于原点。绿色虚线圆为线性调制区边界，红色点线圆为六步波边界。*

从图中可以直观看到：

- 每个有效矢量对应一个开关状态 $(S_a, S_b, S_c)$，例如 $\vec{V}_1(100)$ 表示 a 相上管导通、b、c 相下管导通；
- 6 个有效矢量把 $\alpha\beta$ 平面分成 6 个扇区，每个扇区 60°；
- 零矢量 $\vec{V}_0(000)$ 和 $\vec{V}_7(111)$ 都落在原点，用于调节输出电压的等效幅值；
- 绿色虚线圆以内是 SVPWM 的线性调制区，参考矢量 $|\vec{V}_{ref}| \leq U_{dc}/\sqrt{3}$；
- 红色点线圆对应六步波（方波）调制，幅值为 $2U_{dc}/3$，已进入过调制区。

$$
|V_{max}| = \frac{2U_{dc}}{3} \approx 0.667 U_{dc}
$$

该六边形是 SVPWM 线性调制区的边界。任何期望电压矢量 $\vec{V}_{ref}$ 若位于六边形内，均可由相邻两个有效矢量与零矢量合成。

## 5. 数值示例

**给定条件**：$U_{dc} = 24\,V$，开关状态 $(S_a, S_b, S_c) = (1, 0, 1)$，对应矢量 $\vec{V}_6$。

**求解**：相电压、线电压及 $\alpha\beta$ 坐标。

**解**：

1. 相电压（相对中性点）：

$$
U_{an} = \frac{24}{3}(2 \times 1 - 0 - 1) = 8\,V
$$

$$
U_{bn} = \frac{24}{3}(2 \times 0 - 1 - 1) = -16\,V
$$

$$
U_{cn} = \frac{24}{3}(2 \times 1 - 1 - 0) = 8\,V
$$

验证：$U_{an} + U_{bn} + U_{cn} = 8 - 16 + 8 = 0\,V$ ✓

2. 线电压：

$$
U_{ab} = 24 \times (1 - 0) = 24\,V
$$

$$
U_{bc} = 24 \times (0 - 1) = -24\,V
$$

$$
U_{ca} = 24 \times (1 - 1) = 0\,V
$$

3. $\alpha\beta$ 坐标：

$$
U_\alpha = \frac{24}{3}(2 \times 1 - 0 - 1) = 8\,V
$$

$$
U_\beta = \frac{24}{\sqrt{3}}(0 - 1) = -13.86\,V
$$

幅值：$|V_6| = \sqrt{8^2 + (-13.86)^2} = 16\,V = \frac{2 \times 24}{3}$ ✓

## 6. 代码实现：开关状态到电压矢量的C代码

```c
#include <math.h>

#define SQRT3   1.7320508075688772f
#define UDC     24.0f

typedef struct {
    float alpha;
    float beta;
} VoltageVector;

typedef struct {
    uint8_t sa;  // 上桥臂 A
    uint8_t sb;  // 上桥臂 B
    uint8_t sc;  // 上桥臂 C
} SwitchState;

// 根据开关状态计算 αβ 电压矢量（等幅值变换）
VoltageVector calc_voltage_vector(const SwitchState* s) {
    VoltageVector v;
    float Sa = (float)s->sa;
    float Sb = (float)s->sb;
    float Sc = (float)s->sc;

    v.alpha = (UDC / 3.0f) * (2.0f * Sa - Sb - Sc);
    v.beta  = (UDC / SQRT3) * (Sb - Sc);

    return v;
}

// 计算相电压（相对中性点）
void calc_phase_voltages(const SwitchState* s, float* van, float* vbn, float* vcn) {
    float Sa = (float)s->sa;
    float Sb = (float)s->sb;
    float Sc = (float)s->sc;

    *van = (UDC / 3.0f) * (2.0f * Sa - Sb - Sc);
    *vbn = (UDC / 3.0f) * (2.0f * Sb - Sa - Sc);
    *vcn = (UDC / 3.0f) * (2.0f * Sc - Sa - Sb);
}

// 计算线电压
void calc_line_voltages(const SwitchState* s, float* vab, float* vbc, float* vca) {
    float Sa = (float)s->sa;
    float Sb = (float)s->sb;
    float Sc = (float)s->sc;

    *vab = UDC * (Sa - Sb);
    *vbc = UDC * (Sb - Sc);
    *vca = UDC * (Sc - Sa);
}
```

## 7. 开关损耗分析

为什么要做这一步：开关频率直接决定电流纹波、电磁干扰（EMI, Electromagnetic Interference）和逆变器温升。只有量化开通/关断损耗和导通损耗，才能在器件承受能力与 FOC 控制性能之间选择合适的开关频率和调制方式（7段式或5段式）。

开关损耗由开通损耗 $E_{on}$ 和关断损耗 $E_{off}$ 组成，单次开关能量损耗近似为：

$$
E_{sw} = E_{on} + E_{off} \approx \frac{1}{2} U_{dc} \cdot I_{sw} \cdot (t_{on} + t_{off}) = \frac{1}{2} U_{dc} \cdot I_{sw} \cdot t_{sw}
$$

开关频率 $f_{sw}$ 下的平均开关功率损耗：

$$
P_{sw} = f_{sw} \cdot E_{sw} = \frac{1}{2} f_{sw} U_{dc} I_{sw} t_{sw}
$$

导通损耗（MOSFET 沟道电阻 $R_{DS(on)}$）：

$$
P_{cond} = I_{RMS}^2 \cdot R_{DS(on)}
$$

总损耗限制了逆变器的最高开关频率。在 FOC 应用中，典型开关频率为 $10\sim20\,kHz$；若采用氮化镓（GaN, Gallium Nitride）/ 碳化硅（SiC, Silicon Carbide）器件，可提升至 $50\sim100\,kHz$。

零矢量 $\vec{V}_0$、$\vec{V}_7$ 的选取影响开关次数：

- **7段式 SVPWM**：每个 PWM 周期有 6 次开关动作，波形对称、谐波低
- **5段式 SVPWM**：每个 PWM 周期有 4 次开关动作，开关损耗低但谐波稍高

## 8. 常见错误

### 错误1：忽略死区时间导致桥臂直通

**错误表现**：在开关状态切换瞬间，若上管尚未完全关断而下管已开通，形成直流母线短路（shoot-through），电流急剧上升导致器件烧毁。

**纠正方法**：必须在互补 PWM 中插入死区时间 $T_d$（通常 $1\sim3\,\mu s$），确保上管完全关断后才允许下管开通。现代微控制器（MCU, Microcontroller Unit，如 STM32）的定时器支持硬件死区插入功能。

### 错误2：混淆相电压与线电压的参考点

**错误表现**：初学者常将 $U_{aN}$（相对母线负端）误当作电机相电压 $U_{an}$（相对中性点），导致后续 Clarke 变换结果错误。

**纠正方法**：明确区分：
- $U_{aN}$：相对直流母线负端，仅取 $0$ 或 $U_{dc}$ 两电平
- $U_{an}$：相对电机中性点，取值为 $\{0, \pm U_{dc}/3, \pm 2U_{dc}/3\}$ 共 5 个电平

电机模型中的电压方程必须使用 $U_{an}$，而非 $U_{aN}$。

## 9. 自测习题

**习题1**：已知 $U_{dc} = 48\,V$，开关状态 $(S_a, S_b, S_c) = (1, 1, 0)$，求：
1. 三相相电压 $U_{an}$、$U_{bn}$、$U_{cn}$
2. 线电压 $U_{ab}$、$U_{bc}$、$U_{ca}$
3. $\alpha\beta$ 坐标系下的矢量分量

**答案**：
1. $U_{an} = 16\,V$，$U_{bn} = 16\,V$，$U_{cn} = -32\,V$
2. $U_{ab} = 0\,V$，$U_{bc} = 48\,V$，$U_{ca} = -48\,V$
3. $U_\alpha = 16\,V$，$U_\beta = 27.71\,V$，幅值 $32\,V$

**习题2**：三相逆变器的最大线性调制电压幅值（SVPWM）与方波调制电压幅值分别是多少？请用 $U_{dc}$ 表示。

**答案**：
- 线性调制区最大幅值：$|V_{max}| = \frac{U_{dc}}{\sqrt{3}} \approx 0.577 U_{dc}$（对应六边形内切圆）
- 方波调制（六步波）幅值：$|V_{six-step}| = \frac{2U_{dc}}{3} \approx 0.667 U_{dc}$（对应六边形顶点）

注意：方波调制已超出线性调制区，进入过调制区，电流谐波显著增大。
