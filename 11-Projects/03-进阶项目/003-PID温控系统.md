# 3. PID 温控系统

**目标**：理解闭环控制、传感器、执行器、PID 算法。

## 硬件
- STM32 / Arduino + 热电偶/PT100/DS18B20
- 固态继电器（SSR）或 MOSFET + 加热板
- 可选：风扇制冷（双向控制）

### 技能点
- 温度传感器读取和线性化
- PID 算法实现（位置式/增量式）
- 参数整定（Ziegler-Nichols、试凑法）
- 抗积分饱和、输出限幅、微分滤波
- 自整定（可选）

### 扩展
- 加串口/蓝牙，PC 实时绘制温度曲线
- 加多段温度曲线（回流焊曲线、PCR 温度循环）
- 加制冷（半导体制冷片 TEC）

### 参考
- **Phil's Lab** — PID 控制教程
- **Brett Beauregard** — "Improving the Beginner's PID"（经典博客系列）

### 项目来源与详细资源

- **Arduino PID Library（Brett Beauregard 官方库）**：https://github.com/br3ttb/Arduino-PID-Library — 抗积分饱和（reset windup）、微分冲击（derivative kick）、比例作用于测量值等工程技巧全部体现在源码里，是学习 PID 实现的标杆
- **配套博客系列《Improving the Beginner's PID》**：brettbeauregard.com（从朴素 PID 到生产级实现的逐篇改进，共 8 篇）
- **Phil's Lab** PID / 数字控制系列（离散控制器实现、定点化、抗饱和，phils-lab.net / YouTube）
- **简洁 C 实现参考**：https://github.com/pms67/PID （Phil Salmony 的 PID，约百行，含积分分离与抗饱和写法）
- **传感器资料**：
  - DS18B20：单总线，±0.5℃，用 DallasTemperature 库
  - PT100：需恒流源或比率法 + 三线制补偿，MAX31865 模块最省事
  - 热电偶：MAX6675/MAX31855 冷端补偿模块（K 型）
- **执行器**：SSR（固态继电器）过零触发无干扰；MOSFET 高频 PWM 需配续流二极管；加热板功率按升温速率估算
- **自整定**：Arduino PID Autotune 库（noPowerDrift / relay feedback 法）
- **扩展**：回流焊曲线/PCR 温度循环本质是多段斜坡-保温（ramp-soak）状态机
