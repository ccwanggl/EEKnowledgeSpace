# 4. CAN 总线网络

**目标**：理解 CAN 协议、多节点通信、协议设计。

## 硬件
- 2~3 个 STM32 节点（如 Nucleo-F446RE）
- TJA1050/TJA1043 CAN 收发器
- 终端电阻（120Ω）
- 可选：CAN 分析仪（USB-CAN 适配器）

### 技能点
- CAN 外设配置（波特率、过滤器、中断）
- 多节点通信（广播 + 接收过滤）
- 自定义协议设计（ID 分配、数据帧格式、心跳检测）
- 错误处理（总线关闭恢复、重传）

### 项目示例
- 节点 1：温度传感器，周期性发送温度
- 节点 2：显示屏，显示所有节点数据
- 节点 3：网关，转发到串口或 WiFi
