# 5. GPS 数据记录仪

**目标**：理解 UART、NMEA 协议、数据存储、文件系统。

## 硬件
- STM32 / ESP32
- GPS 模块（NEO-6M/NEO-M8N，UART）
- microSD 模块（SPI）
- 可选：RTC（DS3231）用于时间戳
- 可选：OLED 显示当前位置

### 技能点
- UART 接收和 NMEA 句子解析（$GPGGA、$GPRMC）
- 坐标转换（度分秒 → 十进制度）
- microSD 卡 FAT 文件系统（FatFs）
- CSV 格式记录（时间、经纬度、速度、海拔）
- 低功耗设计（GPS 间歇唤醒）

### 扩展
- 加加速度计，记录运动轨迹和姿态
- 加蓝牙/WiFi，实时上传轨迹
- 用地图软件（Google Earth）可视化轨迹

### 项目来源与详细资源

- **TinyGPS++（Mikal Hart 的 NMEA 解析库）**：Arduino 库管理器搜 "TinyGPSPlus"，库主页与完整说明见 arduniana.org（SparkFun GPS Hookup Guide 也以其为推荐库：learn.sparkfun.com）
- **GPS 模块资料**：u-blox NEO-6M/NEO-M8N 数据手册与 NMEA 协议说明（u-blox 官网 u-blox.com，搜 "NEO-6"）；模块默认 9600 8N1，NMEA 语句以 $GPxxx 开头
- **NEO-6M 接线注意**：3.3V 供电（非 5V）；冷启动首次定位需 2–3 分钟开阔天空
- **FatFs 文件系统**：elm-chan.org/fsw/ff/ （官方页面，含 f_mkfs/f_open/f_write 全部 API 与移植说明）；SPI 模式 microSD 用 chan 的原生例程即可
- **轨迹可视化**：记录为 CSV（时间,纬度,经度,速度）→ GPS Visualizer（gpsvisualizer.com）转 GPX/KML → Google Earth；国内也可用 高德/百度 坐标转换（注意 GCJ-02 偏移）
- **低功耗设计**：u-blox 间歇模式（PMTK 指令或 UBX-RXM-PMREQ）；ESP32 用 deep sleep + RTC 唤醒
- **开源参考实现**：GitHub 搜索 "GPS logger"（如 adafruit 的 Ultimate GPS Logger 系列教程，learn.adafruit.com）
