# 6. 蓝牙低功耗传感器节点

**目标**：理解 BLE、低功耗设计、传感器采集。

## 硬件
- nRF52840 / ESP32-S3 / STM32WB
- 传感器（BME280、光照、加速度）
- 纽扣电池（CR2032）或锂聚合物电池

### 技能点
- BLE 外围设备配置（GATT Service/Characteristic）
- 连接间隔和从机延迟优化（低功耗）
- 传感器间歇采集（定时器唤醒）
- 电池电压监测
- 手机 App（nRF Connect 或自定义）读取数据

### 扩展
- 加 NFC 用于快速配对
- 加蓝牙 Mesh，多节点组网
- 用 Eddystone/iBeacon 广播数据

### 项目来源与详细资源

- **nRF Connect SDK（Nordic 官方，基于 Zephyr RTOS）**：developer.nordicsemi.com，nRF52840 标准开发路径；Nordic DevZone（devzone.nordicsemi.com）是官方问答社区
- **nRF52840-DK 入门**：SparkFun Learn 的《nRF52840 Advanced Development with the nRF5 SDK》（armgcc + nrfutil + DFU 全流程）：https://learn.sparkfun.com/tutorials/nrf52840-advanced-development-with-the-nrf5-sdk/all
- **开源硬件参考**：makerdiary nrf52840-connectkit（原理图/PCB/文档全开源，支持 nRF Connect SDK 与 CircuitPython）：https://github.com/makerdiary/nrf52840-connectkit
- **手机调试 App**：**nRF Connect for Mobile**（Nordic 官方，Android/iOS）——扫描、连接、读写 GATT Characteristic、查看 RSSI，开发必备
- **BLE 要点**：GATT = Service + Characteristic；低功耗核心参数是连接间隔（connection interval 7.5–4000ms）、从机延迟（slave latency）与 supervision timeout；CR2032 供电需用内部 DC-DC（nRF52 内置）
- **简化路线**：ESP32-S3 用 Arduino 的 BLEDevice/BLEServer 库（NimBLE 栈更省内存）；STM32WB 用 STM32CubeWB 包
- **进阶**：蓝牙 Mesh（nRF Mesh App 配网）、Eddystone/iBeacon 广播（无需连接即可发数据）、Thread/Zigbee（nRF52840 多协议共存）
