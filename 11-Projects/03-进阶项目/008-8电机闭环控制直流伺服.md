# 8. 电机闭环控制（直流伺服）

**目标**：理解编码器、PID、H 桥、速度/位置控制。

## 硬件
- STM32F4（高级定时器 + 编码器接口）
- 直流减速电机 + 增量编码器（如 JGA25-370）
- H 桥驱动（TB6612FNG 或 DRV8871）
- 可选：电位器设定目标位置/速度

### 技能点
- 编码器接口（正交解码，方向 + 计数）
- 速度测量（M 法/T 法/MT 法）
- 位置环 + 速度环双环 PID
- PWM 驱动和方向控制
- 加减速曲线（S 曲线或梯形规划）

### 扩展
- 加串口命令，远程控制位置/速度
- 加多轴联动（2 轴画直线、圆弧插补）
- 步进电机闭环（步进 + 编码器，防丢步）
