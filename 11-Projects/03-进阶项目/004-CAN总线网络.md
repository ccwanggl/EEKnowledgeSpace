# 4. CAN 总线网络

**目标**：理解 CAN 协议、多节点通信、协议设计。

## 硬件
- 2~3 个 STM32 节点（如 Nucleo-F446RE）
- TJA1050/TJA1043 CAN 收发器
- 终端电阻（120Ω）
- 可选：CAN 分析仪（USB-CAN 适配器）

### 技能点
- CAN 外设配置（波特率、过滤器、中断）
- 多节点通信（广播 + 接收过滤）
- 自定义协议设计（ID 分配、数据帧格式、心跳检测）
- 错误处理（总线关闭恢复、重传）

### 项目示例
- 节点 1：温度传感器，周期性发送温度
- 节点 2：显示屏，显示所有节点数据
- 节点 3：网关，转发到串口或 WiFi

### 项目来源与详细资源

- **Kvaser CAN Protocol Tutorial**（CAN 协议经典教程，含位时序、仲裁、错误帧、错误计数器，配示波器实测波形）：https://www.kvaser.com/can-protocol-tutorial/ （PDF 版 kvaser.com/wp-content/uploads/2024/06/Kvaser_CAN_Protocol_Tutorial.pdf）
- **ST 官方文章《Using CAN (bxCAN) in Normal mode with STM32》**（收发器选型 SN65HVD230/TJA1050、终端电阻、HSE 晶振精度要求）：ST Community（community.st.com）搜索标题
- **Microchip AN713**：CAN 基础应用笔记（mchp.cn 可下载）；**Bosch CAN 2.0 规范**（CAN Specification 2.0，1991）
- **Phil's Lab** CAN 总线系列视频（硬件层、位时序计算、STM32 bxCAN 配置，phils-lab.net）
- **上位机调试工具**：USB-CAN 适配器（沁恒 CH32 / 周立功 / PEAK PCAN）+ 软件：PCAN-View、**BUSMASTER**（开源，rbei-etas-busmaster.github.io）、**SavvyCAN**（开源，支持日志回放）
- **位时序要点**：波特率 = APB 时钟 / (BRP × (1+BS1+BS2))，采样点建议 87.5%（250k/500k 常用）；总线两端各 120Ω 终端电阻
- **进阶**：CAN FD（FDCAN，STM32G4/H7）→ UDS/OBD-II 协议 → CANopen（CiA 301）/ J1939
