# 3. PID 温控系统

**目标**：理解闭环控制、传感器、执行器、PID 算法。

## 硬件
- STM32 / Arduino + 热电偶/PT100/DS18B20
- 固态继电器（SSR）或 MOSFET + 加热板
- 可选：风扇制冷（双向控制）

### 技能点
- 温度传感器读取和线性化
- PID 算法实现（位置式/增量式）
- 参数整定（Ziegler-Nichols、试凑法）
- 抗积分饱和、输出限幅、微分滤波
- 自整定（可选）

### 扩展
- 加串口/蓝牙，PC 实时绘制温度曲线
- 加多段温度曲线（回流焊曲线、PCR 温度循环）
- 加制冷（半导体制冷片 TEC）
