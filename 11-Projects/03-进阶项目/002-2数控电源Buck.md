# 2. 数控电源（Buck）

**目标**：理解 DC-DC 控制、反馈、ADC、数字控制。

## 硬件
- STM32G4（高分辨率定时器 + ADC）或 STM32F3
- Buck 功率级（MOSFET + 电感 + 二极管 + 电容）
- 输出电压/电流采样（分压 + 采样电阻 + 运放）
- 编码器或按键 + 显示屏（设定电压/电流）

### 技能点
- Buck 拓扑与 PWM 控制
- 电压/电流闭环控制（PID 或数字补偿器）
- ADC 采样时序与 PWM 同步
- 过压/过流保护（硬件 + 软件）
- 数字控制理论（z 变换、离散 PID）
