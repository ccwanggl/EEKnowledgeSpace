# 1. 简易数字示波器

**目标**：综合 ADC、DMA、显示、时基控制。

## 硬件
- STM32F4（如 STM32F407，12-bit ADC + DMA）
- TFT LCD（ILI9341，SPI 或并行）
- 输入衰减/放大电路（运放 + 分压）
- 触发比较器（可选）

### 技能点
- ADC + DMA 连续采集（双缓冲或循环模式）
- 时基控制（采样率可调）
- 触发系统（边沿触发、预触发/后触发）
- 波形显示（描点、插值、缩放）
- 输入保护（TVS + 限流电阻）

### 参考
- **Phil's Lab** — 开源示波器设计
- **DIY 示波器项目**（GitHub 搜索 "STM32 oscilloscope"）

### 项目来源与详细资源

- **Phil's Lab**（Phil Salmony 的硬件设计频道，含 STM32 示波器、ADC/DMA、触发系统、KiCad PCB 全套视频与工程文件）：官网 https://phils-lab.net ，YouTube 搜索 "Phil's Lab oscilloscope"
- **ST 官方 ADC + DMA 参考**：STM32F407 参考手册 RM0090（ADC 三重模式、注入/规则通道、TIM 触发）；AN2668（STM32 的 12 位 ADC 精度提升方法）
- **开源示波器项目参考**：
  - Gabonator "DSO" 系列与 "µosc"（GitHub 搜索 "Gabonator"）
  - scoppy（GitHub "fdxoft" / scoppy —— 用树莓派 Pico 做示波器前端，安卓显示，适合对照架构）
  - **DScope**（04-高级项目的开源示波器，可作为进阶完成后的对标目标）
- **显示库**：ILI9341 用 Adafruit_ILI9341 + Adafruit_GFX（SPI/8 位并口）；uGUI / LVGL 也可作更高级 UI
- **输入前端参考**：经典 1MΩ//15pF 示模输入 + 运放调理；保护用 BAV199 双二极管 + PTC；触发电路可用比较器（LM311/TLV3501）接 TIM 输入捕获
