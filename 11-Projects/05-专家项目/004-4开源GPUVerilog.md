# 4. 开源 GPU（Verilog）

## 目标
用 FPGA 实现一个简化但功能完整的图形处理单元（GPU）。

### 硬件
- FPGA：Artix-7 / ECP5 / Zynq
- 显示接口：VGA / HDMI（通过 TMDS）
- 存储：SRAM / DDR

### 技能点
- 图形管线（顶点处理、光栅化、片段着色）
- 流水线设计
- 内存管理
- 驱动开发
- 计算机架构

### 扩展方向
- 支持 3D 变换
- 添加纹理映射
- 与 RISC-V 软核集成
