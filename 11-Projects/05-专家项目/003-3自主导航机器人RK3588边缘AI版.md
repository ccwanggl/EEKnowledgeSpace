# 3. 自主导航机器人（RK3588 边缘 AI 版）

## 目标
构建一个基于 RK3588 的自主导航机器人，利用 6 TOPS NPU 实现实时视觉感知和 AI 决策。

### 硬件
- **主控**：RK3588（香橙派 5 / ROCK 5B）+ Ubuntu Rockchip / Armbian
- **NPU 推理**：6 TOPS INT8，用于目标检测、车道识别、避障
- **传感器**：
  - 激光雷达（RPLIDAR A1/A2）或深度相机（RealSense D435）
  - IMU（MPU9250 / BNO055）
  - 轮式编码器
- **执行器**：直流电机 + 编码器、舵机
- **通信**：WiFi / 4G / ROS2

### 技能点
- ROS2 / ROS 机器人操作系统
- RKNN 模型部署（YOLOv8 目标检测 + RKNN 转换）
- SLAM 算法（Cartographer、GMapping）或 V-SLAM（ORB-SLAM3）
- 传感器融合（EKF）
- 路径规划（A*、DWA）
- 电机控制与 PID（通过 GPIO/PWM 或独立 MCU 协调）
- GStreamer + RGA 实现摄像头数据预处理

### 扩展方向
- 语音交互（Whisper RKNN 语音识别）
- 多机协作（ROS2 多机器人通信）
- 自动充电（视觉定位充电桩）
- 边缘 LLM 问答（RKLLM + TinyLlama）
