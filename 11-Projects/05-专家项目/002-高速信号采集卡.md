# 2. 高速信号采集卡

## 目标
设计一张基于 FPGA 的高速 ADC 采集卡，支持 USB 3.0 或 PCIe 数据传输。

### 硬件
- FPGA：Artix-7 / Cyclone V / ECP5
- ADC：高速并行 ADC（如 AD9288）或 LVDS 接口 ADC
- 接口：USB 3.0（FT600/CYUSB3014）或 PCIe
- 时钟：低抖动晶振 / PLL

### 技能点
- FPGA 高速接口设计
- ADC 采样与时钟域管理
- DDR 存储缓存
- USB/PCIe 协议栈
- 上位机软件开发（Python/C++）

### 扩展方向
- 实时 FFT 处理
- 示波器前端设计
- 多通道同步采集

### 项目来源与详细资源

**核心来源**
- Digilent OpenScope MZ（开源仪器参考实现）：<https://github.com/Digilent/openscope-mz> — PIC32MZ + 12-bit ADC 的示波器/逻辑分析仪/波形发生器一体设计，硬件、固件、上位机（WaveForms Live）全开源，原理图在 reference.digilentinc.com，适合学习仪器级采集架构与固件组织
- AD9288（8-bit 双通道 100 MSPS 并行 ADC）与 CYUSB3014（EZ-USB FX3，USB 3.0 从机 FIFO）— 经典搭配，数据手册在 ADI / Infineon 官网（名称提及）
- FTDI FT600（USB 3.0 FIFO 桥）— 更简单的上机方案，无需写 USB 协议栈（名称提及）

**关键实现要点**
- 数据通路：ADC → FPGA IOB 寄存器（捕获时钟域）→ FIFO（跨时钟域）→ DDR 乒乓缓存 → USB/PCIe DMA 上传
- 时钟是关键约束：ADC 采样时钟抖动直接决定 SNR，用低抖动晶振 + PLL，FPGA 内部全局时钟缓冲
- 上位机：Python + libusb/pyusb 或 vendor SDK，环形缓冲 + 丢帧统计
