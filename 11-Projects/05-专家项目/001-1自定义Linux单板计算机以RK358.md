# 1. 自定义 Linux 单板计算机（以 RK3588 为核心）

## 目标
设计并制造一块基于 RK3588 的自定义单板计算机（SBC），或深度定制现有 RK3588 开发板。

### 硬件
- **处理器**：RK3588（四核 A76 + 四核 A55 + 6 TOPS NPU + Mali-G610）
- **内存**：LPDDR4/LPDDR4X 4-16GB（根据需求选择）
- **存储**：eMMC 32-128GB + NVMe SSD（通过 PCIe 3.0）
- **外设**：
  - 显示：HDMI 2.1（4K@120fps）或 MIPI DSI（LCD）
  - 网络：千兆以太网 + WiFi 6 / BLE 5.0 模块
  - 扩展：USB 3.1、PCIe 3.0 x4（用于扩展卡）、SATA 3.0
  - 摄像头：MIPI CSI 接口（连接 OV5640/OV13850 等）
- **电源**：多路 DC-DC（Buck）、PMIC（RK806）、上电时序管理
- **散热**：被动散热（散热片）或主动散热（风扇 + 散热片）

### 技能点
- RK3588 最小系统设计与 DDR 布局（等长、阻抗匹配）
- 高速信号完整性（PCIe、MIPI、DDR）
- 设备树（Device Tree）编写与修改（`.dts` / `.dtsi`）
- 使用 Buildroot / Yocto / Ubuntu Rockchip 构建系统
- 内核驱动移植（摄像头、WiFi、显示）
- 使用 RKDevTool 烧录固件和调试
