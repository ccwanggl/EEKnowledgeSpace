# 3. 自主导航机器人（RK3588 边缘 AI 版）

## 目标
构建一个基于 RK3588 的自主导航机器人，利用 6 TOPS NPU 实现实时视觉感知和 AI 决策。

### 硬件
- **主控**：RK3588（香橙派 5 / ROCK 5B）+ Ubuntu Rockchip / Armbian
- **NPU 推理**：6 TOPS INT8，用于目标检测、车道识别、避障
- **传感器**：
  - 激光雷达（RPLIDAR A1/A2）或深度相机（RealSense D435）
  - IMU（MPU9250 / BNO055）
  - 轮式编码器
- **执行器**：直流电机 + 编码器、舵机
- **通信**：WiFi / 4G / ROS2

### 技能点
- ROS2 / ROS 机器人操作系统
- RKNN 模型部署（YOLOv8 目标检测 + RKNN 转换）
- SLAM 算法（Cartographer、GMapping）或 V-SLAM（ORB-SLAM3）
- 传感器融合（EKF）
- 路径规划（A*、DWA）
- 电机控制与 PID（通过 GPIO/PWM 或独立 MCU 协调）
- GStreamer + RGA 实现摄像头数据预处理

### 扩展方向
- 语音交互（Whisper RKNN 语音识别）
- 多机协作（ROS2 多机器人通信）
- 自动充电（视觉定位充电桩）
- 边缘 LLM 问答（RKLLM + TinyLlama）

### 项目来源与详细资源

**核心来源**
- RKNN-Toolkit2 官方仓库：<https://github.com/airockchip/rknn-toolkit2> — 模型转换（ONNX/PyTorch → RKNN）、精度评估、性能分析，支持 RK3588/RV1106 全系 NPU；模型样例在 <https://github.com/airockchip/rknn_model_zoo>（YOLOv8 检测 demo 含训练 → 转换 → C 部署全链路）；边缘 LLM 用 RKNN-LLM（<https://github.com/airockchip/rknn-llm>）；图像预处理用 librga（<https://github.com/airockchip/librga>）
- ROS2 官方文档（docs.ros.org，名称提及）— Humble/Iron 版本教程、tf2、Nav2 导航栈
- SLAM 开源实现：Cartographer（github.com/cartographer-project）、ORB-SLAM3（名称提及）
- Radxa 论坛等社区有 RK3588 上 ROS2 + NPU 推理的集成讨论（forum.radxa.com，名称提及）

**关键实现要点**
- 模型部署标准流：PC 上 rknn-toolkit2 转换量化 → 板端 RKNN Runtime（C API）推理 → RGA 做 resize/色彩空间转换
- ROS2 节点内直接调 RKNN C API 做检测，结果以 topic 发布（这是社区验证过的集成方式）
- YOLOv8 后处理默认跑 CPU，注意 anchor/NMS 参数对齐，ReLU 替代 SiLU 可大幅提升 NPU 帧率
