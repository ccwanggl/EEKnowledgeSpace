# 5. Matter/Thread 边界路由器

## 目标
构建一个支持 Matter 和 Thread 协议的智能家居边界路由器。

### 硬件
- 主控：Raspberry Pi / ESP32-C6 / nRF52840 + Linux 主机
- Thread RCP：nRF52840 / EFR32
- 网络：Ethernet / WiFi

### 技能点
- Thread 协议栈（OpenThread）
- Matter 协议
- 边界路由器架构
- 网络安全与证书
- Linux 网络配置

### 扩展方向
- 多生态兼容（HomeKit、Google Home、Alexa）
- 自定义 Matter 设备
- OTA 升级
