# 硬件版本管理

## 版本命名
- `v1.0.0`：首次发布
- `v1.1.0`：小改动（元件替换、布局优化）
- `v2.0.0`：大改动（原理图重构、接口变更）

### 文件命名规范
```
hardware/
  schematic/
    ProjectName_v1.0.SchDoc
  pcb/
    ProjectName_v1.0.PcbDoc
  gerber/
    Gerber_v1.0/
      ProjectName_v1.0.GTL  (Top Layer)
      ProjectName_v1.0.GBL  (Bottom Layer)
      ProjectName_v1.0.GTO  (Top Silkscreen)
      ...
  bom/
    BOM_v1.0.xlsx
```

### Gerber 检查清单
- [ ] 层顺序正确
- [ ] 钻孔文件包含 NC drill 和 slot
- [ ] 丝印清晰、方向正确
- [ ] 板框和板厚标注
- [ ] 阻抗控制要求单独说明
