# 协作与发布

## Issue 模板
- Bug 报告：现象、复现步骤、期望结果、环境
- 功能请求：背景、方案、影响范围

### Pull Request 检查清单
- [ ] 代码编译通过
- [ ] 自测通过
- [ ] 文档已更新
- [ ] BOM 已同步
- [ ]  reviewed by 至少一人

### 发布流程
1. 在 `main` 分支打 tag：`git tag -a v1.0.0 -m "Release v1.0.0"`
2. 导出 Gerber、BOM、固件 hex/bin
3. 编写 Release Note
4. 上传到 `releases/` 目录或 GitHub Releases
5. 归档测试报告和使用手册
