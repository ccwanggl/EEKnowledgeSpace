# 推荐平台找项目

## 国际平台

- **Hackaday.io** — 全球最大的硬件项目社区，项目质量参差但上限极高，适合找「有人真做出来过」的创意（[[02-博客与网站推荐]]）
- **Hackster** — 平台项目 + 教程文章，嵌入式与 IoT 内容密集
- **Instructables** — 步骤最详细的图文教程，适合跟做（[[02-博客与网站推荐]]）
- **GitHub** — 搜 `awesome-embedded`、`awesome-hardware`、`topic:oscilloscope` 等；复刻前先读 issue 区判断项目是否活着
- **SparkFun Projects** — 教育友好，原理图和库都规范（[[02-博客与网站推荐]]）
- **Adafruit** — 教程质量最高的入门平台，每个传感器都有图文教程（[[02-博客与网站推荐]]）
- **YouTube** — 搜项目名 + "tutorial"/"DIY"；Ben Eater（数字逻辑）、Phil's Lab（硬件设计）、GreatScott!（电源与DIY）值得长期订阅

## 中文平台

- **立创开源硬件平台（oshwhub.com）** — 原理图/PCB/固件全开源的国内项目库，可一键打板，如 Echo-Mate 桌面机器人（见 [[009-AI桌面机器人Echo-Mate]]）
- **达尔闻** — 中文硬件与嵌入式项目来源
- **B 站** — 搜项目名 + 开源/复刻，很多 UP 主附完整工程

## 选项目的判断标准

1. 有**完整的原理图和 BOM**（只有演示视频的不选）
2. 仓库近一年有更新，或 issue 有作者回复
3. 成本和时间在自己的 1.5 倍余量以内
4. 难度比当前级别**高半级**最合适
