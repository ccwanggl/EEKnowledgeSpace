# 4. 3D 打印机控制器

**目标**：理解多轴运动控制、G-code、步进电机、温度控制。

## 硬件
- 主控：STM32F4（如 SKR Mini E3、BTT Octopus）或自研
- 步进电机驱动 × 4（TMC2209，静音驱动）
- 步进电机 × 4（X/Y/Z/E）
- 热床 + 挤出机加热器 + 热敏电阻
- 限位开关 × 3
- 显示屏（可选：TFT 或 12864 LCD）
- 电源（24V 或 12V）

### 软件（理解 Marlin/Klipper 或自研）
- G-code 解析：移动（G0/G1）、温度设定（M104/M109）、风扇（M106）
- 直线插补：Bresenham / DDA 算法
- 加减速曲线：S 曲线或梯形速度规划
- 温度闭环：热床和喷头 PID 温控
- 通信：串口（USB/UART）接收 G-code
- 文件读取：SD 卡读取 G-code 文件

### 技能点
- 多轴实时运动控制
- 数字运动规划（梯形/S 曲线加减速）
- 温度控制与安全（热失控保护）
- 机械配合（步进角、丝杆螺距、挤出比校准）
- 固件配置（Marlin Configuration.h）

### 项目来源与详细资源

**核心来源**
- Marlin 固件官方文档：<https://marlinfw.org/> — 配置项（Configuration.h / Configuration_adv.h）逐条说明、G-code 全集、PlatformIO 构建指南；固件在 GitHub（MarlinFirmware/Marlin）
- Klipper 官方文档：<https://www.klipper3d.org/> —「主机 Linux + 从机 MCU」架构，步率可达 175k steps/s，支持 Input Shaping / Pressure Advance；仓库 <https://github.com/klipper3d/klipper>，前端用 Mainsail / Fluidd（Moonraker API），安装助手 KIAUH
- RepRap 固件列表：<https://reprap.org/wiki/List_of_Firmware> — Marlin/Klipper/Smoothie/Repetier 等对比
- Teaching Tech（YouTube/网站）— 打印机调校（PID、挤出校准、Input Shaping）教程

**选型参考**
- Marlin：跑在主板上（8 位 AVR 到 32 位 ARM 均可），改配置需重新编译烧录
- Klipper：复杂计算在树莓派等主机完成，MCU 只执行定时指令，改 printer.cfg 即时生效，适合高速打印

**关键实现要点**
- 运动规划核心：梯形/S 曲线加减速、Bresenham 多轴联动、look-ahead
- 安全底线：热失控保护（thermal runaway）、加热超时、堵转检测，Marlin 的对应配置项值得逐条研究
- 步进驱动：TMC2209（UART 配置、StallGuard 无传感器归位）是目前主流
