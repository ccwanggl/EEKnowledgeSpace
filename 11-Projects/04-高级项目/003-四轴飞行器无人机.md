# 3. 四轴飞行器（无人机）

**目标**：综合传感器、控制算法、电机驱动、通信。

## 硬件
- 飞控板（F4/F7 如 Betaflight 兼容板，或自制 STM32F4）
- 电调（BLHeli_32 ESC）+ 无刷电机 × 4
- 螺旋桨 × 4
- 遥控器 + 接收机（SBUS/PPM/CRS）
- 电池（LiPo 3S/4S）
- 机架（F450/X 型）

### 软件（可选自研或理解开源）
- 传感器读取：MPU6050/9250（加速度+陀螺），磁力计，气压计
- 姿态解算：互补滤波 或 Madgwick/Mahony AHRS
- 姿态控制：PID 控制横滚/俯仰/偏航角
- 高度控制：气压计/超声波/光流 + PID
- 混控：四个电机的 PWM 分配
- 通信：接收机信号解析，遥测回传

### 技能点
- IMU 数据融合与姿态估计
- 多轴 PID 控制与耦合处理
- 电机特性和电调通信（DShot/OneShot）
- 电源管理（LiPo 充放电、低电压保护）
- 机械设计（重心、振动隔离）

### 安全警告
- 螺旋桨高速旋转危险，测试时务必卸桨或固定
- LiPo 电池有起火风险，需防火袋和正确充电
- 建议先在模拟器（Liftoff/Velocidrone）练习飞行

### 参考
- **Betaflight** 开源固件（GitHub）
- **ArduPilot / PX4** 开源飞控
- **Phil's Lab** — 无人机控制理论

### 项目来源与详细资源

**核心来源**
- Betaflight 固件官方仓库：<https://github.com/betaflight/betaflight> — 开源穿越机/竞速飞控固件（GPL），文档 <https://betaflight.com/docs/wiki>，配置用 Betaflight App（PWA）
- ArduPilot 官方站：<https://ardupilot.org/> — 专业级开源自动驾驶仪（多旋翼/固定翼/无人车，EKF3 状态估计，Lua 脚本扩展），固件下载 firmware.ardupilot.org，地面站用 Mission Planner / QGroundControl
- PX4 开源飞控（名称提及，px4.io）— 与 ArduPilot 同为专业向，生态偏 ROS/研究
- Phil's Lab（YouTube）— 无人机控制理论与硬件设计系列

**选型参考**
- 竞速/花飞：Betaflight（低延迟、RPM 滤波、调参生态成熟）
- 定点/航线/行业应用：ArduPilot 或 PX4
- 同一硬件（如 STM32F405/H743 飞控板）可刷不同固件，互刷需走 DFU（Zadig 装 WinUSB 驱动，STM32CubeProgrammer 或 dfu-util 烧录）

**关键实现要点**
- 自研飞控先读 Betaflight 的 PID 与滤波实现，IMU 用 ICM42688 类 MPU + SPI 接口保证采样率
- 电调协议：DShot300/600（数字，含校验），比 PWM/OneShot 更抗干扰
- 日志分析：Betaflight Blackbox / ArduPilot .bin 日志是调参的核心依据
