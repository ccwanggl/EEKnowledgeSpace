# 1. FPGA 数字钟与数字系统

**目标**：完整 FPGA 设计流程，从 RTL 到比特流。

## 硬件
- FPGA 开发板（Basys 3 / Tang Nano 9K / iCEstick）
- 外部晶振（板载通常 100MHz/50MHz/12MHz）
- 七段数码管或板载 LED
- 可选：按键、蜂鸣器、温度传感器（1-Wire）

### 项目内容
- 分频器：从系统时钟分频到 1Hz
- 计数器：时、分、秒计数
- 状态机：设定时间模式（按键切换）
- 显示驱动：扫描七段数码管或 VGA 显示
- 闹钟功能：蜂鸣器 + 按键消抖
- 可选：RTC 芯片（I2C 接口）备用

### 技能点
- Verilog 状态机、计数器、分频器
- 按键消抖（硬件或软件延时）
- 七段译码和动态扫描
- 约束文件（XDC/PCF）和时钟约束
- 仿真测试（Testbench + GTKWave）
