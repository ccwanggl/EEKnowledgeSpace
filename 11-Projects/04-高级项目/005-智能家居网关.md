# 5. 智能家居网关

**目标**：嵌入式 Linux、多协议、Web 界面、物联网。

## 硬件
- Raspberry Pi / 全志 H3 / i.MX6ULL
- 无线模块：nRF52840（BLE）、ESP32（WiFi）、CC2652（Zigbee）
- 以太网接口（板载或 USB 转以太网）
- 可选：Zigbee USB 棒（如 Sonoff ZBDongle-E）
- 可选：LoRa 模块（SX1262）

### 软件
- **操作系统**：OpenWrt / Armbian / Buildroot 定制的 Linux
- **协议转换**：MQTT Broker（Mosquitto）、Zigbee2MQTT、Home Assistant
- **Web 界面**：Node-RED、Home Assistant、或自建 Flask/FastAPI
- **设备管理**：Zigbee/BLE 设备配对、状态监控、自动化规则
- **安全**：防火墙、TLS、设备认证

### 技能点
- 嵌入式 Linux 系统构建（OpenWrt/Buildroot）
- 多协议桥接（Zigbee ↔ MQTT ↔ WiFi ↔ HTTP）
- 容器化（Docker）在嵌入式中的应用
- Web 后端开发（Python/Node.js）
- 网络安全和物联网安全

### 参考
- **Home Assistant** — 开源智能家居平台（home-assistant.io）
- **Zigbee2MQTT** — Zigbee 到 MQTT 桥接（zigbee2mqtt.io）
- **OpenWrt** — 开源路由器系统（openwrt.org）

### 项目来源与详细资源

**核心来源**
- Home Assistant 官方网站与文档：<https://www.home-assistant.io/> — 开源智能家居平台（本地优先、隐私优先），支持 Zigbee/Matter/Wi-Fi/蓝牙数千种集成，官方硬件 Home Assistant Green / Yellow；安装后从 homeassistant.local:8123 进入
- Zigbee2MQTT：<https://www.zigbee2mqtt.io/> — Zigbee 协调器 ↔ MQTT 桥接，配合 CC2652/CC2538 等协处理器固件
- OpenWrt：<https://openwrt.org/> — 开源路由器 Linux 系统，适合做网关底座
- ESPHome：<https://esphome.io/> — 用 YAML 配置生成 ESP32/ESP8266 固件，Home Assistant 生态首选 DIY 方案
- Tasmota：<https://tasmota.github.io/docs/> — 开源 ESP 设备固件（替代原厂固件，本地控制）
- DIY 继电器 + Web 控制入门教程：<https://randomnerdtutorials.com/esp32-relay-module-ac-web-server/>（Random Nerd Tutorials，ESP32 交流负载 Web 服务器完整示例）
- 云端数据记录可选 ThingSpeak（thingspeak.com，名称提及）

**关键实现要点**
- 网关分层：设备层（Zigbee/BLE）→ 协调器/代理层（Z2M）→ 消息层（MQTT/Mosquitto）→ 自动化层（HA）
- Zigbee 信道避开 WiFi 2.4 GHz 常用信道（Zigbee 11/15/20/25）
- MQTT 主题设计建议：`<位置>/<设备>/<属性>`，保留消息（retained）存设备状态
