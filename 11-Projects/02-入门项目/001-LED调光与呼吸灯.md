# 1. LED 调光与呼吸灯

**目标**：理解 PWM 和模拟输出。

## 硬件
- Arduino Uno / Nano 或 STM32 最小系统
- LED（任意颜色）+ 220Ω 电阻

### 技能点
- PWM 输出（`analogWrite()` 或 HAL 定时器 PWM）
- 占空比与亮度关系
- 延时函数与波形生成

### 扩展
- 多路 PWM RGB LED，实现颜色渐变
- 用 PWM 控制蜂鸣器音调
- 用电位器（ADC）手动调光

### 资源
- **Arduino 官方教程** — Fade 示例
- **GreatScott!** — PWM 原理视频

### 项目来源与详细资源

- **Arduino 官方 Fade 教程**（呼吸灯官方示例，含电路图与代码）：https://www.arduino.cc/en/Tutorial/Fade
- **Arduino Built-in Examples 总目录**（Basics/Digital/Analog 全部内置示例）：https://docs.arduino.cc/built-in-examples/
- **STM32 HAL PWM 参考**：见 `10-RTOS与系统` 与 `04-Microcontrollers` 下的 STM32 笔记；关键外设为 TIM + 输出比较通道
- **扩展阅读**：ESP32 用 LEDC 外设实现 16 路 PWM（`ledcSetup()/ledcAttachPin()`），Arduino 核心的 PWM 频率可用 `analogWriteFrequency()` 修改
- **开源参考实现**：Arduino Project Hub 搜索 "breathing LED" / "RGB fade"（projecthub.arduino.cc），立创开源平台搜索 "呼吸灯" 有大量 PCBA 复刻工程
