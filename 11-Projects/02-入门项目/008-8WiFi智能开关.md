# 8. WiFi 智能开关

**目标**：综合物联网入门。

## 硬件
- ESP32 或 ESP8266（如 NodeMCU）
- 继电器模块（5V，带光耦隔离）
- 轻触开关（手动控制）
- 5V/3.3V 电源

### 技能点
- ESP32 GPIO 控制继电器
- WiFi 连接（Station 模式）
- Web 服务器（HTTP 或 WebSocket）
- 手机/电脑通过浏览器控制
- 安全考虑：继电器隔离、过零检测、OTA 更新

### 扩展
- 加 MQTT，接入 Home Assistant
- 加 Matter 支持，跨平台控制
- 加功率监测（HLW8032、PZEM-004T）
- 设计 PCB，做成产品级
