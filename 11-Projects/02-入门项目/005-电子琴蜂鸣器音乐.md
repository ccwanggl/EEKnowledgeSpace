# 5. 电子琴 / 蜂鸣器音乐

**目标**：理解频率、PWM 和定时器。

## 硬件
- Arduino / STM32
- 无源蜂鸣器 或 小型扬声器 + 功放
- 按键（轻触开关）或 电位器

### 技能点
- 音符频率表（C4=261.63Hz, D4=293.66Hz 等）
- PWM 频率控制音调
- PWM 占空比控制音量
- 定时器中断精确计时
- 简单乐谱编码

### 扩展
- 用 DAC 输出正弦波（更纯净音质）
- 加 MIDI 接口，接收外部 MIDI 键盘
- 使用 FFT 播放存储的 WAV 文件

### 资源
- **Arduino Tone 库** 官方文档
- **Arduino Project Hub** — 音乐项目

### 项目来源与详细资源

- **Arduino 官方 Tone 旋律示例**（含 `pitches.h` 音符频率表，C4=261.63Hz 等全部音名宏定义）：https://www.arduino.cc/en/Tutorial/Tone
- **Arduino 官方音符频率对照表**：https://www.arduino.cc/frequencies
- **内置示例**：`toneMelody`（旋律播放）、`toneKeyboard`（压电键盘）、`toneMultiple`（多扬声器），见 https://docs.arduino.cc/built-in-examples/
- **原理要点**：无源蜂鸣器靠方波频率定音调、`tone()` 用定时器中断翻转引脚；占空比 50% 方波谐波丰富，换 DAC+正弦查表法可显著改善音色
- **开源参考实现**：GitHub 搜索 "arduino piano" / "buzzer music"（如纸钢琴、光敏电阻琴等经典项目）
