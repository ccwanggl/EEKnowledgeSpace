# 4. 简易数字万用表

**目标**：理解 ADC 和分压电路。

## 硬件
- Arduino / STM32（带 12-bit ADC）
- 电阻分压网络（测量 0~30V）
- 精密电阻（1% 或 0.1%）
- 可选：测量电流（采样电阻 + 运放）

### 技能点
- ADC 分辨率与精度
- 分压电路计算
- 量程切换（继电器/模拟开关）
- 校准（零点 + 满量程）

### 扩展
- 加自动量程（继电器切换分压比）
- 加电阻测量（恒流源 + ADC）
- 加二极管导通电压测量

### 资源
- **EEVblog** — 万用表原理和拆解
- **W2AEW** — ADC 测量技巧

### 项目来源与详细资源

- **EEVblog 万用表拆解系列**（YouTube 频道 EEVblog，Dave Jones 拆解 Fluke/Keysight/国产表，讲双积分 ADC、保护电路、输入阻抗设计）
- **W2AEW 示波器/测量频道**（YouTube，RR #124 等视频讲 ADC 有效位数 ENOB、分压与输入保护）
- **关键资料**：
  - MCU ADC 数据手册章节（ATmega328P 10-bit / STM32 12-bit，注意参考电压源与输入阻抗要求——高阻源需加运放跟随或延长采样时间）
  - 精密分压电阻选 0.1% 25ppm 薄膜电阻；校准用标准源两点法（零点 + 满度）
  - 电流测量：高边采样用 INA199/INA282 电流检测放大器；注意共模电压范围
  - 输入保护：双向 TVS + 串联电阻 + 钳位二极管到参考电压
- **开源参考实现**：立创开源平台（oshwhub.com）搜索 "万用表"，有基于 STM32F103 / ESP32 的开源手持表工程（含自动量程、原理图、PCB、固件）；GitHub 搜索 "open source multimeter" 参考 DIY SMU/万用表项目
