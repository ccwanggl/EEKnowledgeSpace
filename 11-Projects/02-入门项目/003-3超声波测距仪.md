# 3. 超声波测距仪

**目标**：理解 GPIO、定时器和中断。

## 硬件
- HC-SR04 超声波模块
- Arduino / STM32
- 可选：I2C LCD 或 OLED 显示距离

### 技能点
- GPIO 输入输出
- 定时器/微秒级延时
- 距离 = 时间 × 声速 / 2
- 中断处理（如使用输入捕获）

### 扩展
- 加蜂鸣器，距离越近声音越急促（倒车雷达）
- 多个超声波传感器，实现简单避障
- 用 STM32 输入捕获模式精确测量
