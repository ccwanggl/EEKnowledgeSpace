# 1. LED 调光与呼吸灯

**目标**：理解 PWM 和模拟输出。

## 硬件
- Arduino Uno / Nano 或 STM32 最小系统
- LED（任意颜色）+ 220Ω 电阻

### 技能点
- PWM 输出（`analogWrite()` 或 HAL 定时器 PWM）
- 占空比与亮度关系
- 延时函数与波形生成

### 扩展
- 多路 PWM RGB LED，实现颜色渐变
- 用 PWM 控制蜂鸣器音调
- 用电位器（ADC）手动调光

### 资源
- **Arduino 官方教程** — Fade 示例
- **GreatScott!** — PWM 原理视频
