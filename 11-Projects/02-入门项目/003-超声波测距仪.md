# 3. 超声波测距仪

**目标**：理解 GPIO、定时器和中断。

## 硬件
- HC-SR04 超声波模块
- Arduino / STM32
- 可选：I2C LCD 或 OLED 显示距离

### 技能点
- GPIO 输入输出
- 定时器/微秒级延时
- 距离 = 时间 × 声速 / 2
- 中断处理（如使用输入捕获）

### 扩展
- 加蜂鸣器，距离越近声音越急促（倒车雷达）
- 多个超声波传感器，实现简单避障
- 用 STM32 输入捕获模式精确测量

### 资源
- **Paul McWhorter** — Arduino 超声波教程

### 项目来源与详细资源

- **How To Mechatronics — HC-SR04 完整指南**（硬件结构、接线、代码、LCD 显示例、精度改进）：https://howtomechatronics.com/tutorials/arduino/ultrasonic-sensor-hc-sr04/
- **DroneBot Workshop — HC-SR04 with Arduino**（含温度补偿公式 `v=331.4+0.606T`、单线模式、多传感器轮询）：https://dronebotworkshop.com/hc-sr04-ultrasonic-distance-sensor-arduino/
- **NewPing 库**（Arduino 库管理器搜 "NewPing"，支持 HC-SR04/SRF05 等，提供 `ping_median()` 中值滤波和定时器中断多传感器模式）
- **HC-SR04 要点**：测距 2cm–400cm，Trig 引脚 ≥10µs 高电平触发，Echo 返回高电平宽度即往返时间；盲区 2cm，角度约 15°
- **进阶**：STM32 用定时器输入捕获测脉宽（μs 级精度）；倒车雷达扩展可参考 NewPing 例程 + `tone()` 变频蜂鸣器
