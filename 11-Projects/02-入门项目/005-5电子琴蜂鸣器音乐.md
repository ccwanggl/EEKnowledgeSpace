# 5. 电子琴 / 蜂鸣器音乐

**目标**：理解频率、PWM 和定时器。

## 硬件
- Arduino / STM32
- 无源蜂鸣器 或 小型扬声器 + 功放
- 按键（轻触开关）或 电位器

### 技能点
- 音符频率表（C4=261.63Hz, D4=293.66Hz 等）
- PWM 频率控制音调
- PWM 占空比控制音量
- 定时器中断精确计时
- 简单乐谱编码

### 扩展
- 用 DAC 输出正弦波（更纯净音质）
- 加 MIDI 接口，接收外部 MIDI 键盘
- 使用 FFT 播放存储的 WAV 文件
