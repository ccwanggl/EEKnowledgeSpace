# 4. 简易数字万用表

**目标**：理解 ADC 和分压电路。

## 硬件
- Arduino / STM32（带 12-bit ADC）
- 电阻分压网络（测量 0~30V）
- 精密电阻（1% 或 0.1%）
- 可选：测量电流（采样电阻 + 运放）

### 技能点
- ADC 分辨率与精度
- 分压电路计算
- 量程切换（继电器/模拟开关）
- 校准（零点 + 满量程）

### 扩展
- 加自动量程（继电器切换分压比）
- 加电阻测量（恒流源 + ADC）
- 加二极管导通电压测量
