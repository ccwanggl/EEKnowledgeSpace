# 2. 温湿度监测站

**目标**：掌握数字传感器和 I2C 通信。

## 硬件
- DHT22 或 BME280（推荐 BME280，精度高）
- Arduino / ESP32 / STM32
- I2C OLED（SSD1306，可选）或串口打印

### 技能点
- I2C 通信（地址、读写、寄存器）
- 传感器数据读取和转换
- 数值显示（串口或 OLED）
- 温湿度物理意义

### 扩展
- 加气压传感器（BME280 自带），计算海拔
- 加 microSD 模块，记录数据到 CSV
- 加 ESP32 WiFi，上传数据到 ThingSpeak/自建服务器

### 资源
- **DroneBot Workshop** — BME280 + OLED 项目
- **Adafruit BME280 教程**（[[02-博客与网站推荐]]）

### 项目来源与详细资源

- **Adafruit BME280 官方教程**（接线、Arduino/CircuitPython 代码、气压测海拔原理）：https://learn.adafruit.com/adafruit-bme280-humidity-barometric-pressure-temperature-sensor-breakout
  - BME280 库通过 Arduino IDE 库管理器安装 `Adafruit BME280` + `Adafruit Unified Sensor`（BSD 协议开源）
  - DHT22 对应 Adafruit DHT sensor library，教程同在 learn.adafruit.com
- **BME280 数据手册**：Bosch Sensortec 官网（bst-bme280-ds002.pdf），I2C 地址 0x76/0x77，SPI 模式可避开地址冲突
- **OLED 显示**：SSD1306 用 Adafruit_SSD1306 库（128×64 I2C 接线仅需 4 线）
- **数据上传扩展**：ThingSpeak（MathWorks 免费 IoT 云平台，thingspeak.com，ESP32 有现成库）；或 MQTT 接入 Home Assistant
- **开源参考实现**：立创开源平台搜索 "温湿度"（如基于 STM32/ESP32 的 OLED 气象站工程，含原理图与 PCB）
