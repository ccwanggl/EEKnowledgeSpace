# 核心 API

## 任务管理
```c
// 创建任务
xTaskCreate(vTaskFunction, "TaskName", STACK_SIZE, pvParameters, PRIORITY, &xHandle);
// 删除任务
vTaskDelete(xHandle);
// 延时
vTaskDelay(pdMS_TO_TICKS(100));  // 100ms
// 挂起/恢复
vTaskSuspend(xHandle);
vTaskResume(xHandle);
```

### 队列
```c
QueueHandle_t xQueue = xQueueCreate(10, sizeof(uint32_t));
xQueueSend(xQueue, &value, portMAX_DELAY);       // 发送，阻塞
xQueueReceive(xQueue, &value, portMAX_DELAY);    // 接收，阻塞
```

### 信号量
```c
// 二值信号量
SemaphoreHandle_t xSemaphore = xSemaphoreCreateBinary();
xSemaphoreGive(xSemaphore);
xSemaphoreTake(xSemaphore, portMAX_DELAY);

// 计数信号量
SemaphoreHandle_t xCounting = xSemaphoreCreateCounting(10, 0);

// 互斥量
SemaphoreHandle_t xMutex = xSemaphoreCreateMutex();
```

### 事件组
```c
EventGroupHandle_t xEventGroup = xEventGroupCreate();
xEventGroupSetBits(xEventGroup, BIT_0);  // 设置位
EventBits_t bits = xEventGroupWaitBits(xEventGroup, BIT_0, pdTRUE, pdFALSE, portMAX_DELAY);
```

### 软件定时器
```c
TimerHandle_t xTimer = xTimerCreate("Timer", pdMS_TO_TICKS(1000), pdTRUE, NULL, vCallback);
xTimerStart(xTimer, 0);
```
