# 核心特点

## 组件丰富
- 内核 + 驱动 + 文件系统 + 网络 + GUI + 包生态
- 软件包数量 > 500 个
- 覆盖传感器、通信、AI、安全等多个领域

### POSIX 兼容
- 支持 pthread、socket、文件 API
- 接近 Linux 的开发体验
- 方便应用迁移

### 多语言支持
- C/C++
- Python（MicroPython）
- JavaScript、Lua

### 开发工具
- **RT-Thread Studio**：基于 Eclipse 的国产 IDE
- 对国产 MCU（GD32、CH32、FM33、N32 等）支持极好

### 版本
- **标准版**：完整功能，组件丰富
- **Nano 版**：极简内核，3KB Flash + 1.2KB RAM
