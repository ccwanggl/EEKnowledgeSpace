# Zephyr vs RT-Thread vs FreeRTOS

| 特性 | Zephyr | RT-Thread | FreeRTOS |
|------|--------|-----------|----------|
| 起源 | 2016，Linux 基金会 | 2006，中国 | 2003，Richard Barry |
| 许可 | Apache 2.0 | Apache 2.0 | MIT |
| 生态 | 国际 IoT/安全 | 中国/国产芯片/丰富组件 | 全球通用，最精简 |
| 连接 | 内置完善 | 软件包扩展 | FreeRTOS+TCP |
| 安全 | PSA Certified，强 | 一般 | 可选（AWS） |
| 中文支持 | 文档翻译中 | 极好，中文社区庞大 | 英文为主 |
| 国产芯片 | 支持，但 RT-Thread 更好 | 最佳 | 支持 |
| 学习曲线 | 陡峭（Kconfig/Device Tree） | 中等 | 平缓 |
| 适合场景 | 安全 IoT、国际项目 | 国内项目、国产芯片、快速开发 | 通用、资源受限、学习 |
