# 常见 RTOS

| RTOS | 许可 | 特点 | 适用 |
|------|------|------|------|
| **FreeRTOS** | MIT（开源） | 最流行，轻量，移植简单，生态庞大 | 通用 |
| **Zephyr** | Apache 2.0 | 现代，安全，丰富协议栈，Linux 基金会 | IoT、边缘 |
| **RT-Thread** | Apache 2.0 | 国产，组件丰富，POSIX 兼容，中文社区 | 国内 |
| **NuttX** | Apache 2.0 | POSIX 兼容，接近 Linux 体验，NASA 使用 | 航天、高端 |
| **ThreadX** | 商业（微软） | 快速，安全认证（SIL 4），Azure RTOS | 汽车、医疗 |
| **embOS** | 商业（SEGGER） | 小巧，稳定，J-Link 集成 | 工业 |
| **Micrium OS** | 商业（Silabs） | 前身 uC/OS，稳定，安全认证 | 工业 |
| **ChibiOS/RT** | GPL/商业 | 极快，极小，适合硬实时 | 汽车、机器人 |
| **Apache NuttX** | Apache 2.0 | 真正的 POSIX 兼容，文件系统完整 | 复杂系统 |
