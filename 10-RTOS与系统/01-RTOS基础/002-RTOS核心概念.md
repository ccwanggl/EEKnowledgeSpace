# RTOS 核心概念

## 任务（Task）
- 独立执行的线程，有自己的栈和优先级
- 状态：Running（运行）、Ready（就绪）、Blocked（阻塞）、Suspended（挂起）
- 创建：指定任务函数、栈大小、优先级、参数

### 调度器（Scheduler）
- **抢占式调度**：高优先级就绪任务立即抢占 CPU
- **时间片轮转**：同优先级任务按时间片轮流执行
- **上下文切换**：保存当前任务状态，恢复下一个任务状态（通常 < 1ms）
- **Tick**：系统时钟中断，驱动调度器（通常 1ms~10ms）

### 同步与通信
| 机制 | 用途 | 类比 |
|------|------|------|
| **信号量（Semaphore）** | 资源计数、互斥 | 停车场空位计数 |
| **互斥量（Mutex）** | 互斥访问共享资源 | 厕所门锁（优先级继承） |
| **队列（Queue）** | 任务间传递数据 | 流水线 |
| **事件组（Event Group）** | 多条件同步 | 标志位集合 |
| **任务通知（Task Notification）** | 轻量同步，一对一 | 直接消息 |
| **流缓冲区/消息缓冲区** | 轻量队列 | 单生产者/单消费者优化 |

### 中断与 ISR
- ISR 中通常只做最小工作：设标志或释放信号量
- 实际处理在任务中完成，避免 ISR 耗时过长
- 某些 RTOS 提供"FromISR"版本 API，用于中断上下文
