# 推荐资源

## 官方文档
- **Rockchip Linux SDK** — 官方内核、u-boot、MPP（瑞芯微资源门户，提取码：rknn）
- **RKNN SDK 文档** — 最新 SDK 指南和 API 参考
- **RKNPU2 教程** — NPU 从入门到实践
- **RK3588 数据手册** — 官方规格（6 TOPS，8K@60fps）

### 社区与教程
- **Radxa 文档** — ROCK 5 系列优质英文文档
- **野火 LubanCat 手册** — 最佳中文 RK3588 教程
- **香橙派论坛** — 社区问题讨论与镜像分享
- **Armbian RK3588** — 官方 Armbian 移植支持
- **CNX Software** — 单板计算机新闻和评测

### 经典教材
- **"Linux Device Drivers"**（Jonathan Corbet）— 经典教材，免费在线
- **"Mastering Embedded Linux Programming"**（Chris Simmonds）
- **Buildroot 官方文档** — 简单构建系统
- **Yocto Project Documentation** — 复杂构建系统
- **Bootlin** — 免费嵌入式 Linux 培训视频（bootlin.com）

### 开源项目参考
- **RKNN Model Zoo** — 30+ 官方预训练模型示例（YOLO11、SAM、Whisper、CLIP）
- **rknn-multi-threaded** — 多线程 NPU 推理（性能 +40%）
- **GStreamer MPP** — 硬件加速视频管线
- **FFmpeg RKMPP** — 8K 视频编解码
- **RKLLM Examples** — 边缘 LLM 聊天机器人示例

### 开发工具
- **RKDevTool** — 固件烧录工具（Windows/Linux）
- **RKNN-Toolkit2 Docker** — 预配置模型转换环境
- **NPU 监控**：`cat /sys/kernel/debug/rknpu/load`
