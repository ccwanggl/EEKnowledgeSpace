# 学习路径（以 RK3588 为核心平台）

## 阶段一：环境搭建（1-2 周）
1. 购买一块 RK3588 开发板（推荐香橙派 5 或 野火 LubanCat-4）
2. 烧录 Ubuntu Rockchip 或 Armbian 系统镜像
3. 配置 SSH、WiFi、基本开发环境（gcc、python、git）
4. 熟悉 RK3588 的硬件接口：GPIO、UART、I2C、SPI、PCIe

### 阶段二：系统开发基础（2-4 周）
1. 学习 Linux 内核编译和烧录（使用 Rockchip 官方内核）
2. 理解 RK3588 设备树结构，修改 `.dts` 启用外设
3. 学习 U-Boot 编译和启动参数配置
4. 使用 Buildroot 构建最小根文件系统

### 阶段三：驱动与接口开发（3-4 周）
按 [[16-Linux设备驱动开发/00-README|Linux 设备驱动开发]] 章节九节推进：
1. 闭环与环境：[[16-Linux设备驱动开发/001-开发环境与内核模块|开发环境与内核模块]] → [[16-Linux设备驱动开发/002-字符设备驱动开发|字符设备驱动开发]]
2. 主干理论：[[16-Linux设备驱动开发/003-Linux设备模型|Linux 设备模型]] + [[16-Linux设备驱动开发/004-设备树开发|设备树开发]]
3. 机制与实战：[[16-Linux设备驱动开发/005-中断体系开发|中断体系]] → [[16-Linux设备驱动开发/006-GPIO和Pinctrl子系统|GPIO 和 Pinctrl]] → [[16-Linux设备驱动开发/007-主流外设驱动|主流外设驱动（含 libgpiod、spidev 用户态）]]
4. 收尾能力：[[16-Linux设备驱动开发/008-驱动调试排错|驱动调试排错]] + [[16-Linux设备驱动开发/009-工程实战能力|工程实战能力（RK 内核工作流）]]
5. 扩展：理解 PCIe 设备枚举和驱动加载（如 NVMe SSD）

### 阶段四：AI 推理与 NPU（3-4 周）
1. 安装 RKNN-Toolkit2 和 RKNPU2 Runtime
2. 将 ONNX 模型（如 YOLOv5）转换为 RKNN 格式
3. 在 RK3588 上运行 C++ 推理示例
4. 使用 RGA 进行图像预处理，优化端到端性能
5. 尝试 RKLLM 部署 TinyLlama 或 Qwen2

### 阶段五：多媒体与产品化（持续）
1. 使用 GStreamer + MPP 实现硬件加速视频编解码
2. 使用 FFmpeg RKMPP 进行 8K 视频处理
3. 设计多线程 NPU 推理架构（rknn-multi-threaded）
4. 系统性能优化：CPU 调频、DDR 带宽、热管理
5. 产品化：OTA 升级、系统安全、看门狗、日志系统
