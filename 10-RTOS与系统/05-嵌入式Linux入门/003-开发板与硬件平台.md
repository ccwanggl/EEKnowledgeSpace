# 开发板与硬件平台

## RK3588 平台详解

**RK3588 核心规格**：
- **CPU**：四核 Cortex-A76 @ 2.4GHz + 四核 Cortex-A55 @ 1.8GHz
- **GPU**：Mali-G610 MC4，支持 OpenGL ES 3.2 / Vulkan 1.2
- **NPU**：6 TOPS INT8，支持 TensorFlow / PyTorch / ONNX / Caffe
- **VPU**：8K@60fps H.265/H.264 解码，8K@30fps 编码
- **内存**：支持 LPDDR4/LPDDR4X/LPDDR5，最高 32GB
- **接口**：PCIe 3.0 x4、USB 3.1、SATA 3.0、MIPI CSI/DSI、HDMI 2.1、eDP
