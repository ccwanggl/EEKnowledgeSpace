# 编码器反馈

## 常见反馈器件
- **霍尔传感器**：检测转子位置，用于 BLDC 换相
- **光电编码器**：增量式/绝对式，测转速和位置
- **磁编码器**：抗污染，适合恶劣环境
- **电流采样电阻**：无传感器控制

### 增量编码器测速
```c
// 单位时间内的脉冲数换算 RPM
float calculate_rpm(int32_t pulse_count, int32_t ppr, float dt)
{
    return (pulse_count / (float)ppr) * 60.0f / dt;
}
```
