# 模拟传感器接口

## 信号调理链
```
传感器 → 放大/滤波 → 电平偏移 → ADC → 数字处理
```

### 放大
- **分压电路**：电阻式传感器（光敏、热敏）
- **仪表放大器**：微弱差分信号（应变片、电桥）
- **跨阻放大器**：电流输出传感器（光电二极管）
- **电荷放大器**：压电传感器（振动、冲击）

### 滤波
- 抗混叠滤波：ADC 前必须加低通，截止频率 < $f_s/2$
- 噪声滤波：RC 或运放有源滤波（[[03-滤波器设计]]）

### 电平偏移
- 双极性信号（如 ±10V）转单极性（0~3.3V）
- 使用运加法器或专用电平转换 IC
