# 显示器件

## LED（发光二极管）
- 简单指示：GPIO + 限流电阻（$R = (V_{CC} - V_f)/I_f$）
- 高亮 LED：需要晶体管或 MOSFET 驱动
- RGB LED：3 路 PWM 控制颜色
- WS2812B/NeoPixel：单线串行，可级联，每个 LED 独立地址
- 注意：LED 是功耗陷阱，设计低功耗系统时需谨慎

### 七段数码管
- 共阴/共阳：所有段公共端接 GND/VCC
- 直接驱动：7~8 个 GPIO + 限流电阻
- 驱动芯片：74HC595（移位寄存器）、TM1637、MAX7219
- 多位显示：动态扫描（人眼视觉暂留）或专用驱动芯片

### LCD（液晶显示）
- **字符 LCD（1602/2004）**：HD44780 控制器，并行或 I2C 转接板（PCF8574）
- **图形 LCD（12864）**：ST7920/SSD1306，SPI/并行
- **TFT LCD**：ILI9341、ST7735，SPI/8080 并行，彩色，带触摸屏
- **e-Paper**：电子墨水，极低功耗，刷新慢，适合静态显示

### OLED
- SSD1306/SSD1331/SH1106，I2C 或 SPI
- 自发光，对比度高，视角广，响应快
- 适合小型仪表、可穿戴、状态显示
