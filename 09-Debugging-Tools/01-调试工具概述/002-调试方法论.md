# 调试方法论

## 分层调试
1. **硬件层**：电源、时钟、复位、焊接、短路、开路
2. **信号层**：波形、电平、时序、协议帧
3. **驱动层**：寄存器配置、中断、DMA、外设状态
4. **应用层**：算法、状态机、通信、数据处理

### 常用调试流程
1. **上电检查**：万用表测各电源电压
2. **时钟检查**：示波器看晶振/时钟波形
3. **复位检查**：确保复位正确释放
4. **最小系统**：先让 LED 闪烁，确认 MCU 运行
5. **串口输出**：重定向 printf，查看程序状态
6. **断点调试**：JTAG/SWD 单步跟踪问题代码
7. **逻辑分析**：抓取通信协议波形，对比预期
8. **信号完整**：高速问题用示波器看眼图、抖动

### 调试思维
- **分而治之**：缩小问题范围，定位到最小可复现单元
- **对比法**：好板 vs 坏板、好代码 vs 坏代码、仿真 vs 实测
- **替换法**：替换怀疑的元件/模块/线缆
- **假设验证**：提出假设，设计实验验证或推翻
- **记录一切**：波形截图、寄存器值、日志，便于复盘
