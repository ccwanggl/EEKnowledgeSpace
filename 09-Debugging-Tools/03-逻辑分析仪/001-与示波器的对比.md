# 与示波器的对比

| 特性 | 示波器 | 逻辑分析仪 |
|------|--------|------------|
| 测量对象 | 模拟电压波形 | 数字逻辑电平 |
| 通道数 | 2~4（模拟） | 8~32+（数字） |
| 采样率 | 高（GSa/s） | 高（MHz~GHz） |
| 分析能力 | 时域、频域、眼图 | 时序、状态、协议解码 |
| 存储深度 | 有限 | 很大（长时间采集） |
| 触发 | 边沿、脉宽、串行 | 复杂模式、多通道、协议 |
| 适用 | 信号质量、模拟电路 | 协议调试、总线分析、时序验证 |

**两者互补**：示波器看信号质量，逻辑分析仪看协议内容。
