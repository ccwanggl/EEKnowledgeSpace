# 逻辑分析仪类型

## 入门级（$10~$100）
- **USB 逻辑分析仪**：连接 PC，软件分析
  - Saleae Logic（原版 $400，国产兼容 $15~$30）
  - DSLogic（梦源科技，$70~$150，开源硬件）
  - Kingst LA（$30~$80，功能全面）
- **特点**：8~16 通道，20~100MHz 采样率，协议解码丰富
- **适用**：Arduino、STM32、ESP32 项目调试

### 专业级（$500~$5000）
- **Saleae Logic Pro 16/8**：$400~$1000，100MHz/500MHz，专业软件
- **DSLogic Plus**：$150，400MHz，开源
- **PicoScope MSO**：集成示波器 + 逻辑分析
- **特点**：高采样率、大存储、更多协议、更稳定触发
- **适用**：高速总线、复杂系统、工业调试

### 高端（$10000+）
- **Tektronix/Keysight/R&S**：MSO 混合信号示波器
- **独立逻辑分析仪**：已逐渐被 MSO 替代
- **特点**：几十到上百通道，GHz 采样率，与示波器时间相关
- **适用**：ASIC 验证、复杂 SoC 调试
