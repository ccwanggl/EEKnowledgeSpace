# 使用技巧

## 连接
- 探头：钩夹或杜邦线，连接被测信号
- 接地：所有通道共用地，确保与被测系统地连接良好
- 阈值电压：设置与逻辑电平匹配（1.8V/2.5V/3.3V/5V TTL/CMOS）
- 采样率：≥ 4× 信号频率（如 1MHz 信号，采样率 ≥ 4MHz）

### 调试 I2C
1. 连接 SCL 和 SDA 到逻辑分析仪
2. 设置协议解码为 I2C，指定 SCL 和 SDA 通道
3. 触发：设置 I2C 地址触发，或 START 条件触发
4. 采集：发送数据，观察解码结果
5. 分析：检查地址是否正确、ACK/NACK、数据内容

### 调试 SPI
1. 连接 SCK、MOSI、MISO、CS（可选）
2. 设置 SPI 协议解码，指定模式和位序（MSB/LSB）
3. 触发：CS 下降沿或特定数据
4. 采集：发送 SPI 命令，观察收发数据

### 调试 UART
1. 连接 TX 和 RX（单向各一根）
2. 设置 UART 解码，指定波特率、数据位、停止位、校验
3. 触发：特定字符或 START 位
4. 采集：发送数据，观察解码文本
