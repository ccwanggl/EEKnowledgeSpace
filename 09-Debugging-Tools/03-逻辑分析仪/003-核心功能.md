# 核心功能

## 协议解码
支持的协议越多，越方便：
- 基本：UART、SPI、I2C、1-Wire、CAN、LIN
- 存储：I2S、SATA、SDIO、eMMC
- 网络：Ethernet MII/RMII、USB（LS/FS/HS）、PCIe
- 无线：BLE（需配合嗅探器）、SPI 转无线模块
- 自定义：可定义任意串行/并行协议

### 触发功能
- **边沿触发**：任一通道上升/下降沿
- **模式触发**：多通道组合状态（如 "CS 低 + MOSI 特定数据"）
- **协议触发**：触发特定 UART 字符、I2C 地址、SPI 数据
- **序列触发**：多个事件的顺序触发
- **毛刺触发**：捕获窄脉冲（如电源噪声导致的错误触发）

### 时序分析
- 测量两个信号的时间差（建立时间、保持时间、延迟）
- 总线状态表：将所有通道组合成状态表，类似逻辑分析仪的传统显示
- 时间戳：精确测量事件间隔
