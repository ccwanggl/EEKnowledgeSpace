# 串口调试技巧

## 常见问题
| 现象 | 可能原因 | 解决 |
|------|----------|------|
| 输出乱码 | 波特率不匹配 | 检查双方波特率 |
| 无输出 | TX/RX 接反、未共地 | 交叉接线，共 GND |
| 丢数据 | 缓冲区溢出 | 增加缓冲区或使用流控 |
| 部分打印 | 半主机未关闭 | 禁用半主机，使用 retarget |

### 协议解码
- 用逻辑分析仪捕获 UART 波形
- 配合 PC 串口助手（如 PuTTY、SecureCRT、SSCOM）
- 复杂协议可用 Python + pyserial 分析

### 时间戳
- 在日志中加入系统 tick 或 RTC 时间
- 便于分析时序问题和延迟
