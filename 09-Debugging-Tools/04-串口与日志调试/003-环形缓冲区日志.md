# 环形缓冲区日志

## 作用
- 解耦日志生成与输出
- 避免 `printf` 阻塞实时任务
- 可在中断中安全写入

### 基本实现思路
```c
#define LOG_BUF_SIZE 1024

typedef struct {
    uint8_t buf[LOG_BUF_SIZE];
    volatile uint16_t head;
    volatile uint16_t tail;
} log_ring_t;

void log_put(char c);
int log_get(char *c);
void log_flush(void);  // 在后台任务中调用
```
