# 调试功能

## 基础调试
- **断点（Breakpoint）**：程序运行到特定地址停止
- **单步（Step）**：Step Into（进入函数）、Step Over（跳过函数）、Step Out（跳出函数）
- **运行/暂停（Run/Halt）**：控制程序执行状态
- **寄存器查看**：CPU 寄存器、外设寄存器
- **内存查看**：任意地址读写，查看变量、缓冲区
- **调用栈（Call Stack）**：查看函数调用层次
- **反汇编**：查看机器码和汇编指令

### 高级调试
- **条件断点**：满足特定条件时才触发（如变量 == 某个值）
- **数据观察点（Watchpoint）**：变量被读写时触发
- **ITM/SWO**：ARM Cortex-M 的仪器跟踪宏单元，单线输出 printf、事件、数据
- **ETM/Trace**：指令追踪，记录程序执行流，需要特殊硬件和连接器
- **RTOS 感知**：查看 FreeRTOS 任务列表、队列、信号量状态（需要插件）
