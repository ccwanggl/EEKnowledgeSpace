# F

- **FAT（File Allocation Table）**：文件分配表，嵌入式常用文件系统
- **FET（Field-Effect Transistor）**：场效应晶体管，如 MOSFET
- **FF（Flip-Flop）**：触发器，时序逻辑基本单元
- **FFT（Fast Fourier Transform）**：快速傅里叶变换，时域到频域转换
- **FIFO（First In First Out）**：先进先出队列，数据缓冲
- **FPU（Floating Point Unit）**：浮点运算单元
- **FPGA（Field-Programmable Gate Array）**：现场可编程门阵列
- **FR-4**：玻纤环氧树脂覆铜板，最常用 PCB 基材
- **FSM（Finite State Machine）**：有限状态机
- **FTDI**：Future Technology Devices International，USB 转串口芯片厂商
