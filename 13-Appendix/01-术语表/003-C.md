# C

- **CAN（Controller Area Network）**：控制器局域网总线，工业/汽车通信标准
- **CMRR（Common-Mode Rejection Ratio）**：共模抑制比，差分电路抑制共模噪声的能力
- **CPLD（Complex Programmable Logic Device）**：复杂可编程逻辑器件，比 FPGA 小
- **Copper Pour**：铺铜，PCB 上大面积铜箔，用于散热、屏蔽和提供参考平面
- **CPU（Central Processing Unit）**：中央处理器
- **CRC（Cyclic Redundancy Check）**：循环冗余校验，错误检测码
- **Crosstalk**：串扰，相邻信号线之间的电磁耦合干扰
- **CSI（Camera Serial Interface）**：MIPI 相机串行接口
- **CSI（Chip Scale Package）**：芯片级封装
