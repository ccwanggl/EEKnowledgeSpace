# 全库审阅与内容规划

## 审阅范围

本次审阅覆盖正式知识内容、顶层导航、内部链接、本地附件和 Markdown 结构。`.obsidian`、`.trash`、`copilot`、`Clippings` 与 `Excalidraw` 不作为正式正文参与质量统计。

重构前知识库共有 853 篇 Markdown，正式内容区有 822 篇。约 375 篇不超过 30 行，基础理论、FOC 和控制理论占据了大部分内容体量，其他工程模块以提纲和速查笔记为主。

## 重构前的主要问题

- 总首页达到 1837 行，同时承担导航、路线图、插件测试、看板、闪卡和历史报告，入口职责不清。
- 正文存在 354 个目录伪链接、263 个缺失目标和 178 个歧义目标。
- 两篇笔记的代码或公式围栏不成对，19 篇没有一级标题，13 篇有多个一级标题。
- 多个顶层 README 只有动态查询，没有稳定的静态模块入口。
- 机器视觉目录只有规划页，却在导航中表现得像已完成模块。
- `11-Machine-Vision` 与 `11-Projects` 共用编号。直接重命名会影响大量路径，本轮保留目录名并在导航中明确区分。

## 本轮处理

- 原总首页已归档，新首页只保留稳定入口和 FOC 主线。
- 新建学习路线、主题索引、测验索引、闪卡和交互学习页面。
- 顶层 README 增加静态模块导航，Dataview 继续作为辅助视图。
- 目录链接和歧义短链接改为明确路径；没有对应笔记的普通概念恢复为正文文本，不再制造空链接。
- 修复代码围栏、公式围栏和一级标题结构。
- 机器视觉改为明确的 `seed` 状态，不创建只有标题的占位笔记。
- 修订 ADC 采样和 SNR 条件、FOC 先修关系、参数辨识目标，以及 MPC 终端代价和稳定性表述。

## 后续优先级

### P1：FOC 工程闭环

1. 建立一套可复现的 PMSM 参数、母线电压、采样频率和负载工况。
2. 用同一套参数贯通模型、PI 设计、SVPWM、仿真和嵌入式实现。
3. 为电流采样、角度方向、死区、过流、欠压和失速分别建立测试步骤与通过条件。
4. 代码示例补齐平台、编译环境、定时器配置和预期波形。

### P2：基础内容去重复

信号与系统、经典控制和 FOC 中重复的一阶、二阶、采样和 PI 内容应由基础笔记给出定义与边界，应用笔记只保留本领域的参数和例子。跨模块引用采用明确路径，不复制整段推导。

### P3：短笔记治理

- 只包含链接的页面并入模块总览。
- 公式速查保留独立页，但补齐符号、单位和适用条件。
- 学习路径、推荐资源和相关主题优先放到模块总览，避免每个子目录重复同一模板。
- 没有项目需求的空白主题保持规划状态，不生成占位正文。
