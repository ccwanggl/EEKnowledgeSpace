# 二极管选型

## 关键参数
- **$V_f$**：正向压降（硅 0.7V，肖特基 0.2~0.5V，LED 1.8~3.3V）
- **$I_{max}$**：最大正向电流
- **$V_{RRM}$**：反向重复峰值电压
- **$t_{rr}$**：反向恢复时间（肖特基最快，<10ns；普通二极管慢，μs 级）
- **封装**：SOD-123、SMA、SMB、SMC、TO-220

### 类型速查
| 类型 | 特点 | 应用 |
|------|------|------|
| **整流二极管** | 1N4007，1A/1000V，慢 | 工频整流 |
| **肖特基** | 低压降、快速、软恢复 | DC-DC、高频整流、防反接 |
| **快恢复/超快恢复** | 几十~几百 ns | 开关电源、逆变器 |
| **齐纳二极管** | 稳压，反向击穿 | 基准、过压保护、电平偏移 |
| **TVS 二极管** | 瞬态抑制，响应快 | ESD/浪涌保护 |
| **LED** | 发光，注意 $V_f$ 和 $I_f$ | 指示、照明、光耦 |
| **光耦** | 光隔离，输入输出隔离 | 强弱电隔离、通信隔离 |
| **续流二极管** | 并联在感性负载上 | 继电器、电机、电感保护 |
