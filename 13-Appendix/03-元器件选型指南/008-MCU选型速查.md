# MCU 选型速查

| 需求 | 推荐平台 | 代表型号 | 理由 |
|------|----------|----------|------|
| 极简入门、教育 | Arduino | ATmega328P | 生态最大，最友好 |
| 快速 IoT 原型 | ESP32 | ESP32-WROOM-32 | WiFi+BLE，$3 |
| 专业嵌入式入门 | STM32 | STM32F103/407 | 生态完善，文档全 |
| 超低功耗传感器 | STM32L4 | STM32L476 | 1.2μA Stop2 |
| 数字电源/电机 | STM32G4 | STM32G431 | 高分辨率定时器 |
| 高性能+HMI | STM32H7 | STM32H743 | 480MHz，图形加速 |
| 国产替代 | GD32 | GD32F103 | 兼容 STM32，更便宜 |
| 国产 RISC-V | CH32V307 | CH32V307VCT6 | 144MHz，USB+ETH+CAN |
| 安全 IoT | Nordic nRF52 | nRF52840 | BLE 5，Zephyr 原生 |
| 智能家居网关 | Raspberry Pi | Raspberry Pi 4/5 | Linux，完整生态 |
| 可穿戴低功耗 | Apollo / Ambiq | Apollo3 | <1μA 睡眠，Cortex-M4F |
| 教育/快速原型 | Raspberry Pi Pico | RP2040 | $4，PIO，MicroPython |
| 高性能 Pico | Pico 2 | RP2350 | 双核，FPU，TrustZone |
| Matter/Thread | ESP32-C6 | ESP32-C6 | WiFi 6 + BLE + 802.15.4 |
| 纯 LoRa | STM32WL | STM32WL55 | 集成 LoRa + MCU |
| 边缘 AI | NVIDIA Jetson | Nano/Orin | GPU + CUDA，AI 推理 |
| 汽车/功能安全 | NXP S32K | S32K3 | ASIL D，安全认证 |
