# 连接器选型

| 类型 | 应用 | 注意 |
|------|------|------|
| **杜邦线/排针** | 面包板、原型 | 2.54mm，注意电流限制 |
| **USB-A/B/C** | 供电、数据、OTG | USB-C 需注意 CC 配置 |
| **JST** | 电池、小信号 | 多种间距（1.0/1.25/2.0/2.5mm），防呆 |
| **XT60/XT30** | 电池、大电流 | 航模标准，大电流低接触电阻 |
| **DC 电源插座** | 外部电源输入 | 5.5/2.1mm 最常见 |
| **RJ45** | 以太网 | 带/不带变压器（Magjack） |
| **SD 卡座** | 存储扩展 | 推推式或翻盖式 |
| **FPC/FFC** | 显示屏、摄像头 | 0.5mm 或 1.0mm 间距 |
| **SMA/BNC/U.FL** | 射频/天线 | 50Ω，匹配阻抗 |
| **PH2.0/XH2.54** | 国产常用 | 连接器成本低，注意质量 |
| **板对板** | 模块连接 | 高插拔寿命、防呆、屏蔽 |
