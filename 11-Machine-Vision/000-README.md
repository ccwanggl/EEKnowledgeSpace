## 计划内容

1. 图像表示、颜色空间、卷积、几何变换和形态学处理。
2. 边缘、角点、特征描述子、匹配和目标检测。
3. 针孔相机模型、畸变、单目标定和双目标定。
4. 立体视觉、深度估计、点云和坐标变换。
5. 嵌入式视觉中的吞吐量、延迟、内存、量化和硬件加速。
6. 工业视觉中的光学、照明、触发、标定、验收和误检分析。

## 建设原则

- 每篇内容需要给出可运行示例、输入数据和预期结果。
- 算法指标必须说明数据集、分辨率、平台和统计口径。
- 工业案例同时记录镜头、工作距离、照明、曝光和机械公差。
- 在内容达到可复现标准前，不创建只有标题的占位笔记。
