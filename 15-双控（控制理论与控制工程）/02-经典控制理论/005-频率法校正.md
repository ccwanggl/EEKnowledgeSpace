# 频率法校正

## 为什么需要校正

通过前几章的学习，我们知道：
- 时域分析：响应快的系统（$\omega_n$ 大）往往超调也大（$\zeta$ 小）
- 频域分析：相位裕度小（$\gamma < 30°$）系统振荡剧烈，相位裕度大（$\gamma > 60°$）系统响应慢
- 稳态精度：0型系统对阶跃有常值误差，I型对斜坡有误差，II型对加速度有误差

**校正**就是给系统"打补丁"——在原有控制器或对象的基础上，增加一个**补偿网络**（或称校正环节），使开环频率特性发生期望的改变，从而改善闭环性能。

校正设计的目标通常是：
1. 足够的相位裕度（$\gamma = 45° \sim 60°$）
2. 足够的增益裕度（$GM > 6$ dB）
3. 满足稳态精度要求（足够的低频增益或积分环节）
4. 足够的高频衰减（抗噪声干扰）
5. 合理的穿越频率（响应速度适中）

## 校正网络的类型

| 类型 | 传递函数 | 核心作用 | 效果 | 典型应用 |
|------|---------|---------|------|---------|
| 超前校正 | $\frac{1+\alpha Ts}{1+Ts}$ ($\alpha > 1$) | 提供正相位 | 增加相位裕度，提高响应速度 | 系统稳定但响应慢 |
| 滞后校正 | $\frac{1+Ts}{1+\beta Ts}$ ($\beta > 1$) | 降低高频增益 | 牺牲速度换稳态精度，增加低频增益 | 稳态精度不足 |
| 滞后-超前 | 两者组合 | 同时改善相位和增益 | 综合改善动态和稳态 | 系统同时有动态和稳态问题 |
| PID | $K_p + K_i/s + K_ds$ | 综合 | 比例快速、积分消误差、微分预见 | 工业控制最常用 |

## 超前校正：给系统"打兴奋剂"

### 物理直觉

超前校正的传递函数：

$$G_c(s) = \frac{1 + \alpha Ts}{1 + Ts}, \quad \alpha > 1$$

- **零点**：$s = -1/(\alpha T)$（在极点左侧，离虚轴更远）
- **极点**：$s = -1/T$（离虚轴更近）

```text
      Im(s)
        |
        |    x 极点 = -1/T
        |    |
        |    |    o 零点 = -1/(αT)
        |    |    |
   -----+----+----+---- Re(s)
        |    |    |
        |    |    |
        |    x    o
        |
```

零极点在负实轴上，零点比极点更靠左。在Bode图上，这对应于：
- 低频段：增益为 0 dB（$s \to 0$ 时 $G_c(s) \to 1$）
- 高频段：增益为 $20\log_{10}\alpha$ dB（$s \to \infty$ 时 $G_c(s) \to \alpha$）
- 在零点转角频率 $\omega_z = 1/(\alpha T)$ 和极点转角频率 $\omega_p = 1/T$ 之间，提供正相位

### 最大超前角与频率

超前网络的相位特性：

$$\phi(\omega) = \arctan(\alpha T\omega) - \arctan(T\omega)$$

用三角恒等式可以证明，最大超前角发生在几何中心频率：

$$\omega_m = \frac{1}{T\sqrt{\alpha}} = \sqrt{\omega_z \omega_p}$$

最大超前角：

$$\sin(\phi_m) = \frac{\alpha - 1}{\alpha + 1} \quad \Rightarrow \quad \alpha = \frac{1 + \sin\phi_m}{1 - \sin\phi_m}$$

| 需要的 $\phi_m$ | 10° | 20° | 30° | 40° | 50° | 60° |
|---------------|-----|-----|-----|-----|-----|-----|
| $\alpha$ | 1.42 | 2.04 | 3.0 | 4.6 | 7.5 | 13.9 |
| 高频增益 (dB) | 3.0 | 6.2 | 9.5 | 13.3 | 17.5 | 22.8 |

> **关键约束**：单个超前网络能提供的最大超前角一般不超过 $60°$（$\alpha = 13.9$）。如果需要更大相位补偿，应使用两个超前网络串联，而不是无限增大 $\alpha$（高频增益过大会放大噪声）。

### 设计步骤

超前校正设计的典型流程：

1. **确定未校正系统的性能**：根据开环传递函数 $G(s)$，画Bode图，确定当前的 $\omega_c$、$\gamma$、$K_p$（或 $K_v$、$K_a$）
2. **明确校正目标**：需要的相位裕度 $\gamma^*$ 和穿越频率 $\omega_c^*$
3. **计算需要的相位补偿**：$\phi_m = \gamma^* - \gamma_{current} + \Delta$（$\Delta$ 是安全裕量，通常 $5° \sim 10°$，因为超前校正会提高穿越频率，原系统在新 $\omega_c$ 处的相位更负）
4. **计算 $\alpha$**：$\alpha = \frac{1 + \sin\phi_m}{1 - \sin\phi_m}$
5. **确定新的穿越频率**：在未校正系统的幅频特性上，找到 $-20\log_{10}\sqrt{\alpha}$ dB 对应的频率作为 $\omega_c^*$（因为超前网络在 $\omega_m$ 处提供 $10\log_{10}\alpha$ dB 的增益提升）
6. **计算 $T$**：$T = \frac{1}{\omega_c^*\sqrt{\alpha}}$，然后 $\omega_z = 1/(\alpha T)$，$\omega_p = 1/T$
7. **验证**：画出校正后的Bode图，检查相位裕度、增益裕度、稳态误差是否满足要求
8. **若不满足**：调整安全裕量或增加校正级数，重复步骤3-7

### 数值示例：超前校正设计

#### 问题

给定被控对象 $G(s) = \frac{K}{s(s+1)}$，要求：
- 速度误差系数 $K_v \geq 10$ s$^{-1}$
- 相位裕度 $\gamma \geq 45°$

设计超前校正网络。

#### 解答

**步骤1：确定开环增益**

$K_v = \lim_{s\to 0} sG(s) = K$，所以 $K = 10$。

未校正系统：$G(s) = \frac{10}{s(s+1)}$。

**步骤2：分析未校正系统**

Bode图：
- 积分环节：低频 -20 dB/dec
- 惯性环节：转角频率 $\omega = 1$ rad/s，此后 -40 dB/dec
- $L(1) = 20\log_{10}(10/1) = 20$ dB
- 穿越频率估计：在 -40 dB/dec 段，从 $\omega=1$（$L=20$ dB）到 $\omega=10$（$L=-20$ dB），穿越在 $\omega \approx 3.08$ rad/s（精确计算：$10/(\omega_c\sqrt{\omega_c^2+1}) = 1$，$\omega_c^2(\omega_c^2+1) = 100$，令 $x = \omega_c^2$，$x^2+x-100=0$，$x = (-1+\sqrt{401})/2 = 9.51$，$\omega_c = 3.08$）。

相位裕度：$\phi = -90° - \arctan(3.08) = -90° - 72° = -162°$，$\gamma = 18°$。

**步骤3：确定需要的相位补偿**

目标 $\gamma^* = 45°$，当前 $\gamma = 18°$，需要补偿 $27°$。考虑安全裕量 $5°$，取 $\phi_m = 32°$。

**步骤4：计算 $\alpha$**

$\alpha = \frac{1 + \sin(32°)}{1 - \sin(32°)} = \frac{1 + 0.530}{1 - 0.530} = \frac{1.530}{0.470} = 3.255$

**步骤5：确定新的穿越频率**

超前网络在 $\omega_m$ 处的增益提升：$10\log_{10}\alpha = 10\log_{10}(3.255) = 5.12$ dB。

在未校正系统的幅频特性上，找到 $L = -5.12$ dB 的频率。$L(1) = 20$ dB，$L(3.08) = 0$ dB。在 -40 dB/dec 段：

$\omega_c^* = 3.08 \times 10^{5.12/40} = 3.08 \times 1.333 = 4.10$ rad/s。

更精确：$L(\omega) = 20 - 40\log_{10}(\omega/1) = -5.12$，$40\log_{10}\omega = 25.12$，$\log_{10}\omega = 0.628$，$\omega_c^* = 4.24$ rad/s。

**步骤6：计算参数**

$\omega_m = \omega_c^* = 4.24$ rad/s（设计时将最大超前角放在新穿越频率处）。

$T = \frac{1}{\omega_m\sqrt{\alpha}} = \frac{1}{4.24 \times 1.804} = \frac{1}{7.65} = 0.131$ s。

$\alpha T = 3.255 \times 0.131 = 0.426$ s。

校正网络：$G_c(s) = \frac{1 + 0.426s}{1 + 0.131s} = \frac{0.426(s+2.35)}{0.131(s+7.63)}$。

简化形式：$G_c(s) = 3.255 \frac{s+2.35}{s+7.63}$。

**步骤7：验证**

校正后开环：$G_c(s)G(s) = \frac{10(1+0.426s)}{s(s+1)(1+0.131s)}$。

在 $\omega_c^* = 4.24$：$|G_cG| = 1$（设计保证）。

相位：$\phi = -90° - \arctan(4.24) + \arctan(0.426 \times 4.24) - \arctan(0.131 \times 4.24)$
$= -90° - 76.7° + \arctan(1.806) - \arctan(0.555)$
$= -90° - 76.7° + 61.0° - 29.0° = -134.7°$。

$\gamma = 180° - 134.7° = 45.3°$。满足要求！

### MATLAB代码

```matlab
% Lead compensator design for G(s) = 10/(s(s+1))
s = tf('s');
G = 10 / (s*(s+1));

% Uncompensated system
[GM, PM, Wcg, Wcp] = margin(G);
fprintf('Uncompensated: PM=%.1f deg, wc=%.2f rad/s\n', PM, Wcp);

% Design lead compensator
phi_m = 32; % desired max phase lead in degrees
alpha = (1 + sind(phi_m)) / (1 - sind(phi_m));
K_dB = 10*log10(alpha); % gain contribution at omega_m

% Find new crossover frequency where uncompensated gain = -K_dB
omega = logspace(-1, 2, 1000);
[mag, phase] = bode(G, omega);
mag_dB = 20*log10(squeeze(mag));
[~, idx] = min(abs(mag_dB + K_dB));
wc_new = omega(idx);

% Calculate T
wm = wc_new;
T = 1 / (wm * sqrt(alpha));

% Lead compensator
Gc = (1 + alpha*T*s) / (1 + T*s);
G_comp = Gc * G;

% Compensated system
[GM_c, PM_c, Wcg_c, Wcp_c] = margin(G_comp);
fprintf('Compensated: PM=%.1f deg, wc=%.2f rad/s\n', PM_c, Wcp_c);

% Bode comparison
figure;
bode(G, G_comp);
legend('Uncompensated', 'Compensated');
grid on;
```

## 滞后校正：牺牲速度换精度

### 物理直觉

滞后校正的传递函数：

$$G_c(s) = \frac{1 + Ts}{1 + \beta Ts}, \quad \beta > 1$$

- **零点**：$s = -1/T$（离虚轴更近）
- **极点**：$s = -1/(\beta T)$（离虚轴更远，在零点左侧）

```text
      Im(s)
        |
        |    o 零点 = -1/T
        |    |
        |    |    x 极点 = -1/(βT)
        |    |    |
   -----+----+----+---- Re(s)
        |    |    |
        |    o    x
        |
```

零极点都在负实轴上，但零点在极点的**右侧**（离虚轴更近）。Bode图特征：
- 低频段：增益 0 dB
- 高频段：增益 $-20\log_{10}\beta$ dB（衰减）
- 在零点和极点之间提供负相位（相位滞后）

> 滞后校正的核心作用：**在不影响穿越频率附近相位特性的前提下，提高低频段增益**。它通过把高频段"压下去"，同时保持低频段不变，从而改善稳态精度。

### 设计要点

滞后校正的设计关键在于：**不要让滞后网络的相位滞后出现在穿越频率附近**。

通常做法：将滞后网络的零点放在穿越频率的 $1/5 \sim 1/10$ 处，即 $\omega_z = \omega_c/5$ 或更小。这样，穿越频率处滞后网络已基本"退场"（相位接近0°），而低频段获得了增益提升。

### 设计步骤

1. 根据稳态精度要求确定需要的增益提升量 $20\log_{10}\beta$ dB
2. 选择 $\omega_z = \omega_c/5$（或更小），确保滞后网络的相位在 $\omega_c$ 处可忽略
3. $T = 1/\omega_z$，$\omega_p = 1/(\beta T)$
4. 验证校正后的相位裕度是否满足要求

## 滞后-超前校正：双管齐下

当系统同时需要：
- 改善动态响应（需要超前相位）
- 提高稳态精度（需要低频增益提升）

单一的超前或滞后校正都难以兼顾。此时使用**滞后-超前校正**：

$$G_c(s) = \frac{(1+T_1s)(1+T_2s)}{(1+\alpha T_1s)(1+\frac{T_2}{\alpha}s)}$$

其中：
- $T_1s$ 部分提供超前相位（$\alpha > 1$）
- $T_2s$ 部分提供滞后增益（低频提升，高频衰减）

设计时先设计滞后部分满足稳态精度，再设计超前部分满足动态性能，然后组合验证。

## PID控制器：超前-滞后-积分的统一框架

PID控制器在频域中对应：

$$G_{PID}(s) = K_p + \frac{K_i}{s} + K_ds = K_p\frac{1 + \frac{K_d}{K_p}s + \frac{K_i}{K_p}\frac{1}{s}}{...}$$

更标准的工业形式：

$$G_{PID}(s) = K_p\left(1 + \frac{1}{T_is} + T_ds\right) = K_p\frac{T_iT_ds^2 + T_is + 1}{T_is}$$

频域特性：
- **积分项** $1/(T_is)$：在低频提供无限大增益，消除稳态误差，但引入 $-90°$ 相位滞后
- **比例项** $K_p$：提供增益，不引入相位变化，决定响应速度
- **微分项** $T_ds$：在高频提供正相位（超前），改善动态响应，但放大噪声

PID在频域的本质是：**一个积分环节（保证稳态精度）+ 一个一阶超前网络（改善动态）**。参数整定就是在低频增益、穿越频率和相位裕度之间找到平衡。

## 常见错误与纠正

### 错误1：超前校正后忘记重新验证穿越频率

**错误做法**：计算超前校正需要的 $\phi_m = 45° - 18° = 27°$，然后直接把最大超前角放在原穿越频率处，认为新系统的相位裕度就是 $45°$。

**纠正**：超前校正不仅提供相位，还提供增益提升。新系统的穿越频率会**增大**到增益提升后的位置。在原 $\omega_c$ 处的相位是 $-162°$（$\gamma=18°$），但在新 $\omega_c^*$ 处，未校正系统的相位可能已经是 $-170°$ 或更负。因此，实际需要的相位补偿是：$\phi_m = \gamma^* - \gamma(\omega_c^*) + \Delta$，不是 $\gamma^* - \gamma(\omega_c)$。安全裕量 $\Delta$ 就是为了补偿这个"穿越频率漂移"带来的额外相位滞后。

### 错误2：滞后校正的零点放在穿越频率附近

**错误做法**：把滞后网络的零点放在 $\omega_c$ 附近，认为这样"最有效地利用"了校正网络。

**纠正**：滞后网络在零点到极点之间提供**负相位**（滞后）。如果把零点放在 $\omega_c$ 附近，穿越频率处正好遇到最大的相位滞后，会把相位裕度拉得更低，系统更加不稳定。正确的做法是将零点放在 $\omega_c/5$ 或更低，确保穿越频率处滞后网络的相位贡献接近 $0°$。

### 错误3：超前校正 $\alpha$ 过大

**错误做法**：为了获得更大的相位补偿，使用 $\alpha = 50$（$\phi_m \approx 75°$），然后发现高频噪声被严重放大，系统对测量噪声极其敏感。

**纠正**：$\alpha$ 越大，高频增益提升越多（$20\log_{10}\alpha$）。如果 $\alpha = 50$，高频增益提升约 34 dB，这意味着高频噪声被放大了 50 倍。工程上通常限制 $\alpha \leq 10$（$\phi_m \leq 55°$）。如果需要更大相位，用**两级超前**串联，每级 $\alpha = 3 \sim 5$。

## 自测习题

### 习题1

未校正系统 $G(s) = \frac{4}{s(s+1)}$，要求相位裕度 $\gamma = 50°$。设计超前校正网络 $G_c(s) = \frac{1+\alpha Ts}{1+Ts}$。

(1) 求未校正系统的穿越频率和相位裕度。

(2) 计算需要的最大超前角 $\phi_m$（取安全裕量 $\Delta = 5°$）。

(3) 计算 $\alpha$ 和 $T$。

### 习题2

系统 $G(s) = \frac{K}{s(0.5s+1)}$，要求 $K_v = 20$ s$^{-1}$，相位裕度 $\gamma = 40°$。

(1) 若不加校正，$K = 20$ 时的相位裕度是多少？

(2) 若采用滞后校正，低频增益需要提升多少？选择 $\beta$。

(3) 若滞后校正的零点放在 $\omega_c/10$，求校正网络参数。

### 习题3

比较超前校正和滞后校正的特点：

(1) 哪种校正会增加系统的穿越频率？哪种会降低？

(2) 哪种校正会改善稳态误差？

(3) 对同一系统，能否同时使用超前和滞后校正？如果能，说明各自的作用频段。

## 习题答案

### 习题1

(1) 未校正系统：$G(s) = \frac{4}{s(s+1)}$。$L(1) = 20\log_{10}4 = 12$ dB。在 -40 dB/dec 段，$L(\omega) = 12 - 40\log_{10}\omega$。令 $L=0$：$40\log_{10}\omega_c = 12$，$\omega_c = 10^{0.3} = 2.0$ rad/s。

$\phi = -90° - \arctan(2) = -90° - 63.4° = -153.4°$。$\gamma = 26.6°$。

(2) 需要的相位补偿：$\phi_m = 50° - 26.6° + 5° = 28.4°$。

(3) $\alpha = \frac{1+\sin(28.4°)}{1-\sin(28.4°)} = \frac{1+0.475}{1-0.475} = \frac{1.475}{0.525} = 2.81$。

$10\log_{10}\alpha = 4.49$ dB。在未校正系统上找到 $-4.49$ dB 的频率：$12 - 40\log_{10}\omega = -4.49$，$40\log_{10}\omega = 16.49$，$\omega_c^* = 10^{0.412} = 2.58$ rad/s。

$T = 1/(2.58 \times \sqrt{2.81}) = 1/(2.58 \times 1.676) = 1/4.32 = 0.231$ s。

$G_c(s) = \frac{1 + 0.65s}{1 + 0.231s}$。

### 习题2

(1) $K = 20$ 时：$G(s) = \frac{20}{s(0.5s+1)}$。$L(1) = 20\log_{10}20 = 26$ dB。转角频率 $\omega = 2$ rad/s。$L(2) = 26 - 20\log_{10}2 = 26 - 6 = 20$ dB。在 -40 dB/dec 段从 $L(2)=20$ 到 $L=0$：$20 - 40\log_{10}(\omega_c/2) = 0$，$\omega_c = 2 \times 10^{0.5} = 6.32$ rad/s。

$\phi = -90° - \arctan(0.5 \times 6.32) = -90° - 72.4° = -162.4°$。$\gamma = 17.6°$。

(2) 未校正系统 $K=20$ 时 $K_v = 20$ 已满足。但系统不稳定（$\gamma$ 太小）。若需要更多稳态精度，滞后校正低频增益提升取决于目标。此处主要问题是动态性能，可能需要滞后-超前或仅用超前。

若必须用滞后校正：需要把穿越频率降到相位裕度为 $40°$ 的位置。在原系统上，$\gamma = 40°$ 对应 $\phi = -140°$，即 $\arctan(0.5\omega) = 50°$，$\omega = 2.38$ rad/s。在 $\omega = 2.38$：$|G| = 20/(2.38\sqrt{1.19^2+1}) = 20/(2.38 \times 1.556) = 5.40$，$L = 14.7$ dB。需要衰减 $14.7$ dB，$\beta = 10^{14.7/20} = 5.43$。

(3) $\omega_c = 2.38$ rad/s，$\omega_z = \omega_c/10 = 0.238$ rad/s。$T = 1/0.238 = 4.20$ s。$\omega_p = 1/(\beta T) = 1/(5.43 \times 4.20) = 0.0439$ rad/s。

$G_c(s) = \frac{1+4.20s}{1+22.8s}$。

### 习题3

(1) 超前校正**增加**穿越频率（提供增益提升），滞后校正**降低**穿越频率（高频衰减，保持低频增益不变但把整体幅频曲线下拉）。

(2) 滞后校正改善稳态误差（通过提升低频增益或增加积分效果）。超前校正不改善稳态误差（低频增益为1，不改变稳态）。

(3) 可以，这就是**滞后-超前校正**。超前环节在中频/高频段提供相位补偿（改善动态），滞后环节在低频段提供增益提升（改善稳态）。两者在频率上"分工"：滞后作用在远低于穿越频率的频段，超前作用在穿越频率附近。

## 小结

- 校正（补偿）是在原有系统上添加网络，改善闭环性能
- 超前校正提供正相位，增加相位裕度和响应速度，但放大高频噪声
- 滞后校正提升低频增益，改善稳态精度，但降低响应速度，不引入相位问题（如果设计正确）
- 滞后-超前校正兼顾动态和稳态，两者在不同频段发挥作用
- 设计流程：分析未校正系统 → 明确性能目标 → 选择校正类型 → 计算参数 → 验证
- PID是工程中最常用的校正形式，其频域本质为积分+比例+微分
- 安全裕量 $\Delta$ 和 $\alpha$ 上限是超前校正设计的两个关键约束

频率法校正为经典控制理论的"设计工具箱"画上了句号。从传递函数到方框图，从时域到根轨迹，再到频域分析与校正，我们拥有了完整的设计方法论。下一章将简要回顾经典控制理论的局限，并展望现代控制理论的引入。
