# 根轨迹法

## 根轨迹的直觉：增益如何"驱赶"极点

根轨迹是经典控制理论中最具几何美感的方法之一。它的核心思想极其直观：

> **当控制器增益 $K$ 从 0 连续变化到 $+\infty$ 时，闭环系统的极点在复平面上画出一条轨迹。只要"沿着这条线走"，你就知道系统在每个 $K$ 值下的稳定性与动态品质。**

这相当于回答了一个工程师在调试控制器时最关心的问题："我把增益调大，系统会更快还是更不稳定？调到多少是极限？"

## 根轨迹的数学基础

### 特征方程与幅角条件

对于单位负反馈系统，开环传递函数为 $KG(s)H(s)$，闭环传递函数为：

$$T(s) = \frac{KG(s)}{1 + KG(s)H(s)}$$

闭环极点满足特征方程：

$$1 + KG(s)H(s) = 0$$

令 $L(s) = G(s)H(s)$，则：

$$L(s) = -\frac{1}{K}$$

由于 $K$ 是正实数（从 0 变到 $+\infty$），$-\frac{1}{K}$ 是负实数。这个等式可以分解为两个条件：

**幅角条件**（决定轨迹的形状）：

$$\angle L(s) = \pm 180°(2k+1), \quad k = 0, 1, 2, \cdots$$

**幅值条件**（决定 $K$ 值）：

$$|L(s)| = \frac{1}{K}$$

> 幅角条件与 $K$ 无关，只取决于开环零极点的位置。因此，**根轨迹的形状完全由开环传递函数的零极点分布决定**，增益 $K$ 只决定"在轨迹的哪个位置"。

### 180°根轨迹与 0°根轨迹

上面的推导假设 $K$ 从 0 到 $+\infty$ 变化，得到的是**180°根轨迹**（幅角条件为 $180°$ 的奇数倍）。

如果系统中存在**正反馈**（或某些负反馈回路等效出的正反馈），特征方程变为 $1 - KG(s)H(s) = 0$，幅角条件变为：

$$\angle L(s) = \pm 360°k$$

这称为**0°根轨迹**。在分析正反馈系统、某些参数根轨迹或非最小相位系统时会出现。

## 根轨迹绘制的基本法则（180°根轨迹）

这些法则是从幅角条件推导出来的，不需要死记，理解其几何意义即可。

### 法则1：分支数、起点与终点

- **分支数**等于闭环极点数 = 开环极点数 $n$（假设 $n \geq m$）
- **起点**（$K=0$）：根轨迹从开环极点出发（$K=0$ 时，特征方程退化为 $D(s)=0$）
- **终点**（$K \to \infty$）：$m$ 条分支趋向开环零点，$n-m$ 条趋向无穷远（沿着渐近线）

### 法则2：实轴上的根轨迹

实轴上某点属于根轨迹，当且仅当其右侧的**实轴开环零极点总数为奇数**。

直觉：实轴上的点到共轭复零极点的角度之和为 $360°$（不影响奇偶性），只算实轴上的零极点。每经过一个零极点，角度贡献 $180°$，奇数个 $180°$ 总和为 $180°$ 的奇数倍。

### 法则3：渐近线

当 $K \to \infty$ 时，$n-m$ 条分支趋向无穷远，沿渐近线方向离去。

渐近线与实轴的夹角：

$$\phi_a = \frac{(2k+1)180°}{n-m}, \quad k = 0, 1, \cdots, n-m-1$$

渐近线与实轴的交点：

$$\sigma_a = \frac{\sum p_i - \sum z_i}{n-m}$$

> 渐近线像一把"扇子"，从实轴上的 $\sigma_a$ 点展开，均匀分布在 $360°$ 内。这告诉你：增益很大时，多余的极点大概会往哪个方向跑。

### 法则4：分离点与汇合点

两条根轨迹分支在实轴上相遇然后分开（或从复平面来汇合），该点称为**分离点/汇合点**。对应重根情况。

分离点满足：

$$\frac{dK}{ds} = 0 \quad \Rightarrow \quad \sum\frac{1}{s-p_i} = \sum\frac{1}{s-z_i}$$

（若零点不存在，右边为 0）。

### 法则5：与虚轴的交点

用**劳斯判据**或令 $s = j\omega$ 代入特征方程求解。交点对应的 $K$ 值是**临界稳定增益**，超过此值系统不稳定。

### 法则6：出射角与入射角

从复极点出发的角度（**出射角**）和到达复零点的角度（**入射角**）可以用幅角条件计算：

出射角：

$$\phi_{dep} = 180° - \sum(\text{从其他极点到该极点的角度}) + \sum(\text{从零点到该极点的角度})$$

## 利用根轨迹设计控制器

### 设计目标：把极点放在"好"区域

根轨迹的终极价值在于设计。工程师可以：
1. 画出根轨迹，看极点可能的分布范围
2. 在复平面上画出"期望区域"（满足超调量、调节时间、阻尼比要求）
3. 调整增益或添加零极点，使根轨迹穿过期望区域

### 典型设计问题：选择增益 $K$

假设要求闭环极点满足 $\zeta \geq 0.5$（即超调量 $M_p \leq 16.3\%$）。在复平面上，$\zeta = 0.5$ 对应从原点出发、与负实轴夹角 $\beta = \arccos(0.5) = 60°$ 的射线。根轨迹与这条射线的交点对应的 $K$ 值就是满足阻尼比要求的增益范围。

对于 $G(s)H(s) = \frac{K}{s(s+1)(s+2)}$：

在射线 $s = -a + ja\tan(60°) = -a + j1.732a$（$a > 0$）上，根轨迹分支从实轴分离后进入上半平面。用幅值条件求对应的 $K$。

若取 $a = 0.5$（即 $s = -0.5 + j0.866$）：

$$|G(s)| = \frac{1}{|s||s+1||s+2|}$$

$$|s| = 1, \quad |s+1| = |0.5+j0.866| = 1, \quad |s+2| = |1.5+j0.866| = 1.732$$

$$K = \frac{1}{|G(s)|} = 1 \times 1 \times 1.732 = 1.732$$

对应的 $K \approx 1.732$。当 $K < 1.732$ 时，极点在这条射线的左侧（阻尼比更大）；当 $K$ 继续增大，极点向右下移动，阻尼比减小，超调量增大。

### 添加零极点改变根轨迹：超前校正与滞后校正

根轨迹的形状不是固定不变的。通过在开环传递函数中添加零点和极点，可以"推拉"根轨迹，使其进入期望区域。

- **添加零点**（如超前校正）：根轨迹被"拉向"零点，通常改善稳定性（使极点左移）
- **添加极点**（如滞后校正）：根轨迹被"推离"极点，通常使系统变慢（极点右移）

例如，原系统 $G(s) = \frac{K}{s(s+1)}$ 的根轨迹是垂直线 $s = -0.5$。添加零点 $s = -2$ 后，$G(s) = \frac{K(s+2)}{s(s+1)}$，根轨迹向左弯曲，所有 $K > 0$ 都稳定（原系统也稳定，但新系统的极点更靠左，响应更快）。

## 参数根轨迹

前述根轨迹以 $K$ 为可变参数，但工程中也常需要分析其他参数（如时间常数、反馈系数）变化的影响。方法是将特征方程整理为：

$$1 + A \cdot P(s) = 0$$

其中 $A$ 是待研究的参数，$P(s)$ 是整理后的等效开环传递函数。然后按常规根轨迹法则绘制。

例如，研究系统 $G(s) = \frac{K}{s(s+\alpha)}$ 中参数 $\alpha$ 变化的影响（$K$ 固定）：

特征方程：$s(s+\alpha) + K = 0 \Rightarrow s^2 + K + \alpha s = 0$

整理为：$1 + \alpha \frac{s}{s^2+K} = 0$

等效开环传递函数：$G_{eq}(s) = \frac{s}{s^2+K}$。注意：此时"零点"在 $s=0$，"极点"在 $s = \pm j\sqrt{K}$。根轨迹的绘制需要用0°法则（因为参数 $\alpha$ 在特征方程中是以正系数乘 $s$）。

## 数值示例：根轨迹绘制与增益选择

### 问题

给定开环传递函数：$G(s)H(s) = \frac{K(s+3)}{s(s+1)(s+2)}$。

(1) 绘制根轨迹的要点。

(2) 求使闭环系统阻尼比 $\zeta = 0.707$ 的增益 $K$。

### 解答

(1) 绘制要点：
- 开环极点：$p_1 = 0$，$p_2 = -1$，$p_3 = -2$（$n=3$）
- 开环零点：$z_1 = -3$（$m=1$）
- 实轴根轨迹：$[-3, -2]$ 和 $[-1, 0]$（右侧零极点总数为奇数）
- 渐近线：$n-m = 2$，角度 $90°$ 和 $270°$（即 $\pm 90°$）
- $\sigma_a = \frac{(0-1-2)-(-3)}{2} = 0$
- 渐近线是通过原点的垂直线！
- 分离点：$\frac{1}{s} + \frac{1}{s+1} + \frac{1}{s+2} = \frac{1}{s+3}$
- 化简：$(s+1)(s+2)(s+3) + s(s+2)(s+3) + s(s+1)(s+3) = s(s+1)(s+2)$
- 展开：$3s^3 + 12s^2 + 11s + 6 = 0$
- 解得近似：$s \approx -0.5$（在 $[-1,0]$ 内）和 $s \approx -2.5$（在 $[-3,-2]$ 内）

(2) $\zeta = 0.707$ 对应 $\beta = \arccos(0.707) = 45°$。在复平面上，这对应直线 $s = -a + ja$（$a > 0$）。

令 $s = -a + ja$ 满足特征方程（或幅角条件），代入 $G(s)H(s)$：

$|s| = \sqrt{2}a$，$|s+1| = \sqrt{(1-a)^2 + a^2} = \sqrt{1-2a+2a^2}$，$|s+2| = \sqrt{(2-a)^2 + a^2} = \sqrt{4-4a+2a^2}$，$|s+3| = \sqrt{(3-a)^2 + a^2} = \sqrt{9-6a+2a^2}$

用数值方法求解：令 $s = -0.7 + j0.7$（取 $a = 0.7$）：

$|G(s)| = \frac{|s+3|}{|s||s+1||s+2|} = \frac{\sqrt{9-4.2+0.98}}{\sqrt{0.98} \cdot \sqrt{1-1.4+0.98} \cdot \sqrt{4-2.8+0.98}} = \frac{\sqrt{5.78}}{\sqrt{0.98} \cdot \sqrt{0.58} \cdot \sqrt{2.18}} \approx \frac{2.404}{1.108 \times 0.112}$... 需要精确计算。

用 MATLAB/Python 精确计算更可靠。这里给出近似值 $K \approx 1.5$（实际需数值求解）。

### Python代码：根轨迹绘制

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import TransferFunction
import control as ctrl

def main():
    # Open-loop transfer function: K*(s+3) / [s(s+1)(s+2)]
    # For root locus, we use the control library
    
    # Define as open-loop with K=1 (root locus will vary K)
    num = [1, 3]
    den = [1, 3, 2, 0]  # s(s+1)(s+2) = s^3 + 3s^2 + 2s
    
    sys = ctrl.TransferFunction(num, den)
    
    # Plot root locus
    plt.figure(figsize=(10, 8))
    ctrl.root_locus(sys, plot=True, xlim=(-4, 1), ylim=(-3, 3))
    plt.axvline(x=0, color='k', linewidth=0.5)
    plt.axhline(y=0, color='k', linewidth=0.5)
    plt.title('Root Locus: $G(s) = \\frac{K(s+3)}{s(s+1)(s+2)}$')
    plt.xlabel('Real Axis')
    plt.ylabel('Imaginary Axis')
    plt.grid(True)
    plt.savefig('root_locus_example.png', dpi=150)
    plt.show()

if __name__ == '__main__':
    main()
```

## 常见错误与纠正

### 错误1：0°根轨迹与180°根轨迹混淆

**错误做法**：看到正反馈系统或参数根轨迹中参数在分子，仍然用180°法则画渐近线（如用 $60°$、$180°$、$300°$）。

**纠正**：0°根轨迹的渐近线角度公式为 $\phi_a = \frac{360°k}{n-m}$（$k=0,1,\cdots,n-m-1$）。实轴上的判断条件也变为：右侧实轴零极点总数为**偶数**的点才是根轨迹。在不确定时，回到幅角条件 $\angle L(s) = 0°$ 验证。

### 错误2：分离点计算后不验证是否在根轨迹上

**错误做法**：解出分离点方程后，直接把所有根都当作有效分离点。

**纠正**：分离点必须位于**实轴上的根轨迹区间**内。例如，若解得 $s = -3$ 但实轴根轨迹只在 $[-2, -1]$ 上，则 $s = -3$ 不是有效分离点。多余解可能来自方程化简过程中的增根。

### 错误3：临界增益与虚轴交点的单位混淆

**错误做法**：劳斯判据算出临界增益 $K = 6$，但代入时把 $K$ 当成开环增益而不是前向通路的总增益。

**纠正**：根轨迹中的 $K$ 是特征方程 $1 + KL(s) = 0$ 中的参数。如果原题中增益是 $K_p$，但传递函数写成 $K_p \cdot \frac{10}{s(s+1)}$，那么根轨迹中的 $K = 10K_p$。劳斯判据算出的 $K$ 需要还原为实际物理增益。始终跟踪 $K$ 在特征方程中的定义。

## 习题答案

### 习题1

(1) 绘制要点：
- 极点：$s = 0$，$s = -4$（$n=2$，$m=0$）
- 实轴根轨迹：$[-4, 0]$（右侧共2个极点，偶数？不对，验证：在 $[-4,0]$ 上右侧有极点 0 和 -4？不，对 $[-4,0]$ 内的点，右侧只有 $s=0$ 一个极点，奇数，所以是根轨迹。在 $(-\infty, -4]$ 上，右侧有 0 和 -4 两个极点，偶数，不是根轨迹。）
- 渐近线：$n-m = 2$，角度 $90°$ 和 $270°$（垂直线），$\sigma_a = \frac{0-4}{2} = -2$
- 分离点：$1/s + 1/(s+4) = 0 \Rightarrow 2s + 4 = 0 \Rightarrow s = -2$（在根轨迹上，有效）
- 与虚轴交点：特征方程 $s^2 + 4s + K = 0$，劳斯表无 $s^1$ 行系数为零的问题（除非退化），实际上 $s = \frac{-4 \pm \sqrt{16-4K}}{2}$。实部始终为 $-2 < 0$，所以**根轨迹始终不与虚轴相交**，系统对所有 $K > 0$ 稳定。

(2) $\zeta = 0.5$ 对应射线 $s = -a + ja\sqrt{3}$。令 $s = -a + j\sqrt{3}a$，代入特征方程：
$(-a + j\sqrt{3}a)^2 + 4(-a + j\sqrt{3}a) + K = 0$
$(a^2 - 3a^2 - 4a + K) + j(-2\sqrt{3}a^2 + 4\sqrt{3}a) = 0$
虚部：$\sqrt{3}a(-2a + 4) = 0 \Rightarrow a = 2$（$a=0$ 舍去）
实部：$-2a^2 - 4a + K = 0 \Rightarrow K = 2(4) + 4(2) = 16$

所以 $K = 16$ 时，$\zeta = 0.5$。

验证：$s = -2 + j2\sqrt{3}$，$|s| = 4$，$|s+4| = |2+j2\sqrt{3}| = 4$，$K = |s||s+4| = 16$。

(3) 最快速响应对应最小调节时间，即最大 $|\sigma| = \zeta\omega_n$。根轨迹在分离点 $s = -2$ 处两个极点重合，此时 $\omega_n = 2$（$\omega_n = \sqrt{K}$，$K = 4$），$\zeta = 1$。$K > 4$ 时，复极点 $\sigma = -2$ 恒定，$\omega_n$ 增大但调节时间 $t_s = 4/(\zeta\omega_n) = 4/|\sigma| = 2$ s 恒定。因此分离点处 $K = 4$ 是临界阻尼最优点。

### 习题2

(1) $n=3$（$s^2(s+5)$ 有三个极点：0, 0, -5），$m=1$（零点 $-2$）。$n-m = 2$。
渐近线角度：$90°$ 和 $270°$（$\pm 90°$）。
$\sigma_a = \frac{(0+0-5)-(-2)}{2} = \frac{-3}{2} = -1.5$。

(2) $K$ 很大时，一条分支趋向零点 $s=-2$，另外两条沿 $\pm 90°$ 渐近线从 $\sigma_a = -1.5$ 趋向无穷远。趋向无穷远的分支在 $K$ 足够大时会进入右半平面（因为渐近线是垂直的，且从 $-1.5$ 出发，向上/下无限延伸始终实部为 $-1.5$）。等等，垂直渐近线实部为 $-1.5$，始终在左半平面。

重新检查：对于 $s^2(s+5)$，两个极点在原点。$K$ 很大时，一条分支趋向 $-2$，另两条沿 $\pm 90°$ 从 $-1.5$ 出发。由于渐近线是垂直的 $s = -1.5$，始终左半平面。但原点处的双重极点会导致分支先进入右半平面吗？

特征方程：$s^2(s+5) + K(s+2) = 0 \Rightarrow s^3 + 5s^2 + Ks + 2K = 0$。
劳斯表：
$s^3$: 1    K
$s^2$: 5    2K
$s^1$: (5K-2K)/5 = 3K/5 > 0
$s^0$: 2K

对所有 $K > 0$，劳斯表第一列全正，系统稳定。所以 $K$ 很大时仍稳定。

### 习题3

(1) 等效开环：特征方程 $s^3 + 2s^2 + Ks + 5 = 0$ 整理为 $1 + K\frac{s}{s^3 + 2s^2 + 5} = 0$。
$G_{eq}(s) = \frac{s}{s^3 + 2s^2 + 5}$。
注意：等效开环极点由 $s^3 + 2s^2 + 5 = 0$ 决定。近似根：$s \approx -2.7$（实根），$s \approx 0.35 \pm j1.2$（两个右半平面复极点！）。

所以等效开环已经有两个右半平面极点。用奈奎斯特判据或劳斯判据分析稳定性。

(2) 特征方程：$s^3 + 2s^2 + Ks + 5 = 0$。
劳斯表：
$s^3$: 1    K
$s^2$: 2    5
$s^1$: (2K-5)/2
$s^0$: 5

临界条件：$2K - 5 = 0 \Rightarrow K = 2.5$。
辅助方程（$s^2$ 行）：$2s^2 + 5 = 0 \Rightarrow s = \pm j\sqrt{2.5} = \pm j1.581$。

所以 $K = 2.5$ 时与虚轴交于 $\pm j1.581$。

## 小结

- 根轨迹是闭环极点随增益 $K$ 变化的轨迹，由开环零极点完全决定
- 180°根轨迹基于幅角条件 $\angle L(s) = 180°(2k+1)$，0°根轨迹基于 $\angle L(s) = 360°k$
- 绘制法则：分支数、起点终点、实轴区间、渐近线、分离点、虚轴交点、出射角
- 根轨迹是设计工具：通过调整增益或添加零极点，使闭环极点进入期望区域
- 渐近线方向和分离点位置是根轨迹形状的关键特征
- 参数根轨迹通过等效开环传递函数分析非增益参数的影响
