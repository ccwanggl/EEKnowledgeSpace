# 从经典到现代的过渡

## 经典控制理论的成就与局限

### 成就了什么

经典控制理论（Classical Control Theory），也称频域法或传递函数法，从20世纪30年代到60年代，成功解决了工业界绝大多数的控制问题。它的核心成就包括：

- **传递函数**：把微分方程转化为代数方程，使系统分析和设计变得标准化
- **方块图**：用图形化方式描述复杂系统的连接关系，便于工程师交流
- **根轨迹**：直观展示增益变化对极点位置的影响，指导控制器参数选择
- **Bode图/Nyquist图**：从频率视角分析系统，稳定性判据不需求解特征方程
- **频域校正**：超前、滞后、PID等网络设计方法，形成了工业控制的标准工具箱

这些方法共同的特点是：**输入-输出（I/O）视角**。工程师只关心"给什么输入，得到什么输出"，不关心系统内部的能量流动、状态演化。

### 局限在哪里

然而，随着被控对象越来越复杂（多输入多输出、非线性、时变、分布式参数），经典控制理论开始显现根本性约束：

| 局限 | 具体表现 | 例子 |
|------|---------|------|
| 只适用于SISO系统 | 传递函数是标量，无法直接处理多个输入和多个输出 | 机器人多关节控制、化工多变量过程 |
| 无法描述内部状态 | 传递函数是零初始条件下的I/O映射，丢失内部信息 | 系统内部某些变量不可测但必须控制 |
| 设计过程试凑性强 | 根轨迹、Bode图校正依赖经验和迭代，缺乏系统性 | 多回路系统调参困难 |
| 时域分析受限 | 高阶系统无解析解，主导极点近似粗糙 | 五阶以上系统难以用时域分析 |
| 无法处理时变系统 | 传递函数要求LTI（线性时不变） | 飞行器质量随燃料消耗变化 |
| 最优性无从谈起 | 没有统一的优化框架，靠经验权衡 | 多个性能指标如何同时优化？ |
| 鲁棒性分析薄弱 | 频域裕度只是局部鲁棒性，无法处理结构化不确定性 | 参数大范围变化时如何保证稳定？ |

> **核心矛盾**：经典控制理论是"黑箱"方法——它只描述外部行为，不揭示内部机制。当系统内部有多个相互耦合的状态变量时，黑箱方法失效。

## 现代控制理论的引入：状态空间视角

### 什么是状态

**状态**是描述系统动态行为所需的**最小**一组变量。如果知道 $t_0$ 时刻的状态 $x(t_0)$ 和 $t \geq t_0$ 时的输入 $u(t)$，就能完全确定 $t \geq t_0$ 时系统的所有输出和内部行为。

状态空间模型的标准形式：

$$\dot{x}(t) = Ax(t) + Bu(t) \quad \text{(状态方程)}$$
$$y(t) = Cx(t) + Du(t) \quad \text{(输出方程)}$$

其中：
- $x \in \mathbb{R}^n$：状态向量（$n$ 个状态变量）
- $u \in \mathbb{R}^m$：输入向量（$m$ 个输入）
- $y \in \mathbb{R}^p$：输出向量（$p$ 个输出）
- $A \in \mathbb{R}^{n \times n}$：系统矩阵（描述状态自身的演化）
- $B \in \mathbb{R}^{n \times m}$：输入矩阵（描述输入如何影响状态）
- $C \in \mathbb{R}^{p \times n}$：输出矩阵（描述状态如何映射到输出）
- $D \in \mathbb{R}^{p \times m}$：直接传输矩阵（通常为零）

```text
        u(t) --->[ B ]---+--->[ 1/s ]---> x(t) --->[ C ]---> y(t)
                        |      ^
                        |      | A
                        +------+
```

### 从传递函数到状态空间：同一个系统的两种"肖像"

对于一个SISO系统，传递函数和状态空间描述是等价的（在最小实现条件下）。

给定传递函数：

$$G(s) = \frac{b_ms^m + b_{m-1}s^{m-1} + \cdots + b_0}{s^n + a_{n-1}s^{n-1} + \cdots + a_0}$$

可以构造多种状态空间实现（可控标准型、可观标准型、对角标准型等）。例如**可控标准型**：

$$A = \begin{bmatrix} 0 & 1 & 0 & \cdots & 0 \\ 0 & 0 & 1 & \cdots & 0 \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & \cdots & 1 \\ -a_0 & -a_1 & -a_2 & \cdots & -a_{n-1} \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ 0 \\ \vdots \\ 0 \\ 1 \end{bmatrix}$$

$$C = \begin{bmatrix} b_0 & b_1 & \cdots & b_{n-1} \end{bmatrix}, \quad D = b_n \text{ (if } m=n\text{)}$$

从状态空间到传递函数：

$$G(s) = C(sI - A)^{-1}B + D$$

> **关键洞察**：传递函数的分母 $s^n + a_{n-1}s^{n-1} + \cdots + a_0$ 就是矩阵 $A$ 的**特征多项式**。传递函数的极点就是 $A$ 的**特征值**。因此，经典控制中的稳定性判据（极点在左半平面）等价于现代控制中的判据（$A$ 的所有特征值实部为负）。

## 现代控制的核心能力

### 1. 多输入多输出（MIMO）系统

状态空间方法天然适用于MIMO系统。$B$ 矩阵有 $m$ 列，$C$ 矩阵有 $p$ 行，$u$ 和 $y$ 可以是向量。

例如，一个双轴机械臂：
- 输入：两个关节的电机力矩 $u = [\tau_1, \tau_2]^T$
- 输出：末端位置 $y = [x, y]^T$
- 状态：关节角度、角速度 $x = [\theta_1, \theta_2, \dot{\theta}_1, \dot{\theta}_2]^T$

经典控制需要用传递函数矩阵处理，但设计困难。状态空间方法统一处理，无需分解为SISO子系统。

### 2. 状态反馈与极点配置

经典控制中，控制器只能基于输出误差 $e = r - y$ 设计（如PID）。现代控制中，如果所有状态可测（或可通过观测器估计），可以直接设计**状态反馈**：

$$u = -Kx + v$$

闭环系统变为：$\dot{x} = (A - BK)x + Bv$。

通过选择反馈增益矩阵 $K$，可以**任意配置**闭环系统的极点（前提是系统可控）。这比经典控制中通过调整增益或添加零极点来"牵引"根轨迹要系统得多。

### 3. 最优控制：LQR

经典控制缺乏统一的优化目标。现代控制提出了**最优控制**框架：

$$\min_{u} J = \int_0^{\infty}(x^TQx + u^TRu)dt$$

其中 $Q$ 和 $R$ 是权重矩阵。这个优化问题的解析解就是**线性二次调节器（LQR）**：$u = -Kx$，其中 $K$ 通过求解**Riccati方程**得到。

LQR自动平衡了状态误差（$x^TQx$）和控制能量（$u^TRu$），无需试凑。这是经典控制无法做到的。

### 4. 状态观测器：看"不到"的东西也能控制

实际系统中，很多状态变量不能直接测量（如电机转子磁链、化学反应中间产物浓度）。现代控制提出了**状态观测器**：

$$\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})$$

通过测量输出 $y$ 和已知的输入 $u$，用观测器估计状态 $\hat{x}$，然后用估计值做状态反馈。这就是著名的**分离原理**：观测器设计和控制器设计可以独立进行。

卡尔曼滤波是最优观测器的代表，在噪声环境下给出状态的最优估计。

### 5. 鲁棒控制：应对不确定性

经典控制的鲁棒性只有相位裕度和增益裕度。现代控制发展了系统的鲁棒控制理论：
- $H_2$ 控制：最小化均方误差
- $H_\infty$ 控制：最小化最坏情况增益
- $\mu$ 分析：处理结构化不确定性

这些方法用优化和线性矩阵不等式（LMI）等工具，可以定量设计出在参数大范围变化时仍稳定的控制器。

## 经典与现代的互补关系

| 维度 | 经典控制理论 | 现代控制理论 |
|------|------------|------------|
| 数学模型 | 传递函数 $G(s)$ | 状态空间 $(A,B,C,D)$ |
| 系统视角 | 输入-输出（黑箱） | 内部状态（白箱） |
| 适用系统 | SISO，LTI | MIMO，时变，非线性（扩展） |
| 分析工具 | 根轨迹、Bode图、Nyquist图 | 特征值、Riccati方程、LMI |
| 设计方法 | 试凑、频域校正、经验公式 | 系统优化、极点配置、LQR |
| 鲁棒性 | 相位裕度、增益裕度 | $H_\infty$、$\mu$ 分析 |
| 实时性 | 在线调参容易 | 观测器/滤波器计算量大 |
| 物理直觉 | 强（频率、增益、相位） | 弱（矩阵、特征向量） |
| 工程应用 | 工业PID占据90%以上 | 航空航天、机器人、先进制造 |

> **现代控制理论不是替代经典控制理论，而是扩展了工具箱**。工程师应根据问题特点选择方法：
> - 简单SISO工业过程：PID（经典频域方法）最经济有效
> - 复杂MIMO系统、需要最优性：状态空间方法
> - 既有多个耦合回路，又需要快速调参：可以结合两者（如频域设计状态反馈权重）

## 数值示例：同一系统，两种视角

### 系统描述

考虑一个直流电机位置控制系统。电机转动惯量 $J = 0.01$ kg·m²，阻尼 $B = 0.1$ N·m·s/rad，电机常数 $K_m = 0.5$ N·m/V。输出为转角 $\theta$，输入为电压 $V$。

动力学方程：

$$J\ddot{\theta} + B\dot{\theta} = K_m V$$

### 经典控制视角：传递函数

取拉普拉斯变换：

$$G(s) = \frac{\Theta(s)}{V(s)} = \frac{K_m}{s(Js + B)} = \frac{50}{s(s+10)}$$

这是一个二阶系统（极点：$s=0$ 和 $s=-10$），含一个积分环节。用经典方法：
- 单位反馈下，特征方程 $s^2 + 10s + 50K = 0$
- 若取 $K=1$：$\omega_n = \sqrt{50} = 7.07$ rad/s，$\zeta = 10/(2\times 7.07) = 0.707$
- $M_p = 4.3\%$，$t_s = 4/(\zeta\omega_n) = 4/5 = 0.8$ s

### 现代控制视角：状态空间

选择状态变量：$x_1 = \theta$（位置），$x_2 = \dot{\theta}$（速度）。

$$\dot{x}_1 = x_2$$
$$\dot{x}_2 = -\frac{B}{J}x_2 + \frac{K_m}{J}V = -10x_2 + 50V$$

状态空间：

$$A = \begin{bmatrix} 0 & 1 \\ 0 & -10 \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ 50 \end{bmatrix}, \quad C = \begin{bmatrix} 1 & 0 \end{bmatrix}, \quad D = 0$$

#### 状态反馈设计

设 $u = -Kx = -[k_1, k_2]\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = -k_1\theta - k_2\dot{\theta}$。

闭环矩阵：$A - BK = \begin{bmatrix} 0 & 1 \\ -50k_1 & -10-50k_2 \end{bmatrix}$。

特征多项式：$s^2 + (10+50k_2)s + 50k_1 = 0$。

若希望 $\omega_n = 10$ rad/s，$\zeta = 0.707$：
- $50k_1 = \omega_n^2 = 100 \Rightarrow k_1 = 2$
- $10 + 50k_2 = 2\zeta\omega_n = 14.14 \Rightarrow k_2 = 0.083$

状态反馈控制器：$u = -2\theta - 0.083\dot{\theta}$。

对比经典控制：
- 经典控制只用位置误差 $e = \theta_{ref} - \theta$ 做PID
- 现代控制同时用了位置和速度信息（PD控制器的形式）
- 状态反馈可以**精确放置极点**，而经典控制只能通过调参间接影响极点位置

### Python代码：状态反馈极点配置

```python
import numpy as np
from scipy.signal import place_poles
import control as ctrl

def main():
    # State-space matrices
    A = np.array([[0, 1], [0, -10]])
    B = np.array([[0], [50]])
    C = np.array([[1, 0]])
    D = np.array([[0]])
    
    # Desired poles: zeta=0.707, wn=10 rad/s
    wn = 10.0
    zeta = 0.707
    s1 = -zeta*wn + 1j*wn*np.sqrt(1-zeta**2)
    s2 = -zeta*wn - 1j*wn*np.sqrt(1-zeta**2)
    desired_poles = [s1, s2]
    
    # Pole placement
    result = place_poles(A, B, desired_poles)
    K = result.gain_matrix
    
    print("State feedback gain K:", K)
    print("k1 =", K[0, 0])
    print("k2 =", K[0, 1])
    
    # Closed-loop system
    A_cl = A - B @ K
    sys_cl = ctrl.StateSpace(A_cl, B, C, D)
    
    # Step response
    t = np.linspace(0, 2, 1000)
    t_out, y = ctrl.step_response(sys_cl, t)
    
    import matplotlib.pyplot as plt
    plt.figure(figsize=(10, 6))
    plt.plot(t_out, y, 'b-', linewidth=1.5)
    plt.axhline(y=1.0, color='r', linestyle='--', alpha=0.5)
    plt.xlabel('Time (s)')
    plt.ylabel('Angular position (rad)')
    plt.title('Step Response with State Feedback (Pole Placement)')
    plt.grid(True)
    plt.savefig('state_feedback_response.png', dpi=150)
    plt.show()

if __name__ == '__main__':
    main()
```

## 常见错误与纠正

### 错误1：认为现代控制比经典控制"更高级"，应该完全替代

**错误做法**：在简单温度控制回路中强行使用LQR和状态观测器，导致代码复杂、调试困难，效果不如PID。

**纠正**：现代控制理论扩展了能力边界，但在简单SISO系统中，经典控制的PID和频域方法仍然是最有效、最可靠的工程选择。选择方法的标准是**问题复杂度**，不是方法的"先进性"。航空器的多轴控制用状态空间，家用热水器用PID——两者都是最优工程决策。

### 错误2：状态空间实现与传递函数不等价时未检查最小实现

**错误做法**：从传递函数构造状态空间时，随意选择一种实现，发现闭环特性与预期不符。

**纠正**：从传递函数到状态空间的转换中，如果传递函数存在**零极点对消**，则状态空间实现可能是**非最小实现**（维数高于实际需要），此时状态反馈设计可能失效（不可控或不可观模态）。在转换前，应先用 `minreal` 或类似工具消除对消零极点，确保最小实现。

例如：$G(s) = \frac{(s+1)(s+2)}{(s+1)(s+3)}$，若不做零极点对消，得到三维状态空间，但其中有一个模态不可控也不可观。正确做法是化为 $G(s) = \frac{s+2}{s+3}$（一维最小实现）。

### 错误3：状态反馈设计时忘记处理参考输入

**错误做法**：设计 $u = -Kx$ 后，直接给系统加阶跃参考输入，发现稳态输出有常值误差。

**纠正**：纯状态反馈 $u = -Kx$ 是**调节器**（regulator），目的是把状态驱动到原点。要跟踪非零参考输入（如位置指令），需要引入**前馈增益**或**积分作用**：

$$u = -Kx + N\cdot r$$

其中 $N$ 选择为使稳态输出等于 $r$。或者，在状态空间中引入积分状态（增广系统），实现无静差跟踪。这与经典控制中积分环节消除稳态误差的原理完全一致。

(2) 若有对消，写出最小实现的传递函数。

系统 $A = \begin{bmatrix} 0 & 1 \\ -2 & -3 \end{bmatrix}$，$B = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$。

(1) 求系统的特征值（即经典控制中的极点）。

(2) 设计状态反馈 $u = -Kx$ 使闭环极点为 $s_{1,2} = -1 \pm j$。

(3) 验证闭环特征多项式。

### 习题3

某工程师在为一个双输入双输出系统（温度与压力耦合控制）选择方法：

(1) 经典控制如何处理这类问题？有什么困难？

(2) 现代控制如何处理这类问题？有什么优势？

(3) 如果两个回路之间的耦合很弱，经典控制是否可行？为什么？

## 习题答案

### 习题1

(1) 因式分解：$G(s) = \frac{2s+3}{(s+2)(s+3)}$。分子 $2s+3 = 2(s+1.5)$，无公因式。无零极点对消。

(2) 已是最小实现。

(3) 可控标准型：

$G(s) = \frac{2s+3}{s^2+5s+6} = \frac{0\cdot s^2 + 2s + 3}{s^2+5s+6}$，所以 $b_2=0, b_1=2, b_0=3$，$a_1=5, a_0=6$。

$$A = \begin{bmatrix} 0 & 1 \\ -6 & -5 \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ 1 \end{bmatrix}, \quad C = \begin{bmatrix} 3 & 2 \end{bmatrix}, \quad D = 0$$

### 习题2

(1) 特征值：$\det(sI - A) = s^2 + 3s + 2 = 0$，$s_1 = -1$，$s_2 = -2$。

(2) 期望特征多项式：$(s+1-j)(s+1+j) = s^2 + 2s + 2 = 0$。

设 $K = [k_1, k_2]$，则 $A - BK = \begin{bmatrix} 0 & 1 \\ -2-k_1 & -3-k_2 \end{bmatrix}$。

闭环特征多项式：$s^2 + (3+k_2)s + (2+k_1) = 0$。

对比：$3+k_2 = 2 \Rightarrow k_2 = -1$；$2+k_1 = 2 \Rightarrow k_1 = 0$。

$K = [0, -1]$。注意：$k_2 = -1$ 是负反馈，即 $u = -0\cdot x_1 - (-1)\cdot x_2 = x_2$？不对，$u = -Kx = -0\cdot x_1 + 1\cdot x_2 = x_2$。这是正反馈？

重新检查：$A-BK = \begin{bmatrix} 0 & 1 \\ -2-k_1 & -3-k_2 \end{bmatrix}$。若 $K = [0, -1]$：$A-BK = \begin{bmatrix} 0 & 1 \\ -2 & -2 \end{bmatrix}$。特征多项式：$s^2 + 2s + 2 = 0$。正确。$u = -Kx = -0\cdot x_1 + 1\cdot x_2 = x_2$。实际上，状态反馈 $u = -Kx$ 中 $K$ 可以是负值元素，对应控制律中某些状态项是"正反馈"。只要整体闭环稳定即可。

(3) 验证：$\det(sI - (A-BK)) = s^2 + 2s + 2 = 0$，根为 $s = -1 \pm j$。符合要求。

### 习题3

(1) 经典控制通常把MIMO系统解耦为多个SISO回路，用单回路PID或频域方法设计。困难：回路之间的耦合可能导致一个回路的调节干扰另一个回路，使得各自独立设计的控制器在闭环中性能退化甚至不稳定。常用的方法有相对增益阵列（RGA）分析配对关系，或设计解耦器。

(2) 现代控制直接用状态空间描述，将多输入多输出作为整体处理。通过状态反馈或输出反馈统一设计，可以天然处理耦合。LQR等最优控制框架直接最小化多变量代价函数，避免了"先解耦再设计"的两步过程。

(3) 如果耦合很弱，经典控制完全可行。此时每个回路的动态几乎不受另一个回路影响，可以分别设计PID。解耦设计反而增加了不必要的复杂性。工程中判断耦合强弱常用RGA或开环交互量分析。

## 小结

- 经典控制理论以传递函数为核心，擅长SISO系统的分析和频域设计，物理直觉强
- 现代控制理论以状态空间为核心，擅长MIMO系统的分析和综合设计，数学框架统一
- 两者不是替代关系，而是互补：经典控制适合简单工业过程，现代控制适合复杂系统
- 状态空间揭示了系统内部机制，支持极点任意配置、最优控制、状态观测和鲁棒控制
- 从经典到现代的过渡是工具箱的扩展，不是范式的推翻
- 在工程实践中，两者经常结合使用：用经典方法快速调参，用现代方法处理复杂耦合和优化

经典控制理论到此处告一段落。掌握传递函数、时域分析、根轨迹、频域分析和频率校正，你已经拥有了分析和设计单输入单输出线性系统的完整工具。接下来，知识库将深入现代控制理论的状态空间方法、最优控制、卡尔曼滤波和MPC等前沿主题。
