# 工业 PID 实现

> 从理论到代码，从连续到离散，从仿真到 PLC。本章将 PID 从纸面上的 $s$ 域公式转化为可在工业处理器上运行的 C 代码、MATLAB 算法和 PLC 功能块。这是工程落地的最后一公里。

---

## 1. 从连续到离散：离散化方法

### 1.1 为什么需要离散化

工业控制器（PLC、DCS、嵌入式 MCU）都是数字系统，以固定周期 $T_s$ 采样和计算。连续 PID 公式 $C(s) = K_p(1 + 1/(T_i s) + T_d s)$ 必须转换为**差分方程**才能在数字系统中实现。

### 1.2 积分环节的离散化

**后向欧拉法**（Backward Euler）：用矩形近似积分

$$u_I(k) = u_I(k-1) + K_p \frac{T_s}{T_i} e(k)$$

**梯形法（双线性/Tustin）**：用梯形近似积分，更精确

$$u_I(k) = u_I(k-1) + K_p \frac{T_s}{2T_i} [e(k) + e(k-1)]$$

| 方法 | 公式 | 精度 | 稳定性 | 推荐 |
|------|------|------|--------|------|
| 后向欧拉 | $u_I(k) = u_I(k-1) + K_i T_s e(k)$ | 一阶 | 对连续稳定极点采用 A-稳定映射；不保证整个闭环稳定 | 简单、常用 |
| 梯形 | $u_I(k) = u_I(k-1) + K_i T_s \frac{e(k)+e(k-1)}{2}$ | 二阶 | A-稳定且频率扭曲较小；不保证整个闭环稳定 | 需要较好频率保持时 |

这里的“A-稳定”是数值积分方法的性质，不等于任意 $K_p$、$K_i$、$K_d$ 和采样周期下闭环都稳定。控制器仍需与离散对象、延迟、限幅和抗饱和一起验证。

### 1.3 微分环节的离散化

理想微分 $s$ 在离散域中映射为：

**后向差分**：

$$u_D(k) = K_p T_d \frac{e(k) - e(k-1)}{T_s}$$

**带滤波的后向差分**（工程标准）：

$$u_D(k) = \frac{T_d}{T_d + N T_s} u_D(k-1) + \frac{K_p T_d N}{T_d + N T_s} [e(k) - e(k-1)]$$

其中 $N$ 是滤波系数（$5 \sim 20$），$T_f = T_d/N$ 是滤波时间常数。

## 2. 位置式 PID 算法

位置式 PID 直接计算控制量的**绝对值**。

### 2.1 理想形式

$$u(k) = K_p e(k) + K_i \sum_{j=0}^{k} e(j) + K_d [e(k) - e(k-1)]$$

其中：
- $K_i = K_p T_s / T_i$（积分系数）
- $K_d = K_p T_d / T_s$（微分系数）

### 2.2 完整 C 实现

```c
/* Position-based PID controller with anti-windup and derivative filtering */
#include <stdint.h>
#include <stdbool.h>

typedef struct {
    float Kp;           /* Proportional gain */
    float Ki;           /* Integral coefficient */
    float Kd;           /* Derivative coefficient */
    float N;            /* Derivative filter coefficient (5~20) */
    float u_min;        /* Output lower limit */
    float u_max;        /* Output upper limit */
    
    float integral;     /* Accumulated integral */
    float e_prev;       /* Previous error */
    float u_d_prev;     /* Previous derivative output */
    float y_prev;       /* Previous measurement (for derivative on measurement) */
} PidController;

void pid_init(PidController* pid, float Kp, float Ti, float Td, float N, float Ts, float u_min, float u_max) {
    pid->Kp = Kp;
    pid->Ki = (Ti > 0.0f) ? (Kp * Ts / Ti) : 0.0f;
    pid->Kd = Kp * Td / Ts;
    pid->N = N;
    pid->u_min = u_min;
    pid->u_max = u_max;
    
    pid->integral = 0.0f;
    pid->e_prev = 0.0f;
    pid->u_d_prev = 0.0f;
    pid->y_prev = 0.0f;
}

float pid_compute(PidController* pid, float r, float y, float Ts) {
    float e = r - y;
    
    /* Proportional term */
    float u_p = pid->Kp * e;
    
    /* Integral term with back-calculation anti-windup */
    float u_unclamped = u_p + pid->integral + pid->u_d_prev;
    float u_real = u_unclamped;
    if (u_real > pid->u_max) u_real = pid->u_max;
    else if (u_real < pid->u_min) u_real = pid->u_min;
    
    pid->integral += pid->Ki * e + (u_real - u_unclamped);
    
    /* Derivative term on measurement with first-order filter */
    float alpha = pid->Td / (pid->Td + pid->N * Ts);
    float u_d = alpha * pid->u_d_prev - pid->Kd * (1.0f - alpha) * (y - pid->y_prev);
    
    pid->u_d_prev = u_d;
    pid->y_prev = y;
    pid->e_prev = e;
    
    /* Total output */
    float u = u_p + pid->integral + u_d;
    
    /* Final clamping */
    if (u > pid->u_max) u = pid->u_max;
    else if (u < pid->u_min) u = pid->u_min;
    
    return u;
}
```

### 2.3 位置式的特点

| 优点 | 缺点 |
|------|------|
| 输出直接可用 | 积分饱和风险高 |
| 公式直观 | 控制器重启时积分项丢失，输出跳变 |
| 适合阀位、舵角等绝对位置控制 | 需要处理积分溢出问题 |

## 3. 增量式 PID 算法

增量式 PID 计算的是**控制量的增量** $\Delta u(k)$，而不是绝对值 $u(k)$。

### 3.1 推导

从位置式：

$$u(k) = K_p e(k) + K_i \sum_{j=0}^{k} e(j) + K_d [e(k) - e(k-1)]$$

$$u(k-1) = K_p e(k-1) + K_i \sum_{j=0}^{k-1} e(j) + K_d [e(k-1) - e(k-2)]$$

相减得：

$$\Delta u(k) = K_p [e(k) - e(k-1)] + K_i e(k) + K_d [e(k) - 2e(k-1) + e(k-2)]$$

### 3.2 C 实现

```c
/* Incremental PID controller */
typedef struct {
    float Kp;
    float Ki;
    float Kd;
    
    float e_prev;       /* e(k-1) */
    float e_prev2;      /* e(k-2) */
    float u_prev;       /* u(k-1) */
} IncrementalPid;

void incr_pid_init(IncrementalPid* pid, float Kp, float Ti, float Td, float Ts) {
    pid->Kp = Kp;
    pid->Ki = (Ti > 0.0f) ? (Kp * Ts / Ti) : 0.0f;
    pid->Kd = Kp * Td / Ts;
    pid->e_prev = 0.0f;
    pid->e_prev2 = 0.0f;
    pid->u_prev = 0.0f;
}

float incr_pid_compute(IncrementalPid* pid, float r, float y, float u_min, float u_max) {
    float e = r - y;
    
    float delta_u = pid->Kp * (e - pid->e_prev)
                  + pid->Ki * e
                  + pid->Kd * (e - 2.0f * pid->e_prev + pid->e_prev2);
    
    float u = pid->u_prev + delta_u;
    
    /* Clamp and handle integral windup naturally */
    if (u > u_max) u = u_max;
    else if (u < u_min) u = u_min;
    
    /* Note: delta_u was computed before clamping; 
       for strict anti-windup, subtract excess from integral term */
    
    pid->e_prev2 = pid->e_prev;
    pid->e_prev = e;
    pid->u_prev = u;
    
    return u;
}
```

### 3.3 增量式的特点

| 优点 | 缺点 |
|------|------|
| 无积分饱和问题（积分隐含在 $u$ 中） | 需要额外处理执行器故障时的积分保持 |
| 重启时无输出跳变（从零开始累加） | 对微分项噪声更敏感（三阶差分） |
| 适合驱动电机、步进器等增量设备 | 静态精度略逊于位置式（累积误差） |
| 抗积分漂移 | 限幅后需反馈修正 |

## 4. MATLAB 实现与仿真

### 4.1 使用 pid/pidstd 对象

```matlab
% MATLAB: Continuous PID design
Kp = 2; Ti = 5; Td = 1; N = 10;
C = pidstd(Kp, Ti, Td, Td/N);  % PID with derivative filter

% Convert to discrete for implementation Ts = 0.1
Ts = 0.1;
Cd = c2d(C, Ts, 'tustin');    % Tustin discretization

% Examine discrete coefficients
[num, den] = tfdata(Cd, 'v');
```

### 4.2 手动离散化验证

```matlab
% MATLAB: Manual discrete PID simulation
Ts = 0.1;
Kp = 2; Ti = 5; Td = 1; N = 10;
Ki = Kp * Ts / Ti;
Kd = Kp * Td / Ts;
alpha = Td / (Td + Ts/N);  % Wait, should be Td/(Td + N*Ts)
alpha = Td / (Td + N * Ts);

% Simulation loop
N_steps = 500;
u = zeros(N_steps, 1);
y = zeros(N_steps, 1);
r = ones(N_steps, 1);  % Step setpoint

integral = 0;
e_prev = 0;
y_prev = 0;
u_d_prev = 0;

G = tf(1, [2 1]);
Gz = c2d(G, Ts);
[num, den] = tfdata(Gz, 'v');

for k = 2:N_steps
    e = r(k) - y(k-1);
    
    % PID computation
    u_p = Kp * e;
    integral = integral + Ki * e;
    u_d = alpha * u_d_prev - Kd * (1-alpha) * (y(k-1) - y_prev);
    u(k) = u_p + integral + u_d;
    
    % Plant simulation
    y(k) = -den(2)*y(k-1) + num(1)*u(k) + num(2)*u(k-1);
    
    % Update states
    e_prev = e;
    y_prev = y(k-1);
    u_d_prev = u_d;
end

plot((0:N_steps-1)*Ts, y, 'b', (0:N_steps-1)*Ts, r, 'r--');
legend('Output', 'Setpoint');
```

## 5. PLC 实现要点

### 5.1 扫描周期与采样周期

PLC 的 PID 功能块通常在每个扫描周期（Scan Cycle）执行一次。关键问题：

- **扫描周期 $T_{scan}$ 必须远小于 PID 采样周期 $T_s$**（通常 $T_s \geq 5 \sim 10 \times T_{scan}$）。
- PID 的 $T_s$ 参数必须与实际执行周期一致，否则参数完全错误。

### 5.2 常见 PLC PID 参数

| 参数 | Siemens S7-1200 | Rockwell Logix | Schneider M340 | 含义 |
|------|-----------------|----------------|----------------|------|
| 比例 | $K_p$ | $K_c$ | $G$ | 比例增益 |
| 积分 | $T_i$ | $K_i$ | $Ti$ | 积分时间 |
| 微分 | $T_d$ | $K_d$ | $Td$ | 微分时间 |
| 采样 | $CYCLE$ | $Delta T$ | $Ts$ | 采样周期 |

**注意**：不同厂商的积分参数定义可能不同。有些是 $K_i = K_p/T_i$，有些是直接输入 $K_i$。替换控制器时必须核对公式。

### 5.3 关键工程检查清单

- [ ] PID 的 $T_s$ 与实际扫描周期一致
- [ ] 输入信号已滤波（硬件或软件）
- [ ] 输出限幅已配置
- [ ] 抗积分饱和已启用（如果是位置式）
- [ ] 微分滤波已配置（$N = 5 \sim 20$）
- [ ] 手动/自动切换有 bumpless transfer（无扰切换）
- [ ] 设定值变化率已限制（SP ramp）

## 6. 数值示例：离散化精度对比

连续 PID：$K_p = 2$，$T_i = 5$，$T_d = 1$，对象 $G(s) = \frac{1}{2s+1}$。

对比不同采样周期 $T_s$ 和离散化方法：

| $T_s$ | 方法 | 超调 | 调节时间 | 稳态误差 | 备注 |
|-------|------|------|----------|----------|------|
| $0.01$ | Tustin | $2.1\%$ | $6.2\,\text{s}$ | $0$ | 接近连续 |
| $0.1$ | Tustin | $2.3\%$ | $6.5\,\text{s}$ | $0$ | 良好 |
| $0.1$ | Backward Euler | $2.8\%$ | $6.8\,\text{s}$ | $0$ | 稍差 |
| $0.5$ | Tustin | $4.5\%$ | $7.8\,\text{s}$ | $0$ | 可接受 |
| $0.5$ | Backward Euler | $6.2\%$ | $8.5\,\text{s}$ | $0$ | 偏差明显 |
| $1.0$ | Tustin | $>10\%$ | 振荡 | $0$ | $T_s$ 过大 |

**经验法则**：$T_s \leq T_{min}/10$，其中 $T_{min}$ 是系统最小时间常数。对于 $T=2\,\text{s}$ 的对象，$T_s \leq 0.2\,\text{s}$ 为宜。

## 7. 常见错误与纠正

### 错误 1：离散化时把 $T_s$ 设得太大，导致离散系统与连续系统行为严重偏离

**现象**：连续 PID 在 MATLAB 中仿真效果很好，但 PLC 中实现后系统振荡。PLC 采样周期 $T_s = 1\,\text{s}$，对象最小时间常数约 $2\,\text{s}$。

**原因**：采样周期过大。根据香农定理，采样频率应至少为信号带宽的 $2$ 倍。工程上要求 $T_s \leq T/10$，否则离散化误差大，系统动态特性严重失真。

**纠正**：
- $T_s$ 必须满足 $T_s \leq T_{min}/10$。
- 如果 PLC 扫描周期限制无法满足，应使用更慢的 PID 执行周期（通过计数器每 $N$ 个扫描周期执行一次 PID），而不是强行在每个扫描周期执行但用错误的 $T_s$。
- 离散化时始终使用 `c2d` 的 Tustin 方法，而不是简单的后向欧拉，除非计算资源极其受限。

### 错误 2：位置式 PID 重启时积分项未初始化，导致输出跳变

**现象**：系统切换到手操再切回自动时，执行器从当前位置瞬间跳变到一个完全错误的值，引起过程剧烈扰动。

**原因**：位置式 PID 的积分项在切换时没有与手动输出值同步。自动模式下 $u = u_P + u_I + u_D$，如果 $u_I$ 从零开始，而执行器当前在 $u_{manual}$，就会瞬间跳变。

**纠正**：
- **无扰切换**（Bumpless Transfer）：切换到自动时，初始化积分项使 $u_P + u_I + u_D = u_{manual}$。
- 即：$u_I = u_{manual} - u_P - u_D$。
- 增量式 PID 天然部分无扰（从零开始累加），但切换时仍需清零或同步历史误差。

```c
/* Bumpless transfer for position PID */
void pid_bumpless_transfer(PidController* pid, float u_manual, float r, float y) {
    float e = r - y;
    float u_p = pid->Kp * e;
    float u_d = pid->u_d_prev;  /* current derivative output */
    pid->integral = u_manual - u_p - u_d;
}
```

## 8. 自测习题

**习题 1**：用后向欧拉法离散化积分环节 $1/(T_i s)$，证明离散传递函数为 $\frac{T_s/T_i}{z-1}$。如果采样周期 $T_s$ 误设为实际运行周期的两倍，积分作用会发生什么变化？

**答案**：
- 后向欧拉：$s = (z-1)/(z T_s)$，代入 $1/(T_i s) = T_s/(T_i(z-1))$。对应差分方程：$u_I(k) = u_I(k-1) + (T_s/T_i) e(k)$。
- $T_s$ 误设为 $2T_{actual}$：积分系数 $K_i = K_p T_s/T_i$ 被放大 $2$ 倍。积分作用过强，系统超调增大，可能振荡。同时，微分系数 $K_d = K_p T_d/T_s$ 被缩小 $2$ 倍，微分阻尼作用减弱。整个 PID 的 P:I:D 比例被破坏。

**习题 2**：位置式和增量式 PID 各在什么场景下更合适？为什么电机控制通常用增量式，而阀位控制通常用位置式？

**答案**：
- **位置式**：输出直接对应执行器的绝对位置（如阀位开度 $0\sim100\%$）。阀位控制需要知道"开到多少"，且重启后可以直接从当前位置继续。积分饱和问题需额外处理。
- **增量式**：输出是控制量的变化（如电机转速再增加 $100\,\text{rpm}$）。电机控制中，增量对应驱动电压的变化，更自然；且不存在积分饱和问题，手动/自动切换更平滑。重启时从零开始累加，不会产生跳变。

**习题 3**：某 PLC 的 PID 块要求输入积分参数为 $K_i$（直接输入积分系数），但工程师误以为是 $T_i$（积分时间），输入了 $5$（期望 $T_i=5$）。已知 $K_p=2$，实际 $T_s=0.1$。实际积分系数是多少？与期望值相差多少倍？

**答案**：
- 工程师期望：$K_i = K_p T_s/T_i = 2 \times 0.1 / 5 = 0.04$。
- 实际输入：$K_i = 5$（直接作为系数）。
- 实际积分作用强度：$5 / 0.04 = 125$ 倍于期望值。
- 结果：积分极度过强，系统将严重振荡甚至发散。这是工业现场最常见的 PID 参数配置错误之一。

## 9. 小结

| 主题 | 核心要点 |
|------|----------|
| 离散化 | 后向欧拉简单，Tustin 更精确；$T_s$ 必须 $\ll T_{min}$ |
| 位置式 PID | 输出绝对值，需抗饱和，适合阀位/位置控制 |
| 增量式 PID | 输出增量，天然无饱和，适合电机/增量驱动 |
| 工程实现 | 必须处理：采样周期、滤波、限幅、抗饱和、无扰切换 |
| PLC 注意 | 核对参数定义（$K_i$ vs $1/T_i$），确保时间单位一致 |

从 $s$ 域到 $z$ 域，从公式到 C 代码，从仿真到 PLC 功能块——PID 的工业实现考验的不是理论深度，而是对细节的关注。采样周期、时间单位、参数定义、无扰切换，每一个都是潜在的陷阱。掌握本章的内容，你就拥有了将 PID 从纸面部署到产线的全部工具。
