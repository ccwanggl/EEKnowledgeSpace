# 最小二乘辨识

> **核心认知锚点**：最小二乘辨识是在**时域**中"拼图"——让模型预测值 $\hat{y}[k]$ 与实际数据 $y[k]$ 的误差平方和最小。得到的 ARX 系数 $\{a_i, b_j\}$ 直接构成 Z 域传递函数 $H(z) = B(z)/A(z)$，再令 $z = e^{j\Omega}$ 即可切入频域。它是连接"数据域"与"复域"最直接的桥梁之一。

## 1. 直觉先行：什么是最小二乘？

想象你在墙上钉了五个钉子，想要拉一条绳子让它们尽可能都在绳子上。由于测量误差，不可能所有钉子都完美落在一条直线上。你会怎么做？

**最小二乘的直觉**：让绳子的位置使得所有钉子到绳子的**垂直距离的平方和**最小。之所以用"平方"而不是绝对值，是因为平方在数学上更容易处理（处处可导），且对大偏差有更强的惩罚作用。

```
y
│
│    ×         ×               ← 钉子（数据点）
│       ×  ╱                   ← 绳子（拟合直线）
│    ×──╱────×
│  ╱
│╱
└──────────────────────▶ x

最小二乘 = 最小化所有点到直线的纵向距离平方和
```

在系统辨识中，"钉子"是输入输出数据对，"绳子"是模型预测值。我们要找一组模型参数，使得模型预测输出与实际输出之间的误差平方和最小。

## 2. 从线性回归到系统辨识

### 2.1 经典线性回归

给定数据 $\{(x_i, y_i)\}_{i=1}^{N}$，假设线性关系：

$$
y_i = \theta_0 + \theta_1 x_i + e_i
$$

最小化损失函数：

$$
J(\theta) = \sum_{i=1}^{N} \left( y_i - \theta_0 - \theta_1 x_i \right)^2
$$

### 2.2 扩展到动态系统：ARX 模型

对于动态系统，当前输出不仅依赖当前输入，还依赖过去的输入和输出。ARX 模型为：

$$
y(t) + a_1 y(t-1) + \cdots + a_{n_a} y(t-n_a) = b_1 u(t-1) + \cdots + b_{n_b} u(t-n_b) + e(t)
$$

> **与变换链的关系**：上式中的延迟 $y(t-1)$ 在 Z 域中就是 $z^{-1}Y(z)$。因此，ARX 差分方程等价于 Z 域传递函数：
> $$
> H(z) = \frac{B(z)}{A(z)} = \frac{b_1 z^{-1} + \cdots + b_{n_b} z^{-n_b}}{1 + a_1 z^{-1} + \cdots + a_{n_a} z^{-n_a}}
> $$
> 这意味着：最小二乘估计的参数向量 $\theta$ 的每一维，都是 $H(z)$ 的一个分子或分母系数。辨识完成时，你不仅"拟合了数据"，而且直接得到了一个可用于 Bode 分析、极点配置和控制器设计的复域模型。

重写为回归形式：

$$
y(t) = \varphi^T(t) \, \theta + e(t)
$$

其中**回归向量** $\varphi(t)$ 和**参数向量** $\theta$ 为：

$$
\varphi(t) = \begin{bmatrix} -y(t-1) \\ \vdots \\ -y(t-n_a) \\ u(t-1) \\ \vdots \\ u(t-n_b) \end{bmatrix}, \quad
\theta = \begin{bmatrix} a_1 \\ \vdots \\ a_{n_a} \\ b_1 \\ \vdots \\ b_{n_b} \end{bmatrix}
$$

### 2.3 批量最小二乘 (Batch LS)

定义预测误差：

$$
\varepsilon(t, \theta) = y(t) - \varphi^T(t) \, \theta
$$

最小化平方误差和：

$$
J_N(\theta) = \sum_{t=1}^{N} \varepsilon^2(t, \theta) = \sum_{t=1}^{N} \left( y(t) - \varphi^T(t) \, \theta \right)^2
$$

写成矩阵形式。令：

$$
Y = \begin{bmatrix} y(1) \\ y(2) \\ \vdots \\ y(N) \end{bmatrix}, \quad
\Phi = \begin{bmatrix} \varphi^T(1) \\ \varphi^T(2) \\ \vdots \\ \varphi^T(N) \end{bmatrix}
$$

则：

$$
J_N(\theta) = (Y - \Phi \theta)^T (Y - \Phi \theta)
$$

对 $\theta$ 求导并令导数为零：

$$
\frac{\partial J_N}{\partial \theta} = -2 \Phi^T (Y - \Phi \theta) = 0
$$

解得：

$$
\boxed{\hat{\theta}_N = (\Phi^T \Phi)^{-1} \Phi^T Y}
$$

这就是著名的**正规方程 (Normal Equation)**。

## 3. 递推最小二乘 (Recursive Least Squares, RLS)

### 3.1 为什么要递推？

在实际工程中（尤其是嵌入式系统和自适应控制），数据是逐点到达的。如果每来一个数据点就重新计算整个 $(\Phi^T \Phi)^{-1}$，计算量太大。RLS 让我们可以用上一步的估计值 $\hat{\theta}_{t-1}$ 和新数据 $(\varphi(t), y(t))$ 快速更新估计值。

> **与 [[14-FOC-电机控制/00-README|14-FOC-电机控制]] 的关联**：RLS 是 FOC 在线参数估计的核心算法。电机运行时，绕组温度变化导致定子电阻 $R_s$ 漂移（温度每升高 $10^\circ\text{C}$，铜阻增加约 4%）。RLS 在每个控制周期（通常 $50\sim100\,\mu\text{s}$）更新 $R_s$ 估计，保证电流环 PI 控制器始终基于准确的参数整定。类似地，惯量 $J$ 的在线辨识可用于转矩前馈补偿和速度环增益自适应。

### 3.2 RLS 的推导

核心思想：利用矩阵求逆引理，避免每次重新求逆。

令 $P_t = \left( \sum_{k=1}^{t} \varphi(k) \varphi^T(k) \right)^{-1}$，则：

$$
P_t^{-1} = P_{t-1}^{-1} + \varphi(t) \varphi^T(t)
$$

应用矩阵求逆引理：

$$
P_t = P_{t-1} - \frac{P_{t-1} \varphi(t) \varphi^T(t) P_{t-1}}{1 + \varphi^T(t) P_{t-1} \varphi(t)}
$$

同时可以证明：

$$
\hat{\theta}_t = \hat{\theta}_{t-1} + P_t \varphi(t) \left( y(t) - \varphi^T(t) \hat{\theta}_{t-1} \right)
$$

### 3.3 标准 RLS 算法

```
初始化：
    theta_0 = 0 (或先验估计)
    P_0 = alpha * I,  alpha >> 1 (通常取 100 ~ 10000)

对于每个时刻 t = 1, 2, 3, ...:
    1. 采集 y(t), 构造回归向量 phi(t)
    2. 计算预测误差: e(t) = y(t) - phi^T(t) * theta_{t-1}
    3. 计算增益: k_t = P_{t-1} * phi(t) / (1 + phi^T(t) * P_{t-1} * phi(t))
    4. 更新参数: theta_t = theta_{t-1} + k_t * e(t)
    5. 更新协方差: P_t = P_{t-1} - k_t * phi^T(t) * P_{t-1}
```

### 3.4 RLS 的 C 语言实现

```c
/* Recursive Least Squares (RLS) for ARX model
 * Model: y(t) + a1*y(t-1) + a2*y(t-2) = b1*u(t-1) + b2*u(t-2) + e(t)
 * Parameters: theta = [a1, a2, b1, b2]^T
 */

#include <math.h>

#define N_PARAM   4       /* number of parameters: na + nb */
#define NA        2       /* a coefficients */
#define NB        2       /* b coefficients */
#define P0_GAIN   100.0   /* initial P = P0_GAIN * I */

static double theta[N_PARAM];   /* parameter estimates */
static double P[N_PARAM][N_PARAM];  /* covariance matrix */
static double y_hist[NA];       /* past outputs */
static double u_hist[NB];       /* past inputs */

void rls_init(void) {
    int i, j;
    for (i = 0; i < N_PARAM; i++) {
        theta[i] = 0.0;
        for (j = 0; j < N_PARAM; j++) {
            P[i][j] = (i == j) ? P0_GAIN : 0.0;
        }
    }
    for (i = 0; i < NA; i++) y_hist[i] = 0.0;
    for (i = 0; i < NB; i++) u_hist[i] = 0.0;
}

void rls_update(double y, double u) {
    double phi[N_PARAM];
    double e, denom;
    double k[N_PARAM];
    double P_phi[N_PARAM];
    int i, j;

    /* Build regression vector */
    phi[0] = -y_hist[0];   /* -y(t-1) */
    phi[1] = -y_hist[1];   /* -y(t-2) */
    phi[2] =  u_hist[0];   /*  u(t-1) */
    phi[3] =  u_hist[1];   /*  u(t-2) */

    /* Prediction error */
    e = y;
    for (i = 0; i < N_PARAM; i++) {
        e -= phi[i] * theta[i];
    }

    /* P * phi */
    for (i = 0; i < N_PARAM; i++) {
        P_phi[i] = 0.0;
        for (j = 0; j < N_PARAM; j++) {
            P_phi[i] += P[i][j] * phi[j];
        }
    }

    /* Denominator: 1 + phi^T * P * phi */
    denom = 1.0;
    for (i = 0; i < N_PARAM; i++) {
        denom += phi[i] * P_phi[i];
    }

    /* Gain vector k = P * phi / denom */
    for (i = 0; i < N_PARAM; i++) {
        k[i] = P_phi[i] / denom;
    }

    /* Update parameters */
    for (i = 0; i < N_PARAM; i++) {
        theta[i] += k[i] * e;
    }

    /* Update covariance: P = P - k * phi^T * P */
    double temp[N_PARAM][N_PARAM];
    for (i = 0; i < N_PARAM; i++) {
        for (j = 0; j < N_PARAM; j++) {
            temp[i][j] = k[i] * phi[j];
        }
    }
    for (i = 0; i < N_PARAM; i++) {
        for (j = 0; j < N_PARAM; j++) {
            double sum = 0.0;
            for (int m = 0; m < N_PARAM; m++) {
                sum += temp[i][m] * P[m][j];
            }
            P[i][j] -= sum;
        }
    }

    /* Shift history buffers */
    y_hist[1] = y_hist[0];
    y_hist[0] = y;
    u_hist[1] = u_hist[0];
    u_hist[0] = u;
}
```

## 4. 带遗忘因子的 RLS

### 4.1 为什么需要遗忘？

在时变系统中，参数会缓慢漂移（如电机绕组温度变化导致电阻变化）。如果 RLS 对所有历史数据一视同仁，旧数据会"拖累"估计，导致跟踪不及时。

**遗忘因子** $\lambda \in (0, 1]$（通常取 $0.95 \sim 0.999$）给旧数据指数衰减的权重：

$$
J_t(\theta) = \sum_{k=1}^{t} \lambda^{t-k} \left( y(k) - \varphi^T(k) \theta \right)^2
$$

修改后的递推公式：

$$
\begin{aligned}
k_t &= \frac{P_{t-1} \varphi(t)}{\lambda + \varphi^T(t) P_{t-1} \varphi(t)} \\
\hat{\theta}_t &= \hat{\theta}_{t-1} + k_t \left( y(t) - \varphi^T(t) \hat{\theta}_{t-1} \right) \\
P_t &= \frac{1}{\lambda} \left( P_{t-1} - k_t \varphi^T(t) P_{t-1} \right)
\end{aligned}
$$

$\lambda$ 越小，遗忘越快，对时变跟踪越灵敏，但对噪声也越敏感。

## 5. 数值示例：完整辨识流程

### 5.1 问题设定

真实系统（二阶 ARX）：

$$
y(t) - 1.5 y(t-1) + 0.7 y(t-2) = 0.5 u(t-1) + 0.3 u(t-2) + e(t)
$$

其中 $e(t) \sim \mathcal{N}(0, 0.01)$。输入 $u(t)$ 为均匀白噪声 $\mathcal{U}(-1, 1)$。

### 5.2 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

# True system parameters
a1_true, a2_true = -1.5, 0.7   # y(t) + a1*y(t-1) + a2*y(t-2) = ...
b1_true, b2_true =  0.5, 0.3

# Simulation setup
N = 1000
np.random.seed(42)
u = np.random.uniform(-1, 1, N)
e = 0.1 * np.random.randn(N)

# Simulate true system
y = np.zeros(N)
for t in range(2, N):
    y[t] = (-a1_true * y[t-1] - a2_true * y[t-2]
            + b1_true * u[t-1] + b2_true * u[t-2]
            + e[t])

# --- Batch Least Squares ---
Phi = np.zeros((N-2, 4))
Y = y[2:]
for t in range(2, N):
    Phi[t-2, :] = [-y[t-1], -y[t-2], u[t-1], u[t-2]]

theta_batch = np.linalg.lstsq(Phi, Y, rcond=None)[0]
print("Batch LS:", theta_batch)

# --- Recursive Least Squares with forgetting ---
lambda_f = 0.99
theta_rls = np.zeros(4)
P = 100.0 * np.eye(4)

# Store trajectories
theta_trajectory = np.zeros((N-2, 4))

for t in range(2, N):
    phi = np.array([-y[t-1], -y[t-2], u[t-1], u[t-2]])
    eps = y[t] - phi @ theta_rls
    denom = lambda_f + phi @ P @ phi
    k = (P @ phi) / denom
    theta_rls = theta_rls + k * eps
    P = (1.0 / lambda_f) * (P - np.outer(k, phi @ P))
    theta_trajectory[t-2, :] = theta_rls

print("RLS final:", theta_rls)
print("True:    ", [-a1_true, -a2_true, b1_true, b2_true])

# Plot parameter convergence
fig, axes = plt.subplots(2, 2, figsize=(10, 6))
param_names = ['a1', 'a2', 'b1', 'b2']
true_vals = [-a1_true, -a2_true, b1_true, b2_true]
for i, ax in enumerate(axes.flat):
    ax.plot(theta_trajectory[:, i], label='RLS estimate')
    ax.axhline(true_vals[i], color='r', linestyle='--', label='True value')
    ax.set_title(param_names[i])
    ax.legend()
    ax.grid(True)
plt.tight_layout()
plt.savefig('rls_convergence.png', dpi=150)
plt.show()
```

### 5.3 结果分析

运行上述代码，你会看到：

| 参数 | 真值 | Batch LS 估计 | RLS 最终估计 |
|------|------|---------------|-------------|
| $a_1$ | 1.5 | ~1.498 | ~1.497 |
| $a_2$ | -0.7 | ~-0.698 | ~-0.701 |
| $b_1$ | 0.5 | ~0.502 | ~0.499 |
| $b_2$ | 0.3 | ~0.298 | ~0.301 |

RLS 轨迹图会显示参数在前 100 个采样点快速收敛，之后围绕真值小幅波动（由于噪声和遗忘因子的作用）。

> **从时域到频域的验证**：辨识得到的参数 $\hat{a}_1, \hat{a}_2, \hat{b}_1, \hat{b}_2$ 对应 Z 域传递函数
> $$
> \hat{H}(z) = \frac{\hat{b}_1 z^{-1} + \hat{b}_2 z^{-2}}{1 + \hat{a}_1 z^{-1} + \hat{a}_2 z^{-2}}
> $$
> 令 $z = e^{j\Omega}$ 代入，得到频率响应 $\hat{H}(e^{j\Omega})$。你可以将其与独立实验（如扫频测试）得到的 Bode 图对比，验证模型是否准确捕捉了系统的共振频率和阻尼特性。这就是统一框架中"从数据域到复域再到频域"的完整闭环。

## 6. 最小二乘的统计性质

### 6.1 无偏性

如果噪声 $e(t)$ 是白噪声，且与回归向量 $\varphi(t)$ 不相关，则 LS 估计是无偏的：

$$
\mathbb{E}[\hat{\theta}_N] = \theta_0
$$

### 6.2 一致性

当 $N \to \infty$ 时，估计值依概率收敛到真值：

$$
\hat{\theta}_N \xrightarrow{P} \theta_0
$$

### 6.3 有效性 (Efficiency)

在所有线性无偏估计中，LS 估计具有最小方差（Gauss-Markov 定理）。

## 7. 常见错误与纠正

### 错误 1：$\Phi^T \Phi$ 接近奇异

**场景**：输入信号变化缓慢，或者两个回归变量高度相关（如 $u(t-1) \approx u(t-2)$）。

**问题**：$(\Phi^T \Phi)^{-1}$ 不存在或数值不稳定，参数估计方差极大。

**纠正**：
1. 检查输入信号是否持续激励；
2. 增加正则化（岭回归）：$\hat{\theta} = (\Phi^T \Phi + \alpha I)^{-1} \Phi^T Y$；
3. 在 RLS 中，保持 $P$ 矩阵有合理的下界，避免 $P \to 0$ 后失去更新能力。

### 错误 2：协方差矩阵 $P$ 失去正定性

**场景**：嵌入式实现中，由于有限字长效应，RLS 的 $P$ 矩阵逐渐失去对称性和正定性。

**问题**：$P$ 不正定会导致增益 $k_t$ 计算异常，参数估计发散。

**纠正**：
1. 每步更新后强制对称化：`P = 0.5 * (P + P.T)`；
2. 使用平方根 RLS (SR-RLS)，直接递推 $P^{1/2}$ 而不是 $P$；
3. 定期检查 $P$ 的特征值，若出现负值则重置。

```python
# Symmetrization fix in Python
def rls_update_fixed(y, u, phi, theta, P, lam=0.99):
    eps = y - phi @ theta
    denom = lam + phi @ P @ phi
    k = (P @ phi) / denom
    theta = theta + k * eps
    P = (1.0 / lam) * (P - np.outer(k, phi @ P))
    # --- FIX: force symmetry ---
    P = 0.5 * (P + P.T)
    return theta, P
```

## 8. 自测习题

**习题 1**：考虑一个一阶系统 $y(t) = a \, y(t-1) + b \, u(t-1) + e(t)$。写出批量最小二乘的正规方程，并说明 $\Phi^T \Phi$ 的维度。

<details>
<summary>答案</summary>

回归向量 $\varphi(t) = [-y(t-1), u(t-1)]^T$，参数向量 $\theta = [a, b]^T$。

$$\Phi = \begin{bmatrix} -y(0) & u(0) \\ -y(1) & u(1) \\ \vdots & \vdots \\ -y(N-1) & u(N-1) \end{bmatrix}_{N \times 2}, \quad Y = \begin{bmatrix} y(1) \\ y(2) \\ \vdots \\ y(N) \end{bmatrix}_{N \times 1}$$

$$\Phi^T \Phi = \begin{bmatrix} \sum y^2(t-1) & -\sum y(t-1)u(t-1) \\ -\sum y(t-1)u(t-1) & \sum u^2(t-1) \end{bmatrix}_{2 \times 2}$$

正规方程：$(\Phi^T \Phi) \hat{\theta} = \Phi^T Y$，解出 $\hat{\theta} = (\Phi^T \Phi)^{-1} \Phi^T Y$。

$\Phi^T \Phi$ 是 $2 \times 2$ 矩阵。

</details>

**习题 2**：RLS 中，如果遗忘因子 $\lambda = 1$，意味着什么？如果 $\lambda = 0.5$，又会怎样？

<details>
<summary>答案</summary>

$\lambda = 1$：**无遗忘**，所有历史数据权重相同。适合时不变系统，估计值方差最小但无法跟踪参数漂移。

$\lambda = 0.5$：**快速遗忘**，旧数据权重呈指数衰减，有效"记忆长度"约为 $1/(1-\lambda) = 2$ 个采样点。对时变系统跟踪极快，但对噪声极度敏感，估计值方差很大。

工程上通常取 $\lambda \in [0.95, 0.999]$，在跟踪速度和噪声抑制之间折中。

</details>

**习题 3**：为什么 ARX 模型的最小二乘估计在有噪声时仍然是无偏的，而输出误差 (OE) 模型需要迭代优化？

<details>
<summary>答案</summary>

ARX 模型：$A(q)y(t) = B(q)u(t) + e(t)$。噪声 $e(t)$ 直接进入方程，且与回归向量（由过去的 $y$ 和 $u$ 组成）中的 $u$ 不相关。如果 $e(t)$ 是白噪声，则它与所有过去的 $y(t-k)$ 也不相关（因为过去的输出只依赖于过去的噪声），因此满足 LS 无偏条件。

OE 模型：$y(t) = G(q,\theta)u(t) + e(t)$。噪声只加在输出端。此时回归向量包含 $y(t-k)$，而 $y(t-k)$ 中含有 $e(t-k)$，导致噪声与回归向量相关，LS 估计有偏。需要使用预测误差法 (PEM) 或极大似然法进行迭代优化。

</details>
