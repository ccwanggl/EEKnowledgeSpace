# 模型验证与阶次选择

## 1. 为什么要验证？

系统辨识不是"算完参数就结束"。一个模型只有在通过严格的验证后，才能用于控制器设计或预测。

**直觉**：就像医生不能只看体检报告上的数字就下诊断，还要问"这些数字和症状是否一致"。模型验证就是"问数据"。

```
            辨识得到的模型
                 │
                 ▼
    ┌────────────────────────────┐
    │      模型验证的三道关卡       │
    ├────────────────────────────┤
    │  1. 预测能力：新数据上准不准？ │
    │  2. 残差分析：还有没有信息没提取？│
    │  3. 阶次合理：是不是太复杂了？ │
    └────────────────────────────┘
                 │
         通过 ──▶ 交付使用
         失败 ──▶ 返回修改模型结构
```

## 2. 交叉验证：预测能力的黄金标准

### 2.1 训练集 / 验证集 / 测试集

- **训练集 (Estimation Set)**：用于估计模型参数。
- **验证集 (Validation Set)**：用于模型选择和调参（如阶次选择）。
- **测试集 (Test Set)**：用于最终评估，在整个建模过程中只能使用一次。

经典比例：60% / 20% / 20%。

### 2.2 拟合度指标

最常用的指标是**归一化均方根误差 (NRMSE) 拟合度**：

$$
\text{Fit} = 100 \times \left( 1 - \frac{\| y - \hat{y} \|_2}{\| y - \bar{y} \|_2} \right)
$$

| Fit 值 | 含义 |
|--------|------|
| 90-100% | 极好（工业上少见，可能过拟合） |
| 70-90%  | 良好 |
| 50-70%  | 一般，可能需要改进模型结构 |
| < 50%   | 较差，需要重新考虑建模方法 |

注意：Fit 值是相对的。如果一个系统的输出几乎被噪声完全淹没，即使最好的模型 Fit 也可能只有 30%。

### 2.3 K 折交叉验证

当数据量有限时，将数据分成 $K$ 份，轮流用 $K-1$ 份训练、1 份验证，最后取平均：

```
Data: [Fold1][Fold2][Fold3][Fold4][Fold5]

Run 1: Train on 2-5, Validate on 1
Run 2: Train on 1,3-5, Validate on 2
Run 3: Train on 1-2,4-5, Validate on 3
Run 4: Train on 1-3,5, Validate on 4
Run 5: Train on 1-4, Validate on 5

Final score = average of 5 validation scores
```

```python
import numpy as np
from sklearn.model_selection import KFold

def kfold_fit_score(Phi, Y, n_splits=5):
    """Evaluate ARX model using K-fold cross-validation."""
    kf = KFold(n_splits=n_splits, shuffle=False)
    scores = []
    for train_idx, val_idx in kf.split(Y):
        Phi_train, Phi_val = Phi[train_idx], Phi[val_idx]
        Y_train, Y_val = Y[train_idx], Y[val_idx]
        theta = np.linalg.lstsq(Phi_train, Y_train, rcond=None)[0]
        Y_pred = Phi_val @ theta
        fit = 100 * (1 - np.linalg.norm(Y_val - Y_pred) / np.linalg.norm(Y_val - np.mean(Y_val)))
        scores.append(fit)
    return np.mean(scores), np.std(scores)
```

## 3. 残差分析

### 3.1 什么是好残差？

残差 $\varepsilon(t) = y(t) - \hat{y}(t)$ 应该像**白噪声**——不可预测、不含任何信息。

如果残差中还有规律，说明模型没有提取完数据中的全部信息。

### 3.2 自相关检验 (ACF)

计算残差的自相关函数：

$$
R_{\varepsilon}(\tau) = \frac{1}{N} \sum_{t=1}^{N-\tau} \varepsilon(t) \varepsilon(t+\tau)
$$

对于白噪声，理论上 $R_{\varepsilon}(\tau) = 0$（$\tau \neq 0$）。实际中，如果 $95\%$ 的 $R_{\varepsilon}(\tau)$ 落在 $\pm 1.96 / \sqrt{N}$ 的置信区间内，则接受"残差为白噪声"的假设。

```
残差自相关图 (ACF):

  R(τ)
   │    │
1.0├────┼────●────                    ● = R(0) 总是 1
   │    │    │
   │    │
 0 ├──░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  ← 95% 置信带
   │    │                              （应在带内）
   │    │
-0.5├───┼────┼────┼────┼────┼────┼───▶ τ
   0    5   10   15   20   25   30

好的残差：除了 τ=0 外，所有点都在置信带内
```

### 3.3 互相关检验 (CCF)

计算残差与输入的互相关：

$$
R_{\varepsilon u}(\tau) = \frac{1}{N} \sum_{t=1}^{N-\tau} \varepsilon(t+\tau) u(t)
$$

如果模型充分描述了输入到输出的动态关系，则残差应与输入不相关——所有 $R_{\varepsilon u}(\tau)$ 都应在置信区间内。

### 3.4 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def residual_analysis(y, y_pred, u, max_lag=30):
    """Analyze residuals: ACF and CCF."""
    eps = y - y_pred
    N = len(eps)
    conf = 1.96 / np.sqrt(N)   # 95% confidence interval
    
    lags = np.arange(max_lag + 1)
    
    # ACF of residuals
    acf = np.correlate(eps, eps, mode='full')[N-1:N+max_lag]
    acf = acf / acf[0]          # normalize
    
    # CCF of residuals and input
    ccf = np.correlate(eps, u, mode='full')[N-1:N+max_lag]
    ccf = ccf / (np.std(eps) * np.std(u) * N)
    
    fig, axes = plt.subplots(2, 1, figsize=(10, 6))
    
    axes[0].stem(lags, acf, basefmt=' ')
    axes[0].axhline(conf, color='r', ls='--')
    axes[0].axhline(-conf, color='r', ls='--')
    axes[0].set_title('ACF of Residuals')
    axes[0].set_xlabel('Lag')
    axes[0].grid(True)
    
    axes[1].stem(lags, ccf, basefmt=' ')
    axes[1].axhline(conf, color='r', ls='--')
    axes[1].axhline(-conf, color='r', ls='--')
    axes[1].set_title('CCF: Residuals vs Input')
    axes[1].set_xlabel('Lag')
    axes[1].grid(True)
    
    plt.tight_layout()
    return fig, acf, ccf
```

## 4. 阶次选择准则

### 4.1 偏差-方差权衡

```
         总误差
           │      ╲      方差 (Variance)
           │       ╲     ↑ overfitting
           │        ╲   /
           │         ╲ /
           │          ●  ← 最优阶次
           │         / ╲
           │        /   ╲
           │       /     ╲  偏差² (Bias²)
           │      /       ↓ underfitting
           └──────────────────▶ 模型复杂度 (阶次)
```

- **低阶次**：模型过于简单，无法捕捉系统动态（高偏差，欠拟合）。
- **高阶次**：模型过于复杂，拟合了噪声（高方差，过拟合）。
- **最优阶次**：在偏差和方差之间取得平衡。

### 4.2 AIC：Akaike 信息准则

$$
\text{AIC} = 2k - 2 \ln(\hat{L})
$$

其中 $k$ 是参数个数，$\hat{L}$ 是似然函数最大值。AIC 越小越好。

对于高斯噪声下的线性回归，可以近似为：

$$
\text{AIC} \approx N \ln\left( \frac{1}{N} \sum_{t=1}^{N} \varepsilon^2(t) \right) + 2k
$$

### 4.3 BIC：Bayesian 信息准则

$$
\text{BIC} = k \ln(N) - 2 \ln(\hat{L})
$$

BIC 对模型复杂度的惩罚比 AIC 更重，倾向于选择更简单的模型。大样本下 BIC 是一致的（能选到真实阶次），而 AIC 倾向于选略高的阶次。

### 4.4 FPE：最终预测误差

$$
\text{FPE} = \frac{N + k}{N - k} \cdot \frac{1}{N} \sum_{t=1}^{N} \varepsilon^2(t)
$$

FPE 直接估计模型在未来数据上的预测误差。

### 4.5 数值示例：阶次选择

```python
import numpy as np
import matplotlib.pyplot as plt

# True system: ARX(2,2,1)
a_true = [1.5, -0.7]
b_true = [0.5, 0.3]
N = 500
np.random.seed(42)
u = np.random.uniform(-1, 1, N)
e = 0.1 * np.random.randn(N)

y = np.zeros(N)
for t in range(2, N):
    y[t] = (1.5*y[t-1] - 0.7*y[t-2] + 0.5*u[t-1] + 0.3*u[t-2] + e[t])

# Try different orders
na_range = range(1, 6)
nb_range = range(1, 6)
nk = 1

best_aic = np.inf
best_order = (1, 1)
aic_matrix = np.zeros((len(na_range), len(nb_range)))

for i, na in enumerate(na_range):
    for j, nb in enumerate(nb_range):
        Phi = np.zeros((N - max(na, nb + nk - 1), na + nb))
        Y = y[max(na, nb + nk - 1):]
        for t in range(max(na, nb + nk - 1), N):
            row = []
            for k in range(1, na + 1):
                row.append(-y[t - k])
            for k in range(nk, nb + nk):
                row.append(u[t - k])
            Phi[t - max(na, nb + nk - 1), :] = row
        
        theta = np.linalg.lstsq(Phi, Y, rcond=None)[0]
        eps = Y - Phi @ theta
        sse = np.sum(eps**2)
        k_param = na + nb
        aic = N * np.log(sse / N) + 2 * k_param
        aic_matrix[i, j] = aic
        
        if aic < best_aic:
            best_aic = aic
            best_order = (na, nb)

print(f"Best order by AIC: na={best_order[0]}, nb={best_order[1]}, AIC={best_aic:.2f}")
# Expected: na=2, nb=2 (matching true system)

# Visualize
fig, ax = plt.subplots(figsize=(8, 6))
im = ax.imshow(aic_matrix, cmap='viridis', origin='lower')
ax.set_xticks(range(len(nb_range)))
ax.set_xticklabels(nb_range)
ax.set_yticks(range(len(na_range)))
ax.set_yticklabels(na_range)
ax.set_xlabel('nb')
ax.set_ylabel('na')
ax.set_title('AIC Heatmap for Order Selection')
plt.colorbar(im, ax=ax, label='AIC')
plt.tight_layout()
plt.savefig('aic_order_selection.png', dpi=150)
plt.show()
```

## 5. 常见错误与纠正

### 错误 1：用训练集评估模型

**场景**：工程师看到 ARX(5,5) 在训练集上的 Fit 为 95%，决定采用这个模型。

**问题**：高阶模型在训练集上几乎总是表现更好，因为它有更多参数去拟合噪声。用训练集评估会系统性地偏向过复杂的模型。

**纠正**：始终使用**独立的验证集**评估模型。更好的做法是绘制"阶次-Fit 曲线"：

```
Fit [%]
  │
95├───────●──── 训练集 (总是上升)
  │      /│
90├─────/─┼──●── 验证集 (先升后降)
  │    /  │  ╲
85├───/   │   ╲
  │  /    │    ╲
80├─●     │     ╲
  │       │
  └───────┼──────────▶ 模型阶次
         最优
```

验证集上的 Fit 达到峰值后下降的点，就是最优阶次。

### 错误 2：忽略残差中的周期性

**场景**：残差 ACF 在滞后 10、20、30 处有明显的尖峰，但工程师认为"整体在置信区间内"而接受了模型。

**问题**：周期性的自相关意味着模型遗漏了系统的某个周期性模态（如机械系统的旋转频率、电源的 50 Hz 干扰）。

**纠正**：
1. 检查输入信号是否充分激发了该频段；
2. 在模型中增加相应的结构（如谐振模态）；
3. 预处理数据（如陷波滤波器去除已知频率干扰）；
4. 使用残差谱估计（Periodogram）来定位隐藏的周期性。

## 6. 自测习题

**习题 1**：AIC 和 BIC 都包含"拟合优度项"和"复杂度惩罚项"。为什么 BIC 对复杂度的惩罚比 AIC 更重？这会导致什么不同的选择倾向？

<details>
<summary>答案</summary>

BIC 的复杂度惩罚项为 $k \ln(N)$，而 AIC 为 $2k$。当 $N > 7$ 时，$\ln(N) > 2$，因此 BIC 的惩罚更重。

这导致：
- **BIC 倾向于选择更简单的模型**（低阶次）。在大样本下，BIC 是**一致估计量**——如果真实模型在候选集中，BIC 会渐近地选到正确阶次。
- **AIC 倾向于选择更复杂的模型**。AIC 不是一致的，但它的预测性能通常更好（最小化预测误差）。

实际建议：如果主要目的是预测，用 AIC；如果主要目的是理解系统结构，用 BIC。

</details>

**习题 2**：一个模型在训练集上的 Fit = 92%，在验证集上的 Fit = 55%。这说明了什么？应该采取什么措施？

<details>
<summary>答案</summary>

这说明模型**严重过拟合**。训练集和验证集之间 37% 的 Fit 差距远超可接受范围（通常应 < 10-15%）。

措施：
1. **降低模型阶次**：减少 $n_a, n_b$ 或状态空间维数。
2. **增加正则化**：在 LS 中加入岭回归惩罚 $\alpha \|\theta\|^2$。
3. **增加数据量**：更多的训练数据可以降低方差。
4. **简化模型结构**：从 ARMAX 降到 ARX，或从神经网络降到线性模型。
5. **检查数据质量**：验证集是否与训练集来自同一分布？如果工况不同，需要考虑域自适应方法。

</details>

**习题 3**：残差与输入的互相关函数 (CCF) 在滞后 0 处显著超出置信区间，但在其他滞后处都在带内。这说明什么？

<details>
<summary>答案</summary>

滞后 0 处 $R_{\varepsilon u}(0)$ 显著非零说明残差与**当前输入**相关。这通常意味着：

1. **模型延迟估计错误**：如果 $n_k$ 设置过大，模型没有利用 $u(t)$ 或 $u(t-1)$ 中的信息。
2. **存在直接馈通 (Direct Feedthrough)**：系统在输入到输出之间存在瞬时通路（$D \neq 0$），但模型假设了严格因果关系。
3. **输入测量中混入了输出噪声**：传感器串扰或共地噪声。

解决方案：检查延迟设置、考虑非严格适当模型、检查传感器接线。

</details>
