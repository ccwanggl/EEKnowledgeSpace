# 频域辨识

> **核心认知锚点**：频域辨识是"变换链"的**逆向切片**——不是从 $H(s)$ 计算 $H(j\omega)$，而是直接从输入输出数据估计 $G(j\omega)$ 或 $G(e^{j\Omega})$。它绕过了"先求时域模型再转换"的步骤，直接在频率轴上"扫描"系统的增益和相位。

## 1. 频域辨识的直觉

时域辨识回答的是："给定输入输出时间序列，系统的差分方程是什么？"频域辨识回答的是："系统对每个频率的正弦信号，放大多少倍、相位移动多少？"

**直觉**：如果你对着一个山谷喊话，山谷会改变你声音的回响特性——低频的声音传得更远，高频的声音被吸收得更快。频域辨识就是"用正弦波探针去扫描系统"，记录每个频率下的响应。

```
       正弦输入 u(t) = sin(ωt)              系统              输出 y(t)
           │                                    ┌───┐              │
           │───────────────────────────────────▶│ G │─────────────▶│
           │                                    └───┘              │
           │                                                        │
           │                    y(t) ≈ |G(jω)| * sin(ωt + ∠G(jω))   │
           │                                                        │
    ┌──────┴──────┐                                          ┌─────┴─────┐
    │  扫频信号源   │                                          │  幅值/相位  │
    │  ω: 0→∞     │                                          │  分析仪     │
    └─────────────┘                                          └───────────┘
```

频域辨识的核心优势：
- **物理直觉清晰**：Bode 图上的每个点都有明确的物理意义（增益和相位）。
- **抗噪声能力强**：可以在特定频率上集中能量，提高信噪比。
- **便于与经典控制设计衔接**：控制器设计（如超前-滞后校正）直接在频域进行。

## 2. 频率响应函数 (FRF) 的估计

### 2.1 理论背景

对于线性时不变 (LTI) 系统，频率响应函数定义为传递函数在 $s = j\omega$ 处的取值：

$$
G(j\omega) = \frac{Y(j\omega)}{U(j\omega)} = H(s)\big|_{s=j\omega}
$$

其中 $Y(j\omega)$ 和 $U(j\omega)$ 分别是输出和输入的傅里叶变换。

> **与变换链的关系**：这就是统一框架中最关键的映射 $s = j\omega$ 的工程应用。在连续系统中，$H(s)$ 是复域（s 平面）的完整描述；$G(j\omega)$ 是 $H(s)$ 在虚轴上的"切片"。频域辨识直接估计这个切片，无需先求出 $H(s)$ 的完整有理函数形式。对离散系统，对应的映射是 $z = e^{j\Omega}$，频域辨识估计的是 $H(z)$ 在单位圆上的切片 $H(e^{j\Omega})$。

### 2.2 经验传递函数估计 (ETFE)

在实际中，我们只有离散采样的时间序列数据。ETFE 直接用 DFT（离散傅里叶变换）估计 FRF：

$$
\hat{G}_N(e^{j\omega_k}) = \frac{Y_N(\omega_k)}{U_N(\omega_k)}
$$

其中 $\omega_k = \frac{2\pi k}{N}$，$U_N(\omega_k)$ 和 $Y_N(\omega_k)$ 分别是输入输出数据的 DFT：

$$
U_N(\omega_k) = \sum_{t=0}^{N-1} u(t) e^{-j\omega_k t}, \quad
Y_N(\omega_k) = \sum_{t=0}^{N-1} y(t) e^{-j\omega_k t}
$$

> **与变换链的关系**：ETFE 的计算核心 DFT/FFT 正是统一框架中"有限实现与局部分析"的典型工具。在理论层面，非周期离散序列的频谱是 DTFT $X(e^{j\Omega})$，它在单位圆上连续且以 $2\pi$ 为周期。DFT 则是对这个连续周期频谱的**等间隔采样**：$X[k] = X(e^{j\Omega})|_{\Omega=2\pi k/N}$。FFT 只是高效计算 DFT 的算法。因此，ETFE 本质上是在有限数据、有限算力条件下，对理论频率响应函数的数值近似。

### 2.3 ETFE 的问题：方差大

ETFE 是频率响应的"粗估计"，其方差约为：

$$
\text{Var}\left[ \hat{G}(e^{j\omega}) \right] \approx \frac{\Phi_v(\omega)}{\Phi_u(\omega)}
$$

其中 $\Phi_v(\omega)$ 是噪声功率谱密度，$\Phi_u(\omega)$ 是输入功率谱密度。

**直觉**：如果某个频率上输入能量很小（$\Phi_u$ 小），而噪声很大（$\Phi_v$ 大），则该频率处的 FRF 估计非常不可靠。

## 3. 改进的频域估计方法

### 3.1 周期图平均法 (Welch 方法)

将数据分成 $M$ 段，每段分别计算 ETFE，然后平均：

$$
\hat{G}(e^{j\omega}) = \frac{\frac{1}{M} \sum_{m=1}^{M} Y_N^{(m)}(\omega) \overline{U_N^{(m)}(\omega)}}{\frac{1}{M} \sum_{m=1}^{M} \left| U_N^{(m)}(\omega) \right|^2}
$$

这种方法称为**谱估计法**，可以显著降低估计方差（以频率分辨率为代价）。

### 3.2 频域最小二乘

假设我们有一组频域数据点 $\{(\omega_k, G_k)\}_{k=1}^{M}$，想要拟合一个有理传递函数：

$$
G(s, \theta) = \frac{b_0 + b_1 s + \cdots + b_m s^m}{1 + a_1 s + \cdots + a_n s^n}
$$

可以最小化复数误差：

$$
J(\theta) = \sum_{k=1}^{M} \left| G_k - G(j\omega_k, \theta) \right|^2 W_k
$$

其中 $W_k$ 是权重（通常取 $W_k = 1/\text{Var}(G_k)$，即方差大的点权重小）。

## 4. 正弦波扫频实验

### 4.1 实验设计

正弦波扫频是最经典的频域辨识方法：

1. 选择一组离散频率点 $\{\omega_1, \omega_2, \ldots, \omega_M\}$，通常在对数坐标上均匀分布（每十倍频程 5~20 个点）。
2. 对每个频率 $\omega_k$，施加输入 $u(t) = A \sin(\omega_k t)$，等待暂态衰减后记录稳态输出。
3. 测量输出的幅值比和相位差。

### 4.2 增益和相位的计算

对于输入 $u(t) = A \sin(\omega t)$，稳态输出为：

$$
y(t) = A \left| G(j\omega) \right| \sin\left( \omega t + \angle G(j\omega) \right) + v(t)
$$

其中 $v(t)$ 为测量噪声。

使用**相关分析法**提取幅值和相位：

$$
\begin{aligned}
R_{uy}^c(\omega) &= \frac{2}{NT} \int_0^{NT} y(t) \sin(\omega t) \, dt \approx A \left| G(j\omega) \right| \cos\phi \\
R_{uy}^s(\omega) &= \frac{2}{NT} \int_0^{NT} y(t) \cos(\omega t) \, dt \approx A \left| G(j\omega) \right| \sin\phi
\end{aligned}
$$

其中 $N$ 为整数周期数，$T = 2\pi/\omega$。然后：

$$
\left| G(j\omega) \right| = \frac{\sqrt{(R_{uy}^c)^2 + (R_{uy}^s)^2}}{A}, \quad
\phi = \arctan\frac{R_{uy}^s}{R_{uy}^c}
$$

## 5. 数值示例：二阶系统的频域辨识

### 5.1 系统定义

真实系统：

$$
G(s) = \frac{4}{s^2 + 1.2s + 4}
$$

这是一个阻尼比 $\zeta = 0.3$、自然频率 $\omega_n = 2$ rad/s 的二阶系统。

### 5.2 Python 实现：扫频 + ETFE

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

# True system
zeta = 0.3
wn = 2.0
num_true = [4.0]
den_true = [1.0, 2*zeta*wn, wn**2]
sys_true = signal.TransferFunction(num_true, den_true)

# Frequency grid (log-spaced)
omega = np.logspace(-1, 2, 200)   # 0.1 to 100 rad/s
w, H_true = signal.freqresp(sys_true, omega)

# --- Sine sweep experiment ---
Ts = 0.01                         # sampling time [s]
t_end = 50.0                      # total experiment time
t = np.arange(0, t_end, Ts)
N = len(t)

# Multi-sine input: sum of sines at selected frequencies
omega_test = np.logspace(-1, 1.5, 15)  # test frequencies
u = np.zeros_like(t)
for wk in omega_test:
    u += np.sin(wk * t + np.random.uniform(0, 2*np.pi))
u = u / np.max(np.abs(u))         # normalize amplitude

# Simulate with noise
np.random.seed(42)
_, y, _ = signal.lsim(sys_true, u, t)
y += 0.05 * np.random.randn(N)    # add measurement noise

# --- ETFE estimation ---
# Compute DFTs
U = np.fft.fft(u)
Y = np.fft.fft(y)
omega_fft = np.fft.fftfreq(N, Ts) * 2 * np.pi

# ETFE (only positive frequencies)
pos_idx = (omega_fft > 0) & (omega_fft < np.pi / Ts)
omega_etfe = omega_fft[pos_idx]
G_etfe = Y[pos_idx] / U[pos_idx]

# --- Welch-style smoothed estimate ---
# Use scipy's csd and welch
f, Puy = signal.csd(u, y, fs=1/Ts, nperseg=1024, window='hann')
f, Puu = signal.welch(u, fs=1/Ts, nperseg=1024, window='hann')
w_welch = 2 * np.pi * f[f > 0]
G_welch = Puy[f > 0] / Puu[f > 0]

# Plot
fig, axes = plt.subplots(2, 1, figsize=(10, 8))

# Magnitude
axes[0].semilogx(w, 20*np.log10(np.abs(H_true)), 'k-', lw=2, label='True')
axes[0].semilogx(omega_etfe, 20*np.log10(np.abs(G_etfe)), 'b.', alpha=0.3, label='ETFE')
axes[0].semilogx(w_welch, 20*np.log10(np.abs(G_welch)), 'r-', lw=1.5, label='Welch smoothed')
axes[0].set_ylabel('Magnitude [dB]')
axes[0].legend()
axes[0].grid(True, which='both', ls='--')
axes[0].set_ylim([-60, 20])

# Phase
axes[1].semilogx(w, np.unwrap(np.angle(H_true)) * 180/np.pi, 'k-', lw=2, label='True')
axes[1].semilogx(omega_etfe, np.unwrap(np.angle(G_etfe)) * 180/np.pi, 'b.', alpha=0.3)
axes[1].semilogx(w_welch, np.unwrap(np.angle(G_welch)) * 180/np.pi, 'r-', lw=1.5)
axes[1].set_ylabel('Phase [deg]')
axes[1].set_xlabel('Frequency [rad/s]')
axes[1].grid(True, which='both', ls='--')

plt.tight_layout()
plt.savefig('freq_id_bode.png', dpi=150)
plt.show()
```

### 5.3 结果解读

运行后会得到 Bode 图：
- **黑色实线**：真实系统的频率响应（已知，用于对比）。
- **蓝色散点**：ETFE 原始估计，在共振频率附近波动较大（因为噪声与系统增益同时放大）。
- **红色实线**：Welch 平滑后的估计，方差显著降低，与真实响应吻合良好。

注意在 $\omega_n = 2$ rad/s 附近，相位从 $0^\circ$ 快速下降到 $-180^\circ$，幅值出现峰值（由于 $\zeta = 0.3$ 阻尼较小）。

## 6. 从频域数据拟合传递函数

### 6.1 问题描述

假设我们已经通过实验获得了 $M$ 个频率点的响应数据 $\{ (\omega_k, \hat{G}_k) \}$。现在想要拟合一个有理传递函数模型：

$$
G(s, \theta) = \frac{B(s, \theta)}{A(s, \theta)} = \frac{b_0 + b_1 s + \cdots + b_m s^m}{1 + a_1 s + \cdots + a_n s^n}
$$

### 6.2  levy 方法（线性化最小二乘）

Levy 方法将非线性问题转化为线性问题。令误差：

$$
\varepsilon_k = A(j\omega_k, \theta) \hat{G}_k - B(j\omega_k, \theta)
$$

最小化 $\sum |\varepsilon_k|^2$ 是关于 $\{a_i, b_i\}$ 的线性最小二乘问题，可直接求解。

**缺点**：加权方式导致对高频数据拟合偏好（因为 $A(j\omega)$ 在高频时幅值大）。

### 6.3 迭代加权 Levy 方法 (Sanathanan-Koerner)

为修正偏差，使用迭代加权：

$$
J^{(i)}(\theta) = \sum_{k=1}^{M} \frac{1}{|A^{(i-1)}(j\omega_k)|^2} \left| A(j\omega_k, \theta) \hat{G}_k - B(j\omega_k, \theta) \right|^2
$$

每一步用上一迭代的 $A$ 做权重，迭代直至收敛。

## 7. 频域辨识 vs. 时域辨识

| 特性 | 频域辨识 | 时域辨识 | 与变换链的关系 |
|------|---------|---------|--------------|
| 物理直觉 | 强（Bode 图） | 弱（差分方程系数） | 频域辨识直接估计 $H(j\omega)$ 或 $H(e^{j\Omega})$，是"全局频率表示"的逆向应用 |
| 抗噪声 | 强（可聚焦能量到特定频段） | 中等（依赖整体信噪比） | 频域辨识可在特定频率上"局部化"信噪比，对应 STFT 的局部化思想 |
| 实验设计 | 需要专门设计（正弦/扫频） | 可用任意输入（如 PRBS） | 扫频实验相当于在 $j\omega$ 轴上逐点采样 |
| 非线性处理 | 困难（依赖叠加原理） | 相对灵活（可用 NARX 等） | 频域方法严格依赖 LTI 假设，时域方法更通用 |
| 与控制器设计衔接 | 直接（Bode 图直接用于超前-滞后设计） | 需先令 $z=e^{j\Omega}$ 转换到频域 | 频域辨识与经典控制设计无缝衔接 |
| MIMO 系统 | 复杂（需逐元素或 SVD） | 自然（状态空间模型） | 时域状态空间方法天然适合 MIMO |
| 有限实现 | 使用 DFT/FFT，$O(N\log N)$ | 最小二乘，$O(Nn^2)$ | 两者都是"有限数据、有限算力"条件下的近似 |

> **选择建议**：如果你的最终目标是做经典频域控制器设计（如超前-滞后校正、PID 频域整定），或系统具有强共振特性需要在特定频段精确建模，优先选择频域辨识。如果你需要在线嵌入式实现、或最终目标是 MPC/状态反馈，时域辨识（最小二乘、子空间方法）通常更合适。

## 8. 常见错误与纠正

### 错误 1：FFT 泄漏 (Spectral Leakage)

**场景**：对一段非周期截断的正弦信号做 DFT，发现频谱在真实频率周围"散开"。

**问题**：DFT 假设信号是周期延拓的。如果截断长度不是信号周期的整数倍，会在边界处引入不连续，导致能量泄漏到相邻频率。

**纠正**：
1. 使用窗函数（如 Hanning、Hamming 窗）平滑截断边界；
2. 保证每个频率点的采集时长是周期的整数倍；
3. 增加数据长度，提高频率分辨率 $\Delta f = 1/T$。

```python
# Apply Hanning window before FFT
window = np.hanning(N)
U_windowed = np.fft.fft(u * window)
Y_windowed = np.fft.fft(y * window)
# Note: windowing reduces amplitude; may need amplitude correction
```

### 错误 2：混叠 (Aliasing)

**场景**：采样率为 100 Hz，但系统响应中含有 80 Hz 的频率成分。

**问题**：根据奈奎斯特采样定理，可恢复的最高频率为 $f_s/2 = 50$ Hz。80 Hz 的成分会被"折叠"到 $100 - 80 = 20$ Hz，造成虚假的频率响应。

**纠正**：
1. 在采样前使用抗混叠模拟低通滤波器，截止频率设为 $f_s/2$；
2. 提高采样率，确保 $f_s > 2 f_{\max}$，其中 $f_{\max}$ 是系统最高有效频率。

## 9. 自测习题

**习题 1**：对一个一阶系统 $G(s) = \frac{K}{\tau s + 1}$ 做正弦波扫频实验。在频率 $\omega = 1/\tau$ 处，幅值比 $|G(j\omega)|$ 和相位 $\angle G(j\omega)$ 分别是多少？

<details>
<summary>答案</summary>

$$
G(j\omega) = \frac{K}{j\omega\tau + 1}
$$

当 $\omega = 1/\tau$ 时：

$$
G(j/\tau) = \frac{K}{j + 1} = \frac{K(1 - j)}{2}
$$

幅值：

$$
|G(j/\tau)| = \frac{K}{\sqrt{1^2 + 1^2}} = \frac{K}{\sqrt{2}} \approx 0.707 K
$$

即 **-3 dB 点**。

相位：

$$
\angle G(j/\tau) = \arctan\left(\frac{-1}{1}\right) = -45^\circ
$$

</details>

**习题 2**：ETFE 的方差与输入信号功率谱密度 $\Phi_u(\omega)$ 成反比。这意味着什么实际含义？

<details>
<summary>答案</summary>

这意味着：
1. 在某个频率上如果输入能量很小（$\Phi_u$ 小），则该频率处的 FRF 估计将非常不精确、方差很大。
2. 为了提高某个频段的辨识精度，应该在该频段增加输入能量——例如使用多正弦信号或在扫频时降低扫频速率。
3. 输入设计是频域辨识的关键：需要保证在所有关心的频率上，$\Phi_u(\omega)$ 都足够大。

</details>

**习题 3**：为什么频域方法对 MIMO 系统的处理比时域方法更困难？

<details>
<summary>答案</summary>

对于 MIMO 系统，频率响应是一个矩阵 $G(j\omega) \in \mathbb{C}^{p \times m}$。频域辨识面临以下困难：

1. **激励分配**：需要同时激励多个输入通道，且各通道之间应互不相关，否则无法分离各传递函数元素的影响。
2. **矩阵分解**：测得的频率响应矩阵可能不对应于任何有限维状态空间模型（秩问题）。
3. **数值稳定性**：对矩阵进行有理拟合比标量传递函数复杂得多。

时域的状态空间方法自然地处理 MIMO 系统，通过子空间辨识等方法可以直接估计 $(A, B, C, D)$ 矩阵，而不需要逐元素处理传递函数。

</details>
