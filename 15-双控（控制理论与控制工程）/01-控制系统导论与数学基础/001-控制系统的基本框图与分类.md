# 控制系统的基本框图与分类

> 掌握框图的语言、信号流图的化简方法，以及控制系统的分类体系。这是从"直觉理解"过渡到"工程分析"的关键一步。
> 
> **核心定位**：框图是**连接时域物理直觉与复频域数学工具的可视化桥梁**。每一个方框 $G(s)$ 背后都是拉普拉斯变换的结果；每一次框图化简都是在代数层面处理微分方程。框图语言让你能"一眼看出"系统的结构，而传递函数让你能"一笔算出"系统的行为。这是进入 [[15-双控（控制理论与控制工程）/02-经典控制理论/000-图解入门：从根轨迹到Bode图|02-经典控制理论]] 之前必须掌握的共同语言。

## 为什么需要框图

在分析复杂控制系统时，我们需要一种直观的方式来表示信号之间的关系。框图（Block Diagram）和信号流图（Signal Flow Graph）就是这样的可视化工具。它们把微分方程或传递函数描述的系统，转化成一张"图"，让你一眼看出信号从哪来、到哪去、经过了哪些变换。

## 框图的基本元件

一个框图由三种基本元件组成：

| 元件 | 符号 | 功能 | 数学描述 |
|------|------|------|----------|
| 方框 | `[G(s)]` | 表示一个动态环节或传递函数 | $Y(s) = G(s) U(s)$ |
| 求和点 | `(Σ)` 或 `(⊕)` | 对多个信号进行加减运算 | $E(s) = R(s) \pm B(s)$ |
| 分支点 | `●` | 把一个信号分成多路输出 | $Y_1 = Y_2 = X$ |

```
     U(s)    +--------+    Y(s)
    ------->|  G(s)  |------->
            +--------+

     R(s) ----.
              \
               v
              (Σ) ---> E(s) = R(s) - B(s)
               ^
              /
     B(s) ----'

     X(s) ----+----> Y1(s) = X(s)
              |
              +----> Y2(s) = X(s)
```

注意：在框图中，**箭头表示信号的单向流动**， implicitly 假设了因果关系。

## 框图化简的基本规则

复杂框图可以通过以下规则逐步化简为单个等效传递函数：

### 规则 1：串联（Series / Cascade）

```
    U --->[G1]--->[G2]---> Y        ≡        U --->[G1·G2]---> Y
```

等效传递函数：

$$
G_{eq}(s) = G_1(s) \cdot G_2(s)
$$

### 规则 2：并联（Parallel）

```
         .--->[G1]--.
    U ---|           |---> Y      ≡      U --->[G1 + G2]---> Y
         '--->[G2]--'
```

等效传递函数：

$$
G_{eq}(s) = G_1(s) + G_2(s)
$$

### 规则 3：反馈回路（Feedback Loop）

```
              +----> Y
              |
    U --->(Σ)--->[G]----->
         -^               |
          |              [H]
          +---------------+
```

等效传递函数（**最重要**，务必记住）：

$$
\frac{Y(s)}{U(s)} = \frac{G(s)}{1 + G(s) H(s)}
$$

> **与变换链的关系**：这个公式不是在时域推导的，而是在 **$s$ 域**（拉普拉斯域）推导的。在时域中，$y(t) = g(t) * e(t)$（卷积），反馈回路会变成一个复杂的卷积方程；但在 $s$ 域中，卷积变成乘法，整个回路变成简单的代数方程。这就是为什么拉普拉斯变换是控制理论的语言基础——它把微分方程和卷积方程变成了代数方程。
> 
> **与 FOC 的关联**：在 [[14-FOC-电机控制/00-README|14-FOC-电机控制]] 中，电流环的闭环传递函数 $\frac{I_d}{I_d^*}$ 正是这个结构。电流控制器 $G_c(s)$ 是前向通路，电机阻抗 $G(s)$ 是对象，电流传感器增益 $H(s)$ 是反馈。理解这个公式，就能理解为什么电流环带宽取决于控制器增益和电机参数。

如果是正反馈（求和点改为 $+$）：

$$
\frac{Y(s)}{U(s)} = \frac{G(s)}{1 - G(s) H(s)}
$$

> 记忆口诀：前向通路 / (1 ± 回路乘积)。负反馈取 $+$，正反馈取 $-$。

### 规则 4：求和点与分支点的移动

当框图不能直接应用前三条规则时，需要**移动求和点或分支点**来重新排列结构。核心原则是：**移动后不能改变任何信号的值**。

| 移动操作 | 原始结构 | 等效结构 | 补偿方法 |
|----------|----------|----------|----------|
| 求和点移过方框 $G$ | 求和点在 $G$ 前 | 求和点在 $G$ 后 | 另一支路乘以 $1/G$ |
| 分支点移过方框 $G$ | 分支点在 $G$ 后 | 分支点在 $G$ 前 | 另一支路乘以 $G$ |

## 数值示例：化简一个多回路框图

考虑如下框图：

```
         +----[G2]----.
         |            |
    U --->(Σ1)--->[G1]--->(Σ2)--->[G3]---> Y
             ^ -        ^ -               |
             |          |                 |
             |          +----[G4]----------+
             |                             |
             +----[H]----------------------+
```

已知：
- $G_1 = \frac{1}{s+1}$
- $G_2 = 2$
- $G_3 = \frac{1}{s}$
- $G_4 = 1$
- $H = 0.5$

**步骤 1**：识别内回路。观察 $(Σ2)$ 和 $G_3, G_4$ 构成一个反馈回路。

内回路的前向通路：$G_3$，反馈通路：$G_4$。

内回路等效：

$$
G_{inner} = \frac{G_3}{1 + G_3 G_4} = \frac{1/s}{1 + 1/s} = \frac{1}{s+1}
$$

**步骤 2**：化简后的框图变为：

```
         +----[G2]----.
         |            |
    U --->(Σ1)--->[G1]--->[G_inner]---> Y
             ^ -                         |
             |                           |
             +----[H]--------------------+
```

前向通路有并联：$G_1 G_{inner}$ 和 $G_2$ 并联？不，仔细看，$G_2$ 是前馈通路，从 $U$ 直接到 $G_{inner}$ 的输出端。

实际上，把 $(Σ1)$ 后的信号记为 $X$：

$$X = G_1 (U - H Y)$$

$$Y = G_{inner} X + G_2 X = (G_{inner} + G_2) X$$

代入：

$$Y = (G_{inner} + G_2) G_1 (U - H Y)$$

$$Y = G_1 (G_{inner} + G_2) U - G_1 (G_{inner} + G_2) H Y$$

$$Y [1 + G_1 (G_{inner} + G_2) H] = G_1 (G_{inner} + G_2) U$$

$$
\frac{Y}{U} = \frac{G_1 (G_{inner} + G_2)}{1 + G_1 (G_{inner} + G_2) H}
$$

**步骤 3**：代入数值。

$G_1 = G_{inner} = \frac{1}{s+1}$，$G_2 = 2$，$H = 0.5$：

$$
G_{inner} + G_2 = \frac{1}{s+1} + 2 = \frac{1 + 2(s+1)}{s+1} = \frac{2s+3}{s+1}
$$

$$
G_1 (G_{inner} + G_2) = \frac{1}{s+1} \cdot \frac{2s+3}{s+1} = \frac{2s+3}{(s+1)^2}
$$

$$
\frac{Y}{U} = \frac{\frac{2s+3}{(s+1)^2}}{1 + 0.5 \cdot \frac{2s+3}{(s+1)^2}} = \frac{2s+3}{(s+1)^2 + 0.5(2s+3)}
$$

展开分母：

$$(s+1)^2 + s + 1.5 = s^2 + 2s + 1 + s + 1.5 = s^2 + 3s + 2.5$$

最终：

$$
\frac{Y(s)}{U(s)} = \frac{2s + 3}{s^2 + 3s + 2.5}
$$

**验证**：代入 $s = 0$（直流增益）：

$$G(0) = \frac{3}{2.5} = 1.2$$

从物理直觉上看：直流时 $G_1(0) = G_{inner}(0) = 1$，$G_2 = 2$，前向通路总增益 $1 \times (1+2) = 3$，反馈回路增益 $3 \times 0.5 = 1.5$，闭环增益 $3 / (1+1.5) = 1.2$，吻合。

## 信号流图与梅森公式

对于更复杂的系统，框图化简可能很繁琐。信号流图（Signal Flow Graph）提供了一种更系统化的方法，配合**梅森增益公式**（Mason's Gain Formula）可以直接写出传递函数。

### 梅森公式

$$
T = \frac{\sum_{k} P_k \Delta_k}{\Delta}
$$

其中：
- $T$：从输入到输出的总增益（传递函数）
- $P_k$：第 $k$ 条前向通路的增益
- $\Delta$：图的特征式（Characteristic Determinant）

$$
\Delta = 1 - \sum L_i + \sum L_i L_j - \sum L_i L_j L_k + \dots
$$

- $L_i$：第 $i$ 个回路的增益
- $\sum L_i L_j$：所有两两不接触回路增益的乘积之和
- $\Delta_k$：去掉与第 $k$ 条前向通路接触的所有回路后，剩余子图的 $\Delta$

### 数值示例：用梅森公式验证

以上面的框图为例：

- 前向通路 1：$U \to Σ1 \to G1 \to G_{inner} \to Y$，增益 $P_1 = G_1 G_{inner}$
- 前向通路 2：$U \to G2 \to Y$？不，$G_2$ 从 $U$ 到 $Σ2$ 的输入端。实际上 $G_2$ 的前向通路是 $U \to G_2 \to Σ2$，但 $Σ2$ 在 $G_3$ 之后。从流图角度看，需要重新梳理。

为了避免混淆，考虑一个更清晰的例子：

```
    U ------->(Σ)------>[G1]------>[G2]------> Y
              ^ -                           |
              |                             v
              +-----------[H]<---------------+
```

- $P_1 = G_1 G_2$
- $L_1 = -G_1 G_2 H$（注意负号来自求和点的负输入）
- $\Delta = 1 - L_1 = 1 + G_1 G_2 H$
- 前向通路接触所有回路，$\Delta_1 = 1$

$$
T = \frac{G_1 G_2}{1 + G_1 G_2 H}
$$

与框图化简结果一致。

## 控制系统的分类

从不同维度，控制系统有多种分类方式：

### 按信号类型

| 类型 | 描述 | 典型应用 |
|------|------|----------|
| **连续系统** | 所有信号都是时间连续函数 | 模拟电路控制、机械调速 |
| **离散系统** | 至少一个信号是时间离散的（序列） | 数字控制器、计算机控制 |
| **混合系统** | 连续被控对象 + 离散控制器 | 绝大多数现代工业控制系统 |

### 按系统结构

| 类型 | 结构特征 | 优缺点 |
|------|----------|--------|
| **开环** | 无反馈通路 | 简单、无稳定问题、对扰动无抵抗 |
| **闭环** | 有反馈通路 | 抗干扰、精度高、可能不稳定 |
| **复合控制** | 开环 + 闭环 | 前馈消除可测扰动，反馈消除剩余误差 |
| **串级控制** | 两个嵌套闭环 | 内环快速抑制内扰，外环保证精度 |

### 按时间域特性

| 类型 | 描述 | 分析方法 |
|------|------|----------|
| **定常系统**（LTI） | 参数不随时间变化 | 传递函数、频域分析 |
| **时变系统** | 参数随时间变化 | 状态空间、Lyapunov 方法 |
| **非线性系统** | 包含非线性元件 | 描述函数、相平面、Lyapunov |

### 按输入输出数量

| 类型 | 描述 | 缩写 |
|------|------|------|
| **单输入单输出** | 一个控制量，一个被控量 | SISO |
| **多输入多输出** | 多个控制量，多个被控量 | MIMO |

现代控制理论的核心优势之一就是能系统处理 MIMO 系统，而经典控制理论主要针对 SISO。

> **与后续模块的关联**：本模块的框图化简是 [[15-双控（控制理论与控制工程）/02-经典控制理论/000-图解入门：从根轨迹到Bode图|02-经典控制理论]] 的必备工具（根轨迹、Bode 图都是基于框图的传递函数）。当你进入 [[15-双控（控制理论与控制工程）/03-现代控制理论/000-图解入门：状态空间为什么更强大|03-现代控制理论]] 时，框图会被"状态空间图"替代——但信号流的概念和梅森公式仍然适用。在 [[14-FOC-电机控制/00-README|14-FOC-电机控制]] 中，dq 轴电流控制就是典型的 MIMO 问题：$d$ 轴和 $q$ 轴的电压指令同时影响两个电流，需要耦合补偿。现代控制理论中的状态空间方法正是处理这种耦合系统的利器。

## 常见错误与纠正

### 错误 1：使用框图化简时遗漏反馈符号

**错误**：在化简反馈回路时，忘记求和点的负号。

**纠正**：负反馈的标准写法是：

```
    U --->(Σ-)--->[G]---> Y
          ^              |
          |_____[H]______|
```

这里的 $(Σ-)$ 表示 $E = U - HY$。如果误写成 $E = U + HY$，则等效传递函数变成 $G/(1-GH)$，在系统实际上是稳定负反馈的情况下，你可能得出不稳定的结论。

**检查方法**：用直流增益（$s=0$）快速验证。如果 $G(0)>0, H(0)>0$，负反馈的闭环直流增益应该小于开环增益，而不是大于。

### 错误 2：梅森公式中遗漏不接触回路

**错误**：在复杂流图中，只计算了单个回路，没计算两个互不接触回路的乘积项。

**纠正**：使用梅森公式时，必须严格检查每一对回路是否有公共节点。例如：

```
    U --->[G1]--->[G2]---> Y
         |              |
         v              v
        [H1]<---[H2]--+
```

如果存在两个独立回路：$L_1 = -G_1 H_1$（局部回路），$L_2 = -G_2 H_2$（主回路），只有当它们共享节点时，$L_1 L_2$ 项才不出现。如果不共享，$\Delta$ 中必须包含 $+ L_1 L_2$ 项。

**建议**：对于复杂框图，先画出完整的信号流图（标注所有节点和支路），再系统性地列出所有前向通路和回路。

## 自测习题

**Q1**. 给定 $G_1 = \frac{1}{s+2}$，$G_2 = \frac{s}{s+1}$，$H = 3$，求下图的闭环传递函数：

```
    U --->(Σ-)--->[G1]--->[G2]---> Y
          ^                   |
          |_______[H]__________|
```

> **答案**：
> $$
> T(s) = \frac{G_1 G_2}{1 + G_1 G_2 H} = \frac{\frac{s}{(s+2)(s+1)}}{1 + \frac{3s}{(s+2)(s+1)}} = \frac{s}{(s+2)(s+1) + 3s} = \frac{s}{s^2 + 6s + 2}
> $$

**Q2**. 解释为什么串联系统的总传递函数是各传递函数的乘积，而不是和。

> **答案**：串联时，第一个系统的输出等于第二个系统的输入：$X = G_1 U$，$Y = G_2 X = G_2 G_1 U$。所以 $Y/U = G_1 G_2$。乘积关系来源于信号的级联传递，不是物理上的叠加。

**Q3**. 某系统有两个前向通路 $P_1 = 5, P_2 = 3$ 和三个回路 $L_1 = -2, L_2 = -1, L_3 = -0.5$。其中 $L_1$ 和 $L_3$ 不接触，其他回路都互相接触。前向通路 $P_1$ 接触所有回路，$P_2$ 只接触 $L_1$ 和 $L_2$。用梅森公式求总增益。

> **答案**：
> $$
> \Delta = 1 - (-2 - 1 - 0.5) + ((-2)(-0.5)) = 1 + 3.5 + 1 = 5.5
> $$
> $$
> \Delta_1 = 1 \quad (P_1 \text{ 接触所有回路})
> $$
> $$
> \Delta_2 = 1 - (-0.5) = 1.5 \quad (P_2 \text{ 不接触 } L_3)
> $$
> $$
> T = \frac{5 \times 1 + 3 \times 1.5}{5.5} = \frac{5 + 4.5}{5.5} = \frac{9.5}{5.5} = \frac{19}{11} \approx 1.727
> $$

**Q4**. 比较开环、闭环、复合控制（前馈+反馈）三种结构在应对可测量外部扰动时的能力差异，并画出复合控制的框图。

> **答案**：
> - 开环：对扰动完全无抵抗能力，扰动直接传递到输出。
> - 闭环：通过反馈检测输出变化并修正，但扰动必须先引起输出变化才能被检测到，存在滞后。
> - 复合控制：前馈通路直接测量扰动并提前补偿，反馈通路消除剩余误差。对可测扰动响应最快。
>
> ```
>         D (扰动)
>           |
>           v
>      +--[Gd]--->(Σ2)--->[G]---> Y
>      |         ^              |
>      |         |              |
>      |    U --->(Σ1)--->[Gc]--+         |
>      |         ^ -                     |
>      |         |                      |
>      |    +----[H]---------------------+
>      |    |
>      +----[Gff] (前馈补偿)
> ```
> 前馈补偿器 $G_{ff}$ 的设计目标是使 $G_d + G_{ff} G = 0$（对扰动完全抑制）。
