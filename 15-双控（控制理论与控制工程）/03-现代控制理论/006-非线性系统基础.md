# 非线性系统基础

## 为什么需要研究非线性

到目前为止，我们讨论的都是线性系统。但真实世界中的控制系统绝大多数是**非线性**的：

- 电机的转矩-电流关系在饱和区非线性
- 机器人关节存在库仑摩擦和粘性摩擦
- 飞行器的空气动力系数随攻角剧烈变化
- 电力电子开关电路本质上是分段线性的

线性控制理论提供了强大的分析工具，但工程师必须知道：
1. 何时线性近似足够好？
2. 何时必须考虑非线性？
3. 如何在非线性框架下分析和设计？

## 非线性系统的描述

### 状态空间形式

一般非线性系统：

$$\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}, \mathbf{u})$$

$$\mathbf{y} = \mathbf{h}(\mathbf{x}, \mathbf{u})$$

其中 $\mathbf{f}$ 和 $\mathbf{h}$ 是非线性向量函数。与线性系统不同，非线性系统：
- 不满足叠加原理
- 可能有多 equilibrium 点
- 响应可能依赖于初始条件的幅值
- 可能出现极限环、混沌等复杂行为

## 平衡点与线性化

### 平衡点的定义

平衡点 $(\mathbf{x}_e, \mathbf{u}_e)$ 满足：

$$\mathbf{f}(\mathbf{x}_e, \mathbf{u}_e) = \mathbf{0}$$

在平衡点，如果没有扰动，系统将永远停留在该状态。

### 线性化：Jacobian 方法

在平衡点附近进行泰勒展开，保留一阶项：

$$\mathbf{f}(\mathbf{x}_e + \delta\mathbf{x}, \mathbf{u}_e + \delta\mathbf{u}) \approx \mathbf{f}(\mathbf{x}_e, \mathbf{u}_e) + \left.\frac{\partial \mathbf{f}}{\partial \mathbf{x}}\right|_e \delta\mathbf{x} + \left.\frac{\partial \mathbf{f}}{\partial \mathbf{u}}\right|_e \delta\mathbf{u}$$

定义偏差状态 $\delta\mathbf{x} = \mathbf{x} - \mathbf{x}_e$，得到线性化系统：

$$\delta\dot{\mathbf{x}} = \mathbf{A}\delta\mathbf{x} + \mathbf{B}\delta\mathbf{u}$$

其中：

$$\mathbf{A} = \left.\frac{\partial \mathbf{f}}{\partial \mathbf{x}}\right|_{(\mathbf{x}_e, \mathbf{u}_e)}, \quad \mathbf{B} = \left.\frac{\partial \mathbf{f}}{\partial \mathbf{u}}\right|_{(\mathbf{x}_e, \mathbf{u}_e)}$$

### 数值示例：倒立摆线性化

非线性倒立摆方程（考虑小车位置 $x$ 和摆角 $\theta$）：

$$(M+m)\ddot{x} + ml\ddot{\theta}\cos\theta - ml\dot{\theta}^2\sin\theta = u$$

$$l\ddot{\theta} + \ddot{x}\cos\theta - g\sin\theta = 0$$

平衡点：$\theta_e = 0, \dot{\theta}_e = 0, \dot{x}_e = 0$（竖直向上）。

Jacobian 计算（在 $\theta = 0$ 附近，$\cos\theta \approx 1, \sin\theta \approx \theta, \dot{\theta}^2 \approx 0$）：

$$\mathbf{A} = \begin{bmatrix}
0 & 1 & 0 & 0 \\
\frac{(M+m)g}{Ml} & 0 & 0 & 0 \\
0 & 0 & 0 & 1 \\
-\frac{mg}{M} & 0 & 0 & 0
\end{bmatrix}$$

取 $M = 1$ kg, $m = 0.1$ kg, $l = 0.5$ m, $g = 9.8$ m/s²：

$$\mathbf{A} \approx \begin{bmatrix} 0 & 1 & 0 & 0 \\ 21.6 & 0 & 0 & 0 \\ 0 & 0 & 0 & 1 \\ -0.98 & 0 & 0 & 0 \end{bmatrix}$$

这就是前面 LQR 章节中使用的线性化模型。

## Lyapunov 稳定性理论

### 自治系统的稳定性

考虑 $\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x})$，$\mathbf{f}(\mathbf{0}) = \mathbf{0}$。

**Lyapunov 稳定性**：对于任意 $\epsilon > 0$，存在 $\delta > 0$，使得 $\|\mathbf{x}(0)\| < \delta$ 蕴含 $\|\mathbf{x}(t)\| < \epsilon$ 对所有 $t \geq 0$ 成立。

**渐近稳定性**：Lyapunov 稳定且 $\|\mathbf{x}(t)\| \to 0$ 当 $t \to \infty$。

### Lyapunov 直接法

如果能找到一个标量函数 $V(\mathbf{x})$ 满足：

1. $V(\mathbf{0}) = 0$
2. $V(\mathbf{x}) > 0$ 对 $\mathbf{x} \neq \mathbf{0}$（正定）
3. $\dot{V}(\mathbf{x}) = \frac{\partial V}{\partial \mathbf{x}}\mathbf{f}(\mathbf{x}) \leq 0$（负半定）

则原点是稳定的。如果 $\dot{V} < 0$（负定），则原点是渐近稳定的。

### 物理直觉

$V(\mathbf{x})$ 可以被想象为系统的"能量"。如果能量沿轨迹不增，系统就不会"发散"。如果能量严格递减，系统必然收敛到能量最小点（原点）。

### 数值示例

考虑系统：

$$\dot{x}_1 = x_2$$
$$\dot{x}_2 = -x_1 - x_2^3$$

选取候选 Lyapunov 函数 $V = \frac{1}{2}(x_1^2 + x_2^2)$：

$$\dot{V} = x_1\dot{x}_1 + x_2\dot{x}_2 = x_1x_2 + x_2(-x_1 - x_2^3) = -x_2^4 \leq 0$$

$\dot{V}$ 负半定（在 $x_2 = 0$ 时为零）。应用 LaSalle 不变集原理：$\dot{V} = 0$ 的集合为 $x_2 = 0$，在此集合上 $\dot{x}_2 = -x_1$，要保持在集合上必须有 $x_1 = 0$。因此最大不变集是原点，系统全局渐近稳定。

## 相平面分析

### 二维系统的图形化方法

对于二阶自治系统 $\dot{x}_1 = f_1(x_1, x_2)$, $\dot{x}_2 = f_2(x_1, x_2)$，相平面是分析行为的有力工具。

在相平面上，每个点 $(x_1, x_2)$ 处的向量场由 $(f_1, f_2)$ 给出，轨迹就是向量场的积分曲线。

### 线性系统的相图分类

根据特征值位置，二阶线性系统的相图分为：

| 特征值类型 | 相图名称 | 稳定性 |
|-----------|---------|--------|
| 两个负实数 | 稳定结点 | 渐近稳定 |
| 两个正实数 | 不稳定结点 | 不稳定 |
| 一正一负 | 鞍点 | 不稳定 |
| 负实部复数 | 稳定焦点 | 渐近稳定 |
| 正实部复数 | 不稳定焦点 | 不稳定 |
| 纯虚数 | 中心 | Lyapunov 稳定但非渐近稳定 |

### Van der Pol 振荡器

经典的非线性系统：

$$\dot{x}_1 = x_2$$
$$\dot{x}_2 = -x_1 + \mu(1 - x_1^2)x_2$$

当 $\mu > 0$ 时，系统存在一个**稳定的极限环**——无论初值如何，轨迹最终都收敛到一个闭合轨道。

```text
    相平面示意 (Van der Pol, μ = 1)
    
         x2
          |
    +-----●-----+   <-- 极限环
    |     |     |
    |  ←  |  →  |
    |     |     |
----+-----+-----+---- x1
    |     |     |
    |  →  |  ←  |
    |     |     |
    +-----●-----+
```

极限环是非线性系统特有的现象，线性系统不可能出现（线性系统的轨迹要么收敛到原点，要么发散到无穷，要么是椭圆）。

## 反馈线性化

### 核心思想

对于某些非线性系统，可以通过坐标变换和反馈，将其转化为线性系统。

### 输入-状态线性化

考虑单输入系统：

$$\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}) + \mathbf{g}(\mathbf{x})u$$

如果能找到输出函数 $y = h(\mathbf{x})$，使得其相对阶（relative degree）等于系统阶数 $n$，则可以通过反馈：

$$u = \frac{v - L_f^n h(\mathbf{x})}{L_g L_f^{n-1} h(\mathbf{x})}$$

将系统转化为链式积分器：

$$y^{(n)} = v$$

然后对 $v$ 设计线性控制器。

### 数值示例

考虑系统：

$$\dot{x}_1 = x_2$$
$$\dot{x}_2 = -x_1^3 + u$$

选择 $y = x_1$，则 $\ddot{y} = \dot{x}_2 = -x_1^3 + u$。令 $u = x_1^3 + v$，得到 $\ddot{y} = v$，即双积分器。

对 $v$ 设计 PD 控制器：$v = -k_p y - k_d \dot{y}$，闭环系统：$\ddot{y} + k_d \dot{y} + k_p y = 0$。

## 常见错误与纠正

### 错误1：线性化范围判断失误

**错误做法**：对倒立摆在 $\theta = 0$ 处线性化后，直接应用于 $\theta = 60°$ 的大角度摆动控制。

**问题**：线性化只在平衡点附近有效。$\sin(60°) = 0.866 \neq 60° \times \pi/180 = 1.047$，误差约 17%。大角度下线性模型的极点位置和实际系统完全不同，基于线性模型设计的控制器可能失效甚至失稳。

**纠正**：
1. 明确线性化的有效范围：通常 $|\theta| < 15°$~$30°$
2. 对大范围运动，使用多个线性化模型（增益调度）
3. 或使用非线性控制方法（反馈线性化、滑模控制等）

### 错误2：将线性稳定性结论推广到非线性系统

**错误说法**："线性化后的系统矩阵特征值全为负，所以原非线性系统全局渐近稳定。"

**问题**：线性化只能给出**局部**结论。Lyapunov 第一方法（间接法）说的是：如果线性化矩阵的特征值实部全为负，则非线性系统的平衡点是**局部**渐近稳定的。它不给出吸引域的大小，也不处理中心或不稳定情况。

**纠正**：
1. 线性化分析后，使用 Lyapunov 直接法估计吸引域
2. 对关键系统，进行数值仿真覆盖所有可能的初值和操作条件
3. 注意：如果线性化有纯虚特征值，线性化方法无法下结论，必须回到 Lyapunov 直接法

## 自测习题

**习题1**：求系统 $\dot{x}_1 = x_2$, $\dot{x}_2 = -\sin x_1 - 0.5x_2$ 的所有平衡点，并判断其在原点的稳定性。

**答案**：平衡点满足 $x_2 = 0$ 且 $\sin x_1 = 0$，即 $x_1 = k\pi, x_2 = 0$（$k \in \mathbb{Z}$）。

在原点 $(0, 0)$ 处线性化：

$$\mathbf{A} = \begin{bmatrix} 0 & 1 \\ -\cos(0) & -0.5 \end{bmatrix} = \begin{bmatrix} 0 & 1 \\ -1 & -0.5 \end{bmatrix}$$

特征值：$\lambda^2 + 0.5\lambda + 1 = 0 \Rightarrow \lambda = -0.25 \pm 0.968j$。实部为负，局部渐近稳定。

用 Lyapunov 直接法：取 $V = \frac{1}{2}x_2^2 + (1 - \cos x_1)$（物理能量），$\dot{V} = x_2\dot{x}_2 + \sin x_1 \dot{x}_1 = x_2(-\sin x_1 - 0.5x_2) + \sin x_1 \cdot x_2 = -0.5x_2^2 \leq 0$。由 LaSalle 原理，系统渐近稳定。

**习题2**：某非线性系统的线性化矩阵在某平衡点有特征值 $\lambda_1 = -1, \lambda_2 = 0.5$。能得出什么结论？

**答案**：线性化有一个正实部特征值，根据 Lyapunov 第一方法的逆否命题，非线性系统的该平衡点**不稳定**。这是少数能从线性化得到全局结论的情况之一——不稳定性可以通过线性化证明，但稳定性只能得到局部结论。

**习题3**：解释为什么线性时不变系统不可能有极限环。

**答案**：线性系统满足叠加原理和缩放不变性。如果存在周期解 $\mathbf{x}(t)$，则 $2\mathbf{x}(t)$ 也是解，且振幅加倍。但极限环要求存在一个孤立的闭合轨道，附近轨迹要么收敛到它、要么发散离开它——这与线性系统的缩放不变性矛盾。线性系统的周期解只可能形成连续族（如中心点的椭圆族），不可能孤立存在。
