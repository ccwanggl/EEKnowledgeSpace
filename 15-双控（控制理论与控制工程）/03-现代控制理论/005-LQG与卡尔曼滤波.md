# LQG与卡尔曼滤波

## 问题的完整图景

到目前为至，我们讨论了两个独立的问题：

1. **LQR**：假设状态完全已知，设计最优状态反馈控制
2. **Luenberger 观测器**：假设控制已知，设计状态估计器

但真实世界中，**两个假设都不成立**：
- 状态有**过程噪声**（模型不准、外部扰动）
- 测量有**传感器噪声**

LQG（Linear Quadratic Gaussian）控制将这两个问题优雅地结合起来：用**卡尔曼滤波器**替代 Luenberger 观测器，在噪声环境中实现最优状态估计，再用估计值做 LQR 反馈。

## 随机系统的描述

### 带噪声的状态空间模型

$$\dot{\mathbf{x}} = \mathbf{A}\mathbf{x} + \mathbf{B}\mathbf{u} + \mathbf{w}$$

$$\mathbf{y} = \mathbf{C}\mathbf{x} + \mathbf{v}$$

其中：

| 噪声 | 名称 | 假设 | 协方差 |
|------|------|------|--------|
| $\mathbf{w}(t)$ | 过程噪声 | 零均值白噪声 | $E[\mathbf{w}(t)\mathbf{w}^T(\tau)] = \mathbf{W}\delta(t-\tau)$ |
| $\mathbf{v}(t)$ | 测量噪声 | 零均值白噪声 | $E[\mathbf{v}(t)\mathbf{v}^T(\tau)] = \mathbf{V}\delta(t-\tau)$ |

通常假设 $\mathbf{w}$ 和 $\mathbf{v}$ 互不相关。

### 关键参数：噪声协方差

$\mathbf{W}$ 和 $\mathbf{V}$ 是 LQG 设计的核心参数：

| 协方差 | 物理意义 | 增大时的效果 |
|--------|---------|------------|
| $\mathbf{W}$ | 模型不确定性和外部扰动的强度 | 观测器更信任测量，增益 $\mathbf{L}$ 增大 |
| $\mathbf{V}$ | 传感器噪声的强度 | 观测器更信任模型预测，增益 $\mathbf{L}$ 减小 |

## 卡尔曼滤波器

### 核心思想：最小均方误差估计

卡尔曼滤波器在每一时刻做两件事：

1. **预测**：根据模型预测下一时刻的状态和协方差
2. **更新**：用新测量值校正预测，得到最优估计

估计准则：**最小化估计误差的协方差矩阵的迹**（即均方误差之和）。

### 连续时间卡尔曼滤波器方程

状态估计：

$$\dot{\hat{\mathbf{x}}} = \mathbf{A}\hat{\mathbf{x}} + \mathbf{B}\mathbf{u} + \mathbf{L}(\mathbf{y} - \mathbf{C}\hat{\mathbf{x}})$$

这与 Luenberger 观测器形式相同，但增益 $\mathbf{L}$ 的计算方式不同：

$$\mathbf{L} = \boldsymbol{\Sigma}\mathbf{C}^T\mathbf{V}^{-1}$$

其中 $\boldsymbol{\Sigma}$ 是滤波误差协方差矩阵，满足滤波 Riccati 方程：

$$\mathbf{A}\boldsymbol{\Sigma} + \boldsymbol{\Sigma}\mathbf{A}^T - \boldsymbol{\Sigma}\mathbf{C}^T\mathbf{V}^{-1}\mathbf{C}\boldsymbol{\Sigma} + \mathbf{W} = \mathbf{0}$$

### 与 LQR 的对偶关系

| LQR | 卡尔曼滤波 |
|-----|-----------|
| $\mathbf{A}^T\mathbf{P} + \mathbf{P}\mathbf{A} - \mathbf{P}\mathbf{B}\mathbf{R}^{-1}\mathbf{B}^T\mathbf{P} + \mathbf{Q} = 0$ | $\mathbf{A}\boldsymbol{\Sigma} + \boldsymbol{\Sigma}\mathbf{A}^T - \boldsymbol{\Sigma}\mathbf{C}^T\mathbf{V}^{-1}\mathbf{C}\boldsymbol{\Sigma} + \mathbf{W} = 0$ |
| $\mathbf{K} = \mathbf{R}^{-1}\mathbf{B}^T\mathbf{P}$ | $\mathbf{L} = \boldsymbol{\Sigma}\mathbf{C}^T\mathbf{V}^{-1}$ |
| 控制权重 $\mathbf{R}$ | 测量噪声协方差 $\mathbf{V}$ |
| 状态惩罚 $\mathbf{Q}$ | 过程噪声协方差 $\mathbf{W}$ |

这就是著名的 **LQR-Kalman 对偶性**：求解滤波 Riccati 方程等价于求解一个对偶 LQR 问题的控制 Riccati 方程。

### 离散时间卡尔曼滤波（更常用）

离散时间卡尔曼滤波在数字实现中更为常见：

**预测步**：

$$\hat{\mathbf{x}}_{k|k-1} = \mathbf{A}_d\hat{\mathbf{x}}_{k-1|k-1} + \mathbf{B}_d\mathbf{u}_{k-1}$$

$$\boldsymbol{\Sigma}_{k|k-1} = \mathbf{A}_d\boldsymbol{\Sigma}_{k-1|k-1}\mathbf{A}_d^T + \mathbf{W}_d$$

**更新步**：

$$\mathbf{L}_k = \boldsymbol{\Sigma}_{k|k-1}\mathbf{C}^T(\mathbf{C}\boldsymbol{\Sigma}_{k|k-1}\mathbf{C}^T + \mathbf{V})^{-1}$$

$$\hat{\mathbf{x}}_{k|k} = \hat{\mathbf{x}}_{k|k-1} + \mathbf{L}_k(\mathbf{y}_k - \mathbf{C}\hat{\mathbf{x}}_{k|k-1})$$

$$\boldsymbol{\Sigma}_{k|k} = (\mathbf{I} - \mathbf{L}_k\mathbf{C})\boldsymbol{\Sigma}_{k|k-1}$$

### 数值示例：一维运动估计

考虑一个在直线上运动的物体，位置为 $x$，速度为 $v$：

$$\mathbf{A} = \begin{bmatrix} 1 & T \\ 0 & 1 \end{bmatrix}, \quad \mathbf{C} = \begin{bmatrix} 1 & 0 \end{bmatrix}$$

只能测量位置（GPS），但位置测量有噪声。假设 $T = 0.1$ s，过程噪声 $\mathbf{W} = \text{diag}(0, 0.01)$（速度受随机加速度扰动），测量噪声 $V = 1$。

```python
import numpy as np

# System parameters
T = 0.1
A = np.array([[1, T], [0, 1]], dtype=float)
C = np.array([[1, 0]], dtype=float)
W = np.diag([0.0, 0.01])
V = np.array([[1.0]])

# Solve Kalman filter Riccati equation
from scipy.linalg import solve_continuous_are
# For filtering: solve A*Sigma + Sigma*A^T - Sigma*C^T*V^{-1}*C*Sigma + W = 0
Sigma = solve_continuous_are(A.T, C.T, W, V)
L = Sigma @ C.T @ np.linalg.inv(V)
print("Sigma =", Sigma)
print("L =", L)
```

结果：$\mathbf{L} \approx \begin{bmatrix} 0.14 \\ 0.01 \end{bmatrix}$。位置估计对测量校正较敏感（$L_1$ 较大），速度估计更依赖模型预测（$L_2$ 较小）——因为我们没有直接测量速度。

## LQG 控制器

### 分离原理的随机版本

LQG 控制 = LQR 状态反馈 + 卡尔曼滤波器状态估计：

$$\mathbf{u} = -\mathbf{K}\hat{\mathbf{x}}$$

令人惊讶的是，**分离原理在随机情形下依然成立**：

1. LQR 增益 $\mathbf{K}$ 只取决于 $(\mathbf{A}, \mathbf{B}, \mathbf{Q}, \mathbf{R})$
2. 卡尔曼增益 $\mathbf{L}$ 只取决于 $(\mathbf{A}, \mathbf{C}, \mathbf{W}, \mathbf{V})$
3. 二者可以独立设计

闭环系统的极点 = LQR 极点 $\cup$ 卡尔曼滤波器极点。

### LQG 的代价

LQG 的最小代价为：

$$J_{LQG} = J_{LQR} + \text{tr}(\mathbf{P}\boldsymbol{\Sigma}_{ss}\mathbf{C}^T\mathbf{V}^{-1}\mathbf{C}\boldsymbol{\Sigma}_{ss})$$

其中第一项是"全信息"LQR 的代价，第二项是由于使用估计而非真实状态带来的额外代价。这被称为 **certainty equivalence cost**。

### 数值示例：LQG 设计流程

```matlab
% Plant
A = [0 1 0 0; 20.6 0 0 0; 0 0 0 1; -0.5 0 0 0];
B = [0; -2; 0; 0.5];
C = [1 0 0 0; 0 0 1 0];  % measure angle and position

% LQR design
Q = diag([100, 1, 1, 0.25]);
R = 0.01;
K = lqr(A, B, Q, R);

% Kalman filter design
W = diag([0.01, 0.1, 0.01, 0.1]);  % process noise
V = diag([0.1, 0.5]);               % measurement noise
L = lqe(A, eye(4), C, W, V);        % Kalman gain

% Check closed-loop poles
eig(A - B*K)     % LQR poles
eig(A - L*C)     % Kalman poles
```

```python
import numpy as np
from scipy.linalg import lqr_solve, solve_continuous_are

# LQR part
K, P, eig_lqr = lqr_solve(A, B, Q, R)

# Kalman filter part (via duality)
Sigma = solve_continuous_are(A.T, C.T, W, V)
L = Sigma @ C.T @ np.linalg.inv(V)

print("LQR poles:", eig_lqr)
print("Kalman poles:", np.linalg.eigvals(A - L @ C))
```

## 卡尔曼滤波器的扩展

### 扩展卡尔曼滤波器（EKF）

对于非线性系统：

$$\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}, \mathbf{u}) + \mathbf{w}$$

$$\mathbf{y} = \mathbf{h}(\mathbf{x}) + \mathbf{v}$$

EKF 在每一步对非线性函数进行线性化：

$$\mathbf{A}_k = \left.\frac{\partial \mathbf{f}}{\partial \mathbf{x}}\right|_{\hat{\mathbf{x}}_k}, \quad \mathbf{C}_k = \left.\frac{\partial \mathbf{h}}{\partial \mathbf{x}}\right|_{\hat{\mathbf{x}}_k}$$

然后应用标准卡尔曼滤波方程。EKF 是导航（GPS/INS 组合）、机器人定位（SLAM）的核心算法。

### 无迹卡尔曼滤波（UKF）

EKF 的线性化可能引入较大误差。UKF 使用一组**sigma 点**（确定性采样点）来传播概率分布，避免了显式求导，通常比 EKF 更精确。

## 常见错误与纠正

### 错误1：噪声协方差矩阵不适当

**错误做法**：随意设置 $\mathbf{W}$ 和 $\mathbf{V}$，如 $\mathbf{W} = \mathbf{I}, \mathbf{V} = \mathbf{I}$，而不考虑实际物理噪声特性。

**问题**：协方差矩阵的相对大小决定了观测器的"信任偏向"。如果 $W_{ii} \gg V_{jj}$，滤波器会过度信任测量；反之则过度信任模型。错误的设置会导致：
- 估计值剧烈抖动（过度信任噪声测量）
- 估计值滞后严重（过度信任不准的模型）

**纠正**：
1. 从传感器数据手册获取测量噪声统计特性
2. 通过实验辨识过程噪声强度
3. 使用自适应卡尔曼滤波在线调整协方差
4. 至少通过仿真比较不同 $\mathbf{W}/\mathbf{V}$ 比例的效果

### 错误2：忽略 LQG 的鲁棒性缺陷

**错误假设**："LQR 有很好的鲁棒性裕度，所以 LQG 也一样。"

**问题**：这是著名的 **LQG 鲁棒性悖论**。虽然 LQR 和卡尔曼滤波各自有良好的鲁棒性，但组合后的 LQG 控制器**可能具有任意差的鲁棒性**。原因是 LQR 的回路传递特性在加入观测器后被破坏了。

**纠正**：
1. 使用 **LTR（Loop Transfer Recovery）** 技术：通过调整 $\mathbf{W}$ 使 LQG 的回路传递函数趋近于 LQR 的回路传递函数
2. 使用 $H_\infty$ 或 $\mu$ 综合方法设计鲁棒控制器
3. 始终对 LQG 闭环系统进行鲁棒性分析（检查增益裕度和相位裕度）

## 自测习题

**习题1**：某系统的状态方程为 $\dot{x} = -x + u + w$，测量方程为 $y = x + v$，其中 $w$ 和 $v$ 是强度分别为 $W = 1$ 和 $V = 4$ 的白噪声。求稳态卡尔曼增益 $L$。

**答案**：一维 Riccati 方程：$2(-1)\Sigma - \Sigma^2 \cdot \frac{1}{4} + 1 = 0$，即 $\Sigma^2/4 + 2\Sigma - 1 = 0$。

解得 $\Sigma = -4 + 2\sqrt{5} \approx 0.472$（取正解）。

$L = \Sigma / V = 0.472 / 4 \approx 0.118$。

物理意义：测量噪声较大（$V=4$），所以滤波器对测量的信任度较低，增益较小。

**习题2**：在 LQG 中，为什么观测器误差动态不受控制输入 $u$ 影响？

**答案**：与确定性 Luenberger 观测器相同的推导。定义误差 $\mathbf{e} = \mathbf{x} - \hat{\mathbf{x}}$，则：

$$\dot{\mathbf{e}} = \mathbf{A}\mathbf{x} + \mathbf{B}\mathbf{u} + \mathbf{w} - \mathbf{A}\hat{\mathbf{x}} - \mathbf{B}\mathbf{u} - \mathbf{L}(\mathbf{C}\mathbf{x} + \mathbf{v} - \mathbf{C}\hat{\mathbf{x}})$$

$$= (\mathbf{A} - \mathbf{L}\mathbf{C})\mathbf{e} + \mathbf{w} - \mathbf{L}\mathbf{v}$$

控制输入 $u$ 抵消了，但误差动态现在受过程噪声 $\mathbf{w}$ 和测量噪声 $\mathbf{v}$ 驱动。$\mathbf{e}$ 的稳态协方差由 $\boldsymbol{\Sigma}$ 描述。

**习题3**：比较 Luenberger 观测器和卡尔曼滤波器在设计哲学上的根本区别。

**答案**：

| 方面 | Luenberger 观测器 | 卡尔曼滤波器 |
|------|-----------------|-------------|
| 设计目标 | 极点配置（收敛速度） | 最小化均方误差 |
| 增益计算 | 手动或 Ackermann 公式 | Riccati 方程自动求解 |
| 噪声处理 | 假设无噪声 | 显式建模噪声统计特性 |
| 最优性 | 无最优性保证 | 在均方误差意义下最优 |
| 适用场景 | 确定性系统、简单应用 | 噪声环境、高精度估计 |

Luenberger 观测器是"工程师直觉"驱动的设计——你希望误差多快收敛就配置相应极点。卡尔曼滤波器是"统计最优"驱动的设计——在噪声环境中给出数学上最优的估计。实际工程中，如果对噪声特性了解不多，Luenberger 观测器往往更简单直接；如果噪声统计特性已知且估计精度要求高，卡尔曼滤波器是更好的选择。
