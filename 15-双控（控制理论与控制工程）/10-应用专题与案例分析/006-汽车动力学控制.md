# 汽车动力学控制

> 汽车是控制理论最复杂的应用平台之一：质量超过一吨、速度高达数十米每秒、轮胎与地面接触的非线性力学、人类生命安全直接相关。从 ABS 防抱死到自动驾驶的轨迹跟踪，控制算法贯穿现代汽车的每一个关键系统。

---

## 汽车动力学的物理直觉

想象你驾驶一辆汽车在湿滑路面上急转弯。你打方向盘（前轮转角 $\delta$），车身开始转向，但惯性让车身有继续直线的趋势（侧偏）。轮胎侧向力与侧偏角的关系是非线性的——小角度近似是线性的，大角度时轮胎会"饱和"甚至打滑。这就是汽车动力学控制的**核心非线性来源**。

```
        y (lateral)
        ^
        |
   v <--+---> x (longitudinal)
        |
        |
        
   Vehicle coordinates:
   - x: forward
   - y: left (ISO convention)
   - z: up
   
   Sideslip angle β: angle between velocity vector and body x-axis
   Yaw rate ψ_dot: rate of rotation about z-axis
```

## 车辆三自由度模型

### 自行车模型（单轨模型）

将四轮车辆简化为两轮（前后轮合并），假设左右对称：

$$
m(\dot{v}_x - v_y \dot{\psi}) = F_{xf} \cos\delta - F_{yf} \sin\delta + F_{xr}
$$

$$
m(\dot{v}_y + v_x \dot{\psi}) = F_{xf} \sin\delta + F_{yf} \cos\delta + F_{yr}
$$

$$
I_z \ddot{\psi} = a(F_{xf} \sin\delta + F_{yf} \cos\delta) - b F_{yr}
$$

其中：
- $v_x, v_y$：纵向、侧向速度
- $\psi$：横摆角（yaw）
- $\delta$：前轮转角
- $a, b$：质心到前、后轴距离
- $F_{yf}, F_{yr}$：前、后轮侧向力

### 线性轮胎模型（小侧偏角）

$$
F_{yf} = C_{\alpha f} \alpha_f, \quad F_{yr} = C_{\alpha r} \alpha_r
$$

侧偏角定义为轮胎行进方向与指向方向之差：

$$
\alpha_f = \delta - \frac{v_y + a \dot{\psi}}{v_x}, \quad \alpha_r = -\frac{v_y - b \dot{\psi}}{v_x}
$$

### 线性化横向动力学

假设 $v_x \approx$ 常数，小角度近似 $\sin\delta \approx \delta$，$\cos\delta \approx 1$，得到：

$$
m(\dot{v}_y + v_x \dot{\psi}) = C_{\alpha f} \left(\delta - \frac{v_y + a \dot{\psi}}{v_x}\right) + C_{\alpha r} \left(-\frac{v_y - b \dot{\psi}}{v_x}\right)
$$

$$
I_z \ddot{\psi} = a C_{\alpha f} \left(\delta - \frac{v_y + a \dot{\psi}}{v_x}\right) - b C_{\alpha r} \left(-\frac{v_y - b \dot{\psi}}{v_x}\right)
$$

### 数值示例

某乘用车参数：

| 参数 | 符号 | 数值 | 单位 |
|------|------|------|------|
| 质量 | $m$ | 1500 | kg |
| 横摆惯量 | $I_z$ | 2500 | kg·m² |
| 前轴距离 | $a$ | 1.2 | m |
| 后轴距离 | $b$ | 1.4 | m |
| 前侧偏刚度 | $C_{\alpha f}$ | 60000 | N/rad |
| 后侧偏刚度 | $C_{\alpha r}$ | 50000 | N/rad |
| 纵向速度 | $v_x$ | 20 | m/s |

代入并整理为状态空间形式 $\dot{\mathbf{x}} = A\mathbf{x} + B\delta$，其中 $\mathbf{x} = [v_y, \dot{\psi}]^T$：

$$
A = \begin{bmatrix} \frac{-(C_{\alpha f} + C_{\alpha r})}{m v_x} & \frac{-a C_{\alpha f} + b C_{\alpha r}}{m v_x} - v_x \\ \frac{-a C_{\alpha f} + b C_{\alpha r}}{I_z v_x} & \frac{-(a^2 C_{\alpha f} + b^2 C_{\alpha r})}{I_z v_x} \end{bmatrix}
$$

计算数值：

$$
A = \begin{bmatrix} -3.67 & -17.5 \\ 0.96 & -4.38 \end{bmatrix}, \quad B = \begin{bmatrix} 40 \\ 28.8 \end{bmatrix}
$$

特征值：解 $\det(sI - A) = 0$：

$$
s^2 + 8.05 s + 32.9 = 0 \implies s = -4.03 \pm j3.22
$$

对应阻尼比 $\zeta = 0.78$，自然频率 $\omega_n = 5.74\,\text{rad/s} \approx 0.91\,\text{Hz}$。系统本身稳定，但横摆响应较慢。

## 车辆稳定性控制（ESC/ESP）

### 控制目标

让车辆的实际横摆角速度 $\dot{\psi}$ 跟踪驾驶员意图（由方向盘转角和车速决定的期望横摆率）：

$$
\dot{\psi}_{des} = \frac{v_x}{L(1 + K_{us} v_x^2)} \delta
$$

其中 $L = a + b$ 为轴距，$K_{us}$ 为**不足转向梯度**：

$$
K_{us} = \frac{m}{L}\left(\frac{b}{C_{\alpha f}} - \frac{a}{C_{\alpha r}}\right)
$$

### 数值示例

$$
K_{us} = \frac{1500}{2.6}\left(\frac{1.4}{60000} - \frac{1.2}{50000}\right) = 576.9 \times (2.33 \times 10^{-5} - 2.4 \times 10^{-5}) = -4.0 \times 10^{-3}\,\text{s}^2/\text{m}^2
$$

$K_{us} < 0$ 表示该车为**过度转向**（oversteer），高速转弯时后轮先达到侧向力极限，车尾有甩出趋势。

### ESC 控制律

ESC 通过对单个车轮施加差动制动产生横摆力矩。控制律通常采用**前馈 + 反馈**：

$$
M_z = M_{z,ff} + K_p (\dot{\psi}_{des} - \dot{\psi}) + K_d \frac{d}{dt}(\dot{\psi}_{des} - \dot{\psi})
$$

其中 $M_{z,ff}$ 为基于参考模型的前馈力矩，反馈项纠正实际与期望的偏差。

## 自适应巡航控制（ACC）

### 纵向动力学

简化纵向模型（忽略传动和发动机动态）：

$$
\dot{v}_x = a_{des} = u
$$

被控对象是一个**双积分器**：距离误差 $e_d = d_{des} - d$，速度误差 $e_v = v_{lead} - v_{ego}$：

$$
\ddot{e}_d = \ddot{d}_{des} - \dot{v}_{lead} + u
$$

### 间距策略

**恒定时间间距（Constant Time Headway）**：

$$
d_{des} = d_0 + \tau_h v_{ego}
$$

其中 $\tau_h = 1.5 \sim 2.0\,\text{s}$ 为跟车时距。这比恒定距离策略更符合人类驾驶习惯——车速越快，跟车距离越大。

### 滑模控制设计

定义滑模面：

$$
s = \dot{e}_d + \lambda e_d + \kappa \int e_d dt
$$

控制律使 $\dot{s} = -\eta \, \text{sgn}(s)$，得到：

$$
u_{des} = \ddot{d}_{des} - \dot{v}_{lead} + \lambda \dot{e}_d + \kappa e_d + \eta \, \text{sgn}(s)
$$

为减少抖振，用饱和函数替代符号函数：

```c
/* ACC longitudinal controller with smooth sliding mode */
#define LAMBDA      0.5f
#define KAPPA       0.05f
#define ETA         2.0f
#define PHI         0.5f    /* boundary layer thickness */

float sat(float x, float bound) {
    if (x > bound) return 1.0f;
    if (x < -bound) return -1.0f;
    return x / bound;
}

float acc_control(float d_err, float v_err, float a_lead) {
    float s = v_err + LAMBDA * d_err;  /* simplified sliding surface */
    float a_des = -a_lead + LAMBDA * v_err + KAPPA * d_err + ETA * sat(s, PHI);
    
    /* Clamp to vehicle limits */
    if (a_des > 3.0f) a_des = 3.0f;    /* max acceleration */
    if (a_des < -5.0f) a_des = -5.0f;  /* max deceleration */
    return a_des;
}
```

## 自动驾驶轨迹跟踪：MPC 应用

### 问题设置

在 Frenet 坐标系下（沿参考路径的纵向 $s$ 和横向 $d$），车辆运动学模型：

$$
\dot{s} = \frac{v \cos(\theta - \theta_{ref})}{1 - \kappa_{ref} d}
$$

$$
\dot{d} = v \sin(\theta - \theta_{ref})
$$

$$
\dot{\theta} = \frac{v}{L} \tan\delta
$$

其中 $\kappa_{ref}$ 为参考路径曲率。

### 线性时变 MPC

在每个控制周期，沿参考轨迹线性化，构建离散线性模型：

$$
\mathbf{x}_{k+1} = A_k \mathbf{x}_k + B_k \mathbf{u}_k
$$

优化目标：

$$
\min_{\mathbf{u}_0, \ldots, \mathbf{u}_{N-1}} \sum_{k=0}^{N-1} \left( \|\mathbf{x}_k - \mathbf{x}_{ref,k}\|_Q^2 + \|\mathbf{u}_k\|_R^2 \right) + \|\mathbf{x}_N - \mathbf{x}_{ref,N}\|_{Q_f}^2
$$

约束：
- 道路边界：$|d_k| < d_{max}$
- 执行器限幅：$|\delta_k| < \delta_{max}$，$|a_k| < a_{max}$
- 避障：$(s_k, d_k)$ 不在障碍物占据区域内

这是一个标准的**QP 问题**，可用 OSQP、qpOASES 等求解器实时求解（预测时域 $N = 20 \sim 40$，周期 $50 \sim 100\,\text{ms}$）。

## 常见错误与纠正

### 错误 1：线性控制器直接用于轮胎饱和区

**现象**：高速急转弯时，ESC 或 LKA（车道保持）控制器发出巨大方向盘指令，但车辆反而甩尾失控。

**原因**：线性轮胎模型 $F_y = C_\alpha \alpha$ 仅在侧偏角小于 $3° \sim 5°$ 有效。当侧偏角超过 $10°$，轮胎侧向力达到峰值后下降（饱和）。此时控制器继续增大指令，但轮胎无法提供更多侧向力。

**纠正**：
- 在线估计轮胎侧偏刚度或饱和极限
- 控制器输出限幅（rate limit + magnitude limit）
- 进入非线性区时切换为**基于相平面**的稳定控制（如 $(\beta, \dot{\psi})$ 相平面分析）

### 错误 2：忽略轮胎-路面摩擦系数变化

**现象**：在干燥路面标定的控制器，到冰雪路面完全失效。ABS 标定车在北京测试通过，到哈尔滨冬季测试抱死。

**原因**：轮胎侧偏刚度 $C_\alpha \propto \mu$，摩擦系数 $\mu$ 从干沥青的 $0.8$ 降到冰雪的 $0.2$，侧向力极限降低为 $1/4$。

**纠正**：
- 实时估计路面附着系数（利用轮速差、加速度计、转向扭矩）
- 基于估计的 $\hat{\mu}$ 缩放控制器增益或约束边界
- 采用增益调度：$K(\hat{\mu}) = K_0 \cdot \hat{\mu}$

## 自测习题

**1.** 某车 $m = 1200\,\text{kg}$，$a = 1.0\,\text{m}$，$b = 1.5\,\text{m}$，$C_{\alpha f} = 50000\,\text{N/rad}$，$C_{\alpha r} = 40000\,\text{N/rad}$。计算不足转向梯度 $K_{us}$，判断转向特性。

> 答案：
> $$K_{us} = \frac{1200}{2.5}\left(\frac{1.5}{50000} - \frac{1.0}{40000}\right) = 480 \times (3.0 \times 10^{-5} - 2.5 \times 10^{-5}) = 2.4 \times 10^{-3}\,\text{s}^2/\text{m}^2$$
> $K_{us} > 0$，为**不足转向**（understeer），前轴先达到极限，转弯时 tendency 是"推头"。

**2.** ACC 采用恒定时间间距 $\tau_h = 1.5\,\text{s}$，当前车速 $v = 30\,\text{m/s}$，静止间距 $d_0 = 5\,\text{m}$。计算期望跟车距离。若前车突然以 $-3\,\text{m/s}^2$ 减速，本车最大减速度 $-6\,\text{m/s}^2$，判断是否碰撞。

> 答案：
> $$d_{des} = 5 + 1.5 \times 30 = 50\,\text{m}$$
> 本车减速到前车速度所需时间 $t = (v_{rel})/(a_{max}) = (0 - (-3))$... 需要更完整分析：
> 假设两车初始速度相同 $30\,\text{m/s}$，前车减速 $3\,\text{m/s}^2$，本车最大减速度 $6\,\text{m/s}^2$。
> 相对加速度 $a_{rel} = -6 - (-3) = -3\,\text{m/s}^2$。
> 停止相对运动所需距离：$d_{brake} = v_{rel}^2 / (2 |a_{rel}|) = 0$（同速）。
> 但需要考虑反应延迟。若 ACC 反应延迟 $0.3\,\text{s}$，前车在 $0.3\,\text{s}$ 内走了 $30 \times 0.3 - 0.5 \times 3 \times 0.09 = 8.87\,\text{m}$，本车走了 $9\,\text{m}$，距离缩短 $0.13\,\text{m}$，远小于 $50\,\text{m}$，安全。

**3.** 为什么说汽车轮胎力是"控制系统中最讨厌的非线性"？简述至少两个原因。

> 答案：
> 1. **饱和特性**：侧向力随侧偏角先线性增加，达到峰值后下降，控制器无法通过增大指令获得更大力；
> 2. **强耦合性**：纵向力（制动/驱动）和侧向力通过摩擦圆耦合，$\sqrt{F_x^2 + F_y^2} \le \mu F_z$，加速时转弯能力下降；
> 3. **参数不确定**：$\mu$ 随路面、温度、胎况变化，难以精确建模。

**4.** 线性化自行车模型在什么条件下失效？自动驾驶控制器应如何处理？

> 答案：失效条件：
> - 大侧偏角（$> 5°$），轮胎进入非线性区；
> - 大前轮转角（轮胎侧偏角假设失效）；
> - 轮胎滑移（ABS 触发、漂移）；
> - 非平面路面（坡道、倾斜）。
> 处理方法：
> - 多模型切换（线性 MPC / 非线性 MPC）
> - 基于物理的轮胎模型（Pacejka 魔术公式）
> - 数据驱动的端到端补偿
