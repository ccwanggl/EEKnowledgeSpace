# 过程控制

> 化工、冶金、食品、制药……这些行业的共同点是：**过程缓慢、大滞后、强耦合、模型不确定**。控制一个 $100\,\text{m}^3$ 的反应釜温度，和伺服电机定位是截然不同的游戏。

---

## 过程控制的物理直觉

想象你用煤气灶烧水。你转动旋钮（操纵变量），但水温（被控变量）不会立刻变化——火焰加热锅底、锅底传热给水、水内部对流均匀化，每一步都有延迟。这就是**过程控制的核心特征：滞后**。

过程控制的典型变量：

| 变量类型 | 例子 | 时间尺度 |
|----------|------|----------|
| 被控变量（CV） | 温度、压力、液位、pH | 响应分钟~小时 |
| 操纵变量（MV） | 阀门开度、加热功率、进料流量 | 执行器秒级 |
| 扰动变量（DV） | 环境温度、原料成分、下游需求 | 不可控 |

---

## 过程模型：一阶加纯滞后（FOPDT）

绝大多数工业过程可以用一个极简模型描述：

$$
G(s) = \frac{K e^{-\tau_d s}}{\tau s + 1}
$$

其中：
- $K$：过程增益（稳态输出变化 / 稳态输入变化）
- $\tau$：时间常数（响应速度）
- $\tau_d$：纯滞后时间（死区时间）

### 直观理解

```
 input
   |
   v
  +--+      +--------+      +----------+
  |  |----->|  Gain  |----->| 1/(τs+1) |-----> output
  +--+      |   K    |      | 一阶惯性  |
   |        +--------+      +----------+
   |                              ^
   |         +--------+           |
   +-------->|  e^-τd·s |---------+
             | 纯滞后   |
             +--------+
```

纯滞后 $e^{-\tau_d s}$ 是过程控制中最棘手的因素。它让控制器"看不到"自己动作的效果，导致相位裕度下降。

### 数值示例

某反应釜温度控制系统，通过调节蒸汽阀开度控制釜温。阶跃测试数据如下：

| 参数 | 数值 | 来源 |
|------|------|------|
| 阀开度变化 | $\Delta u = 10\%$ | 人为施加 |
| 稳态温升 | $\Delta T = 15°\text{C}$ | 测量 |
| 过程增益 $K$ | $15/10 = 1.5$ | $\Delta T / \Delta u$ |
| 到达 63.2% 时间 | $\tau + \tau_d = 8\,\text{min}$ | 阶跃响应 |
| 开始响应时间 | $\tau_d = 2\,\text{min}$ | 目测拐点 |
| 时间常数 $\tau$ | $6\,\text{min}$ | 相减 |

模型为：

$$
G(s) = \frac{1.5 e^{-2s}}{6s + 1} \quad (s \text{ in min}^{-1})
$$

## 大滞后的控制难题

### 为什么 PID 对大滞后效果差？

PID 控制器基于**当前误差**计算控制动作。但大滞后系统中，当前误差反映的是 $\tau_d$ 之前的控制动作效果。PID 的"微分预测"和"积分记忆"都会被滞后误导。

**举例**：设 $\tau_d = 2\,\text{min}$，$T_s = 10\,\text{s}$。控制器看到温度偏低，加大加热。但真正的升温要在 2 分钟后才出现。在这 2 分钟内，控制器会**继续增大输出**（积分累积），导致 2 分钟后严重超调。

### 滞后比 $\tau_d / \tau$ 的重要性

| $\tau_d / \tau$ | 可控性 | 推荐策略 |
|-----------------|--------|----------|
| $< 0.3$ | 良好 | 常规 PID |
| $0.3 \sim 1.0$ | 一般 | PID + Smith 预估 |
| $> 1.0$ | 困难 | 采样控制、MPC、前馈 |

上例中 $\tau_d / \tau = 2/6 \approx 0.33$，处于临界区域。

## Smith 预估器

### 核心思想

既然知道滞后存在，那就**在控制器内部建一个模型**，让控制器"提前看到"无滞后的响应，从而避免过度调节。

```
          +-------+
r ----->  |  C(s) | ----+--------------------> u ---> Plant
          +-------+     |                           G(s)=Km·e^-τd·s/(τs+1)
                        |      +----------+              |
                        |  +-->|  Model   |--+           | y
                        |  |   | Gm(s)    |  |           |
                        |  |   +----------+  |           |
                        |  |                 v           |
                        |  |   +----------+  |           v
                        +--+-->|  e^-τd·s |<-+      +-------+
                               +----------+          | Sum   |---> e
                                                     |   -   |
                                                     +---^---+
                                                         | ym
```

控制器 $C(s)$ 看到的等效被控对象变为无滞后的 $G_m(s)$，可以设计更高增益。

### 数学推导

设模型精确（$G_m = G$），Smith 预估器的闭环传递函数为：

$$
\frac{Y(s)}{R(s)} = \frac{C(s) G(s)}{1 + C(s) G_m(s)} = \frac{C(s) G_m(s) e^{-\tau_d s}}{1 + C(s) G_m(s)}
$$

特征方程中**不含** $e^{-\tau_d s}$！滞后被"移"到了闭环外部，仅影响输出时延，不影响稳定性。

### 数值设计

对模型 $G_m(s) = \frac{1.5}{6s + 1}$（去掉滞后），设计 PI 控制器。采用**Lambda 整定法**：设期望闭环时间常数 $\lambda = \tau = 6\,\text{min}$（保守）或 $\lambda = \tau/3 = 2\,\text{min}$（激进）。

Lambda 整定公式：

$$
K_p = \frac{\tau}{K \lambda}, \quad T_i = \tau
$$

取 $\lambda = 3\,\text{min}$：

$$
K_p = \frac{6}{1.5 \times 3} = 1.33, \quad T_i = 6\,\text{min}
$$

积分增益 $K_i = K_p / T_i = 1.33 / 6 = 0.222\, \text{min}^{-1}$。

## 串级控制（Cascade Control）

### 场景

反应釜温度控制中，蒸汽流量本身也会波动（上游压力变化）。与其让温度环直接输出阀位，不如加一个**流量内环**。

```
    T_set ----->[  TC  ]-----> F_set ----->[  FC  ]-----> Valve -----> Heat -----> Reactor
                    ^                           ^                                   |
                    |                           |                                   |
                T_meas                      F_meas                                T_meas
```

### 优势

| 特性 | 单环控制 | 串级控制 |
|------|----------|----------|
| 流量扰动抑制 | 慢（靠温度环） | 快（流量环秒级响应） |
| 温度环带宽 | 受限 | 可更高（外环只需控制"慢对象"） |
| 非线性补偿 | 差 | 好（流量环线性化阀门特性） |

设计要点：内环（流量）必须比外环（温度）快 **5 倍以上**。

## 采样 PI 控制（Dahlin 算法）

对于大滞后过程，另一种思路是**接受滞后的存在**，设计一个控制器让闭环响应也呈现一阶滞后形式：

$$
\frac{Y(z)}{R(z)} = \frac{(1 - q) z^{-N-1}}{1 - q z^{-1}}
$$

其中 $q = e^{-T_s / \lambda}$，$N = \tau_d / T_s$ 为整数滞后拍数，$\lambda$ 为期望闭环时间常数。

由此反解控制器：

$$
C(z) = \frac{1}{G(z)} \cdot \frac{(1-q) z^{-N-1}}{1 - q z^{-1} - (1-q) z^{-N-1}}
$$

这就是 **Dahlin 控制器**，属于**模型算法控制（MAC）**的一种简化形式。若模型精确，闭环将精确呈现设定的响应。

## MATLAB 仿真

```matlab
% FOPDT process
K = 1.5; tau = 6; tau_d = 2;  % in minutes
Gs = tf(K, [tau, 1], 'InputDelay', tau_d);

% PID with Smith Predictor (approximate)
Kp = 1.33; Ti = 6; Td = 0;
C = pid(Kp, Kp/Ti, 0);

% Compare: PID alone vs PID + Smith
sys_plain = feedback(C*Gs, 1);

% Smith predictor simulation (requires custom model)
Gm = tf(K, [tau, 1]);  % model without delay
C_smith = feedback(C, C*(Gm - Gs));
sys_smith = feedback(C_smith*Gs, 1);

figure;
step(sys_plain, sys_smith);
legend('PID Only', 'PID + Smith');
title('Reactor Temperature Control');
grid on;
```

## 常见错误与纠正

### 错误 1：忽略测量滞后，把采样周期设得太小

**现象**：控制系统采样周期为 $1\,\text{s}$，但温度传感器热惯性导致测量本身有 $30\,\text{s}$ 滞后。控制器对每个微小波动都反应，导致阀门频繁动作（wear and tear）。

**纠正**：采样周期应匹配过程动态。对于 $\tau = 6\,\text{min}$ 的过程，$T_s = 10 \sim 30\,\text{s}$ 足够。记住经验公式：$T_s \approx 0.1 \tau$。

### 错误 2：Smith 预估器模型失配导致不稳定

**现象**：实际过程增益从设计时的 $K = 1.5$ 变为 $K = 2.0$（反应物料变化），Smith 预估器开始震荡。

**纠正**：Smith 预估器对模型误差敏感。稳健做法是：
- 在线辨识更新模型参数
- 降低控制器增益，换取鲁棒性
- 改用更鲁棒的 MPC 方法处理约束和模型不确定

## 自测习题

**1.** 某换热器过程模型为 $G(s) = \frac{2 e^{-5s}}{10s + 1}$（单位：°C / %阀位，时间单位为 min）。判断 $\tau_d / \tau$，评估可控性。

> 答案：$\tau_d / \tau = 5/10 = 0.5$，处于临界区域。常规 PID 可工作但需保守整定，推荐使用 Smith 预估器或串级控制。

**2.** 对上题过程，用 Lambda 整定法设计 PI 参数，取 $\lambda = 5\,\text{min}$。

> 答案：
> $$K_p = \frac{\tau}{K \lambda} = \frac{10}{2 \times 5} = 1.0$$
> $$T_i = \tau = 10\,\text{min}, \quad K_i = K_p/T_i = 0.1\,\text{min}^{-1}$$

**3.** 解释为什么串级控制中，内环流量控制器通常用 PI，而外环温度控制器可用 PID 或 PI？

> 答案：流量环需要快速无静差跟踪（流量指令来自温度环），故用 PI。温度环面对大滞后，微分项对噪声敏感且效果有限，通常只用 PI 或加入滤波。若用 PID，需对微分输入加低通滤波。

**4.** 某工程师将 PID 采样周期设为 $T_s = 0.5\,\text{s}$ 控制一个 $\tau = 30\,\text{min}$ 的大滞后过程，有什么问题？

> 答案：采样周期过小会导致：
> 1. 测量噪声被过度采样，控制器对噪声敏感；
> 2. 阀门执行器寿命缩短（频繁动作）；
> 3. 离散化数值问题（积分累积精度）。
> 建议 $T_s = 0.1 \tau \approx 3\,\text{min}$。

## 工程经验法则

| 场景 | 推荐方案 |
|------|----------|
| 滞后小 ($\tau_d/\tau < 0.2$) | 单环 PID，IMC 整定 |
| 滞后中等，模型已知 | Smith 预估器 |
| 多变量耦合 | 解耦控制 + 多回路 PID |
| 约束多、多变量 | MPC（模型预测控制） |
| 非线性严重 | 增益调度、自适应控制 |
