# 电力电子变换器控制

> 电力电子变换器是控制理论最"硬核"的应用场景之一：开关频率高达 $100\,\text{kHz}$，带宽要求 $10\,\text{kHz}$ 以上，所有控制必须在几十微秒内完成。在这里，控制理论不是锦上添花，而是决定效率、稳定性和 EMI 的核心。
>
> **与变换链的关系**：电力电子变换器控制是"复域系统分析"（$s$ 域）与"有限实现"（$z$ 域）的极速结合。状态空间平均法得到 $s$ 域传递函数，补偿器在 $s = j\omega$ 上设计相位裕度，最后通过数字 PWM 在 $z$ 域（$z = e^{sT}$）实现，整个控制周期可能只有 $10\,\mu\text{s}$。如果你学过 [[14-FOC-电机控制/00-README|14-FOC-电机控制]]，逆变器驱动 PMSM 的功率级本质上就是这里讨论的 Buck/Boost 变换器控制的直接延伸。

---

## 变换器控制的物理直觉

想象你用开关控制水流：快速开关阀门，通过调节"开"与"关"的时间比例（占空比 $D$），就可以精确控制平均流量。DC-DC 变换器同理——用半导体开关（MOSFET/IGBT）的通断，把一种直流电压变换为另一种。

```
Buck (降压):  Vin ----->[SW]----+----> Vout = D * Vin
                               |
                              L,C
                               |
                              GND

Boost (升压): Vin ----> L ----+[SW]--+---> Vout = Vin / (1-D)
                               |     |
                              D     C
                               |     |
                              GND   GND
```

## Buck 变换器平均模型

### 状态空间平均法

对 Buck 变换器，在一个开关周期 $T_s$ 内：

- 开关导通时（$DT_s$）：电感电压 $v_L = V_{in} - v_C$
- 开关关断时（$(1-D)T_s$）：电感电压 $v_L = -v_C$

在一个周期内平均：

$$
L \frac{d\langle i_L \rangle}{dt} = D V_{in} - \langle v_C \rangle
$$

$$
C \frac{d\langle v_C \rangle}{dt} = \langle i_L \rangle - \frac{\langle v_C \rangle}{R}
$$

### 线性化小信号模型

对稳态工作点 $(V_{in}, D, V_o, I_L)$ 施加小扰动：$v_{in} = V_{in} + \hat{v}_{in}$，$d = D + \hat{d}$，对平均方程取**拉普拉斯变换**，得到小信号传递函数：

$$
G_{vd}(s) = \frac{\hat{v}_o(s)}{\hat{d}(s)} = \frac{V_{in}}{LC s^2 + \frac{L}{R} s + 1}
$$

> **与变换链的关系**：这是**$s$ 域**的传递函数。分母是二阶多项式，对应时域中的两个储能元件（电感 $L$ 和电容 $C$）。通过求根可得到两个极点，在 $s$ 平面上的位置直接决定了变换器的动态响应：阻尼比 $\zeta$ 从 $s$ 域系数直接读出，无需解微分方程。这就是"复域系统分析"的价值——把物理元件（$L$、$C$）的时域动态转化为 $s$ 域的代数结构。

这是典型的**二阶低通特性**。对 $V_{in} = 12\,\text{V}$，$L = 4.7\,\mu\text{H}$，$C = 22\,\mu\text{F}$，$R = 5\,\Omega$：

$$
G_{vd}(s) = \frac{12}{(4.7 \times 10^{-6})(22 \times 10^{-6}) s^2 + \frac{4.7 \times 10^{-6}}{5} s + 1}
$$

$$
G_{vd}(s) = \frac{12}{1.034 \times 10^{-10} s^2 + 9.4 \times 10^{-7} s + 1}
$$

自然频率和阻尼比：

$$
\omega_n = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{1.034 \times 10^{-10}}} \approx 98.5\,\text{krad/s} \approx 15.7\,\text{kHz}
$$

$$
\zeta = \frac{1}{2R}\sqrt{\frac{L}{C}} = \frac{1}{10}\sqrt{\frac{4.7}{22}} \approx 0.046
$$

阻尼极低！这意味着开环 Buck 对占空比扰动会有剧烈振铃。

## 电压模式控制

### 单环 PID

直接采样输出电压 $v_o$，与参考 $V_{ref}$ 比较，控制器输出占空比 $d$：

```
Vref ---->(-)-->[Gc(s)]--->[PWM]--->[Buck]---> Vo
            ^                              |
            +------------------------------+
```

控制器设计目标：在保持稳定的条件下，最大化闭环带宽以快速响应负载跳变。

### 类型 III 补偿器

由于 $G_{vd}(s)$ 在 $\omega_n$ 处有 $-180°$ 相位跳变，普通 PI 难以补偿。Buck 电压环通常使用**类型 III 补偿器**（双极点双零点）：

$$
G_c(s) = G_0 \frac{(1 + s/\omega_{z1})(1 + s/\omega_{z2})}{s(1 + s/\omega_{p1})(1 + s/\omega_{p2})}
$$

> **与变换链的关系**：类型 III 补偿器的设计完全在**频域**（$s = j\omega$）上进行。我们通过 $s = j\omega$ 把 $G_{vd}(s)$ 和 $G_c(s)$ 映射到频率轴，观察它们的幅频和相频特性。补偿器的零点被精确放置在 $s$ 平面的特定位置，以"拉抬"被控对象在谐振频率附近的相位滞后，确保开环传递函数在穿越频率处有足够的相位裕度。这是"复域设计、频域验证"的典型工程流程。

补偿器提供一个原点极点（积分，消除静差）、两个零点（补偿 LC 双极点的相位滞后）、两个高频极点（抑制开关噪声）。

### 设计步骤

1. 选择穿越频率 $f_c = f_{sw} / 10$（如开关频率 $500\,\text{kHz}$，则 $f_c = 50\,\text{kHz}$）
2. 将两个零点放在谐振频率 $f_0 = \omega_n / (2\pi) \approx 15.7\,\text{kHz}$ 附近
3. 一个极点放在 $f_{p1} = f_c$ 处，另一个在 $f_{p2} = f_{sw}/2$（或 ESR 零点处）
4. 计算 $G_0$ 使得 $f_c$ 处开环增益为 $0\,\text{dB}$

## 电流模式控制

### 峰值电流模式

电压模式的问题：LC 谐振峰导致补偿复杂。电流模式在电压环内加入**电流内环**，让电感电流跟踪电压环指令：

```
Vref ---->[Voltage]---> Iref ---->[Current]---> d ---->[Buck]---> Vo
            ^    PI              ^    Comparator                 |
            |                    |    (cycle-by-cycle)            |
            +--------------------+--------------------------------+
```

### 电流内环的简化效果

当电流环足够快时，电感电流"被控住"，Buck 从二阶系统降为一阶系统：

$$
G_{vd}^{eff}(s) \approx \frac{R}{1 + s R C}
$$

电压环设计因此大幅简化，可以用简单的 PI 或类型 II 补偿器。

### 数值设计

对上述 Buck，$R = 5\,\Omega$，$C = 22\,\mu\text{F}$，有效被控对象：

$$
G_{vd}^{eff}(s) = \frac{5}{1 + 1.1 \times 10^{-4} s}
$$

时间常数 $\tau = 110\,\mu\text{s}$，对应极点频率 $f_p = 1/(2\pi\tau) \approx 1.45\,\text{kHz}$。

设计 PI 控制器使穿越频率 $f_c = 10\,\text{kHz}$：

$$
K_p = \frac{2\pi f_c C}{\text{current sense gain}} = \frac{2\pi \times 10000 \times 22\times10^{-6}}{0.1} \approx 13.8
$$

其中假设电流采样增益为 $0.1\,\text{V/A}$。

## C 代码实现：数字峰值电流控制

```c
/* Digital peak current mode controller for Buck converter
 * PWM frequency: 500 kHz, ADC sampling on sync
 * 与变换链的关系：下面的代码是 z 域控制器的时域实现。
 * 电压环 PI 在 s 域设计，通过 z = e^{sT}（T=2us，对应500kHz）映射到数字域。
 * 由于开关频率极高，离散化近似误差很小，但采样延迟（~1.5T）的相位滞后
 * 在 s = jω 上必须计入设计。
 */
#include <stdint.h>

#define VREF_Q15        24576       /* 0.75 in Q15 = 12V/16V for 3.3V ADC ref */
#define Kp_Q15          45056       /* ~1.375 in Q15 */
#define Ki_Q15          512         /* integral gain */
#define DUTY_MAX        780         /* 95% of 822 counts for 500kHz @ 411MHz */
#define DUTY_MIN        20
#define CURRENT_LIMIT   819         /* 10A with 0.1V/A sense, 12-bit ADC */

volatile int16_t v_error_integral = 0;

void pwm_isr(void) {
    /* Read ADC results (assumed done by DMA) */
    int16_t v_out = ADC_VOUT;   /* Q12 or raw ADC */
    int16_t i_inductor = ADC_IL; /* raw ADC, 0.1V/A */
    
    /* --- Voltage loop (PI, executed every PWM cycle) --- */
    int16_t v_error = VREF_Q15 - v_out;
    
    /* Anti-windup: only integrate if output not saturated */
    if (duty < DUTY_MAX && duty > DUTY_MIN) {
        v_error_integral += (Ki_Q15 * v_error) >> 15;
        /* Clamp integrator */
        if (v_error_integral > 32767) v_error_integral = 32767;
        if (v_error_integral < -32767) v_error_integral = -32767;
    }
    
    int32_t v_ctrl = ((int32_t)Kp_Q15 * v_error >> 15) + v_error_integral;
    
    /* v_ctrl is the current reference */
    int16_t i_ref = v_ctrl;  /* may need scaling */
    
    /* --- Current loop (cycle-by-cycle comparator) --- */
    /* Hardware comparator: when i_inductor > i_ref, turn off switch */
    /* Software fallback: */
    if (i_inductor > i_ref || i_inductor > CURRENT_LIMIT) {
        PWM_SET_DUTY(0);
    } else {
        /* Normal operation: duty controlled by voltage loop */
        int32_t duty_calc = (v_ctrl * DUTY_MAX) >> 15;
        if (duty_calc > DUTY_MAX) duty_calc = DUTY_MAX;
        if (duty_calc < DUTY_MIN) duty_calc = DUTY_MIN;
        PWM_SET_DUTY((uint16_t)duty_calc);
    }
}
```

> **与变换链的关系**：上面的 C 代码是**$z$ 域**的时域实现。电压环 PI 控制器在 $s$ 域中设计（补偿器 $G_c(s)$ 在 $s = j\omega$ 上满足相位裕度要求），然后通过离散化（Tustin 或 ZOH）映射到 $z$ 域。由于开关频率 $f_{sw} = 500\,\text{kHz}$ 极高，采样周期 $T_s = 2\,\mu\text{s}$ 极小，$z = e^{sT}$ 的近似误差很小，但数字控制固有的采样-更新延迟（约 $1.5T_s$）在 $s = j\omega$ 上引入额外相位滞后，在高带宽设计中必须显式计入。这是"$s$ 域设计、$z$ 域实现、$s = j\omega$ 验证"的完整链条在极速控制中的体现。

## 常见错误与纠正

### 错误 1：未补偿电流环的次谐波振荡

**现象**：电流模式 Buck 在占空比 $D > 0.5$ 时，出现 $f_{sw}/2$ 的次谐波振荡，输出电压低频波动。

**原因**：峰值电流模式的固有不稳定性。当 $D > 0.5$ 时，小的电流扰动会在每个周期放大，形成不收敛的振荡。

**纠正**：加入**斜坡补偿（Slope Compensation）**。在电流参考上叠加一个与开关周期同步的下降斜坡，斜率 $m_a$ 满足：

$$
m_a > \frac{m_2 - m_1}{2}
$$

其中 $m_1$ 为电感电流上升斜率，$m_2$ 为下降斜率。典型取 $m_a = 0.75 m_2$。

### 错误 2：电压采样与 PWM 更新不同步

**现象**：负载跳变时输出电压过冲严重，相位裕度测量结果与理论设计不符。

**原因**：数字控制中存在**采样-更新延迟**。ADC 在 PWM 周期中间采样，但占空比更新要到下一个周期才开始生效，引入约 $1.5 T_s$ 的等效延迟。这个额外的相位滞后在高带宽设计中可能致命。

**纠正**：
- 采用"采样在谷点、更新在峰值"的策略，最小化延迟
- 在设计中明确计入 $e^{-1.5 T_s s}$ 的相位滞后
- 降低穿越频率，或采用预测控制补偿延迟

## 自测习题

**1.** Buck 变换器 $V_{in} = 24\,\text{V}$，$L = 10\,\mu\text{H}$，$C = 47\,\mu\text{F}$，$R = 10\,\Omega$。计算开环传递函数 $G_{vd}(s)$ 的谐振频率和阻尼比。

> 答案：
> $$\omega_n = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{10^{-5} \times 4.7 \times 10^{-5}}} = 46.2\,\text{krad/s}$$
> $$f_0 = 7.35\,\text{kHz}$$
> $$\zeta = \frac{1}{2R}\sqrt{\frac{L}{C}} = \frac{1}{20}\sqrt{\frac{10}{47}} = 0.023$$
> 阻尼极低，需要补偿器提供大量相位提升。

**2.** 电流模式控制为什么能把二阶 Buck 系统"降阶"为一阶？物理直觉是什么？

> 答案：因为电感电流被内环"硬控"住，相当于电感动态被电流环消除。物理上，电感变成了一个受控电流源，输出只剩下电容-负载 RC 网络的一阶动态。

**3.** 峰值电流模式的斜坡补偿斜率 $m_a$ 应如何选择？为什么 $D < 0.5$ 时通常不需要？

> 答案：$m_a > (m_2 - m_1)/2$，通常取 $m_a \approx 0.75 m_2$。当 $D < 0.5$ 时，$m_1 > m_2$，自然满足稳定条件；当 $D > 0.5$ 时，$m_2 > m_1$，扰动会逐周期放大，必须加补偿。

**4.** 数字控制的 Buck 变换器，开关频率 $1\,\text{MHz}$，目标电压环带宽 $100\,\text{kHz}$。是否可行？

> 答案：不可行。经验法则要求 $f_c \le f_{sw}/10 = 100\,\text{kHz}$，但数字控制的采样-更新延迟（约 $1.5 T_s = 1.5\,\mu\text{s}$）在 $100\,\text{kHz}$ 处引入 $-54°$ 额外相位滞后。实际可行带宽约 $50 \sim 80\,\text{kHz}$。若用模拟控制或预测补偿，可接近 $100\,\text{kHz}$。
