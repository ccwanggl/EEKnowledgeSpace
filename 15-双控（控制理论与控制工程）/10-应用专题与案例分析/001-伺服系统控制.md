# 伺服系统控制

> 伺服（Servo）一词源自拉丁语 *servus*（奴隶），意即系统完全听从指令。从数控机床到机器人关节，从硬盘寻道到光刻机定位，高精度伺服控制是现代制造业的基石。
>
> **与变换链的关系**：伺服系统控制是"复域系统分析"（$s$ 域）在机电领域的直接应用。电流环、速度环、位置环的每一层设计，本质上都是在 $s$ 平面配置极点、通过 $s = j\omega$ 验证频域特性，最后通过 $z = e^{sT}$ 映射到数字实现。如果你学过 [[14-FOC-电机控制/00-README|14-FOC-电机控制]]，这里的三环架构与 FOC 的电流环/速度环几乎完全同构。

---

## 伺服系统的物理直觉

想象你用手指追踪桌面上缓慢移动的小球。你的眼睛观测小球位置（反馈），大脑计算手指与球的偏差（误差），手臂肌肉调整力度和方向（控制）。伺服系统就是这个过程的机电翻版：**传感器 → 控制器 → 驱动器 → 电机 → 机械负载 → 传感器**。

```
      +-------+      u(t)      +---------+   omega   +--------+    theta
 r(t) |       |----------->|  Power  |-------->| Motor  |---------->
----->|  C(s) |              | Driver  |         | + Load |      |
  -   |       |<-------------|         |         +--------+      |
  ^   +-------+   feedback   +---------+            |            |
  |                                                 | encoder    |
  +-------------------------------------------------+------------+
```

### 三环架构：电流环 → 速度环 → 位置环

伺服系统通常采用**三环嵌套**结构：

| 环路 | 带宽 | 采样周期 | 控制器 | 作用 |
|------|------|----------|--------|------|
| 电流环（最内）| 最高 | $50 \sim 100 \, \mu\text{s}$ | PI | 控制电磁转矩 |
| 速度环（中间）| 中等 | $100 \sim 500 \, \mu\text{s}$ | PI | 控制转速 |
| 位置环（最外）| 最低 | $500 \, \mu\text{s} \sim 2 \, \text{ms}$ | P / PID | 控制位置 |

设计原则：**内环带宽是外环的 5~10 倍**。如果速度环带宽为 $500 \, \text{Hz}$，电流环应设计到 $3 \sim 5 \, \text{kHz}$。

## 伺服电机数学模型

### 永磁同步电机（PMSM）的简化模型

在 $d-q$ 旋转坐标系下（FOC 控制），假设已经完美解耦，$q$ 轴电流到电磁转矩的关系为：

$$
T_e = \frac{3}{2} p \psi_f i_q = K_t i_q
$$

其中 $p$ 为极对数，$\psi_f$ 为永磁体磁链。机械运动方程：

$$
J \frac{d\omega}{dt} = T_e - B \omega - T_L
$$

位置与速度关系：

$$
\frac{d\theta}{dt} = \omega
$$

联立以上方程，以 $i_q$ 为输入、$\theta$ 为输出，忽略负载 $T_L$，对以上微分方程取**拉普拉斯变换**，消去中间变量，得到从电流到位置的三阶传递函数：

$$
G_{\theta}(s) = \frac{\Theta(s)}{I_q(s)} = \frac{K_t}{s(Js + B)} = \frac{K_t/J}{s^2 + (B/J)s}
$$

> **与变换链的关系**：这个传递函数是**$s$ 域**的表示。分母中的 $s$ 对应时域的积分（位置是速度的积分），$s$ 的一次项对应一阶动态。极点位于 $s = 0$ 和 $s = -B/J$，前者是积分器（位置自然累积），后者是机械时间常数。这些信息在时域微分方程中需要解方程才能看到，但在 $s$ 域中一目了然——这就是拉普拉斯变换作为"复域系统分析"工具的价值。

### 数值示例

一台伺服电机的参数如下：

| 参数 | 符号 | 数值 | 单位 |
|------|------|------|------|
| 转矩常数 | $K_t$ | 0.32 | N·m/A |
| 转动惯量 | $J$ | 0.0004 | kg·m² |
| 阻尼系数 | $B$ | 0.0002 | N·m/(rad/s) |

传递函数为：

$$
G_{\theta}(s) = \frac{800}{s(s + 0.5)}
$$

这是一个**I 型系统**（含一个积分环节），对阶跃位置指令的稳态误差为零，但对斜坡指令有常值误差。

## 电流环设计

### 被控对象

电流环的被控对象是电机的 $q$ 轴电枢回路：

$$
L_q \frac{di_q}{dt} + R_s i_q = v_q - K_e \omega
$$

由于电感 $L_q$ 很小（典型值 $1 \sim 5 \, \text{mH}$），电流环响应极快。设计目标通常是**一阶响应**，时间常数 $\tau_i \approx L_q / R_s$。

### PI 参数整定

对电流环采用**零极点对消法**：设 PI 控制器为 $C_i(s) = K_{pi} + \frac{K_{ii}}{s}$，令其零点对消电机电枢极点：

$$
\frac{K_{ii}}{K_{pi}} = \frac{R_s}{L_q}
$$

> **与变换链的关系**：零极点对消法是**$s$ 域的代数操作**。PI 控制器的零点 $s = -K_{ii}/K_{pi}$ 被精确放置在电机电枢极点 $s = -R_s/L_q$ 的位置，两者在复平面上重合并抵消。这在时域中难以理解（"抵消一个动态"是什么意思？），但在 $s$ 域中就是分子分母相约——清晰的代数直觉。这正是拉普拉斯变换把"微分方程求解"变成"多项式运算"的威力。

则开环传递函数近似为积分器加增益，闭环为一阶系统：

$$
\frac{I_q(s)}{I_q^{*}(s)} = \frac{K_{pi}/L_q}{s + K_{pi}/L_q} = \frac{1}{\tau_{cl} s + 1}
$$

其中 $\tau_{cl} = L_q / K_{pi}$ 为期望闭环时间常数。若要求 $\tau_{cl} = 0.2 \, \text{ms}$，$L_q = 2 \, \text{mH}$，则：

$$
K_{pi} = \frac{L_q}{\tau_{cl}} = \frac{0.002}{0.0002} = 10 \, \text{V/A}, \quad K_{ii} = K_{pi} \cdot \frac{R_s}{L_q}
$$

## 速度环设计

### 被控对象

速度环的被控对象是"电流闭环 + 机械系统"。当电流环足够快时，可近似认为 $I_q(s) \approx I_q^{*}(s)$。于是速度环被控对象简化为：

$$
G_{\omega}(s) = \frac{K_t}{Js + B}
$$

### 对称最优法（Modulus Optimum）

这是伺服领域最经典的整定方法。目标是使闭环传递函数的幅频特性尽可能平坦（modulus 最优）。

> **与变换链的关系**："幅频特性平坦"是一个**频域**（$s = j\omega$）概念。我们在 $s$ 域设计控制器，然后通过 $s = j\omega$ 映射到频域验证：闭环传递函数的幅值 $|T(j\omega)|$ 在穿越频率附近没有尖峰或凹陷，意味着系统对不同频率的输入信号有一致的响应能力，不会"选择性放大"某些频率成分。

对 I 型系统（含一个积分器），设速度 PI 控制器为 $C_{\omega}(s) = K_{p\omega} + \frac{K_{i\omega}}{s}$。

对称最优整定公式为：

$$
K_{p\omega} = \frac{J}{2 K_t \tau_{sum}}, \quad K_{i\omega} = \frac{K_{p\omega}}{4 \tau_{sum}}
$$

其中 $\tau_{sum}$ 为电流环等效时间常数与所有小时间常数之和。

### 数值示例

沿用上面的电机参数，$K_t = 0.32 \, \text{N·m/A}$，$J = 0.0004 \, \text{kg·m}^2$，设 $\tau_{sum} = 0.5 \, \text{ms}$：

$$
K_{p\omega} = \frac{0.0004}{2 \times 0.32 \times 0.0005} = 1.25 \, \text{A·s/rad}
$$

$$
K_{i\omega} = \frac{1.25}{4 \times 0.0005} = 625 \, \text{A/rad}
$$

## 位置环设计

### P 控制与 PD 控制

位置环通常只需要比例控制 $C_{\theta}(s) = K_{p\theta}$，因为速度环已经提供了积分作用（速度环 PI 对位置而言相当于 I 控制）。

开环传递函数：

$$
L(s) = K_{p\theta} \cdot \frac{C_{\omega}(s) G_{\omega}(s)}{s}
$$

### 前馈补偿

在点对点定位（Point-to-Point）应用中，仅反馈控制往往导致跟踪滞后。加入**速度前馈**和**加速度前馈**可大幅提升跟踪精度：

```
     +--------+    +--------+    +--------+
 r --| K_ffv  |--->|  Sum   |--->| Speed  |---> motor
     | K_ffa  |--->|        |    |  Loop  |
     +--------+    +--------+    +--------+
                      ^
                      | theta_feedback
                      |
                 Position Loop
```

前馈增益通常设置为：

$$
K_{ffv} = \frac{1}{K_t / J \cdot \text{(gear ratio)}}, \quad K_{ffa} = 0 \text{（或根据加速度需求设定）}
$$

## MATLAB 仿真验证

```matlab
% Servo three-loop controller design
Kt = 0.32;      % Nm/A
J = 4e-4;       % kg.m^2
B = 2e-4;       % Nm/(rad/s)
Lq = 2e-3;      % H
Rs = 1.5;       % Ohm

% Current loop (approximate)
Kpi = 10;
Kii = Kpi * Rs / Lq;
Ci = tf([Kpi, Kii], [1, 0]);
Gcurr = tf(1, [Lq, Rs]);  % simplified current plant
cl_curr = feedback(Ci*Gcurr, 1);

% Speed loop
Kpw = 1.25;
Kiw = 625;
Cw = tf([Kpw, Kiw], [1, 0]);
Gmech = tf(Kt, [J, B]);
cl_speed = feedback(Cw * cl_curr * Gmech, 1);

% Position loop
Kptheta = 50;
Gpos = tf(1, [1, 0]);
cl_pos = feedback(Kptheta * cl_speed * Gpos, 1);

figure; step(cl_pos);
title('Position Step Response'); grid on;
```

## 常见错误与纠正

### 错误 1：三环带宽倒置

**现象**：位置环响应反而比速度环快，系统震荡不稳定。

**原因**：违背了"内环带宽 > 外环带宽"的基本原则。外环控制器试图纠正内环尚未响应完的动态。

**纠正**：按 $f_{BW,current} : f_{BW,speed} : f_{BW,pos} \approx 10 : 5 : 1$ 设计。例如电流环 $5\,\text{kHz}$，速度环 $1\,\text{kHz}$，位置环 $200\,\text{Hz}$。

### 错误 2：忽略机械谐振

**现象**：速度环增益提高到一定值后，某个频率点出现剧烈振荡，频谱中有明显尖峰。

**原因**：机械传动链（联轴器、丝杠、皮带）存在柔性环节，形成谐振峰。被控对象不是纯刚性，而是：

$$
G(s) = \frac{K_t}{s(J_m s + B_m + \frac{K_{flex}(J_l s + B_l)}{s^2 + \cdots})}
$$

**纠正**：
- 降低速度环增益（牺牲带宽）
- 加入**陷波滤波器**（notch filter）抑制谐振频率
- 改用刚性联轴器或直接驱动（直驱电机）

## 自测习题

**1.** 伺服三环中，哪一环负责产生电磁转矩？哪一环保证最终位置无静差？

> 答案：电流环产生电磁转矩（$T_e = K_t i_q$）。位置环外环配合速度环积分作用保证位置无静差。

**2.** 已知电机 $K_t = 0.5 \, \text{N·m/A}$，$J = 0.001 \, \text{kg·m}^2$，$B = 0.0005 \, \text{N·m/(rad/s)}$。用对称最优法，设 $\tau_{sum} = 1 \, \text{ms}$，计算速度环 PI 参数 $K_{p\omega}$ 和 $K_{i\omega}$。

> 答案：
> $$K_{p\omega} = \frac{0.001}{2 \times 0.5 \times 0.001} = 1.0 \, \text{A·s/rad}$$
> $$K_{i\omega} = \frac{1.0}{4 \times 0.001} = 250 \, \text{A/rad}$$

**3.** 为什么位置环通常只用 P 控制，而不需要积分项？

> 答案：因为速度环 PI 控制器中的积分项，对位置误差 $e_{\theta}$ 而言相当于对速度误差 $e_{\omega} = \dot{e}_{\theta}$ 的积分。因此速度环的 I 作用已经等效为位置环的 I 作用。额外加积分会导致过积分和超调。

**4.** 某伺服系统机械谐振频率测得为 $800\,\text{Hz}$，速度环带宽设计目标为 $200\,\text{Hz}$。是否安全？如果不安全，应如何处理？

> 答案：不安全。谐振频率 $800\,\text{Hz}$ 仅比目标带宽高 4 倍，实际运行中可能因增益裕度不足激发振荡。应在速度环反馈中加入 $800\,\text{Hz}$ 陷波滤波器，或将带宽降低到 $100\,\text{Hz}$ 以下。
