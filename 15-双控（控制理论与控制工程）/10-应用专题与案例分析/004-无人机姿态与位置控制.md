# 无人机姿态与位置控制

> 四旋翼无人机是最经典的欠驱动系统：四个输入（电机转速）控制六个自由度（位置 + 姿态）。它不能独立控制所有状态，但通过巧妙的控制结构，可以实现稳定的悬停和机动飞行。

---

## 四旋翼的物理直觉

想象四个螺旋桨对称安装在十字机臂上。对角电机同向旋转，相邻电机反向旋转，抵消反扭矩。通过改变四个电机的转速，可以产生四种基本控制效应：

```
     M1(CW)        M2(CCW)
        \          /
         \   +z  /
          \  |  /
           \ | /
       y<---o--->x
           / | \
          /  |  \
         /   -z  \
        /          \
     M3(CCW)       M4(CW)
```

| 控制通道 | 动作 | 电机调节方式 |
|----------|------|-------------|
| 升力 (Thrust) | 垂直升降 | 四电机同增同减 |
| 横滚 (Roll) $\phi$ | 左右倾斜 | M1↑M3↓ 或反之 |
| 俯仰 (Pitch) $\theta$ | 前后倾斜 | M2↑M4↓ 或反之 |
| 偏航 (Yaw) $\psi$ | 水平旋转 | CW↑CCW↓（利用反扭矩差） |

## 刚体动力学模型

### 平移运动

在惯性系（地球坐标系）下，位置 $\mathbf{p} = [x, y, z]^T$ 的运动方程：

$$
m \ddot{\mathbf{p}} = m \mathbf{g} + \mathbf{R}_{IB} \begin{bmatrix} 0 \\ 0 \\ -T \end{bmatrix} - \mathbf{D}
$$

其中：
- $m$：机体质量
- $\mathbf{g} = [0, 0, g]^T$：重力加速度
- $T$：四个螺旋桨总拉力
- $\mathbf{R}_{IB}$：从机体坐标系到惯性系的旋转矩阵
- $\mathbf{D}$：空气阻力（通常建模为与速度成正比）

关键观察：**平移加速度由姿态决定**。拉力矢量始终沿机体 $z$ 轴向下，要往前飞，必须先俯倾，让拉力有向前的分量。

### 旋转运动

在机体坐标系下，角速度 $\boldsymbol{\omega} = [p, q, r]^T$ 的欧拉方程：

$$
\mathbf{I} \dot{\boldsymbol{\omega}} + \boldsymbol{\omega} \times \mathbf{I}\boldsymbol{\omega} = \boldsymbol{\tau}
$$

其中 $\mathbf{I} = \text{diag}(I_{xx}, I_{yy}, I_{zz})$ 为惯性张量，$\boldsymbol{\tau} = [\tau_x, \tau_y, \tau_z]^T$ 为电机产生的三轴力矩。

对于对称四旋翼（$I_{xx} = I_{yy}$），展开得：

$$
I_{xx} \dot{p} + (I_{zz} - I_{yy}) q r = \tau_x
$$

$$
I_{yy} \dot{q} + (I_{xx} - I_{zz}) p r = \tau_y
$$

$$
I_{zz} \dot{r} + (I_{yy} - I_{xx}) p q = \tau_z
$$

### 数值示例

某小型四旋翼参数：

| 参数 | 符号 | 数值 | 单位 |
|------|------|------|------|
| 质量 | $m$ | 1.5 | kg |
| 机臂长度 | $l$ | 0.25 | m |
| $x$ 轴惯量 | $I_{xx}$ | 0.03 | kg·m² |
| $y$ 轴惯量 | $I_{yy}$ | 0.03 | kg·m² |
| $z$ 轴惯量 | $I_{zz}$ | 0.05 | kg·m² |
| 拉力系数 | $k_T$ | $1.2 \times 10^{-5}$ | N/(rad/s)² |
| 力矩系数 | $k_M$ | $2.5 \times 10^{-7}$ | N·m/(rad/s)² |

悬停时每个电机转速：

$$
4 k_T \omega_0^2 = m g \implies \omega_0 = \sqrt{\frac{m g}{4 k_T}} = \sqrt{\frac{1.5 \times 9.81}{4 \times 1.2 \times 10^{-5}}} \approx 555\,\text{rad/s} \approx 5300\,\text{RPM}
$$

## 控制架构：串级 PID

四旋翼控制通常采用**位置环 → 速度环 → 姿态环 → 角速度环**的四层串级结构：

```
Position Setpoint ---->[Pos Loop]----> Velocity Setpoint
                              |
Velocity Setpoint ---->[Vel Loop]----> Attitude Setpoint (tilt angles)
                              |
Attitude Setpoint ---->[Att Loop]----> Angular Rate Setpoint
                              |
Rate Setpoint -------->[Rate Loop]----> Motor Commands
```

### 最内环：角速度环

角速度环直接控制电机响应，带宽最高（$50 \sim 100\,\text{Hz}$）。由于机体动力学在小角度近似下近似解耦，每个轴独立使用 PID：

$$
\tau_x = K_{p,p} (p_d - p) + K_{i,p} \int (p_d - p) dt + K_{d,p} \frac{d}{dt}(p_d - p)
$$

小角度下，陀螺仪直接测量 $p, q, r$，无需额外估计。

### 姿态环

姿态环接收期望姿态角 $\phi_d, \theta_d, \psi_d$，输出期望角速度。由于姿态角与角速度的关系为：

$$
\begin{bmatrix} \dot{\phi} \\ \dot{\theta} \\ \dot{\psi} \end{bmatrix} = \begin{bmatrix} 1 & \sin\phi \tan\theta & \cos\phi \tan\theta \\ 0 & \cos\phi & -\sin\phi \\ 0 & \sin\phi / \cos\theta & \cos\phi / \cos\theta \end{bmatrix} \begin{bmatrix} p \\ q \\ r \end{bmatrix}
$$

在小角度假设下（$\phi, \theta \ll 1$），简化为 $\dot{\phi} \approx p$，$\dot{\theta} \approx q$，$\dot{\psi} \approx r$。姿态环因此也近似解耦，可用独立 P 控制：

$$
p_d = K_{p,\phi} (\phi_d - \phi), \quad q_d = K_{p,\theta} (\theta_d - \theta), \quad r_d = K_{p,\psi} (\psi_d - \psi)
$$

### 位置与速度环

位置环输出期望速度，速度环输出期望姿态角（注意：速度控制通过倾斜实现，不是直接力控制）。

水平速度到姿态角的映射：

$$
\theta_d = \arctan\left(\frac{\dot{x}_d}{g}\right), \quad \phi_d = -\arctan\left(\frac{\dot{y}_d}{g}\right)
$$

这来自平移方程的稳态假设：$\ddot{x} = g \tan\theta$，当 $\ddot{x} = \dot{x}_d$ 很小时，$\theta_d \approx \dot{x}_d / g$。

## 姿态估计：互补滤波

### 问题

无人机需要实时知道 $\phi, \theta, \psi$，但：
- **加速度计**：静态时测重力方向可算姿态，但动态时受振动和加速度干扰
- **陀螺仪**：积分角速度得姿态，但存在零偏漂移

### 互补滤波思想

让加速度计提供**低频准确**的姿态参考，陀螺仪提供**高频快速**的变化率，二者互补：

```
Accel --->[Low-pass]---+---> Attitude Estimate
                       |
Gyro  --->[Integrator]-+-->[High-pass]---+
```

数学表达（一阶互补滤波）：

$$
\hat{\theta}(s) = \frac{1}{\tau s + 1} \theta_{accel}(s) + \frac{\tau s}{\tau s + 1} \frac{\omega_y(s)}{s}
$$

离散实现：

```c
/* First-order complementary filter for pitch angle */
#define TAU         0.05f   /* time constant in seconds */
#define DT          0.001f  /* sampling period */
#define ALPHA       (TAU / (TAU + DT))  /* ~0.98 */

float comp_filter_pitch(float gyro_y, float accel_x, float accel_z, float theta_prev) {
    /* Gyro integration */
    float theta_gyro = theta_prev + gyro_y * DT;
    
    /* Accel angle (small angle approx) */
    float theta_accel = atan2f(-accel_x, accel_z);
    
    /* Complementary fusion */
    float theta = ALPHA * theta_gyro + (1.0f - ALPHA) * theta_accel;
    return theta;
}
```

### 为什么是互补的？

- $\tau$ 大（$\alpha \to 1$）：更信任陀螺，快速响应但会漂移
- $\tau$ 小（$\alpha \to 0$）：更信任加速度计，无漂移但受振动影响
- 典型值 $\tau = 0.05 \sim 0.1\,\text{s}$，对应截止频率 $f_c = 1/(2\pi\tau) \approx 1.6 \sim 3.2\,\text{Hz}$

## 常见错误与纠正

### 错误 1：忽视偏航角的控制特殊性

**现象**：无人机悬停时缓慢自旋，偏航控制几乎无效。

**原因**：偏航力矩来自四个电机反扭矩之差，而反扭矩通常只有拉力的 $1/20 \sim 1/50$。偏航通道的"控制 authority"很弱。更严重的是，当电机接近饱和时，偏航控制最先失效。

**纠正**：
- 偏航 PID 积分增益要足够大（因为静差容忍度低）
- 在电机指令分配时预留偏航控制余量
- 考虑主动偏航阻尼（如尾翼、共轴双桨）

### 错误 2：用原始加速度计直接算姿态，不做振动滤波

**现象**：无人机在悬停时姿态估计剧烈抖动，导致电机嗡嗡作响，甚至发散坠毁。

**原因**：旋翼振动频率通常在 $100 \sim 500\,\text{Hz}$，远超姿态动态。加速度计不加低通滤波直接用于姿态计算，会把振动误认为姿态变化。

**纠正**：
- 加速度计信号必须经过硬件/软件低通滤波（截止频率 $10 \sim 30\,\text{Hz}$）
- 减震垫物理隔离高频振动
- 互补滤波器中的 $\tau$ 不能选太小，否则会引入振动

## 自测习题

**1.** 四旋翼质量 $m = 2.0\,\text{kg}$，拉力系数 $k_T = 1.5 \times 10^{-5}\,\text{N/(rad/s)}^2$。计算悬停时单个电机的转速（RPM）。

> 答案：
> $$\omega_0 = \sqrt{\frac{2.0 \times 9.81}{4 \times 1.5 \times 10^{-5}}} = \sqrt{327000} \approx 572\,\text{rad/s}$$
> $$\text{RPM} = \frac{572 \times 60}{2\pi} \approx 5460\,\text{RPM}$$

**2.** 若希望无人机以水平加速度 $a_x = 2\,\text{m/s}^2$ 前飞，需要的俯仰角 $\theta$ 是多少？（假设小角度）

> 答案：
> $$\theta \approx \frac{a_x}{g} = \frac{2}{9.81} \approx 0.204\,\text{rad} \approx 11.7°$$
> 注：实际 $\theta = \arctan(a_x/g) = 11.5°$，小角度近似误差约 2%。

**3.** 互补滤波器参数 $\tau = 0.05\,\text{s}$，采样周期 $T_s = 1\,\text{ms}$。计算 $\alpha$ 值，并解释在 $1\,\text{Hz}$ 和 $100\,\text{Hz}$ 扰动下，滤波器分别信任哪个传感器。

> 答案：
> $$\alpha = \frac{0.05}{0.05 + 0.001} = 0.98$$
> - $1\,\text{Hz}$：低于截止频率 $f_c = 3.18\,\text{Hz}$，信任加速度计（低频通道）
> - $100\,\text{Hz}$：远高于截止频率，信任陀螺仪（高频通道）

**4.** 为什么四旋翼是"欠驱动"系统？它能否原地侧向平移而不改变姿态？

> 答案：四旋翼有 4 个独立输入（电机转速）但 6 个自由度（3 位置 + 3 姿态），自由度 > 输入数，故为欠驱动。它**不能**在不改变姿态的情况下侧向平移——侧向加速度必须通过倾斜拉力矢量获得，这是欠驱动的本质特征。
