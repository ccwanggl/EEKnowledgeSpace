# 机器人运动控制

> 机器人控制的核心矛盾是：**任务在笛卡尔空间（末端位置/姿态），但执行器在关节空间（电机角度）**。控制理论的价值，在于用系统化的方法弥合这一鸿沟。

---

## 机器人运动控制的层次结构

```
+-------------------+
| 任务规划 (Task)    |  "把杯子从A拿到B"
+-------------------+
         |
         v
+-------------------+
| 路径规划 (Path)    |  避开障碍的3D轨迹
+-------------------+
         |
         v
+-------------------+
| 轨迹生成 (Trajectory)| 带时间参数的位置/速度/加速度
+-------------------+
         |
         v
+-------------------+
| 运动学/动力学控制   |  逆运动学 + 关节伺服
+-------------------+
         |
         v
+-------------------+
| 关节伺服 (Servo)   |  三环PID/力矩控制
+-------------------+
```

本章聚焦**轨迹生成 → 运动学/动力学控制**两层。

---

## 关节空间 vs 笛卡尔空间控制

| 控制空间 | 优点 | 缺点 | 适用场景 |
|----------|------|------|----------|
| 关节空间 | 计算快、无奇异性问题 | 末端轨迹不直观 | 点对点定位（PTP） |
| 笛卡尔空间 | 直接控制末端轨迹 | 需实时逆运动学、可能遇奇异 | 弧焊、喷涂、装配 |

### 直觉理解

关节空间控制像"让每个关节各自转到位"；笛卡尔空间控制像"直接指挥手末端走到某处"。前者简单但末端走的是不可预测的曲线，后者直观但计算复杂。

## 轨迹规划：从点到轨迹

### 多项式插值

给定起点 $\theta_0$、终点 $\theta_f$、运动时间 $t_f$，最常用的是**五次多项式**：

$$
\theta(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3 + a_4 t^4 + a_5 t^5
$$

边界条件：
- 位置：$\theta(0) = \theta_0$，$\theta(t_f) = \theta_f$
- 速度：$\dot{\theta}(0) = 0$，$\dot{\theta}(t_f) = 0$
- 加速度：$\ddot{\theta}(0) = 0$，$\ddot{\theta}(t_f) = 0$

解得：

$$
a_0 = \theta_0, \quad a_1 = a_2 = 0
$$

$$
a_3 = \frac{10(\theta_f - \theta_0)}{t_f^3}, \quad a_4 = \frac{-15(\theta_f - \theta_0)}{t_f^4}, \quad a_5 = \frac{6(\theta_f - \theta_0)}{t_f^5}
$$

### 数值示例

单关节从 $\theta_0 = 0°$ 运动到 $\theta_f = 90°$（$= \pi/2 \, \text{rad}$），$t_f = 2\,\text{s}$：

$$
a_0 = 0, \quad a_3 = \frac{10 \times \pi/2}{8} = 1.96, \quad a_4 = \frac{-15 \times \pi/2}{16} = -1.47, \quad a_5 = \frac{6 \times \pi/2}{32} = 0.295
$$

最大速度出现在 $t = t_f/2 = 1\,\text{s}$：

$$
\dot{\theta}(1) = 3a_3(1)^2 + 4a_4(1)^3 + 5a_5(1)^4 = 5.89 - 5.89 + 1.47 = 1.47\,\text{rad/s}
$$

最大加速度出现在 $t = 0.21t_f$ 和 $t = 0.79t_f$（数值求解），约为 $\pm 3.5\,\text{rad/s}^2$。

## 逆运动学（IK）

### 问题定义

已知末端执行器位姿 $(x, y, z, \alpha, \beta, \gamma)$，求关节角 $\mathbf{q} = [q_1, q_2, \ldots, q_n]^T$。

### 两连杆平面臂的解析解

```
    (x2, y2)  <-- end effector
       |
      L2
       |
    (x1, y1)
       |
      L1
       |
     (0, 0)  <-- base
```

正向运动学：

$$
x = L_1 \cos q_1 + L_2 \cos(q_1 + q_2)
$$

$$
y = L_1 \sin q_1 + L_2 \sin(q_1 + q_2)
$$

逆运动学解析解：

$$
c_2 = \frac{x^2 + y^2 - L_1^2 - L_2^2}{2 L_1 L_2}
$$

$$
s_2 = \pm \sqrt{1 - c_2^2}
$$

$$
q_2 = \text{atan2}(s_2, c_2)
$$

$$
q_1 = \text{atan2}(y, x) - \text{atan2}(L_2 s_2, L_1 + L_2 c_2)
$$

### 数值示例

设 $L_1 = 1.0\,\text{m}$，$L_2 = 0.8\,\text{m}$，目标点 $(x, y) = (1.2, 0.6)$：

$$
c_2 = \frac{1.44 + 0.36 - 1 - 0.64}{2 \times 1 \times 0.8} = \frac{0.16}{1.6} = 0.1
$$

$$
s_2 = \sqrt{1 - 0.01} = \pm 0.995
$$

取 elbow-down 解（$s_2 > 0$）：

$$
q_2 = \text{atan2}(0.995, 0.1) = 1.47\,\text{rad} \approx 84.3°
$$

$$
q_1 = \text{atan2}(0.6, 1.2) - \text{atan2}(0.8 \times 0.995, 1 + 0.8 \times 0.1) = 0.464 - 0.665 = -0.20\,\text{rad} \approx -11.5°
$$

## 动力学模型与计算力矩控制

### 拉格朗日方程

机器人动力学的一般形式：

$$
\mathbf{M}(\mathbf{q}) \ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q}, \dot{\mathbf{q}}) \dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) = \boldsymbol{\tau}
$$

其中：
- $\mathbf{M}(\mathbf{q})$：$n \times n$ 质量矩阵（正定）
- $\mathbf{C}(\mathbf{q}, \dot{\mathbf{q}})$：科氏力和离心力项
- $\mathbf{g}(\mathbf{q})$：重力项
- $\boldsymbol{\tau}$：关节驱动力矩

### 计算力矩控制（Computed Torque）

核心思想：**用模型抵消非线性，把系统线性化为双积分器**。

设期望轨迹为 $\mathbf{q}_d(t)$，定义控制律：

$$
\boldsymbol{\tau} = \mathbf{M}(\mathbf{q}) \left( \ddot{\mathbf{q}}_d + \mathbf{K}_v \dot{\mathbf{e}} + \mathbf{K}_p \mathbf{e} \right) + \mathbf{C}(\mathbf{q}, \dot{\mathbf{q}}) \dot{\mathbf{q}} + \mathbf{g}(\mathbf{q})
$$

其中 $\mathbf{e} = \mathbf{q}_d - \mathbf{q}$ 为跟踪误差。

代入动力学方程，得到误差动力学：

$$
\ddot{\mathbf{e}} + \mathbf{K}_v \dot{\mathbf{e}} + \mathbf{K}_p \mathbf{e} = 0
$$

若 $\mathbf{K}_p$ 和 $\mathbf{K}_v$ 为正定对角阵，误差指数收敛到零。

## Python 实现：两连杆臂轨迹跟踪

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# Two-link planar arm parameters
L1, L2 = 1.0, 0.8
m1, m2 = 2.0, 1.5
g = 9.81

def forward_kin(q):
    """Forward kinematics: q=[q1,q2] -> (x,y)"""
    q1, q2 = q
    x = L1*np.cos(q1) + L2*np.cos(q1+q2)
    y = L1*np.sin(q1) + L2*np.sin(q1+q2)
    return np.array([x, y])

def inverse_kin(x, y, elbow_down=True):
    """Analytical inverse kinematics"""
    c2 = (x**2 + y**2 - L1**2 - L2**2) / (2*L1*L2)
    if abs(c2) > 1:
        return None  # unreachable
    s2 = np.sqrt(1 - c2**2) if elbow_down else -np.sqrt(1 - c2**2)
    q2 = np.arctan2(s2, c2)
    q1 = np.arctan2(y, x) - np.arctan2(L2*s2, L1 + L2*c2)
    return np.array([q1, q2])

def dynamics(qdq, t, tau_func):
    """Robot dynamics: state=[q1,q2,dq1,dq2]"""
    q = qdq[:2]
    dq = qdq[2:]
    q1, q2 = q
    dq1, dq2 = dq
    
    # Mass matrix M(q)
    M11 = (m1+m2)*L1**2 + m2*L2**2 + 2*m2*L1*L2*np.cos(q2)
    M12 = m2*L2**2 + m2*L1*L2*np.cos(q2)
    M22 = m2*L2**2
    M = np.array([[M11, M12],[M12, M22]])
    
    # Coriolis C(q,dq)*dq
    h = -m2*L1*L2*np.sin(q2)
    C = np.array([[h*dq2, h*(dq1+dq2)],[-h*dq1, 0]])
    
    # Gravity g(q)
    g1 = (m1+m2)*g*L1*np.cos(q1) + m2*g*L2*np.cos(q1+q2)
    g2 = m2*g*L2*np.cos(q1+q2)
    G = np.array([g1, g2])
    
    tau = tau_func(q, dq, t)
    ddq = np.linalg.solve(M, tau - C@dq - G)
    return np.concatenate([dq, ddq])

# Trajectory: circle in task space
def desired_traj(t):
    """Desired end-effector trajectory: circle"""
    cx, cy = 1.0, 0.5
    r = 0.3
    omega = 1.0
    x_d = cx + r*np.cos(omega*t)
    y_d = cy + r*np.sin(omega*t)
    return np.array([x_d, y_d])

# Computed torque controller
Kp = np.diag([100, 100])
Kv = np.diag([20, 20])

def computed_torque(q, dq, t):
    """Computed torque control law"""
    # Get desired joint trajectory (via IK)
    pd = desired_traj(t)
    qd = inverse_kin(pd[0], pd[1])
    if qd is None:
        qd = q  # fallback
    
    # Numerical differentiation for desired velocity/acceleration
    dt = 1e-3
    pd_next = desired_traj(t+dt)
    qd_next = inverse_kin(pd_next[0], pd_next[1])
    if qd_next is None:
        qd_next = qd
    dqd = (qd_next - qd) / dt
    ddqd = np.zeros(2)  # simplified
    
    e = qd - q
    de = dqd - dq
    
    # Feedforward + PD
    tau = M_of_q(q) @ (ddqd + Kv@de + Kp@e) + C_of_q(q,dq)@dq + G_of_q(q)
    return tau

# Helper functions for M, C, G (same as in dynamics)
def M_of_q(q):
    q1, q2 = q
    M11 = (m1+m2)*L1**2 + m2*L2**2 + 2*m2*L1*L2*np.cos(q2)
    M12 = m2*L2**2 + m2*L1*L2*np.cos(q2)
    return np.array([[M11, M12],[M12, m2*L2**2]])

def C_of_q(q, dq):
    q1, q2 = q
    dq1, dq2 = dq
    h = -m2*L1*L2*np.sin(q2)
    return np.array([[h*dq2, h*(dq1+dq2)],[-h*dq1, 0]])

def G_of_q(q):
    q1, q2 = q
    g1 = (m1+m2)*g*L1*np.cos(q1) + m2*g*L2*np.cos(q1+q2)
    g2 = m2*g*L2*np.cos(q1+q2)
    return np.array([g1, g2])

# Simulation
t = np.linspace(0, 10, 1000)
q0 = np.array([0.5, 0.5, 0, 0])  # initial state
sol = odeint(dynamics, q0, t, args=(computed_torque,))

# Plot end-effector trajectory
x_traj = [forward_kin(s[:2])[0] for s in sol]
y_traj = [forward_kin(s[:2])[1] for s in sol]
plt.plot(x_traj, y_traj, label='Actual')
plt.plot(1.0+0.3*np.cos(t), 0.5+0.3*np.sin(t), '--', label='Desired')
plt.axis('equal'); plt.legend(); plt.title('End-Effector Tracking')
plt.show()
```

## 常见错误与纠正

### 错误 1：忽略奇异位形

**现象**：机器人在某个姿态附近，关节速度指令突然变得极大，甚至溢出。

**原因**：逆运动学在**奇异位形**（如两连杆完全伸直或折叠）处，雅可比矩阵 $J$ 降秩，$\dot{\mathbf{q}} = J^{-1} \dot{\mathbf{x}}$ 的数值解发散。

**纠正**：
- 在奇异点附近改用**阻尼最小二乘（Damped Least Squares）**：$\dot{\mathbf{q}} = J^T (J J^T + \lambda^2 I)^{-1} \dot{\mathbf{x}}$
- 规划轨迹时避开奇异位形
- 对关节速度做限幅

### 错误 2：用独立关节 PID 控制多连杆臂

**现象**：各关节单独用 PID 伺服到目标角度，但末端轨迹严重偏离期望，尤其是在高速运动时。

**原因**：独立关节 PID 忽略了**耦合动力学**。连杆 2 的运动会带动连杆 1 受到科氏力和离心力，独立 PID 将其视为外部扰动被动补偿，无法主动抵消。

**纠正**：采用**计算力矩控制**或**前馈补偿**。至少在每个关节加入重力补偿项 $g_i(q)$，高速应用必须加入 $\mathbf{M}(\mathbf{q})$ 和 $\mathbf{C}(\mathbf{q}, \dot{\mathbf{q}})$。

## 自测习题

**1.** 单关节五次多项式轨迹，从 $0°$ 到 $180°$（$\pi\,\text{rad}$），$t_f = 3\,\text{s}$。求 $a_3, a_4, a_5$，并计算 $t = 1.5\,\text{s}$ 时的速度和加速度。

> 答案：
> $$a_3 = \frac{10\pi}{27} \approx 1.16, \quad a_4 = \frac{-15\pi}{81} \approx -0.582, \quad a_5 = \frac{6\pi}{243} \approx 0.0776$$
> $$\dot{\theta}(1.5) = 3a_3(1.5)^2 + 4a_4(1.5)^3 + 5a_5(1.5)^4 = 7.83 - 5.87 + 1.96 = 1.57\,\text{rad/s}$$
> $$\ddot{\theta}(1.5) = 6a_3(1.5) + 12a_4(1.5)^2 + 20a_5(1.5)^3 = 10.47 - 15.72 + 7.83 = 2.09\,\text{rad/s}^2$$

**2.** 两连杆臂 $L_1 = L_2 = 1.0\,\text{m}$，目标点 $(0, 1.5)$。是否存在解析解？为什么？

> 答案：不存在。最大可达距离为 $L_1 + L_2 = 2.0\,\text{m}$，最小为 $|L_1 - L_2| = 0$。虽然 $1.5 < 2.0$ 看似可达，但 $c_2 = (2.25 - 2)/2 = 0.125$，$|c_2| \le 1$，数学上有解。然而需要检查具体数值：
> $$c_2 = 0.125, \quad s_2 = \pm 0.992$$
> 存在两组解，工作空间内可达。若目标点为 $(0, 2.1)$，则不可达。

**3.** 计算力矩控制中，若质量矩阵 $\mathbf{M}(\mathbf{q})$ 建模存在 $20\%$ 误差，闭环误差动力学还是 $ \ddot{\mathbf{e}} + \mathbf{K}_v \dot{\mathbf{e}} + \mathbf{K}_p \mathbf{e} = 0 $ 吗？

> 答案：不是。实际闭环为 $\ddot{\mathbf{e}} + \mathbf{K}_v \dot{\mathbf{e}} + \mathbf{K}_p \mathbf{e} = \mathbf{M}^{-1} \Delta\mathbf{M} (\ddot{\mathbf{q}}_d + \mathbf{K}_v \dot{\mathbf{e}} + \mathbf{K}_p \mathbf{e})$，存在残余耦合。但若 $\Delta\mathbf{M}$ 不大且 $K_p, K_v$ 足够大，系统仍可稳定。更严格的方法是自适应控制或鲁棒控制。

**4.** 为什么高速机器人必须考虑科氏力 $\mathbf{C}(\mathbf{q}, \dot{\mathbf{q}})$？用直觉解释。

> 答案：科氏力产生于转动坐标系中的直线运动。想象你站在旋转的圆盘上扔球，球会偏转。机器人关节 2 转动时，连杆 2 的质心相对连杆 1 做"直线"运动（在连杆 1 坐标系中），但连杆 1 本身在转动，因此产生科氏力反作用于关节 1。高速时此力显著，独立 PID 无法预见和抵消。
