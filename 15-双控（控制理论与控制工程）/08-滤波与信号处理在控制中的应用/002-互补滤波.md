# 互补滤波

> 互补滤波是工程实践中最具性价比的多传感器融合方案。它不需要矩阵求逆、不需要噪声统计模型、计算量极小——却能在一阶近似的框架下给出令人惊讶的好结果。理解互补滤波，是理解"频域分工"这一核心思想的绝佳入口。

---

## 1. 互补滤波的起源：一个工程直觉

### 1.1 IMU 的经典困境

在姿态估计中，两类传感器各有优劣：

| 传感器 | 低频特性 | 高频特性 | 噪声特性 |
|-------|---------|---------|---------|
| 加速度计 | 准（可测重力方向） | 差（受振动干扰） | 高频噪声 |
| 陀螺仪 | 差（积分漂移） | 准（直接测角速度） | 低频漂移 |

如果把它们的频域特性画出来：

```
可信度
  ^
  |  陀螺仪可信度高 .........       ...................
  |  (低漂移区)       .       .   (高带宽区)
  |                   .       .
  |                   .       .
  |  加速度计可信度高 ..       .......................
  |  (静态准确)       .       .   (振动干扰区)
  |                   .       .
  +-------------------+-------+---------------------> 频率
                     fc      
                   (截止频率)
```

**核心洞察**：在低频段相信加速度计（无漂移），在高频段相信陀螺仪（响应快）。两者互补，各取所长。

## 2. 一阶互补滤波器的数学推导

### 2.1 频域互补分解

设待估计量为 $\theta$（如俯仰角）。定义两个传感器的输出：

- 加速度计：直接测量角度，但受高频噪声 $n_a$ 污染：$\theta_a = \theta + n_a$
- 陀螺仪：测量角速度 $\dot{\theta}_g = \dot{\theta} + b_g + n_g$，其中 $b_g$ 为缓慢变化的零偏漂移

互补滤波器的设计目标：用低通滤波器 $G_{LP}(s)$ 提取加速度计的低频分量，用高通滤波器 $G_{HP}(s)$ 提取陀螺仪积分后的高频分量，且满足：

$$
G_{LP}(s) + G_{HP}(s) = 1
$$

选择最简单的一阶低通：

$$
G_{LP}(s) = \frac{\alpha}{s + \alpha}
$$

则对应的高通为：

$$
G_{HP}(s) = 1 - G_{LP}(s) = \frac{s}{s + \alpha}
$$

### 2.2 时域实现

滤波器输出：

$$
\hat{\theta}(s) = G_{LP}(s) \cdot \theta_a(s) + G_{HP}(s) \cdot \frac{\dot{\theta}_g(s)}{s}
$$

注意 $\dot{\theta}_g$ 积分后进入高通路径。展开：

$$
\hat{\theta}(s) = \frac{\alpha}{s + \alpha}\theta_a(s) + \frac{s}{s + \alpha} \cdot \frac{\dot{\theta}_g(s)}{s} = \frac{\alpha \theta_a(s) + \dot{\theta}_g(s)}{s + \alpha}
$$

交叉相乘得到微分方程：

$$
s\hat{\theta}(s) + \alpha\hat{\theta}(s) = \alpha\theta_a(s) + \dot{\theta}_g(s)
$$

转换为时域：

$$
\dot{\hat{\theta}} + \alpha\hat{\theta} = \alpha\theta_a + \dot{\theta}_g
$$

整理为误差反馈形式：

$$
\dot{\hat{\theta}} = \dot{\theta}_g + \alpha(\theta_a - \hat{\theta})
$$

**这就是一阶互补滤波器的标准形式**——它本质上是一个 PI 控制器：陀螺仪提供"微分项"（开环积分），加速度计提供"反馈校正项"。

### 2.3 离散化实现

使用欧拉前向离散化 $s \approx \frac{1 - z^{-1}}{T_s}$：

$$
\hat{\theta}_k = \hat{\theta}_{k-1} + T_s \left[\dot{\theta}_{g,k} + \alpha(\theta_{a,k} - \hat{\theta}_{k-1})\right]
$$

令 $\gamma = \alpha T_s$（通常取 $0.01 \sim 0.1$），则：

$$
\hat{\theta}_k = (1 - \gamma)\hat{\theta}_{k-1} + \gamma\theta_{a,k} + T_s \dot{\theta}_{g,k}
$$

```c
/* First-order complementary filter for pitch angle estimation */
float complementary_filter_1st(float theta_est_prev,
                                float accel_theta,
                                float gyro_rate,
                                float gamma,
                                float Ts)
{
    /* gamma: trust weight on accelerometer (typical 0.02 ~ 0.05) */
    float theta_est;
    theta_est = (1.0f - gamma) * theta_est_prev
                + gamma * accel_theta
                + Ts * gyro_rate;
    return theta_est;
}
```

## 3. 二阶互补滤波：在线估计陀螺漂移

### 3.1 问题动机

一阶互补滤波假设陀螺仪的零偏 $b_g$ 已知或很小。实际中，$b_g$ 随温度变化缓慢漂移。若不对其补偿，角度估计最终仍会发散。

### 3.2 增广状态设计

将陀螺零偏 $b_g$ 作为待估计的附加状态：

$$
\begin{bmatrix} \dot{\hat{\theta}} \\ \dot{\hat{b}}_g \end{bmatrix} = \begin{bmatrix} 0 & -1 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} \hat{\theta} \\ \hat{b}_g \end{bmatrix} + \begin{bmatrix} 1 \\ 0 \end{bmatrix}\dot{\theta}_g + \begin{bmatrix} K_p \\ K_i \end{bmatrix}(\theta_a - \hat{\theta})
$$

这正是一个**PI 控制器结构**：
- $K_p$：比例增益，校正角度误差
- $K_i$：积分增益，估计并补偿陀螺漂移

### 3.3 C 实现

```c
typedef struct {
    float theta;    /* estimated angle [rad] */
    float bias;     /* estimated gyro bias [rad/s] */
    float Kp;       /* proportional gain */
    float Ki;       /* integral gain */
} ComplementaryFilter2nd;

void cf2_init(ComplementaryFilter2nd* cf, float Kp, float Ki)
{
    cf->theta = 0.0f;
    cf->bias = 0.0f;
    cf->Kp = Kp;
    cf->Ki = Ki;
}

float cf2_update(ComplementaryFilter2nd* cf,
                  float accel_theta,
                  float gyro_rate,
                  float Ts)
{
    float error = accel_theta - cf->theta;
    
    /* Integrate bias estimate */
    cf->bias += cf->Ki * error * Ts;
    
    /* Rate = gyro - bias + proportional correction */
    float rate = gyro_rate - cf->bias + cf->Kp * error;
    
    /* Integrate angle */
    cf->theta += rate * Ts;
    
    return cf->theta;
}
```

### 3.4 与卡尔曼滤波的关系

二阶互补滤波器的误差动态方程可以写成状态空间形式，其结构与稳态卡尔曼滤波器等价。二者的对应关系：

| 互补滤波参数 | 卡尔曼滤波对应量 |
|------------|---------------|
| $K_p$ | 与加速度计噪声协方差 $R$ 相关 |
| $K_i$ | 与陀螺零偏过程噪声 $Q_b$ 相关 |

**本质**：互补滤波是卡尔曼滤波在特定简化假设下的**稳态近似**。当噪声统计特性不精确已知时，互补滤波用两个手动调参 $K_p, K_i$ 替代了完整的 Riccati 方程求解。

## 4. 数值示例

### 4.1 参数设计

设计一个用于四旋翼飞行器的俯仰角互补滤波器：

| 参数 | 值 | 说明 |
|-----|-----|-----|
| $T_s$ | $2\,\text{ms}$ | 采样周期（500 Hz IMU） |
| $\alpha$ | $20\,\text{rad/s}$ | 截止频率对应 $\approx 3.2\,\text{Hz}$ |
| $\gamma = \alpha T_s$ | $0.04$ | 加速度计信任权重 |

选择 $":K_p = 2\zeta\omega_n = 2 \times 0.707 \times 15 \approx 21.2$，$K_i = \omega_n^2 = 225$。

### 4.2 MATLAB 仿真

```matlab
% Complementary filter simulation for attitude estimation
Ts = 0.002;             % sample time [s]
N = 5000;               % number of samples
t = (0:N-1)*Ts;

% True signal: sinusoidal pitch angle
f_sig = 0.5;            % signal frequency [Hz]
theta_true = 0.3 * sin(2*pi*f_sig*t);
omega_true = 0.3 * 2*pi*f_sig * cos(2*pi*f_sig*t);

% Sensor models
noise_acc = 0.02;       % accelerometer noise [rad]
bias_gyro = 0.05;       % gyro bias [rad/s]
noise_gyro = 0.01;      % gyro noise [rad/s]

theta_acc = theta_true + noise_acc*randn(1,N);
omega_gyro = omega_true + bias_gyro + noise_gyro*randn(1,N);

% 1st-order complementary filter
gamma = 0.04;
theta_est_1st = zeros(1,N);
for k = 2:N
    theta_est_1st(k) = (1-gamma)*theta_est_1st(k-1) ...
                       + gamma*theta_acc(k) ...
                       + Ts*omega_gyro(k);
end

% 2nd-order complementary filter
Kp = 21.2;
Ki = 225;
theta_est_2nd = zeros(1,N);
bias_est = zeros(1,N);
for k = 2:N
    error = theta_acc(k) - theta_est_2nd(k-1);
    bias_est(k) = bias_est(k-1) + Ki*error*Ts;
    rate = omega_gyro(k) - bias_est(k) + Kp*error;
    theta_est_2nd(k) = theta_est_2nd(k-1) + rate*Ts;
end

% Plot results...
```

仿真结果预期：
- 一阶滤波器：角度跟踪良好，但存在微小漂移
- 二阶滤波器：角度跟踪良好，且零偏被在线估计补偿

## 5. 常见错误与纠正

### 错误 1：互补截止频率选择不当

**现象 A（$\alpha$ 过大 / $\gamma$ 过大）**：估计值过度受加速度计高频振动干扰，在机动或振动环境中输出剧烈抖动。

**现象 B（$\alpha$ 过小 / $\gamma$ 过小）**：估计值对加速度计响应过慢，无法快速收敛到真实角度，动态跟踪滞后严重。

**纠正方法**：
- 分析加速度计噪声频谱和陀螺仪漂移特性
- $\alpha$ 应设在两者之间：高于陀螺有效带宽、低于振动干扰主频段
- **经验法则**：对于多旋翼飞行器，$\alpha \approx 10 \sim 50\,\text{rad/s}$（对应 $1.6 \sim 8\,\text{Hz}$）是常用范围
- 实际飞行中通过阶跃响应和正弦跟踪实验迭代调整

### 错误 2：欧拉角奇异性与万向节锁

**现象**：当俯仰角接近 $\pm 90°$ 时，横滚和偏航的定义变得模糊，互补滤波器输出出现跳变或发散。

**原因**：使用欧拉角 $(\phi, \theta, \psi)$ 表示姿态时存在**万向节锁（Gimbal Lock）**——这是三维旋转用三个参数表示的固有几何限制。

**纠正方法**：
1. **四元数表示**：用四元数 $\mathbf{q} = [q_0, q_1, q_2, q_3]^T$ 替代欧拉角，四元数互补滤波器的更新方程为：

$$
\dot{\mathbf{q}} = \frac{1}{2}\boldsymbol{\Omega}(\boldsymbol{\omega})\mathbf{q}
$$

其中 $\boldsymbol{\Omega}$ 为角速度的反对称矩阵。四元数没有奇异点。

2. **方向余弦矩阵（DCM）滤波**：直接对旋转矩阵做互补滤波。

```c
/* Quaternion-based complementary filter (simplified) */
void quaternion_cf_update(float q[4], float acc[3], float gyro[3],
                          float Kp, float Ki, float Ts)
{
    /* Normalize accelerometer to get gravity direction */
    float ax = acc[0], ay = acc[1], az = acc[2];
    float norm = sqrt(ax*ax + ay*ay + az*az);
    ax /= norm; ay /= norm; az /= norm;
    
    /* Estimated gravity from quaternion */
    float gx = 2.0f*(q[1]*q[3] - q[0]*q[2]);
    float gy = 2.0f*(q[0]*q[1] + q[2]*q[3]);
    float gz = q[0]*q[0] - q[1]*q[1] - q[2]*q[2] + q[3]*q[3];
    
    /* Error is cross product between estimated and measured gravity */
    float ex = ay*gz - az*gy;
    float ey = az*gx - ax*gz;
    float ez = ax*gy - ay*gx;
    
    /* PI correction on gyro */
    static float bias[3] = {0};
    for (int i = 0; i < 3; i++) bias[i] += Ki * (&ex)[i] * Ts;
    
    float wx = gyro[0] - bias[0] + Kp * ex;
    float wy = gyro[1] - bias[1] + Kp * ey;
    float wz = gyro[2] - bias[2] + Kp * ez;
    
    /* Quaternion derivative */
    float q_dot[4];
    q_dot[0] = 0.5f * (-q[1]*wx - q[2]*wy - q[3]*wz);
    q_dot[1] = 0.5f * ( q[0]*wx - q[3]*wy + q[2]*wz);
    q_dot[2] = 0.5f * ( q[3]*wx + q[0]*wy - q[1]*wz);
    q_dot[3] = 0.5f * (-q[2]*wx + q[1]*wy + q[0]*wz);
    
    for (int i = 0; i < 4; i++) q[i] += q_dot[i] * Ts;
    
    /* Normalize */
    norm = sqrt(q[0]*q[0] + q[1]*q[1] + q[2]*q[2] + q[3]*q[3]);
    for (int i = 0; i < 4; i++) q[i] /= norm;
}
```

## 6. 自测习题

### 习题 1
一阶互补滤波器 $\dot{\hat{\theta}} = \dot{\theta}_g + \alpha(\theta_a - \hat{\theta})$。若 $":$\alpha = 10\,\text{rad/s}$，输入为 $\theta_a = 0$（无角度变化），陀螺仪存在恒定漂移 $b_g = 0.1\,\text{rad/s}$。求稳态角度估计误差 $\hat{\theta}_\infty$。

<details>
<summary>点击查看答案</summary>

稳态时 $\dot{\hat{\theta}} = 0$：

$0 = \dot{\theta}_g + \alpha(0 - \hat{\theta}_\infty)$

假设 $\dot{\theta}_g = 0 + b_g = 0.1$：

$0 = 0.1 - 10\hat{\theta}_\infty$

$\hat{\theta}_\infty = 0.01\,\text{rad} \approx 0.57°$

这就是一阶互补滤波器无法完全消除陀螺漂移的定量表现。二阶互补滤波器通过引入积分项可将此误差消除到零。

</details>

### 习题 2
二阶互补滤波器的参数 $K_p = 16$，$K_i = 100$。求其特征方程，并判断系统的阻尼比和自然频率。

<details>
<summary>点击查看答案</summary>

误差动态（令 $e = \theta - \hat{\theta}$）：

$\ddot{e} + K_p \dot{e} + K_i e = 0$

特征方程：$s^2 + K_p s + K_i = s^2 + 16s + 100 = 0$

对比标准二阶形式 $s^2 + 2\zeta\omega_n s + \omega_n^2 = 0$：

$\omega_n = \sqrt{100} = 10\,\text{rad/s}$

$2\zeta\omega_n = 16 \Rightarrow \zeta = 16/(2\times10) = 0.8$

阻尼比 $\zeta = 0.8$（略欠阻尼，响应较快且有适度超调）。

</details>

### 习题 3
在四旋翼飞行器中，为什么加速爬升时仅用加速度计估计俯仰角会出错？互补滤波器如何处理这种情况？

<details>
<summary>点击查看答案</summary>

加速度计测量的是**比力（specific force）** $\mathbf{f} = \mathbf{a} - \mathbf{g}$，而非纯重力方向。当飞行器加速时，额外的线性加速度被叠加到测量值上，导致"虚假"的重力方向估计。

互补滤波器的应对机制：
1. 加速度计仅通过低通滤波器贡献低频信息，线性加速度通常是高频或瞬态的
2. 陀螺仪通过高通路径提供高频姿态变化信息，不受线性加速度影响
3. 若长时间持续加速，一阶互补滤波仍会缓慢收敛到错误角度；二阶滤波通过 IMU 误差模型或 GPS 辅助可进一步抑制

更高级的解决方案：引入加速度计幅值检测——当 $||\mathbf{a}||$ 显著偏离 $g$ 时，临时降低 $\gamma$ 对加速度计的信任权重。

</details>
