# 卡尔曼滤波

> 卡尔曼滤波是现代控制理论中最优雅的算法之一。它的核心思想出奇的简单：每一次测量都带有不确定性，与其完全相信传感器，不如把"传感器说的"和"模型预测的"加权融合——给更可靠的一方更大的权重。这个权重是**在线自适应计算**的，不需要人工调参。

> **核心认知锚点**：卡尔曼滤波是**统一变换链在状态空间中的噪声版本**——它把 $z$ 域的系统模型（$\mathbf{x}_k = \mathbf{A}\mathbf{x}_{k-1} + \mathbf{B}\mathbf{u}_{k-1}$ 是 $H(z)$ 的时域状态实现）与最优估计理论结合，在离散时间、带噪声条件下实现了对系统状态的"最优重建"。

---

## 1. 从一个生活比喻开始

假设你蒙着眼走路，每隔几步允许你睁开眼睛看一眼周围确认位置。你有两个信息来源：

1. **你的脚底感觉**（模型预测）：根据上一步的位置和步伐长度，估计当前位置——但不准，因为每一步都可能多走或少走一点。
2. **睁开眼睛看到的**（传感器测量）：直接看到周围标志物——但也不准，因为可能有雾、眼睛可能看花。

卡尔曼滤波就是那个帮你决定"该更信脚感还是更信眼睛"的**最优融合器**。

```
+-----------+         +-----------+
|   上一步   |         |  传感器   |
|  最优估计  |         |  测量值   |
+-----+-----+         +-----+-----+
      |                     |
      v                     v
+-----+---------------------+-----+
|         卡尔曼增益 K           |
|   (决定信模型还是信测量)        |
+-----+---------------------+-----+
      |
      v
+-----+-----+
|  当前最优  |
|  状态估计  |
+-----------+
```

## 2. 问题数学建模

### 2.1 线性离散系统模型

> **与变换链的关系**：下面这组状态方程和测量方程，是**离散时间系统的时域表示**。状态转移矩阵 $\mathbf{A}$ 本质上是 $z$ 域系统函数 $H(z)$ 的**状态空间实现**（$H(z) = \mathbf{H}(z\mathbf{I} - \mathbf{A})^{-1}\mathbf{B}$），而噪声项 $\mathbf{w}_k$、$\mathbf{v}_k$ 则把"理想 $z$ 域模型"扩展为"带不确定性的真实系统"。卡尔曼滤波的任务，就是在这一不确定框架下，做最优的状态估计。

考虑一个被高斯白噪声驱动的线性离散系统：

**状态方程**（系统如何演化）：

$$
\mathbf{x}_{k} = \mathbf{A}\mathbf{x}_{k-1} + \mathbf{B}\mathbf{u}_{k-1} + \mathbf{w}_{k-1}
$$

**测量方程**（传感器看到什么）：

$$
\mathbf{z}_{k} = \mathbf{H}\mathbf{x}_{k} + \mathbf{v}_{k}
$$

其中：

| 符号 | 含义 | 维度 |
|-----|------|-----|
| $\mathbf{x}_k$ | 状态向量（待估计量） | $n \times 1$ |
| $\mathbf{u}_k$ | 控制输入 | $p \times 1$ |
| $\mathbf{z}_k$ | 测量向量 | $m \times 1$ |
| $\mathbf{A}$ | 状态转移矩阵 | $n \times n$ |
| $\mathbf{B}$ | 控制输入矩阵 | $n \times p$ |
| $\mathbf{H}$ | 观测矩阵 | $m \times n$ |
| $\mathbf{w}_k$ | 过程噪声，$\mathbf{w}_k \sim \mathcal{N}(0, \mathbf{Q})$ | $n \times 1$ |
| $\mathbf{v}_k$ | 测量噪声，$\mathbf{v}_k \sim \mathcal{N}(0, \mathbf{R})$ | $m \times 1$ |

**核心假设**：过程噪声与测量噪声均为零均值高斯白噪声，且互不相关。

### 2.2 噪声的统计特性

```
         高斯分布
           ^
  概率密度  |      ***
           |    *******    <- 大部分样本集中在均值附近
           |   *********
           |  ***********
           | *************
           +-----------------> 样本值
                 |----|
               2*sigma  (约95%概率落在此区间)
```

高斯假设的物理意义：噪声由大量独立微小扰动叠加而成，根据中心极限定理，其分布趋向高斯。这一假设使得均值和方差**完全刻画**了噪声的统计特性。

## 3. 卡尔曼滤波的五大公式

卡尔曼滤波在每个时间步 $k$ 执行两个阶段的计算：**预测（Predict）**与**更新（Update）**。

### 3.1 预测阶段（时间更新）

利用系统模型，从 $k-1$ 时刻的最优估计 $\hat{\mathbf{x}}_{k-1}^+$ 预测 $k$ 时刻的先验估计：

$$
\text{(1)} \quad \hat{\mathbf{x}}_{k}^- = \mathbf{A}\hat{\mathbf{x}}_{k-1}^+ + \mathbf{B}\mathbf{u}_{k-1}
$$

$$
\text{(2)} \quad \mathbf{P}_{k}^- = \mathbf{A}\mathbf{P}_{k-1}^+\mathbf{A}^T + \mathbf{Q}
$$

其中 $\mathbf{P}$ 为**误差协方差矩阵**，其对角线元素表示各状态估计的不确定度（方差）。

### 3.2 更新阶段（测量更新）

当新的测量 $\mathbf{z}_k$ 到达时，用其修正预测：

$$
\text{(3)} \quad \mathbf{K}_k = \mathbf{P}_k^- \mathbf{H}^T \left(\mathbf{H}\mathbf{P}_k^- \mathbf{H}^T + \mathbf{R}\right)^{-1}
$$

$$
\text{(4)} \quad \hat{\mathbf{x}}_{k}^+ = \hat{\mathbf{x}}_{k}^- + \mathbf{K}_k\left(\mathbf{z}_k - \mathbf{H}\hat{\mathbf{x}}_{k}^-\right)
$$

$$
\text{(5)} \quad \mathbf{P}_{k}^+ = \left(\mathbf{I} - \mathbf{K}_k\mathbf{H}\right)\mathbf{P}_k^-
$$

### 3.3 公式 (3) 的直觉解读：卡尔曼增益

令 $\mathbf{S} = \mathbf{H}\mathbf{P}_k^- \mathbf{H}^T + \mathbf{R}$ 为**新息协方差**（预测测量值的不确定性 + 传感器噪声的不确定性）。

考察两个极端情况：

| 场景 | 物理含义 | 卡尔曼增益 $\mathbf{K}$ | 结果 |
|-----|---------|----------------------|-----|
| $\mathbf{R} \to 0$（传感器极准） | 测量几乎无噪声 | $\mathbf{K} \to \mathbf{H}^{-1}$ | 完全相信测量：$\hat{\mathbf{x}}^+ = \mathbf{H}^{-1}\mathbf{z}$ |
| $\mathbf{P}^- \to 0$（模型极准） | 预测几乎无误差 | $\mathbf{K} \to \mathbf{0}$ | 完全相信模型：$\hat{\mathbf{x}}^+ = \hat{\mathbf{x}}^-$ |

一般情况：$\mathbf{K}$ 在两者之间连续变化，**自动完成最优加权**。这是卡尔曼滤波最优美的性质——无需手动调参。

## 4. 完整数值示例：一维匀加速运动估计

### 4.1 问题设定

一辆小车沿直线运动，状态为位置和速度：$\mathbf{x} = \begin{bmatrix} p \\ v \end{bmatrix}$。有加速度输入 $u = a$，位置传感器有噪声。

**状态转移**（采样周期 $T_s = 0.1\,\text{s}$）：

$$
\mathbf{A} = \begin{bmatrix} 1 & T_s \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} 1 & 0.1 \\ 0 & 1 \end{bmatrix}, \quad
\mathbf{B} = \begin{bmatrix} \frac{T_s^2}{2} \\ T_s \end{bmatrix} = \begin{bmatrix} 0.005 \\ 0.1 \end{bmatrix}
$$

**观测**（仅测位置）：

$$
\mathbf{H} = \begin{bmatrix} 1 & 0 \end{bmatrix}
$$

**噪声参数**：
- 过程噪声（加速度扰动）：$\mathbf{Q} = \begin{bmatrix} 0.01 & 0 \\ 0 & 0.01 \end{bmatrix}$
- 测量噪声（位置传感器）：$R = 0.5$

**初始条件**：$\hat{\mathbf{x}}_0 = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$，$\mathbf{P}_0 = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$

### 4.2 Python 实现

```python
import numpy as np

def kalman_filter_step(x_est, P_est, z, u, A, B, H, Q, R):
    """
    Single Kalman filter step (predict + update).
    
    Args:
        x_est: previous state estimate (n x 1)
        P_est: previous error covariance (n x n)
        z: measurement (m x 1)
        u: control input (p x 1)
        A, B, H, Q, R: system matrices
    
    Returns:
        x_est, P_est: updated state and covariance
    """
    # --- Predict ---
    x_pred = A @ x_est + B * u
    P_pred = A @ P_est @ A.T + Q
    
    # --- Update ---
    S = H @ P_pred @ H.T + R
    K = P_pred @ H.T @ np.linalg.inv(S)
    
    innovation = z - H @ x_pred
    x_est = x_pred + K * innovation
    P_est = (np.eye(len(x_est)) - K @ H) @ P_pred
    
    return x_est, P_est


# System parameters
Ts = 0.1
A = np.array([[1.0, Ts], [0.0, 1.0]])
B = np.array([[0.5 * Ts**2], [Ts]])
H = np.array([[1.0, 0.0]])
Q = np.array([[0.01, 0.0], [0.0, 0.01]])
R = 0.5

# Initial state
x_est = np.array([[0.0], [0.0]])
P_est = np.eye(2)

# Simulate a constant acceleration a = 1 m/s^2 with noise
np.random.seed(42)
true_pos = 0.0
true_vel = 0.0
a = 1.0

for k in range(20):
    # True state evolution
    true_vel += a * Ts
    true_pos += true_vel * Ts + 0.5 * a * Ts**2
    
    # Noisy measurement
    z = true_pos + np.random.normal(0, np.sqrt(R))
    
    # Kalman filter
    x_est, P_est = kalman_filter_step(x_est, P_est, z, a, A, B, H, Q, R)
    
    print(f"k={k:2d}: true_p={true_pos:.3f}, z={z:.3f}, "
          f"est_p={x_est[0,0]:.3f}, est_v={x_est[1,0]:.3f}, "
          f"P_pp={P_est[0,0]:.4f}")
```

运行后可以看到：
- 位置估计 $\hat{p}$ 快速收敛到真实值附近
- 速度估计 $\hat{v}$（传感器不直接测量！）被间接估计出来
- 协方差 $P_{pp}$ 随时间递减，反映估计不确定度降低

## 5. 从卡尔曼滤波到控制系统的状态反馈

卡尔曼滤波器与状态反馈控制器天然配对。完整的 LQG（Linear Quadratic Gaussian）控制结构如下：

```
         +----------+      +----------+      +----------+
r[k] --> |  LQR     |----->|  Plant   |----->|  Sensor  |----> z[k]
         | Controller|      |  x=Ax+Bu |      |  z=Hx+v  |
         +----------+      +----------+      +-----+----+
              ^                                    |
              |                                    v
              |                              +----------+
              +------------------------------|  Kalman  |
                 u = -K * x_est             |  Filter  |
                                            | x_est    |
                                            +----------+
```

**分离原理**：在 LQG 中，控制器增益 $\mathbf{K}$ 和卡尔曼增益可以**独立设计**。这是控制理论中一个极重要的结论——观测器设计与控制器设计解耦。

> **与 FOC 的关联**：在 [[14-FOC-电机控制/00-README|14-FOC-电机控制]] 中，无传感器控制的核心问题正是"如何从反电势观测转子位置和速度"。这本质上是一个**降维卡尔曼滤波/状态观测器问题**：电机电气方程（$\frac{di}{dt} = -\frac{R}{L}i + \frac{v}{L}$）提供了状态转移模型，电流传感器提供了测量，而转子位置/速度是需要估计的隐藏状态。FOC 中常用的滑模观测器、PLL 速度跟踪，都是卡尔曼滤波思想在实时约束（电流环 50–100 μs）下的工程简化。掌握本章的 KF/EKF 理论，是理解 FOC 无传感器控制算法的数学基础。

## 6. 扩展卡尔曼滤波器（EKF）简介

当系统为非线性时：

$$
\mathbf{x}_k = f(\mathbf{x}_{k-1}, \mathbf{u}_{k-1}) + \mathbf{w}_{k-1}
$$

$$
\mathbf{z}_k = h(\mathbf{x}_k) + \mathbf{v}_k
$$

EKF 的核心思想是**在每个时间步做一阶泰勒展开**，将非线性系统线性化：

$$
\mathbf{A}_k = \left.\frac{\partial f}{\partial \mathbf{x}}\right|_{\hat{\mathbf{x}}_{k-1}^+}, \quad
\mathbf{H}_k = \left.\frac{\partial h}{\partial \mathbf{x}}\right|_{\hat{\mathbf{x}}_{k}^-}
$$

然后用标准卡尔曼公式计算。EKF 广泛应用于：
- GPS/INS 组合导航
- SLAM（同时定位与建图）
- 电池 SOC（荷电状态）估计

## 7. 常见错误与纠正

### 错误 1：协方差矩阵 $\mathbf{P}$ 失去对称正定性

**现象**：长时间运行后，$\mathbf{P}$ 出现负特征值或明显不对称，导致滤波器发散。

**原因**：
1. 有限精度计算中，$(\mathbf{I} - \mathbf{KH})\mathbf{P}^-$ 的更新公式是**数值不稳定的**
2. 舍入误差累积破坏了 $\mathbf{P}$ 的对称性和正定性

**纠正方法**：使用**Joseph 稳定形式**更新协方差：

$$
\mathbf{P}_k^+ = (\mathbf{I} - \mathbf{K}_k\mathbf{H})\mathbf{P}_k^-(\mathbf{I} - \mathbf{K}_k\mathbf{H})^T + \mathbf{K}_k\mathbf{R}\mathbf{K}_k^T
$$

此形式始终保证 $\mathbf{P}$ 对称半正定，代价是大约 3 倍计算量。在关键应用中（如航天器导航），这是标准做法。

### 错误 2：$\mathbf{Q}$ 和 $\mathbf{R}$ 调参不当

**现象 A（$\mathbf{Q}$ 过大）**：估计值过度响应测量噪声，曲线抖动剧烈，模型预测几乎不起作用。

**现象 B（$\mathbf{R}$ 过大）**：估计值对测量变化反应迟钝，滞后明显，无法跟踪真实状态的快速变化。

**纠正方法**：
1. **基于物理的初始化**：$\mathbf{R}$ 可由传感器标定数据直接获得（测量噪声方差）；$\mathbf{Q}$ 反映模型与真实系统的失配程度
2. **自适应卡尔曼滤波**：在线估计 $\mathbf{Q}$ 和 $\mathbf{R}$（如 Sage-Husa 方法、变分贝叶斯方法）
3. **启发式调参法则**：
   - 先设 $\mathbf{Q}$ 为较小值，$\mathbf{R}$ 为传感器噪声方差
   - 若估计滞后 → 适当增大 $\mathbf{Q}$（更信测量）
   - 若估计抖动 → 适当增大 $\mathbf{R}$（更信模型）

## 8. 自测习题

### 习题 1
一个标量系统 $x_k = x_{k-1} + w_{k-1}$，$z_k = x_k + v_k$，其中 $Q = 1$，$R = 4$，$P_0 = 1$。
(1) 求稳态卡尔曼增益 $K_\infty$；
(2) 若 $Q$ 增大为 $9$（过程噪声更大），$K_\infty$ 如何变化？解释物理意义。

<details>
<summary>点击查看答案</summary>

(1) 标量 Riccati 方程稳态：$P = P - P^2/(P + R) + Q$，即 $P^2/(P+R) = Q$。

令 $Q = 1, R = 4$：$P^2 = (P+4) \Rightarrow P^2 - P - 4 = 0$

$P = \frac{1 + \sqrt{1+16}}{2} = \frac{1+\sqrt{17}}{2} \approx 2.56$

$K_\infty = \frac{P}{P+R} = \frac{2.56}{6.56} \approx 0.39$

(2) 当 $Q = 9$：$P^2 = 9(P+4) \Rightarrow P^2 - 9P - 36 = 0$

$P = \frac{9 + \sqrt{81+144}}{2} = \frac{9+15}{2} = 12$

$K_\infty = \frac{12}{12+4} = 0.75$

$K$ 增大意味着过程噪声变大时，模型预测不可靠，滤波器更信任传感器测量。

</details>

### 习题 2
证明：在标量情况下，若 $\mathbf{P}_0 = 0$（初始状态完全已知），则无论 $\mathbf{Q}$ 和 $\mathbf{R}$ 取何值，都有 $K_1 = 0$。

<details>
<summary>点击查看答案</summary>

$P_0 = 0$ 时：

$P_1^- = A^2 P_0 + Q = Q$

$K_1 = \frac{P_1^- H}{H^2 P_1^- + R} = \frac{Q \cdot 1}{Q + R}$

等等——若 $P_0 = 0$ 且 $A = 1$，则 $P_1^- = Q$。所以 $K_1 = Q/(Q+R)$，不一定为 0。

重新审题：若 $P_0 = 0$ **且** $Q = 0$（模型完全精确无噪声），则 $P_1^- = 0$，$K_1 = 0$。此时永远 $P_k^- = 0$，永远不需要测量更新。

这正是物理直觉：如果你完全确信模型是精确的，就不需要传感器了。

</details>

### 习题 3
一个二阶系统，状态 $\mathbf{x} = \begin{bmatrix} \theta \\ \dot{\theta} \end{bmatrix}$（角度和角速度），仅有角速度陀螺仪测量 $\dot{\theta}$（即 $\mathbf{H} = \begin{bmatrix} 0 & 1 \end{bmatrix}$）。问：卡尔曼滤波能否估计出角度 $\theta$？为什么？

<details>
<summary>点击查看答案</summary>

能。虽然传感器不直接测量 $\theta$，但系统模型中 $\theta$ 和 $\dot{\theta}$ 是耦合的：$\theta_{k+1} = \theta_k + T_s \dot{\theta}_k$。

通过角速度的测量和上述耦合关系，角度可以被**间接估计**出来。这称为**可观性（observability）**问题。

可观性矩阵：$\mathcal{O} = \begin{bmatrix} H \\ HA \end{bmatrix} = \begin{bmatrix} 0 & 1 \\ 0 & 1 \end{bmatrix}$，秩为 1 < 2，系统**不完全可观**。

等等——实际上 $HA = \begin{bmatrix} 0 & 1 \end{bmatrix} \begin{bmatrix} 1 & T_s \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} 0 & 1 \end{bmatrix}$，可观性矩阵秩仍为 1。

这意味着角度无法被唯一确定（只能确定角速度），角度估计将完全依赖于初始值，没有测量对其修正。卡尔曼滤波在此场景下**无法有效估计角度**。

这是 IMU 设计中必须同时使用加速度计（测角度）和陀螺仪（测角速度）的根本原因。

</details>
