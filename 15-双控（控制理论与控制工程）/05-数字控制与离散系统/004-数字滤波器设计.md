# 数字滤波器设计

> 在数字控制系统中，滤波器不仅用于抗混叠和降噪，还直接影响控制回路的相位裕度。本章系统讲解连续滤波器的离散化方法（双线性变换、脉冲响应不变法），对比IIR与FIR特性，并给出陷波滤波器（notch filter）的完整设计流程。

---

## 为什么数字控制系统需要数字滤波器？

数字滤波器在控制系统中扮演三重角色：

| 角色 | 目的 | 典型位置 |
|------|------|----------|
| **抗混叠预处理** | 阻止ADC采样前的高频噪声进入数字域 | 传感器 → ADC之前（模拟） |
| **测量降噪** | 平滑传感器数据，减少控制抖动 | ADC → 控制器之间（数字） |
| **补偿器实现** | 将设计的连续补偿器 $D(s)$ 变为可执行的 $D(z)$ | 控制器内部（数字） |

> **关键区分**：抗混叠滤波器**必须是模拟的**（在ADC之前），因为混叠一旦发生就不可逆。而测量降噪和补偿器实现可以用数字滤波器。

## 从连续到离散：三种经典变换

### 方法1：前向欧拉（Forward Euler）

$$ s = \frac{z - 1}{T_s} $$

**直观**：导数用当前差分近似 $\frac{dx}{dt} \approx \frac{x[k+1] - x[k]}{T_s}$。

**问题**：可能把S左半平面的稳定极点映射到Z平面单位圆**外部**。

**适用**：简单低通，但需谨慎验证稳定性。

### 方法2：后向欧拉（Backward Euler）

$$ s = \frac{z - 1}{z T_s} = \frac{1 - z^{-1}}{T_s} $$

**优点**：S左半平面始终映射到Z平面单位圆**内部**，稳定性保持。

**缺点**：频率畸变严重，高频增益被压缩。

### 方法3：双线性变换（Bilinear / Tustin）

$$ s = \frac{2}{T_s} \cdot \frac{z - 1}{z + 1} $$

**核心思想**：用梯形面积代替矩形面积来近似积分。

**频率映射关系**：

令 $z = e^{j\omega_d T_s}$，$s = j\omega_a$，代入得：

$$ j\omega_a = \frac{2}{T_s} \cdot \frac{e^{j\omega_d T_s} - 1}{e^{j\omega_d T_s} + 1} = \frac{2}{T_s} \cdot j \tan\left(\frac{\omega_d T_s}{2}\right) $$

$$ \omega_a = \frac{2}{T_s} \tan\left(\frac{\omega_d T_s}{2}\right) $$

**频率预扭曲（Pre-warping）**：若要求在某一特定频率 $\omega_c$ 处精确匹配，则修改变换为：

$$ s = \frac{\omega_c}{\tan(\omega_c T_s / 2)} \cdot \frac{z - 1}{z + 1} $$

这样 $\omega_a = \omega_c$ 精确对应 $\omega_d = \omega_c$。

| 特性 | 前向欧拉 | 后向欧拉 | 双线性变换 |
|------|----------|----------|------------|
| 稳定性保持 | ❌ 可能不稳定 | ✓ 稳定 | ✓ 稳定 |
| 频率响应保真 | 差 | 差 | 好（需预扭曲） |
| 直流增益保持 | ✓ | ✓ | ✓ |
| 实现复杂度 | 简单 | 简单 | 简单 |
| 推荐场景 | 避免使用 | 低要求场合 | **首选方法** |

## IIR与FIR：两种数字滤波器结构

### IIR（Infinite Impulse Response）

差分方程形式：

$$ y[k] = \sum_{i=0}^{M} b_i x[k-i] - \sum_{i=1}^{N} a_i y[k-i] $$

- **特点**：利用历史输出（反馈），脉冲响应无限长
- **优点**：同样阶数下，频率选择性强，计算量小
- **缺点**：可能不稳定，相位非线性
- **来源**：通常由连续滤波器（Butterworth、Chebyshev、Bessel）通过双线性变换离散化得到

### FIR（Finite Impulse Response）

差分方程形式：

$$ y[k] = \sum_{i=0}^{N} h_i x[k-i] $$

- **特点**：仅用历史输入（无反馈），脉冲响应有限长
- **优点**：绝对稳定，可设计为**线性相位**
- **缺点**：达到同样性能需要更高阶数（更多计算量）
- **来源**：窗函数法、频率采样法、Parks-McClellan最优设计

```text
    IIR结构 (Direct Form II)           FIR结构
    
    x[k]──►[+]──►[z^-1]──►[+]──►...──► y[k]      x[k]──►[h0]──►[+]
           ▲ -ai   │   bi ▲                           │
           │        │      │                        [z^-1]
           └──[z^-1]◄──────┘                           │
                                                      [h1]──►[+]
                                                         ...
```

## 数值示例：一阶低通滤波器的离散化

### 连续原型

一阶低通滤波器：

$$ H(s) = \frac{\omega_c}{s + \omega_c} $$

其中 $\omega_c = 2\pi \times 10 = 62.83\,\text{rad/s}$（截止频率 $10\,\text{Hz}$），$T_s = 0.001\,\text{s}$。

### 双线性变换（无预扭曲）

$$ s = \frac{2}{T_s} \cdot \frac{z-1}{z+1} = 2000 \cdot \frac{z-1}{z+1} $$

$$ H(z) = \frac{\omega_c}{2000 \frac{z-1}{z+1} + \omega_c} = \frac{\omega_c(z+1)}{2000(z-1) + \omega_c(z+1)} $$

$$ = \frac{62.83(z+1)}{(2000+62.83)z + (-2000+62.83)} = \frac{62.83(z+1)}{2062.83z - 1937.17} $$

化为 $z^{-1}$ 形式：

$$ H(z) = \frac{0.03046(1 + z^{-1})}{1 - 0.9391z^{-1}} $$

### 双线性变换（有预扭曲）

在 $\omega_c$ 处预扭曲：

$$ \omega_{pre} = \frac{2}{T_s} \tan\left(\frac{\omega_c T_s}{2}\right) = 2000 \tan(0.0314) = 62.86\,\text{rad/s} $$

由于 $T_s$ 很小，预扭曲前后差异极小。但在低频采样率下（如 $T_s = 0.01\,\text{s}$），差异显著。

### 脉冲响应不变法（对比）

连续脉冲响应：

$$ h(t) = \omega_c e^{-\omega_c t} $$

采样并Z变换：

$$ H(z) = \sum_{k=0}^{\infty} \omega_c e^{-\omega_c k T_s} z^{-k} = \frac{\omega_c}{1 - e^{-\omega_c T_s} z^{-1}} $$

$$ = \frac{62.83}{1 - 0.9391z^{-1}} $$

注意：脉冲响应不变法保持了脉冲响应形状，但直流增益可能不匹配（需要额外增益补偿）。

## 陷波滤波器（Notch Filter）设计

### 应用场景

电机控制、机械系统中，特定频率的共振（如 $50/60\,\text{Hz}$ 工频干扰、机械谐振频率）需要被精确抑制，而不影响其他频段。

### 连续陷波滤波器

$$ H_{notch}(s) = \frac{s^2 + \omega_0^2}{s^2 + 2\zeta\omega_0 s + \omega_0^2} $$

- $\omega_0$：陷波中心频率
- $\zeta$：阻尼系数（$\zeta \ll 1$ 时陷波尖锐）

在 $\omega = \omega_0$ 处，$H(j\omega_0) = 0$（完全抑制）。

### 离散化（带预扭曲的双线性变换）

设 $\omega_0 = 2\pi \times 50 = 314.16\,\text{rad/s}$，$\zeta = 0.05$，$T_s = 0.001\,\text{s}$。

预扭曲：

$$ c = \frac{2}{T_s} = 2000, \quad \omega_{pre} = c \tan\left(\frac{\omega_0 T_s}{2}\right) = 2000 \tan(0.157) = 318.3\,\text{rad/s} $$

双线性变换 $s = c \frac{z-1}{z+1}$，代入得：

$$ H(z) = \frac{c^2(z-1)^2 + \omega_{pre}^2(z+1)^2}{c^2(z-1)^2 + 2\zeta\omega_{pre} c(z^2-1) + \omega_{pre}^2(z+1)^2} $$

展开整理（用Python/MATLAB完成符号计算后），得到标准二阶IIR形式：

$$ H(z) = \frac{b_0 + b_1 z^{-1} + b_2 z^{-2}}{1 + a_1 z^{-1} + a_2 z^{-2}} $$

## MATLAB/Python实现

### MATLAB

```matlab
% Design a discrete notch filter
Ts = 0.001;              % 1 kHz sampling
f0 = 50;                 % notch at 50 Hz
zeta = 0.05;

% Continuous prototype
wn = 2*pi*f0;
H_s = tf([1 0 wn^2], [1 2*zeta*wn wn^2]);

% Discretize with pre-warped Tustin
H_z = c2d(H_s, Ts, 'prewarp', wn);

% Display coefficients
[num, den] = tfdata(H_z, 'v');
disp('Numerator:'), disp(num);
disp('Denominator:'), disp(den);

% Frequency response
bode(H_z);
```

### Python

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

# Sampling parameters
Ts = 0.001          # 1 kHz
fs = 1 / Ts
f0 = 50.0           # notch frequency [Hz]
zeta = 0.05

# Continuous notch filter: H(s) = (s^2 + w0^2) / (s^2 + 2*zeta*w0*s + w0^2)
w0 = 2 * np.pi * f0
num_s = [1, 0, w0**2]
den_s = [1, 2*zeta*w0, w0**2]

# Bilinear transform with pre-warping
w0_pre = (2/Ts) * np.tan(w0 * Ts / 2)
num_s_pre = [1, 0, w0_pre**2]
den_s_pre = [1, 2*zeta*w0_pre, w0_pre**2]

# Discretize
num_z, den_z = signal.bilinear(num_s_pre, den_s_pre, fs=fs)
print(f"Notch filter coefficients:")
print(f"  b = {num_z}")
print(f"  a = {den_z}")

# Frequency response
w, h = signal.freqz(num_z, den_z, worN=8192, fs=fs)

plt.figure(figsize=(10, 4))
plt.subplot(1, 2, 1)
plt.semilogx(w, 20*np.log10(np.abs(h)))
plt.axvline(x=f0, color='r', linestyle='--', label=f'f0={f0}Hz')
plt.xlabel('Frequency [Hz]')
plt.ylabel('Magnitude [dB]')
plt.title('Notch Filter Response')
plt.legend()
plt.grid(True)

plt.subplot(1, 2, 2)
plt.semilogx(w, np.angle(h, deg=True))
plt.axvline(x=f0, color='r', linestyle='--')
plt.xlabel('Frequency [Hz]')
plt.ylabel('Phase [deg]')
plt.title('Phase Response')
plt.grid(True)

plt.tight_layout()
plt.show()

# Test: apply to 50 Hz sine + 10 Hz sine
k = np.arange(0, 1000)
x = np.sin(2*np.pi*50*k*Ts) + 0.5*np.sin(2*np.pi*10*k*Ts)
y = signal.lfilter(num_z, den_z, x)

print(f"Input 50Hz component RMS: {np.sqrt(np.mean(x**2)):.3f}")
print(f"Output 50Hz component RMS after notch: {np.sqrt(np.mean(y[500:]**2)):.4f}")
```

## 常见错误与纠正

### 错误1：用数字陷波滤波器替代模拟抗混叠滤波

**错误表现**：工程师认为"反正要在数字域做陷波，ADC前就不需要模拟低通了"。结果高频噪声被混叠到基带，数字陷波对此无能为力。

**纠正**：抗混叠和数字滤波是**互补而非替代**关系。模拟抗混叠滤波器必须在ADC之前，其截止频率应低于 $f_s/2$。数字滤波器处理的是已经"安全采样"后的信号，用于精细的频率整形。

```text
    传感器 ──► [模拟抗混叠 LPF, fc < fs/2] ──► [ADC] ──► [数字滤波器] ──► 控制器
                                              ↑              ↑
                                          防止混叠       精细降噪/补偿
```

### 错误2：双线性变换后忽略频率畸变

**错误表现**：用双线性变换离散化一个 $100\,\text{Hz}$ 截止的低通滤波器，采样率 $1\,\text{kHz}$，发现实际截止频率变成了 $96\,\text{Hz}$。

**纠正**：双线性变换把无限频率范围压缩到有限奈奎斯特区间，必然产生**频率畸变**。当 $f_c$ 接近 $f_s/2$ 时，畸变严重。必须做预扭曲：

$$ f_{pre} = \frac{f_s}{\pi} \tan\left(\frac{\pi f_c}{f_s}\right) $$

用 $f_{pre}$ 代替 $f_c$ 设计连续原型，再离散化，可保证目标频率处精确匹配。

### 习题1

用双线性变换（无预扭曲）将 $H(s) = \frac{1}{s+1}$ 离散化，$T_s = 0.1\,\text{s}$。求 $H(z)$ 并验证直流增益。

<details>
<summary>点击查看答案</summary>

$$ s = \frac{2}{0.1} \cdot \frac{z-1}{z+1} = 20 \frac{z-1}{z+1} $$

$$ H(z) = \frac{1}{20\frac{z-1}{z+1} + 1} = \frac{z+1}{20(z-1) + (z+1)} = \frac{z+1}{21z - 19} $$

化为 $z^{-1}$ 形式：

$$ H(z) = \frac{1 + z^{-1}}{21 - 19z^{-1}} = \frac{0.0476(1 + z^{-1})}{1 - 0.9048z^{-1}} $$

直流增益验证：

$$ H(1) = \frac{2}{21-19} = 1 = H(s)\big|_{s=0} \quad \checkmark $$

### 习题2

设计一个抑制 $100\,\text{Hz}$ 机械共振的陷波滤波器，$\zeta = 0.02$，$T_s = 0.0005\,\text{s}$（$2\,\text{kHz}$ 采样）。用预扭曲双线性变换求离散系数 $b_0, b_1, b_2, a_1, a_2$。

<details>
<summary>点击查看答案</summary>

连续原型：

$$ H(s) = \frac{s^2 + \omega_0^2}{s^2 + 2\zeta\omega_0 s + \omega_0^2}, \quad \omega_0 = 2\pi \times 100 = 628.3\,\text{rad/s} $$

预扭曲：

$$ c = \frac{2}{T_s} = 4000, \quad \omega_{pre} = 4000 \tan(0.157) = 636.6\,\text{rad/s} $$

代入 $s = c\frac{z-1}{z+1}$ 并展开（用符号计算），整理为：

$$ H(z) = \frac{0.9844 - 1.8430z^{-1} + 0.9844z^{-2}}{1 - 1.8430z^{-1} + 0.9688z^{-2}} $$

即 $b_0=0.9844, b_1=-1.8430, b_2=0.9844, a_1=-1.8430, a_2=0.9688$。

（注：实际工程中使用MATLAB `c2d` 或 Python `scipy.signal.bilinear` 完成精确计算。）
</details>

### 习题3

解释为什么高阶IIR滤波器通常采用级联二阶节（SOS, Second-Order Sections）实现，而不是直接实现高阶差分方程。

<details>
<summary>点击查看答案</summary>

**原因**：

1. **数值稳定性**：高阶直接实现中，系数 $a_i$ 和 $b_i$ 对极点/零点位置极其敏感。微小的系数量化误差（如从float64降到float32）可能把极点推到单位圆外，导致不稳定。

2. **动态范围**：级联结构中每个二阶节的信号动态范围适中，避免中间结果溢出。

3. **模块化**：二阶节（Biquad）是标准结构，便于DSP硬件加速。

MATLAB示例：`[sos, g] = tf2sos(b, a)` 把高阶传递函数转换为级联二阶节。
</details>
