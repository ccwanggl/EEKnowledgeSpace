# 离散PID实现

> 从模拟 PID 的拉普拉斯表达式 $U(s) = K_p E(s) + K_i \frac{E(s)}{s} + K_d s E(s)$ 出发，推导位置式和增量式两种数字 PID 算法。这不是"把模拟 PID 随便近似一下"——而是**把连续复域 $s$ 中的补偿器 $C(s)$，通过 $z = e^{sT_s}$ 的近似映射，转换为离散域 $C(z)$，再实现为差分方程和 C 代码**。本章深入讨论积分饱和、微分冲击等工程陷阱，并提供可直接用于 STM32 的 C 代码实现。

---

## 模拟PID的回顾

模拟PID控制器的时域表达式：

$$ u(t) = K_p \, e(t) + K_i \int_0^t e(\tau)\,d\tau + K_d \frac{de(t)}{dt} $$

拉普拉斯域：

$$ U(s) = K_p \, E(s) + K_i \frac{E(s)}{s} + K_d \, s \, E(s) $$

三个通道的物理直觉：

- **P（比例）**：现在有多偏？
- **I（积分）**： historically 偏了多少？
- **D（微分）**：偏差变化有多快？

---

## 离散化方法：从积分和微分开始

### 积分项：矩形法近似

$$ \int_0^{t} e(\tau)\,d\tau \approx T_s \sum_{j=0}^{k} e[j] $$

这是**前向矩形法**。更精确的是**梯形法**（Tustin）：

$$ \int_0^{t} e(\tau)\,d\tau \approx T_s \sum_{j=0}^{k} \frac{e[j] + e[j-1]}{2} $$

### 微分项：后向差分

$$ \frac{de}{dt} \approx \frac{e[k] - e[k-1]}{T_s} $$

### 位置式PID公式

综合以上，**位置式（Positional）PID**：

$$ u[k] = K_p \, e[k] + K_i T_s \sum_{j=0}^{k} e[j] + K_d \frac{e[k] - e[k-1]}{T_s} $$

或写成三部分分离形式：

$$ u[k] = u_P[k] + u_I[k] + u_D[k] $$

其中：

$$ u_P[k] = K_p \, e[k] $$
$$ u_I[k] = u_I[k-1] + K_i T_s \, e[k] $$
$$ u_D[k] = K_d \frac{e[k] - e[k-1]}{T_s} $$

> **与变换链的联系**：位置式 PID 是 $C(s) = K_p + \frac{K_i}{s} + K_d s$ 的离散化结果。其中积分项 $1/s$ 通过矩形法近似为 $\frac{T_s}{1 - z^{-1}}$（即 $1/s$ 对应 $z/(z-1)$），微分项 $s$ 通过后向差分近似为 $\frac{1 - z^{-1}}{T_s}$。从统一框架看，这些近似是 $z = e^{sT_s}$ 的低阶展开：矩形法对应 $s \approx \frac{z-1}{T_s}$，Tustin 积分对应 $s \approx \frac{2}{T_s} \frac{z-1}{z+1}$。不同离散化方法 = 不同阶的 $z = e^{sT_s}$ 近似，其频率响应在 $z = e^{j\omega T_s}$（单位圆）上与原 $C(j\omega)$ 的吻合度不同。

## 增量式PID：更安全的工程选择

### 推导

位置式直接输出控制量的绝对值。若系统故障，$u[k]$ 可能跳变到任意值，对执行器有害。

**增量式（Incremental/Velocity）PID** 只输出**控制量的变化**：

$$ \Delta u[k] = u[k] - u[k-1] $$

展开：

$$ \Delta u[k] = K_p(e[k] - e[k-1]) + K_i T_s \, e[k] + K_d \frac{e[k] - 2e[k-1] + e[k-2]}{T_s} $$

最终输出：

$$ u[k] = u[k-1] + \Delta u[k] $$

### 两种形式对比

| 特性 | 位置式PID | 增量式PID |
|------|-----------|-----------|
| 输出物理意义 | 控制量绝对值 | 控制量增量 |
| 故障安全性 | 差（单点故障导致跳变） | 好（故障时增量为零） |
| 积分饱和 | 需要显式处理 | 天然抑制（无显式积分累积） |
| 手动/自动切换 | 需要无扰切换逻辑 | 天然无扰 |
| 计算量 | 稍小 | 稍大（需存3个历史误差） |
| 适用场景 | 直接驱动DAC | 驱动积分型执行器（步进电机、阀位积分） |

> **工程建议**：除非执行器本身就是积分性质（如步进电机、脉冲调宽），否则**优先使用位置式PID + 抗饱和逻辑**，因为它更直观、参数整定与模拟PID更一致。

## 积分饱和（Windup）与抗饱和策略

### 问题描述

当执行器达到物理极限（如电机100%占空比、阀门全开），控制量 $u$ 被钳位。此时若误差持续存在，积分项会继续累积（"饱和"），直到误差反向。当误差最终反向时，积分项需要很长时间才能"退饱和"，导致巨大的超调和恢复延迟。

```text
  y
  │      ┌──────────┐
  │     /│  超调!   │\
  │    / │←─积分饱和│ \
  │───┘  │  导致    │  └──► 设定值
  │      └──────────┘
  │
  └─────────────────────────► t
       ↑
    执行器饱和
```

### 抗饱和策略1：积分钳位（Clamping）

最简单的方法：当总输出达到限幅时，停止积分项更新。

```c
if (u_total > U_MAX || u_total < U_MIN) {
    // do NOT update integral term
} else {
    integral += Ki * Ts * error;
}
```

### 抗饱和策略2：反馈抗饱和（Back-Calculation）

更优雅的方法：计算实际输出与未受限输出之差，按比例反馈给积分项：

$$ u_{unsat}[k] = u_P[k] + u_I[k] + u_D[k] $$

$$ u_{sat}[k] = \text{sat}(u_{unsat}[k], U_{MIN}, U_{MAX}) $$

$$ u_I[k] = u_I[k-1] + K_i T_s \, e[k] + \frac{T_s}{T_t}(u_{sat}[k] - u_{unsat}[k]) $$

其中 $T_t$ 为**跟踪时间常数**，通常取 $T_t = \sqrt{T_i T_d}$ 或 $T_t = T_i/K_p$。

### 抗饱和策略3：条件积分（Conditional Integration）

仅在误差和控制量同号（即控制器在"努力"而非"抑制过冲"）时积分：

```c
if (error * (u_sat - u_eq) > 0) {
    // error and control action have same direction
    integral += Ki * Ts * error;
}
```

## 微分冲击与微分先行

### 问题：设定值突变引起的微分冲击

位置式PID中，微分项为：

$$ u_D[k] = K_d \frac{e[k] - e[k-1]}{T_s} = K_d \frac{(r[k] - y[k]) - (r[k-1] - y[k-1])}{T_s} $$

当设定值 $r$ 发生阶跃突变时，即使 $y$ 没变，误差 $e$ 的突变也会在微分项产生一个**巨大的尖峰**——这就是**微分冲击（Derivative Kick）**。

### 解决方案：对测量值微分（微分先行）

改写微分项，只对**测量值** $y$ 微分，不对 $r$ 微分：

$$ u_D[k] = -K_d \frac{y[k] - y[k-1]}{T_s} $$

这样设定值突变不会引起微分冲击。完整的**微分先行PID**：

$$ u[k] = K_p \, e[k] + K_i T_s \sum e[j] - K_d \frac{y[k] - y[k-1]}{T_s} $$

### 实际代码中的低通微分

纯微分对噪声极其敏感。工程中常对微分项加一个一阶低通滤波器：

$$ \tau_f \frac{du_D}{dt} + u_D = -K_d \frac{dy}{dt} $$

离散化后：

$$ u_D[k] = \frac{\tau_f}{\tau_f + T_s} u_D[k-1] - \frac{K_d}{\tau_f + T_s}(y[k] - y[k-1]) $$

其中 $\tau_f = \frac{T_s}{N}$，$N$ 通常取 $5\!\sim\!20$。

## 完整C代码实现（位置式 + 抗饱和 + 微分先行）

```c
/*
 * discrete_pid.c
 * Position-form PID with anti-windup and derivative-on-measurement
 * Sampling period: Ts [s]
 */

#include <stdint.h>
#include <stdbool.h>

typedef struct {
    // Gains
    float Kp;
    float Ki;
    float Kd;
    float Ts;           // sampling period [s]
    float tau_f;        // derivative filter time constant [s]

    // Limits
    float u_min;
    float u_max;

    // State
    float integral;
    float y_prev;       // previous measurement
    float u_d_prev;     // previous filtered derivative term
    bool  initialized;
} PID_Controller_t;

/*
 * Initialize PID controller
 */
void PID_Init(PID_Controller_t *pid,
              float Kp, float Ki, float Kd,
              float Ts, float N_filter,
              float u_min, float u_max)
{
    pid->Kp = Kp;
    pid->Ki = Ki;
    pid->Kd = Kd;
    pid->Ts = Ts;
    pid->tau_f = Ts / N_filter;   // derivative filter: tau = Ts/N
    pid->u_min = u_min;
    pid->u_max = u_max;

    pid->integral = 0.0f;
    pid->y_prev = 0.0f;
    pid->u_d_prev = 0.0f;
    pid->initialized = false;
}

/*
 * Update PID controller (call at every sampling instant)
 * r: setpoint
 * y: measured output
 * returns: control output u
 */
float PID_Update(PID_Controller_t *pid, float r, float y)
{
    if (!pid->initialized) {
        pid->y_prev = y;
        pid->initialized = true;
    }

    float e = r - y;

    // Proportional term
    float u_p = pid->Kp * e;

    // Integral term (accumulate before anti-windup)
    pid->integral += pid->Ki * pid->Ts * e;

    // Derivative-on-measurement with low-pass filter
    float dy = y - pid->y_prev;
    float alpha = pid->tau_f / (pid->tau_f + pid->Ts);
    float u_d = alpha * pid->u_d_prev - (pid->Kd / (pid->tau_f + pid->Ts)) * dy;

    // Compute unsaturated output
    float u_unsat = u_p + pid->integral + u_d;

    // Saturation
    float u_sat;
    if (u_unsat > pid->u_max) {
        u_sat = pid->u_max;
    } else if (u_unsat < pid->u_min) {
        u_sat = pid->u_min;
    } else {
        u_sat = u_unsat;
    }

    // Back-calculation anti-windup
    // If saturated, reduce integral by the excess amount
    if (u_unsat != u_sat) {
        pid->integral += (u_sat - u_unsat);
    }

    // Update states for next iteration
    pid->y_prev = y;
    pid->u_d_prev = u_d;

    return u_sat;
}

/*
 * Reset controller (e.g., on mode switch)
 */
void PID_Reset(PID_Controller_t *pid, float y_current)
{
    pid->integral = 0.0f;
    pid->y_prev = y_current;
    pid->u_d_prev = 0.0f;
}
```

## 数值示例：电机速度控制

某直流电机速度控制系统，模拟PID参数经整定为：

$$ K_p = 2.0, \quad K_i = 5.0, \quad K_d = 0.1, \quad T_s = 0.01\,\text{s} $$

设电机输出限幅为 $u \in [-10, +10]\,\text{V}$，初始速度 $y[0] = 0$，设定值阶跃到 $r = 5\,\text{rad/s}$。

**前3步的手算**：

| $k$ | $r[k]$ | $y[k]$ | $e[k]$ | $u_P$ | $u_I$ | $u_D$ | $u_{unsat}$ | $u_{sat}$ |
|-----|--------|--------|--------|-------|-------|-------|-------------|-----------|
| 0 | 5 | 0 | 5 | 10 | 0 | 0 | 10 | 10 |
| 1 | 5 | 0.5 | 4.5 | 9 | 0.25 | -10 | -0.75 | -0.75 |
| 2 | 5 | 1.2 | 3.8 | 7.6 | 0.44 | -7 | 1.04 | 1.04 |

> 注：第1步 $u_D$ 巨大是因为测量值从0跳到0.5，微分先行中的 $-K_d \cdot dy/T_s = -0.1 \times 0.5/0.01 = -5$... 实际代码中由于低通滤波，冲击会被抑制。手算展示了无滤波时的理论值。

> **FOC 关联**：在 [[14-FOC-电机控制/00-README|14-FOC-电机控制]] 中，$d$ 轴和 $q$ 轴电流环的 PI 控制器本质上就是**位置式 PID 去掉 D 项**（因为电流环通常不需要微分）。FOC 中的电流环 PI 参数 $K_p$ 和 $K_i$ 通常通过 $s$ 域设计（如极点配置）后离散化得到。本节中的抗饱和、微分先行等概念，在 FOC 速度环（有 PI 无 D）和位置环中完全适用。事实上，FOC 代码中的 `PI_Controller_Update()` 函数与本节给出的 C 代码结构几乎一致。

## 常见错误与纠正

### 错误1：直接对误差做差分而不使用微分先行

**错误表现**：代码写 `derivative = Kd * (error - error_prev) / Ts`。当操作员改变设定值时，电机发出巨大噪声甚至振荡。

**纠正**：始终使用**微分先行**（derivative on measurement）。微分的物理意义是"预测被控量的变化趋势"，而不是"预测设定值的变化趋势"。修改后的代码：

```c
// WRONG: derivative on error
du_d = Kd * (e - e_prev) / Ts;

// CORRECT: derivative on measurement + filtered
du_d = alpha * du_d_prev - (Kd / (tau_f + Ts)) * (y - y_prev);
```

### 错误2：积分饱和导致巨大超调后束手无策

**错误表现**：系统进入饱和后，恢复时间极长。工程师反复减小 $K_i$，导致稳态误差无法消除。

**纠正**：不要简单减小 $K_i$。正确的做法是实现**反馈抗饱和**或**积分钳位**。抗饱和逻辑可以让积分项在饱和期间停止增长，退出饱和后立即恢复正常调节，无需牺牲稳态性能。

```c
// Simple but effective: clamp integral term
if (integral > I_MAX) integral = I_MAX;
if (integral < I_MIN) integral = I_MIN;
```

即使最简单的积分钳位，也比重调参数有效得多。

> **从统一框架理解**：积分饱和是**离散化后的非线性效应**。在连续 PID $C(s) = K_p + K_i/s + K_d s$ 中，积分项 $K_i/s$ 的时域输出 $u_I(t)$ 可以无限增长。数字实现只是把同样的无限增长"拍成"了离散序列 $u_I[k]$。抗饱和不是在"修正离散化的缺陷"，而是在**数字实现中补偿执行器饱和这一物理非线性**。从变换链视角看，理想 PID $C(s)$ 假设输出无限大；工程实现中，DAC 的限幅把这个假设打破了，因此需要额外逻辑保持系统行为与 $C(s)$ 的线性设计一致。

> **FOC 关联**：FOC 中的 $q$ 轴电流环 PI 输出是电压参考 $V_q^*$，经 SVPWM 后变成逆变器占空比。当电机需要大扭矩时，$V_q^*$ 可能超出逆变器直流母线电压 $V_{DC}$ 可提供的范围——这就是**电压饱和**。如果不做抗饱和，积分项会持续累积，导致电流超调和恢复延迟。现代 FOC 代码（如 ST、TI 的电机库）都内置了积分钳位或反馈抗饱和逻辑。

## 自测习题

### 习题1

某温度控制系统使用位置式PID，$K_p = 5, K_i = 0.5, K_d = 0.1, T_s = 0.5\,\text{s}$。初始稳态时 $r = y = 20°\text{C}$，$u = 0$。在第 $k=0$ 时刻设定值阶跃到 $r = 25°\text{C}$，测量值尚未变化。计算 $u[0]$（假设无抗饱和）。

<details>
<summary>点击查看答案</summary>

$$ e[0] = 25 - 20 = 5 $$

$$ u_P[0] = 5 \times 5 = 25 $$

$$ u_I[0] = 0 + 0.5 \times 0.5 \times 5 = 1.25 $$

$$ u_D[0] = 0.1 \times \frac{5 - 0}{0.5} = 1.0 $$

（注意：若用微分先行，$u_D[0] = 0$，因为 $y$ 未变）

$$ u[0] = 25 + 1.25 + 1.0 = 27.25 $$

若执行器限幅为 $\pm 20$，则输出饱和。此时若无抗饱和，积分项会继续累积，导致后续超调。
</details>

### 习题2

推导增量式PID的完整公式，并说明它为什么对积分饱和天然免疫。

<details>
<summary>点击查看答案</summary>

增量式PID：

$$ \Delta u[k] = K_p(e[k]-e[k-1]) + K_i T_s e[k] + \frac{K_d}{T_s}(e[k]-2e[k-1]+e[k-2]) $$

$$ u[k] = u[k-1] + \Delta u[k] $$

**天然抗饱和原因**：增量式不显式存储积分累积项。输出限幅只影响当前 $u[k]$，不会导致历史累积。即使 $u[k]$ 被钳位，下一拍的 $\Delta u[k+1]$ 仍基于当前误差正常计算，不存在"积分债务"需要偿还。
</details>

### 习题3

在STM32中实现上述PID，控制周期 $1\,\text{ms}$。若 $K_p=1.0, K_i=100.0, K_d=0.001$，分析浮点运算下积分项的数值问题。

<details>
<summary>点击查看答案</summary>

积分项每步更新：

$$ \Delta u_I = K_i \cdot T_s \cdot e = 100 \times 0.001 \times e = 0.1 \cdot e $$

若误差 $e = 0.01$（1% 偏差），则 $\Delta u_I = 0.001$。单精度浮点（float32）尾数约7位有效数字，对绝对值较大的累积值（如 $u_I = 1000$），加上 $0.001$ 时会发生**精度丢失**（$1000 + 0.001 = 1000$ 在float中可能不变）。

**解决方案**：
1. 使用双精度（double）存储积分项
2. 或把 $K_i$ 和 $T_s$ 合并为 $K_i' = K_i T_s = 0.1$，减少乘法次数
3. 或使用定点数运算（Q15/Q31），避免浮点精度问题
</details>
