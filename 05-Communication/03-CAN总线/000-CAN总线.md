# CAN 总线

CAN（Controller Area Network）由 Bosch 在 1980 年代为汽车内部减少线束而设计，现在同时是车载网络和工业现场总线的标准。它把"多主仲裁 + 差分传输 + 链路层自动纠错重发"打包在一起，用较低的速率换来极高的可靠性，这个取舍正好匹配控制类数据的特点：帧短、频繁、对延迟有上界要求、环境电磁干扰强。

## 什么时候选 CAN

CAN 适合的场合有三个共同点：节点分布在几米到几十米、数据以短帧周期性传输为主、环境有较强电磁干扰。它的优势在于是链路层自带错误检测与自动重发，不需要应用层再补一套可靠性机制。

CAN 不适合的场合也很明确：需要传大块数据（固件镜像、图像）时，8 或 64 字节的帧长会让有效带宽被帧开销吃掉，应该改用 USB 或以太网；需要长距离高速时，CAN 的速率随距离快速下降；节点数量极多且需要 IP 语义时，应该用工业以太网。

- SAE J1939 系列标准——商用车应用层
- ISO 14229（UDS）——统一诊断服务
- 各收发器与控制器厂商的应用笔记（TI、NXP、Microchip）——物理层与隔离设计的实操细节
