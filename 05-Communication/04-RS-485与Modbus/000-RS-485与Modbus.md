# RS-485 与 Modbus

RS-485 定义了工业现场最常用的差分串行物理层，Modbus 则是跑在它上面最广泛的应用层协议。两者常被一起提及，但它们解决的是不同层次的问题：RS-485 保证"比特能在几十米到上千米的电缆上抗住干扰地传过去"，Modbus 定义"这些字节表示读哪个寄存器"。现场排查时必须先分清故障出在哪一层，否则会在协议解析上浪费大量时间。

## 什么时候用 RS-485 + Modbus

这套组合适合的场景有明确的共同特征：距离几十米到上千米、节点数在几个到几十个、数据量小且以周期性采集为主、现场有较强电磁干扰、需要对接第三方设备或组态软件。

它的优势是门槛低——一根双绞线、一个收发器、一个 UART 外设就能实现，调试工具便宜且通用性好。代价是速率低、实时性由主站轮询决定、没有链路层自动纠错，可靠性要靠应用层的 CRC 和超时重试来保证。

不适合的场景：需要传输大文件或图像（带宽不足）、需要毫秒级确定性闭环控制（轮询周期限制）、节点数量上百且拓扑复杂（应改用 CAN 或工业以太网）。
