# USB 协议

USB 是唯一同时承担供电、低速控制、批量数据和实时流传输的通用外部总线：同一根线缆上先完成电气连接与角色判定，再通过描述符把设备"自我介绍"给主机，最后由主机按固定时间节拍轮询各个端点。嵌入式工程师遇到的大多数问题并不在协议条文里，而在"枚举为什么失败""CDC 为什么丢数据""插到某些口上只认 500 mA"这类交界处——它们分别落在物理层、描述符层和供电协商层。

本目录按"物理与拓扑 → 描述符与传输 → 设备实现与调试 → 供电与 PD"四段组织，每篇都尽量给出可核对的电气参数、字段含义和排查顺序，并明确哪些数字必须回到具体器件的数据手册确认。

## 版本与速率速查

| 名称 | 标称速率 | 编码 | 常见实际吞吐 |
|---|---|---|---|
| Low Speed（USB 1.0/1.1） | 1.5 Mbps | NRZI + 位填充 | 约 0.1 MB/s，HID 低带宽外设 |
| Full Speed（USB 1.1/2.0） | 12 Mbps | NRZI + 位填充 | 约 1 MB/s 以内 |
| High Speed（USB 2.0） | 480 Mbps | NRZI + 位填充 | 批量约 35～40 MB/s |
| SuperSpeed（USB 3.2 Gen 1） | 5 Gbps | 8b/10b | 约 400 MB/s |
| SuperSpeed+（USB 3.2 Gen 2 / Gen 1×2） | 10 Gbps | 128b/132b / 8b/10b | 约 0.9～1 GB/s |
| USB 3.2 Gen 2×2 | 20 Gbps | 128b/132b 双通道 | 受主机与存储限制 |
| USB4 | 20/40 Gbps | 128b/132b | 40 Gbps 双向，可隧道 PCIe 与 DP |

速率与编码细节见 [[05-Communication/05-USB协议/001-USB版本与物理层|USB 版本与物理层]]，表格中的实际吞吐取决于主机控制器、驱动与设备端缓冲，只能作为量级参考。

## 传输类型与端点速查

| 传输类型 | 方向 | 高速包上限 | 带宽/延迟 | 重传 | 典型用途 |
|---|---|---|---|---|---|
| 控制 | 双向（端点 0 必用） | 64 B | 保证但开销大 | 有 | 枚举、类请求、命令 |
| 中断 | 主机轮询，IN/OUT | 1024 B | 保证上限与时延 | 有 | HID、CDC 通知 |
| 批量 | 主机调度，IN/OUT | 512 B | 不保证，空闲时占用 | 有 | MSC、CDC 数据 |
| 等时 | 主机调度，IN/OUT | 1024 B | 保证带宽，不保证正确 | 无 | UAC、UVC |

## 常用设备类速查

| 类 | 类代码（bInterfaceClass） | 典型设备 | 免驱程度 |
|---|---|---|---|
| HID | 0x03 | 键盘、鼠标、自定义小数据 | 高，Windows/Linux/macOS 自带 |
| CDC-ACM | 0x02 / 0x0A | 虚拟串口、调试口 | 中，Win10 起内置 usbser |
| MSC | 0x08 | U 盘、读卡器、固件交换盘 | 高 |
| UAC | 0x01 | 声卡、USB 麦克风 | 高（UAC1 更兼容） |
| UVC | 0x0E | 摄像头 | 高 |
| DFU | 0xFE / 0x01 | 固件升级 | 中，需 dfu-util 或厂商工具 |
| CDC-ECM / RNDIS | 0x02 / 0x06 | USB 网卡 | ECM 在 Linux/macOS 免驱，RNDIS 偏向 Windows |
| MTP / PTP | 0x06 / 0x01 | 手机、相机媒体传输 | 中，依赖系统组件 |

## 推荐资料

- Jan Axelson《USB Complete》——从协议到设备类与主机编程，覆盖 USB 2.0 与 3.x。
- Beyond Logic《USB in a Nutshell》——免费在线，描述符与枚举讲得最清楚，见 [[12-Resources/02-博客与网站推荐/001-综合教程与学习\|综合教程与学习]]。
- Microchip University 的 USB 系列课程与 USB Made Simple 教程，见 [[12-Resources/03-在线课程与教程/003-厂商认证与培训\|厂商认证与培训]]。
- USB-IF 官方规范：USB 2.0、USB 3.2、USB4、USB Type-C、USB PD；USB-IF 的 Class Codes 文档是查 `bInterfaceClass` 取值的第一手来源。
- 开源实现 TinyUSB（GitHub `hathach/tinyusb`）与 Zephyr USB 子系统，读代码比读规范更快建立直觉。

设备实现与抓包调试见 [[05-Communication/05-USB协议/004-嵌入式USB实现与调试|嵌入式 USB 实现与调试]]；供电协商与 PD 见 [[05-Communication/05-USB协议/005-USB供电与USB-PD|USB 供电与 USB-PD]]。
