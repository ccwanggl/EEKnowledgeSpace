# 通信协议概述

嵌入式系统很少独立工作。传感器、执行器、上位机、云端和其他 MCU 之间的每一次数据交换，都由"物理层电气约定 + 链路层帧规则 + 上层数据含义"这三件事共同决定。把它们统称为"协议"容易掩盖一个事实：同一根线上可以跑很多种协议，同一个协议也可以跑在不同的物理层上（Modbus 可以跑 RS-485、RS-232 或 TCP；TCP/IP 可以跑以太网、WiFi 或 4G）。

这一层目录不深挖单个协议的寄存器与驱动，而是建立一套可以复用的判断框架：先看清协议在哪个层次解决什么问题，再按距离、速率、拓扑、可靠性、功耗和成本缩小候选范围，最后才去查具体器件的数据手册。
